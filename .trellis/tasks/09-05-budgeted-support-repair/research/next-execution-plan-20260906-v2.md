## 2. 共同基础与五个工作块

主问题仍是“统一预算下，可实现局部修复/可靠性反馈是否改善coded FER”；辅助问题是改善来自哪个接口。最多两个主张、三个基线家族。以下B1—B5是本版工作块，不改写父设计原B1—B5的历史编号；对应父S0—S8明确列出。

共同基础沿用v1：生成器保持原分数Doppler截断模型，P_phys=8；接收器直接选择最终整数字典原子，K_active≤40、接收器扩展0，生成器k_leak=2。A0是真正无F2P的OMP路径；A2为同容量F2P。A0不能用“先算F2P再override”的keep诊断假冒，不能计算未使用的Hhat0/scorer。A2两处OMP cap及nomination40 prior域须一致；新prior400 iid-QPSK帧，不截断真标签。

新模式关闭的历史回放、同输入hash、真值隔离、每轮容量、唯一列/增益对应、单位和合法失败检查仍须通过。良态复数求解残差上限complex128=1e-10、complex64=1e-4；工程失败先修复，不用FER调参掩盖。先契约测试，再适用静态检查/编译，再真实GPU smoke。未修改生成器，不能通过把信道改成无泄漏来恢复基线。

### B1：表示、增益与位置（S0/S2；新壳实现属S3/S4）

**B1-a 支撑账本，必须随既有运行记录，不另扫容量。**

| 量 | 定义/验收 |
|---|---|
| P_phys | 仿真物理路径槽位；只用于模拟和离线评估，部署不能读本帧真值 |
| K_emit | 各物理路径截断/边界裁剪/功率裁剪后，合并前的泄漏条目数；对应旧P_actual的实际来源 |
| K_true与显著分量 | 相同(delay,k)的复系数先合并；列数、系数幅值与阈值分别保存；相消不能仍按两条有效原子计数 |
| K_prop/K_active | OMP提名、每轮raw/candidate/selected/protected/pruned/final列；最终≤40，临时union另记上限 |
| BP图E/度数 | 从实际送入各次BP的H及实际阈值计算边数、平均/最大行列度、阈值舍弃误差；含末次BP，不能由K_active推算 |

不再用裸P或P_eff同时表示显著泄漏数与图宽。显著原子统计需固定阈值；系数平方加权召回是字典系数指标，未验证正交性前不叫物理信道能量比例。路径匹配一对一，容差按字典分辨率预先冻结；碰撞/不可辨识槽单列。

每阶段报告候选计数召回、合并系数加权召回及

\[E_{repr}(S)=\min_g\|H_{true}-\sum_{i\in S}g_iG_i\|_F^2/\|H_{true}\|_F^2.\]

同时检查生成器真实合并字典表示能否重构H及其实际列数；不能因P=8就断言任意接收器8列足够。把失败定位为“未入池/入池未选/选后剪掉/表示可用但增益差/检测图丢失”，这些是分类线索，因果判断仍看干预。

**B1-b 固定支撑增益桥接：必需有运行或明确不足裁决。** 在选定新壳已使用的192个fit帧，仅追加固定最终支撑的H_true最小Frobenius投影参考。只在登记的增益/H输入处干预，不改支撑/观测/末端判决；其信息和额外成本标oracle。

验收：支撑/输入/下游规则一致；独立密集LS验证投影；报告E_repr、实际估计误差、三流paired win/harm/FER。投影可救回→表示内估计有空间；投影仍差且E_repr大→表示不足线索；E_repr小而FER仍差→不能归咎候选，需保留检测/译码解释。它不是最优FER上界。

**B1-c 位置三臂：补齐“参考”与“精修”的区别。** 预登记开发24帧，每流前8帧；共同已知量化delay、P=8及rounded初始Doppler槽位，比较rounded固定、由y优化局部Doppler、真位置参考。三臂都用同一截断簇生成/归一化/裁剪规则、pilot-LS/SVD及同一后续接收，共72次接收评估。

首个局部控制固定：每路径仅在初始中心±0.5bin及合法边界内，两轮坐标搜索，步长0.25/0.125bin；每坐标比较±步及当前值，每候选重拟合增益，按共同pilot残差接受。最多初始1+2×8×2=33次目标拟合/帧；不搜索步长。共同rounded槽是已知参考信息，优化不得再读真实小数偏移来选步、停止或调参。秩/裁剪切换及失败全记，未收敛不能冒称收敛；良态无碰撞小例须先证明实现确实在优化位置。

验收与裁决：局部臂比rounded改善且跨流有一致线索→位置路线值得研究；只有真位置有效→存在参考空间但当前优化未实现；残差下降而FER不降→只支持局部拟合；少错/混合→INCONCLUSIVE。报告完整样本和事先定义的可辨识情形，不能删秩亏帧得到正结论。

这一诊断可回答“已知路径槽下是否有位置空间”，**不能代签完整非oracle离网接收机**。如要升级部署，另需从direct40输出估计路径分组、数量、时延的接口及验证；完整连续Doppler/分数时延模型也未覆盖。二者列为明确范围缺口，只有位置线索及预算支持时选择最多一条增强，不默认开发。

### B3：统计一致性与允许keep（S3；不得挂在V GO后）

**B3-a 先验收模型契约，可在CPU上独立推进。** 冻结一次事务的y、Phi、正定C、初始S与容量/保护政策。令C=LL^H、W=L^-1、A=W Phi、z=Wy、P_S=A_S A_S^dagger：

\[r_w=(I-P_S)z,\quad v_i=(I-P_S)W\phi_i,\quad D_i=|v_i^Hr_w|^2/(v_i^Hv_i).\]
\[J(S)=\min_g\|W(y-\Phi_Sg)\|^2,\qquad J(S)-J(S+i)=D_i.\]

这是白化空间中经典OLS一步投影几何的应用；不作为新理论或条件CFAR保证。[原作者论文§II-B/II-C](https://arxiv.org/html/1111.0522v2)

验收：良态小型复数系统中，对独立SVD-LS逐个重拟合得到的下降，complex128相对误差≤1e-8/归一化近零绝对≤1e-10，complex64分别≤1e-3/1e-5；归一化能量固定为max(1,||Wy||²)。还需空支撑、白C、复数缩放、近共线/重复候选、非法C、以及“白C仍因候选未投影而排反”的反例。不能用被测公式自身作唯一参考。

当前普通LS残差、原列白化分母、含prior的logLambda分别记录；完整logLambda不等于D。第一机制对照固定相同pi、sh2与装配函数，仅改变原T/q与新D/q_perp；prior值在共同状态冻结，不同时重训prior。另有无prior、直接按D排序的经典OLS控制，不能把整套配方变化归因于投影一项。

**B3-b 最终动作契约。** 定义F(S)=J(S)+lambda|S|。提案必须经过实际保护、剪枝、扩展/去重、容量检查、最终GLS refit，才比较F(S)-F(S')。**评估F时的GLS最优增益必须是实际提交的增益**；不能用GLS算通过、却提交普通LS或扩展邻居零增益。keep完整恢复事务前按共同规则拟合的状态，不残留临时估计。

首版lambda=0、tau=0，不搜索双门限；数值余量另记，delta必须>tau+eta×max(1,|F前|,|F后|,||Wy||²)才提交，eta为complex128的1e-10/complex64的1e-5。临界、秩不确定、预算耗尽分别记录。保留更多噪声原子也可能降低F，故这不是防假新增或无害保证；满容量同基数交换中lambda抵消，不声称完成lambda识别。

按白化后单位范数列检验秩，eta_rank=10×max(N,K+1)×eps(dtype)；候选/最终系统不可靠则拒绝并报告，当前模型无效则工程HOLD，不静默删列或加jitter。良态容差不是任意病态系统的正确性证明。

必过反例：K=1、y=e1+epsilon e2、0<epsilon<1，新增e2暂时有益，但保护e2剪掉e1后目标变坏，必须拒绝。keep、drop/replace、空池、同分、重复列、裁剪及数值失败均有不同日志原因。只预算一个完整事务提案时，拒绝可停止，但原因只能是提案预算耗尽，不能宣称余下候选都无效。

**B3-c 首个机制包，48个预登记开发帧。**

| 臂 | 评分 | 接受 |
|---|---|---|
| R00 | 原残差/原白化充分统计 | 原top-k，无F否决 |
| R01 | 同R00 | 完整F门控，可keep |
| R10 | 一致投影充分统计 | 原top-k，无F否决 |
| R11 | 同R10 | 完整F门控，可keep |

四臂共有最终GLS refit及保护规则；R00不是历史A2，另保留未改同容量A2与真实A0。用共同参考状态冻结候选表；首包每帧一个完整事务、沿现有F2P至多两轮形成提案，candidate/active冲突只过滤不补新列，记录有效数量。机制解释只对共同状态/共同表成立；后续闭环池变化不冒称逐轮完全相同。

再加R11的protect=0单改动，才回答取消保护；经典无prior OLS控制最多一臂，与已有等价臂合并。最多8个受控臂（含A0/A2），另至多48次共同keep完整反事实，共≤432次接收评估。控制回放必须包含完整末次BP/LLR/LDPC；反事实成本属于诊断。

### B4：可靠性反馈及其使用入口（S4；独立于B3）

|---|---|---|
| F_mean | 原均值DA-LS，T1 | 同壳基准 |
| F_uniform | 每轮当前H构造H diag(v0) H^H+sigma²I；v0为均匀星座的已缩放方差 | 当前H下，先验数据功率的GLS入口 |
| F_dynamic | 同一构造，v0改为当前工作概率的v，T1 | 可靠性方差政策的总闭环效应 |
| O_data | 仅DA-LS均值使用真实缩放数据，其他按原oracle接口 | 该入口的信息参考；非部署、非数学最优上界 |

这里选择F_uniform而非把H0也冻结的F_prior，以减少同时改变H来源和v的混杂。自然闭环H/sigma仍会分化，因此矩输入归因结合共同轨迹，不把两条自然轨迹的相关性当局部因果证明。不扫温度，不复活已负面的J_soft，也不同时上评分×V组合。

每轮按v/(1-rho)固定分箱实际|x-mu|²，报NLL/Brier、max(p)≥0.9且符号错误的频率、该组v/实际误差和后续FER；阈值0.9只作预登记解释，不能事后调优。p、mu、v来自同一概率；当前v已含数据功率，C不再重复乘(1-rho)。记录dals反馈与noise反馈各自温度/单位。病例按固定ID取每类至多3例，不另造统计分母。

F_dynamic与F_uniform相当→不能主张逐轮可靠性必要；只有O_data有效→可实现性缺口；可靠性更好但FER无益→只支持校准层结果。每个臂独立GO/HOLD/NO-GO，不关闭B3或表示研究。

**译码反馈边界必须结案为明确范围声明**：现LDPC只末端译码，本任务的首轮动态反馈来自检测器。不能借图片措辞宣称已有turbo译码迭代。若结论确需“译码外信息带来的可靠性”，需新增SISO外信息接口、去除重复先验/自反馈、固定译码调用预算与一个单入口对照；它是最多一条条件增强的候选，与完整非oracle离网竞争资源。当前记“尚未实现/未验证”，不得以O_data代签。

### B5：路线选择、独立验证、同预算确认（S5—S8）

**改变v1全局门：任一可实现路线通过自己的开发门，才准备其确认；不再要求必须V GO。** 候选/表示诊断和理论契约即使没有可部署胜者也必须留下裁决，不能因主路线停止而静默漏掉。

- 先在fit选择A0/A2参考，按FER优先；开发并列选较简单A0，正式ref仍按同预算FER/P95选择。工作点由基线确定，8dB保留锚点；不在[0.05,0.20]时用父规定的基线专属SNR校准，不能按新方法收益换点。
- B1—B4用于开发和分支选择。基于全部开发证据、完整成本预检，最多选两个可实现候选进入192帧fit；按FER→预先登记复杂度/候选ID破同分，只冻结一个进入384帧新validation。选择全部在validation打开之前完成。
- 上述证据指候选自身所需且已登记的证据，不要求等待无关慢任务：例如V验证不依赖全池排序枚举完成。若先冻结并验证V，其余路线可继续独立开发，但不得利用这份validation改变候选或复用它选赢家；后续候选另登记新验证流。覆盖报告仍逐项保留未完成问题，不能提前声称全部回答。
- validation跑两个基线及唯一候选，共3×384=1152次。若另一基线比暂定ref合并更好且至少两流更好，参考选择不稳，记HOLD；不事后换搭档复用这份验证。
- 开发GO仍是合并RR≤0.90、至少两流净改善、其余不净退化，且工程/参考资格通过；总体变差且至少两流变差为NO-GO，其余HOLD。低错误或参考工作点失去判别力为HOLD。该门只控制投入，不是G1/G3。
- validation未GO不在同一数据上调参或追加至翻正。另一条未选候选要继续验证，先登记新的独立分割；不能轮流在同一validation挑赢家。
- A/B/C最多三族强基线、邻近方法复现范围、实际分析器覆盖/功效、完整预算均在Dtest前冻结。旧geom差异有自己的复现边界，不阻塞其他可做工作，但不能冒称基线已复现。

**正式标准不降**：G1为FER比双侧95%区间上端<0.90；G2为旧A2锚点均值/P95×1.10的共同上限，区间上端均达标、显存≤22GiB；G3为所有必需护栏FER绝对损害的同时95%上界<0.01。每臂≥1000计时帧、另≥10预热、≥10交错块，CPU/GPU完整链路同步计时，GPU独占。功效按父计划：实际分析器覆盖验证、每n≥5000MC、R=.80情景功效95%下界≥90%，同时满足护栏样本需求；Dtest固定样本、不窥视追加。

## 5. 最终逐项验收

每个J1—J5、D1—D6交付一行：`当前结论 / 证据scope / 配置与输入hash / 结果及区间 / 成本 / 停止原因 / 未覆盖边界`。允许状态为：`SUPPORTED_WITHIN_SCOPE`、`NEGATIVE_WITHIN_SCOPE`、`INCONCLUSIVE`、`ENGINEERING_BLOCKED`；仅列“计划存在”不算科学验收。

尤其不得代签：旧壳→新壳；单动作→全组合；GLS最小目标→实际OLS提交；低NLL→低FER；oracle→可部署；相同迭代数→相同预算；真位置→观测驱动精修；检测软反馈→译码外信息；截断模型→完整连续模型。
