# 候选池、支撑语义与位置参考覆盖核查

2026-09-06，只读本地代码/计划审查；没有运行接收机、SSH或新实验。范围为I1/I2/I3/I5与direct40下一轮计划，不替代其他接口审查。

## 结论

旧证据足以选择先检查增益/反馈，但不足以宣布候选遗漏、池内排序或离网已经排除。direct40的≤40直接原子、nomination40先验及扩展0改变了候选与实际表示；旧骨架的瓶颈裁决必须标成历史线索。现计划P1已覆盖基本容量/真值隔离，P2记录图宽和NMSE；缺的是从候选→动作→最终H→BP图的可归因账本，以及V失败时避免把新骨架表示不足误判成反馈普遍无效的桥接分支。

## 1. 旧干预真正回答的内容

| 干预 | 已有证据 | 不能推出 |
|---|---|---|
| I1 | 固定实际整数支撑，对H_true作Frobenius投影；8dB 28/192→2/192；代码在外环替换H | 不是真物理增益，不是可实现估计器，也不是最优FER上界。几乎可救回旧支撑，不保证direct40也足够 |
| I2 | 固定原scorer，池96→192；首轮raw支撑∪池的真整数列召回.78598→.87068，8dB仍28/192 | 不能排除候选瓶颈。新增列可能弱、被错误排序、剪掉、拟合失真或对已有错误无帮助；总FER相等也不等于逐帧无变化 |
| I3 | 24预选帧，固定首轮96池；keep+96个单列动作，原保护/剪枝/refit/扩展及完整下游；current/best均1/24，keep2/24 | 仅在该单轮单加动作族，未见聚合FER排序空间；不覆盖双轮多加、组合交换、池外列、新prior、direct40。24帧少错不足排除小收益；不能拿该局部best和双轮A2之差命名排序遗憾 |
| I5 | 24帧，已知量化时延和8物理槽，真k_real基vs rounded基，pilot-LS后固定H；0/24 vs16/24 | 没有用y估位置，没有局部优化，不是连续参数精修。真/rounded同时改变簇权、有效整数列、秩与可表达H；真位置秩亏4帧，rounded8帧；不覆盖分数时延或完整连续Doppler信道 |

I2的计数召回分母是`truth_unique_columns`，并未按合并后的复系数能量加权。真实展开条目可能碰撞并相消，弱泄漏列与强列一票等权。I3的oracle-best依据信息位错误、raw错误等选择，属于离线多次尝试参考。I5中rounded整数位置的簇侧分量随核改变，故“都P=8”没有控制相同字典自由度或有效秩。

## 2. 五种支撑量应在P1/P2输出中分别闭合

| 对象 | 必须记录/验证 |
|---|---|
| 物理槽位 | P_phys、真量化delay/k_real、路径碰撞；只离线评估，不输入在线策略 |
| 生成器泄漏条目 | 每路径展开、边界裁剪/功率裁剪、合并前条目数；模拟器k_leak=2不随接收器扩展0改变 |
| 唯一字典原子 | 合并相同(delay,k)后的复系数、列ID；计数召回与聚合能量覆盖分开报，相消后零能量不凭路径条目数充当有效维数 |
| 接收支撑 | raw、每轮候选有序ID、入选/删除/保护、临时union、最终unique列、最终增益；direct40扩展0且最终≤40，并记固定支撑投影残差以测表示损失 |
| BP图 | 对最终复数叠加H按实际BP阈值取边：E、平均/最大行列度、阈值及阈值前后H能量差；图宽不等于K_active，多个原子可同偏移且相消 |

已有`P_eff`文字尚不是上述可验证定义。Torch BP实际以`abs(H)>=threshold`建边；需要覆盖外环Torch BP及末次NumPy BP真实调用的阈值，不能只从原子数推断图成本。此项优先复用P2既有评估，新增字段和静态/小数值契约即可，不增加FER网格。

候选账本至少同时报：首轮S∪池覆盖、最终支撑覆盖、能量覆盖、固定最终支撑的最佳H投影NMSE、动作前后保留/损失的真值能量（均离线评估）。这能区分“未入池”“入池未选”“选后剪掉”“表示足够而估计差”。不能单凭相关性作因果归因。

## 3. 最小追加与停止边界

### 第一小包直接补入的规划内容

1. P1/P2补上述字段、唯一合并与图阈值契约；P3继续原冻结V(T1)验证，不重选温度、不展开离网。
2. P0预登记一个**条件性**新骨架桥接包：仅当P2工作点HOLD，或P3为HOLD/NO-GO且拟解释瓶颈时启用。必须先登记额外臂帧/费用并纳入已有预算；不自动挤掉384帧验证。
3. 最便宜桥接：选定direct40参考，在已使用192个fit帧上补一臂I1固定最终支撑最佳H投影（192接收评估）。同y、最终列、初始状态、检测器/噪声规则及下游随机流，只替换增益；报告三流paired win/harm及区间。这只诊断：I1救回说明表示内有空间；I1也差且投影损失高说明表示不足线索；I1也差但投影损失低仍可能是检测/译码瓶颈，不能径直归候选。
4. 若不给这192次额度，直接保留“direct40表示/增益瓶颈未桥接”，V的NO-GO只终止当前V候选；不得把六项旧诊断当新骨架全部验收。无需为完成本小包强制补跑完整I2/I3/I5。

### 仅当证据指向候选缺失时的有限定位包

不盲扫M。使用预选24个已用开发帧（每流8帧，不按坏帧选），冻结raw支撑、池、scorer和单列完整动作语义。每帧对比keep、当前池内argmax单动作、一个池外真值辅助列单动作，共至多72次完整接收；池外列事先按合并真系数能量最大且ID破同分确定，无合格列记keep且保留分母。共享相同cap、删列规则、保护和重拟合；真值只供离线提名，成本不进入部署主表。

该包只问“一个有代表性的遗漏列能否经当前完整动作帮助”，不是池外oracle最优，也不排除组合效应。只有出现跨流有益线索才提候选支线；阴性保留未知。要独立证明排序瓶颈仍须同一固定池中回放同一完整动作族的候选比较；不以单个真值列替代I3，不默认重跑24×97。

### I5保留为未闭合，不加入本轮必跑臂

若以后选择离网支线，最小可实现控制须含：相同初始量化delay、P槽位、边界/裁剪/增益求解和预算下，rounded基→由y驱动的局部Doppler精修→真位置参考。位置误差用同一可辨识匹配，记录有效秩与列集、拟合目标、NMSE、完整FER、成本；碰撞槽位不比较不可辨识逐路径参数。另在良态无碰撞小例隔离位置优化，与当前秩亏/截断案例分开。完整连续模型/分数时延是另一个模型验证，不通过当前I5代签。

## 父会话追加要求后的独立路线首包

父会话要求候选/位置路线独立于V GO；因此上述“条件性/以后”是初版资源建议，最终计划应对每项指定必做证据或显式INCONCLUSIVE，不能静默省略。以下是可直接纳入统一首包的限额选项。

- **候选四臂，24帧×4=96次**：冻结direct40的raw和原M96。选池外合并真系数能量最大的缺失列j*，以原池最低scorer列替换，始终保持96个唯一候选，只一出一入。四臂为keep、原池argmax单动作、新池同scorer argmax单动作、强制j*单动作；均执行同一单轮单加/保护/删除/refit/cap40/完整BP译码。无缺失列记不适用并保留分母。新池scorer不得再次提名或改外生输入。强制j*优而新池策略不优说明选择/后续利用仍可能阻塞；新池策略也优支持候选覆盖路线线索；二者都不优不足排除遗漏或组合效应。池内完整排序遗憾仍为INCONCLUSIVE，不把四臂称全池oracle枚举。
- **位置三臂，24帧×3=72次**：已知量化delay、P8，rounded固定/观测y驱动的局部Doppler优化/真位置参考；部分oracle接口用于隔离位置，不是完整部署臂。局部臂从rounded起步，在初始中心±0.5bin及合法物理边界内，用固定次数的有界优化和重拟合pilot-LS残差目标，固定求解上限及接受规则；真位置不能参与初始化、步长选择或停止。裁剪/秩变化和失败显式登记。局部跨流收益→位置线索；仅真位置有效→可达空间未被方法实现；残差降FER不降→整机不支持；少错/不确定→INCONCLUSIVE。
- 若要把局部位置精修升级为**direct40非oracle接收路线**，还缺“由direct40自由原子得到路径分组、时延和槽数”的可实现初始化接口。当前I5不能代签；最小首包可先登记此项INCONCLUSIVE，同时给明确后续依赖。完全连续Doppler/分数时延生成器仍不覆盖。
- 加入I1的192帧增益桥接时，上述诊断上限共360次完整接收评估，另含局部位置内层求解；原拟1728次小包必须更新成本而非隐含扩容。每个新24帧集合应预先冻结并共享，复用开发数据只作诊断，不进入独立确认。
