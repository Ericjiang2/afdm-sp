# v3 简单基线实现与工程验收

三个初始估计器仅接收y、Phi、容量40和已有sigma2，不接收H真值、P、真位置或数据标签。公共OMP只运行一次；可选路径观察器不改变默认算术。规模控制在同路径k=0..40按冻结J选取；ridge固定S40与原度量；SBL固定共同sigma2、最多20次EM，最后按最后后验二阶矩gamma剪枝，返回该后验均值，无LS去偏。SBL初始化floor为machine epsilon乘(y均方/字典列平均能量)，只用于初始化，不逐轮clip。

新增initial_estimator接口要求关闭F2P，禁止同时使用oracle支持或support override。后续10outer、20BP、50LDPC不改变。终端H/y/pilot/sigma快照供后续固定H的sigma干预；每次BP图边单独记录，避免用40原子代替实际图费用。初始误差离线按复数合并真字典计算，保留遗漏/增益/伪分量/域外残差的全部六项交叉项。

失败复现：合法空支持使BP零边分支只返回单个硬输出，而soft调用要求三元组，导致解包错误。修复零边soft接口返回星座先验均值/方差；有边默认数值路径未动，hard-only原返回保留。

验证：远端小维回归19项通过，扩展接口/已有GLS/反馈27项通过；另6项基线单元通过，含独立正交标量Gaussian后验计算与SBL输出逐项吻合。OMP观察器输出与原函数相同；ridge与解析解相同；空支持完整小型链路可运行。预算队列测试通过，独立V3余额约束不借用旧S2。

实际完整链路试跑2帧计入既定额度：B0 rep30/frame0输入hash、最终H hash、sigma2和信息错误数与旧fit192原件完全相同；B0耗时1.1606秒，size c0.5耗时1.1852秒，两槽GPU峰值1291MiB。费用仅试跑，不据单帧替代开发中位数或正式G2。剩余1918完整评估已登记独立不可变快照、两槽、2400秒硬截止，后续逐帧审计决定BASE-04。

主会话完成实现与检查，独立性有限。工程通过不代表强基线科学效果通过；数值病态/失败及成本门需要实际开发结果审计，不用单帧推断全体有效。
