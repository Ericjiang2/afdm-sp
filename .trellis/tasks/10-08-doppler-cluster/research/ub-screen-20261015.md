## 0. 中文摘要

- 目的：上一轮下界（res-20261014-03）在 Kc_best 的 0.23–0.65 倍处就过界，说明不了余量。本协议补**上界**：在某个负载 K 上，
  证明"任何接收机"在 i.i.d. QPSK 下的信息率都低于码率 τ=1。若这能在 1.10×/1.25× Kc_best 处成立，就证明余量 ≤10%/≤25%。
- 上界：输出熵用 Gaussian 最大熵放大、给定数据后输出条件熵精确（信道为 Gaussian 律）。代数上
  `UB = E[J] + Σ_n log2(1 + a c_n/σ²) − E[f]`，J、f 与 screen 完全相同，所以**不需要接收机仿真、不需要 QR**，只算 f 和 J。
- 三个参考：MODEL、PHYS（Gaussian，与实测信道律不匹配，Gaussian 是同协方差下最难学的律，结论不能迁移到射线信道）；
  RAY-genie（实测射线律，给接收机 genie 多普勒角——只会让上界更松，但律匹配，是唯一能对实际系统下"无余量"结论的参考）。
- 统计：每个判定点用新的独立帧（MODEL 8192、PHYS/RAY 4096），Bernstein 区间宽度项解析上 ≤ 0.025 bit/符号（Gate F 已按设计常数算过），
  避免上一轮"构造上不可能通过"的缺陷。估计约 4–6 core-hours（CPU，deinlab）。

## 1. Object and question

Same system as C1 and the lower-bound screen (§1 there): N = 1024, SP with pilot energy rho and QPSK data energy
a = 1 - rho, sigma2 = 10^(-SNR/10), time-domain model Y = sum_l D_l(s) a_l + w, D_l(s) = diag(cp_l ⊙ S_l s), s = pt + xt.

Question: at a fixed load K = 8L above the best measured practical cliff Kc_best, is the information rate I(d; y)/N of the
i.i.d.-QPSK ensemble provably below tau = 1 bit/symbol, **for every receiver**? If so at K = 1.10 Kc_best, the practical
receiver is within ~10% of what any receiver can support under that reference (in the information-rate sense of §3).

## 2. Upper bound (per frame, bits)

**Proposition (UB).** Fix N, the pilot, and genie side information G independent of d (G = delay set D for MODEL/PHYS;
G = (D, ray counts, ray angles) for RAY-genie). Suppose that given G the tap sequences are jointly zero-mean proper Gaussian,
independent across taps, a_l | G ~ CN(0, R_l(G)), and d is i.i.d. uniform QPSK with E|d_m|^2 = a, w ~ CN(0, sigma2 I),
with (a, d, w) mutually independent given G. Then

    I(d; y) <= I(d; y | G) <= E_G [ log2 det(I + Cbar(G) / sigma2) - E_d log2 det(I + C_s(d, G) / sigma2) ],

with C_s(d, G) = sum_l D_l(s) R_l(G) D_l(s)^H and Cbar(G) = E_d C_s(d, G) = C_p(G) + a diag(c(G)), where
C_p(G) = sum_l D_l(pt) R_l(G) D_l(pt)^H and c_n(G) = sum_l R_l(G)[n, n] (from E|xt_m|^2 = a, E xt_m xt_m'^* = 0 for
m != m', |cp_l| = 1; this is the screen's `cvec`; c_n = 1 for PHYS and RAY).

Derivation (four steps):
1. I(d; y) <= I(d; y | G): G independent of d, so I(d; y | G) = I(d; y, G) >= I(d; y).
2. I(d; y | G) = h(y | G) - h(y | d, G); both finite since sigma2 > 0.
3. h(y | d, G) is exact: given (d, G), y = sum_l D_l(s) a_l + w is proper Gaussian with covariance sigma2 I + C_s(d, G).
4. h(y | G) <= log2 det(pi e Cov(y | G)) (proper Gaussian maximises entropy for a given covariance; holds for improper y as
   well, Neeser-Massey). Cov(y | G) = sigma2 I + E_d C_s(d, G) because E a_l = 0 and (a, d, w) independent; E_d C_s uses
   E xt = 0 (no pilot-data cross term) and E xt xt^H = a I (xt = IDAFT of i.i.d. QPSK, unitary).

**Reuse of the screen's quantities.** With Q = sigma2 I + a diag(c), the first term is
log2 det(Q + C_p) - N log2 sigma2 = J(G) + sum_n log2(1 + a c_n / sigma2), J the screen's T3 value (log2 det(Q + C_p) - log2 det Q).
So the per-frame UB score is

    u(G, d) = J(G) + Cst - f(d, G),   Cst = sum_n log2(1 + a c_n / sigma2),   f = log2 det(I + C_s / sigma2),

and E[u] >= I(d; y). Compared with the lower-bound score l = A(h) - f + J, the UB replaces the QPSK ZF-SIC coherent term A
by Cst (Gaussian-input, fading-free coherent term); learning cost and pilot term are identical. No channel realisation and no
QR are needed.

### 2.1 References

- **MODEL** (Gaussian, receiver's BEM prior): R_l = (1/K) M M^H, M = sqrt(N) 8-DPSS columns (W = 2.5), K = 8L. As in the screen.
- **PHYS** (Gaussian with the generator's second-order statistics): R_l = (1/L) J0(4 pi (n - n') / N), rank-13 truncation
  (error 2.6e-13) as in the screen.
- **RAY-genie** (the generator's actual ray law, genie angles): given counts r_l = 1 + Poisson(3) and angles theta_lj
  ~ U[0, 2 pi), the generator's a_l[n] = sum_j g_lj exp(2 pi i nu_lj n / N), nu = 2 cos theta, g_lj ~ CN(0, 1/(L r_l)), is
  Gaussian with R_l(G) = (1/(L r_l)) E_l E_l^H, E_l[n, j] = exp(2 pi i nu_lj n / N), rank r_l. Then c_n = 1, Q = (sigma2 + a) I,
  Cst = N log2(1 + a / sigma2). Taps have different R_l: use the general K-side factor form with total rank sum_l r_l.
  The genie (angles known) only loosens the bound; the law matches the channel on which Kc_best was measured.

## 3. Scope (what is and is not claimed)

- Input law: i.i.d. uniform QPSK (same ensemble as the lower bound). A certified UB/N < tau states that the ensemble's
  information rate is below the code rate; it is **not** a converse for the (3,6) LDPC codebook, and it does not use Fano at
  the FER .5 operating point. The comparison with Kc_best carries the same code-gap assumption as the screen (P7 there);
  tau = 1 (no code-gap credit) makes the UB claim conservative (a larger K_UB than tau = 1.154 would give).
- Receiver knowledge: the bound holds for receivers **without** the genie (delays, R_l, angles), since genie only loosens it.
- Channel law: MODEL/PHYS results hold for a Gaussian channel with that covariance. For fixed covariance the Gaussian law is
  the least learnable, so a Gaussian NEAR-LIMIT does not transfer to the ray channel. Only RAY-genie speaks about the measured
  channel law.
- Load axis: K = 8L for all references (the practical cliff axis). No monotonicity in K is assumed: claims are at the tested
  loads only.
- Kc_best: the fixed historical point estimates of the screen §5 (5 uncensored conditions; 9.5 dB report-only).

Endpoint = (reference, condition, ratio): 3 x 5 x 2 = 30 one-sided endpoints, delta_i = .05 / 30 = 1.667e-3 (Bonferroni).
Per endpoint: n fresh i.i.d. frames (new seed domain 0x49425542 "IBUB", distinct from the screen and every C1/DDST stream;
frames shared across the conditions that use the same (reference, L), as in the screen). Statistic on the combined per-frame
score u (one Bernstein term, no split):

    UCB = mean(u) + sqrt(2 S_u^2 ln(2/delta_i) / n) + 7 b_u ln(2/delta_i) / (3 (n - 1)),

with the proven range b_u = B_f + B_J, B_f = N log2[1 + beta (sqrt(rho) + sqrt(a))^2 / sigma2] (f in [0, B_f]: AM-GM on the
eigenvalues and tr C_s <= beta ||s||^2 <= beta N (sqrt(rho) + sqrt(a))^2), B_J = N log2(1 + beta rho / sigma2) (J in [0, B_J]),
beta = sum_l max_n R_l[n, n] (MODEL 4.344, PHYS 1, RAY 1). Endpoint **certified** iff UCB / N < tau = 1.

**Gate F (feasibility, analytic from design constants, computed 2026-10-15 before any data).** Range term per symbol
7 b_u ln(2/delta_i) / (3 (n - 1) N) at n = 4096: MODEL .030-.039, PHYS and RAY .017-.024. Frozen n: **MODEL 8192
(<= .0196), PHYS 4096 (<= .0235), RAY 4096 (<= .0235)**, i.e. <= .025 bit/symbol at every decision endpoint. (The screen's
defect was a range term of 2.5-4.7 bit/symbol at n = 64.)

## 5. Decision rule

Per (reference, condition): H_up = 1.10 if both the 1.10 and the 1.25 endpoints are certified; H_up = 1.25 if only the 1.25
endpoint is certified; otherwise H_up = "> 1.25". (1.10 certified with 1.25 not certified is recorded as NON-MONOTONE and
counts as "> 1.25".) Labels per reference, on the 5 conditions, in this order:

1. **NEAR-LIMIT**: H_up = 1.10 in >= 4/5 -> "under reference X, the i.i.d.-QPSK information rate falls below the code rate
   within ~10% above the practical cliff".
2. **BOUNDED-25**: H_up <= 1.25 in >= 4/5 -> same with ~25%.
3. **UNINFORMATIVE**: the UB cannot exclude more than ~25% headroom; this does not assert headroom.

Route consequences (for the user's decision, not automatic):

| RAY-genie | MODEL / PHYS | reading |
|---|---|---|
| NEAR-LIMIT or BOUNDED-25 | any | headroom on the measured channel is bounded; a stronger receiver (M3) is not justified on load; M2 can be written with a two-sided reference |
| UNINFORMATIVE | NEAR-LIMIT or BOUNDED-25 | bounded under the Gaussian surrogate only; any larger gain on the measured channel would have to exploit ray sparsity (Doppler structure). No headroom claim either way |
| UNINFORMATIVE | UNINFORMATIVE | standard bounds cannot decide at these SNRs; stop bound work unless the user funds a data-aided lower bound or a matched practical arm |

## 7. Computation plan, gates, cost

Per frame and reference: draw G (and data), compute f (all 5 conditions at once) and J; K-side factor form when the total
rank <= 700 (MODEL 8L, PHYS 13L, RAY sum_l r_l), N-side otherwise (screen code paths reused; RAY needs per-tap factors).
Gates before scoring:
- **UB1** toy: UB >= MI - err in all 27 deterministic cases of the screen's U4 set, using the implemented UB function.
- **UB2** identity: on 3 frames per reference at L in {8, 32}, direct N-side log2 det(I + Cbar / sigma2) equals J + Cst to relative 1e-9.
- **UB3** mean covariance: Monte Carlo mean of C_s over 2000 QPSK draws matches Cbar = C_p + a diag(c) (relative Frobenius
  error within 4 standard errors).
- **UB4** RAY law: drawing counts, angles and gains from the RAY-genie stream and forming E_l g_l reproduces the screen's
  `draw_rays` tap sequences bitwise for the same stream (whose law was checked against `draw_c1_paths`), and
  diag R_l(G) = 1/L exactly.
- **OP** reproducibility fingerprint (`_argv`, `_config`) in every results json; rows gzip on deinlab, md5 locally.
Cost (from the screen's f + J timings, single thread): decision ~4.0 core-hours (MODEL 9 L x 8192, PHYS 9 L x 4096, RAY 9 L x
4096), report-only ~1.5; with shared-machine contention <= 8 core-hours. Requested cap: 10 core-hours, CPU only, <= 20
concurrent single-thread jobs.
