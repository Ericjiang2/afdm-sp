# Design

The [protocol](../../../experiments/cstate_codelay_sbl_stage3_20261118/PROTOCOL.md) is canonical. Extend E-1 geometry in an isolated namespace with narrow, byte-bound covariance call-site substitutions, reusing its selector, direct fallback, refinement and small normal solve. Reuse native F0 and E-1 A1 continuation for both arms. Reuse DEINLAB's sealed E-3/E-3b rows for accuracy. For timing, run the original E-3 single-variant route and an isolated single-variant E-3b route, with all physical-frame-static caches prewarmed and hash qualification outside the timer.
