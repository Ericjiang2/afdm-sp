## 2. 总体判断与发展潜力

**结论：pivot-with-rescue-route——保留问题和现象，改造中心论点。**

方向有继续研究的价值，但当前“新问题 + 新模型 + 闭式通用预算”的包装高于已经建立的贡献。最扎实的定位是：

> 给定 SP 接收机、信道表示和归一化条件，首轮平均估计误差服从可解释的维数—能量规律；这一规律与接收机可靠性之间存在可研究的联系，并在特定条件下伴随非单调性能变化。

它尚不是“所有 SP 接收机只能承受 K < κN”的必要可行性界，也不是迭代收敛定理。

**发展潜力：中等。** 如果能用 AFDM 实际观测矩阵、信道协方差和检测/译码传递关系，推出有适用范围、可独立预测的工作区间，仍可形成有分量的分析论文。若最后只剩经典 LMMSE 公式的反解、重新拟合的阈值和几张新信道曲线，完整 Transactions 稿件的中心贡献偏弱。

**判断置信度：中高。** 公式重叠、阈值逻辑和代码口径已有直接依据；新的 AFDM 谱条件是否具有足够独特性，仍需对选定命题作更窄的文献比较。

## 3. 问题定义与研究价值

真正值得研究的问题是：在总发射能量和观测长度有限时，怎样判断一个 SP-AFDM 接收机能否获取足够可靠的信道与数据信息，以及失败由哪一环节造成。

需要区分三个对象：

1. **物理信道复杂度**：连续延迟、多普勒谱、可分辨模态及其能量。
2. **接收机表示维数**：选择了多少路径、延迟和 BEM 系数。当前 C1 为每个时延 8 个复 DPSS 系数，即 K = 8L。
3. **可用于检测的可靠性**：取决于信道估计误差的方向和分布、导频消除、检测器、编码和迭代调度。

这三者有关联，但不能互换。相同物理信道可用不同阶数表示；相同 K 也可对应完全不同的可辨识性和误差分布。问题的实用价值在于给出“何时、为何、怎样配置”，而不只是展示某一基线发生失效。

## 4. 核心洞察与贡献拆解

合理的逻辑链为：

**有限导频能量与数据自干扰 → 首轮可辨识信息不足 → 检测/译码可靠性受限 → 反馈可能无法改善估计 → 特定接收机出现性能边界。**

另有一条收益链：

**更多可利用的独立信道模态 → 适当编码与检测下的分集收益。**

二者共同作用可以产生 U 型，但“同时存在收益和代价”不必然推出 U 型，更不能直接识别迭代自举失败。

| 拟议成分 | 当前合理定位 | 对论文的作用 |
| --- | --- | --- |
| B 在多延迟、多射线信道下失效 | 特定表示与容量限制下的问题证据 | 动机和适用范围说明 |
| DPSS 表示每抽头的多普勒扩展 | 已知方法在当前 SP 接收机中的应用 | 技术基础；可保留的小创新 |
| 首轮 shrinkage 误差规律 | 经典 LMMSE/ridge 风险在当前设置中的具体化 | 分析起点 |
| K* = κN | 在假设和校准门限下的代理预算 | 可用设计近似；不宜独立承担主要理论创新 |
| 特定 SNR 下 FER 的 U 型 | 有意义的条件性现象 | 支持“分集与估计代价竞争” |
| 非正交、非平坦谱下的工作区间及其迭代解释 | 尚待形成的核心命题 | 最有价值的改造方向 |

## 6. 第一性原理与数学边界

### 6.1 从真实观测出发

令总发射功率归一化为 1：

\[
x=p+d,\quad \|p\|^2=\rho N,\quad E[d]=0,\quad
E[dd^H]=(1-\rho)I,
\]
\[
H(c)=\sum_{j=1}^K c_jB_j,\qquad
y=A_pc+u,\quad
A_p=[B_1p,\ldots,B_Kp],\quad u=H(c)d+w.
\]

若数据、零均值信道系数和噪声满足通常的独立性条件，记 C = E[cc^H]，则

\[
E[cu^H]=0,\qquad
R_u=(1-\rho)E[HH^H]+\sigma^2 I.
\]

因此最佳复线性估计器具有误差协方差

\[
C_e=C-CA_p^H(A_pCA_p^H+R_u)^{-1}A_pC.
\tag{1}
\]

C、R_u 可逆时，

\[
C_e=(C^{-1}+A_p^HR_u^{-1}A_p)^{-1}.
\tag{2}
\]

这里不需要把 u 与 c 假装成独立高斯量。它们通常相关于高阶矩；式 (1) 是 LMMSE 风险，不自动是真实非线性 MMSE 或后验协方差。

物理误差为

\[
\bar\epsilon=
E\|H-\hat H\|_F^2/N=\operatorname{tr}(W C_e),\quad
W_{ij}=\operatorname{tr}(B_i^HB_j)/N.
\tag{3}
\]

只有在 W = I 的相容坐标下才直接等于 tr(C_e)。有限 BEM 的遗漏项也必须进入观测模型；若与保留系数相关，需要交叉协方差。DPSS 列本身正交，不意味着经过移位导频后的 A_p 各列正交。

### 6.2 现有误差规律为何成立，它究竟说明什么

先考虑物理误差坐标已白化、tr(C) = 1、且

\[
A_p^HR_u^{-1}A_p=\alpha I,\qquad
\alpha=\frac{\rho N}{\sigma^2+1-\rho}=\frac1s.
\tag{4}
\]

式 (4) 的后一等号进一步使用白的无条件自干扰与正交等能量导频列。实际 N × K 观测要满足这一满列秩条件，还必须 K ≤ N。

假定平坦先验 I/K 的接收机相当于对
\[
z=c+\eta,\quad E[\eta\eta^H]=\alpha^{-1}I,\quad E[c\eta^H]=0
\]
作统一收缩：
\[
\hat c_{\rm flat}=az,\quad a=\frac{\alpha}{K+\alpha}.
\]
其平均风险为
\[
\boxed{\bar\epsilon_{\rm flat}
=(1-a)^2+a^2K/\alpha
=\frac{K}{K+\alpha}
=\frac{Ks}{1+Ks}.}
\tag{5}
\]

**即使真实 C 不平坦，只要这些等信息条件与总能量归一化成立，flat shrinker 仍满足式 (5)。** 因而 1–3% 的均值吻合有价值，但不能据此证明 Jakes 的真实先验平坦，也不能证明反馈动力学。

式 (5) 正是 Liang 等原文式 (8)–(10) 在平坦 tap 功率下的特例。将 tap 数换成当前的 BEM 系数数，是可保留的应用推导，创新主张应据此收窄。

当 σ² → 0、固定 N 且 0 < ρ < 1 时，α → ρN/(1−ρ)，首轮线性估计仍有数据自干扰造成的风险平层。这不等于全部联合、非线性或编码 SP 接收机的信息极限。

### 6.3 K* 的严格含义：平均代理预算

为理论预算定义基于平均误差的代理量，
\[
q_{\rm budget}=\frac{1-\rho}{\sigma^2+\bar\epsilon},\qquad
b=\frac{1-\rho}{\gamma}-\sigma^2.
\]
脚本的每帧 SINR_spec 则把分母中的 ε̄ 换成该帧误差，再对结果求平均；一般 E[SINR_spec] ≠ q_budget，不能混为同一统计量。

于是 q_budget ≥ γ 等价于 ε̄ ≤ b。将式 (5) 代入，在 0 < b < 1 时得到
\[
\boxed{K\le K^*
=\frac{\alpha b}{1-b}
=N\frac{\rho b}{(\sigma^2+1-\rho)(1-b)}.}
\tag{6}
\]

- b < 0：即使误差为零也达不到该代理门限。
- b = 0：非严格不等式只有形式上的 K = 0 可满足。
- 0 < b < 1：有限预算如式 (6)。
- b ≥ 1：此标量风险模型不产生有限门限；并不取消式 (4) 的秩限制或保证真实系统可承载无限维数。

**式 (6) 的代数正确。缺口是把“平均代理量达标”升级为“反馈能够启动”“可靠译码”或“SP 必须满足的容量界”。**

首先，ε̄ 是均值而 FER 是尾部/事件概率。均值 0.2 小于门限 0.3，也可能有 40% 的帧误差为 0.5、其余为 0。均值预算并不能独立决定失败比例。

其次，现有 γ = 1.37 来自 FER = 0.5 的交叉位置拟合；目标改为 FER = 0.1 就是不同设计问题。κ ≈ 0.16–0.35 应标为选定 SNR、功率、接收机、码和终点下的校准系数，不是材料常数。

### 6.4 一个实质性的反例：相同 K 可以有不同预算结论

若接收机利用真实 C，式 (4) 下的风险为
\[
\bar\epsilon_{\rm matched}
=\sum_{j=1}^K\frac{\lambda_j}{1+\alpha\lambda_j}
\le \frac{K}{K+\alpha},\quad \sum_j\lambda_j=1.
\tag{7}
\]

因为 λ/(1+αλ) 为凹函数，Jensen 不等式给出上界；全部 K 个特征值均为 1/K 时取等号。若实际秩 r < K，即使非零谱平坦，风险也为 r/(r+α)，严格小于这个 K 维上界。

例如 α = 1、b = 0.6 时，K* = 1.5。取 K = 2：

- 平坦谱 (0.5, 0.5) 的风险为 2/3，超过 0.6。
- 满秩谱 (0.99, 0.01) 的风险为 0.99/1.99 + 0.01/1.01 ≈ 0.507，小于 0.6。

因此 K > K* 不必导致协方差匹配接收机的平均代理量失败。这里 K ≤ K* 是理想条件下的保守充分条件；对原 flat 接收机，它才是相应风险表达式的等价反解。

此外，同 K、同 C 但导频矩阵列相关，也会改变风险。两列完全相同会留下不可观测差方向，增加观测能量无法消除该方向的误差。这个线性代数反例用于反驳“仅 K/N 足够”的一般性，不声称当前 AFDM 配置恰好存在完全重复列。

一个可精确定义的估计负担量是
\[
K_{\rm eff}(\alpha)=
\sum_j\frac{\alpha\lambda_j}{1+\alpha\lambda_j},
\qquad \bar\epsilon_{\rm matched}=K_{\rm eff}(\alpha)/\alpha.
\tag{8}
\]
它随信息强度变化，不是固定的物理路径数。Slepian 能量集中谱也不自动等于真实 Jakes 协方差谱。

### 6.5 怎样把非理想导频纳入可用准则

对真实平坦 C = I/K，设 F = A_p^H R_u^{-1} A_p，并且
\[
\alpha(1-\delta)I\preceq F\preceq\alpha(1+\delta)I,
\quad 0\le\delta<1.
\]
由矩阵逆的序关系，
\[
\frac{K}{K+\alpha(1+\delta)}
\le \operatorname{tr}C_e
\le \frac{K}{K+\alpha(1-\delta)}.
\tag{9}
\]

当 0 < b < 1 时，相对于式 (6)，有明确的两个方向：
\[
K\le(1-\delta)K^*\ \Longrightarrow\ \bar\epsilon\le b,
\qquad
\bar\epsilon\le b\ \Longrightarrow\ K\le(1+\delta)K^*.
\]
这些仍受相同的建模、能量与秩条件约束，并不是 FER 界，也不能直接推广到真实 C 非平坦的 mismatched 接收机。

式 (9) 本身只是经典矩阵不等式。真正可能形成 AFDM 贡献的是：从实际 chirp、延迟与簇内 Doppler 几何推得有用的 δ 或更紧谱界，并说明它怎样改变接收机的可操作配置。仅把 K 换成未经定义的 K_eff 不够。

### 6.6 同一个谱如何产生“分集收益—估计负担”的双重作用

理想 CSI、相干 ML、c ~ CN(0,C)、且独立噪声 w ~ CN(0,σ²I) 下，对码字差 Δx 定义
\[
\Phi_{\Delta x}=[B_1\Delta x,\ldots,B_K\Delta x].
\]
标准 Gaussian 二次型与 Chernoff 推导给出成对误差概率上界
\[
P(x\to x')
\le \frac12\det\left(
I+\frac{1}{4\sigma^2}
C^{1/2}\Phi_{\Delta x}^H\Phi_{\Delta x}C^{1/2}
\right)^{-1}.
\tag{10}
\]

若 Δx 未包含数据功率，需要把相应功率放入系数。式 (10) 是 PEP 上界，不是当前 LDPC 接收机的 FER 公式。

这个行列式的高 SNR 指数由
\[
\operatorname{rank}
\left(C^{1/2}\Phi_{\Delta x}^H\Phi_{\Delta x}C^{1/2}\right)
\]
决定。要达到 rank(C)，码字差映射还必须在信道支撑空间上无零方向；不能只数 K，或者仅凭“使用 AFDM”就宣布达到最大分集。

令 t = 1/(4σ²)。在额外的理想几何条件 Φ_Δx^H Φ_Δx = qI 下，保持 α、t、q 和总能量不变，并把谱变得更均匀：

- 式 (7) 中凹函数之和增大，平均信道估计更困难。
- 式 (10) 中 Σ log(1+tqλ_j) 增大，PEP 上界减小。

这给出了严谨的“同一组模态既提供收益、又增加估计负担”的解释。它来自经典谱分析，不能当作新发现申报；应用于实际 AFDM 的非理想几何并导出新的范围，才可能产生增量。

即使这两条都成立，FER 是否 U 型，仍取决于竞争强度、编码和 SNR。两种趋势的存在不保证内部极小值。

### 6.7 首轮门限与反馈收敛之间仍差一座桥

相同初始可靠性 r_0 = 0.6，在
\[
r_{t+1}=r_t^2
\quad\text{与}\quad
r_{t+1}=2r_t-r_t^2
\]
中分别收敛到 0 与 1。单独知道初值不能决定终态。

要作自举机制主张，应定义与实际估计器、检测器、译码器和调度对应的状态映射
\[
z_{t+1}=\mathcal T(z_t;\rho,\sigma^2,N,C,A_p,\text{code,schedule}),
\]
说明坏/好固定点、稳定性与初值所在的吸引域。多维局部稳定性涉及 Jacobian 的谱半径；EXIT 隧道也是整条传递关系的性质。

不要求所有有限长度 LDPC 的门限都有闭式解。可以使用明确假设下的传递分析，或与待预测数据分离的校准；但应保持“理论推导”“半解析近似”“经验拟合”三个层级。

实际检测质量还需从
\[
y-\hat Hp=\hat Hd+(H-\hat H)(p+d)+w
\tag{11}
\]
出发。导频残差、数据残差及其与同一数据/噪声的相关性不能省略。现有 SINR_spec、SINR_recv、SINR_phys 不是同一量；不能直接把 SINR_spec 叫作物理检测 SINR，也不能武断认定分母必然少了一个 (1−ρ)。

### 6.8 N 缩放的物理不变量

记采样率 f_s、块时长 T、物理多普勒 f_D，则
\[
T=N/f_s,\qquad \nu_{\max}=f_D T.
\]
对给定精度的带限过程，DPSS 的有效表示维数近似为
\[
D(N)\approx 2f_DN/f_s+\Delta_\varepsilon(N).
\]
这里是有效时间带宽维数加过渡裕度，不是所有有限射线模型的精确代数秩。

若固定 f_s、物理 f_D 和分辨后的延迟数 L，
\[
\frac{K(N)}{N}
\approx \frac{2Lf_D}{f_s}
+\frac{L\Delta_\varepsilon(N)}{N}.
\tag{12}
\]

所以加长块长会同时增加观测量和需跟踪的时变复杂度。K* ∝ N 不能单独推出“增加 N 总能解除物理信道瓶颈”。

| 保持的量 | 改变 N 时随之改变的量 | 可以回答的问题 |
| --- | --- | --- |
| 固定 f_s、物理 f_D、物理延迟剖面 | T、Doppler bins、所需 D；码长还需另行说明 | 同一物理场景的块长选择 |
| 固定子载波间隔 Δf = f_s/N、物理 f_D | 带宽/采样率、延迟采样与可分辨结构 | 固定时长下的带宽扩展 |
| 固定 bins、整数延迟与 BEM 规则 | 物理尺度未必固定 | 归一化模型的数值相似性 |

同 f_s 与 f_D 下，从 N = 1024、ν_max = 2 变到 N = 256，应得到 ν_max = 0.5，而不是 1。2 bins 是否对应极端移动还取决于 f_s/N、载频和传播场景；不能从 N 与 bins 单独判断。旧生产配置实际是 16 kHz 采样，1 bin = 15.625 Hz，不能误写为 kHz。

## 7. 主要优势与可保留成分

1. **问题有清楚的资源含义。** 不增加时频专用导频，并不意味着估计资源无限；导频能量、自干扰和可辨识模态提供了直接的设计语言。
2. **已有结果允许形成有边界的现象陈述。** U 型无需被抛弃，但应绑定已经支持的 SNR、功率、表示和接收机条件。
3. **经典方法的 AFDM 应用仍值得保留。** 用户接受有用的小创新；诚实引用后，DPSS、协方差或阶数设计可继续作为方法组件。问题在于论文中心贡献的强度，而非要求每个组件原创。
4. **分析类论文是合理形式。** 不必强行添加新网络或新优化器；一个非平凡、可解释、能指导选择的工作区间，也可以是核心贡献。

### A1. 哪些结论可以保留，哪些必须改变口径

### A2. 三处会影响因果解释的口径问题

**C1-E01：预测指标混用。** 各 SNR/ρ 条件内合并 L、仅在 A3 成功子集计算时，flat arm 的 SINR_spec AUC 是约 0.808–0.891；0.996–0.998 属于首轮 LLR 指标。其中 r1_ll_in 来自首轮联合检测输出，r1_ll_app 来自译码后的 APP。这些 LLR 指标有用，但已经利用了循环中的处理结果，不能等同于 pilot-only 质量几乎完美决定最终成败。

**C1-E02：断崖宽度有确定的因子 2 错误。** 若
\[
P=\operatorname{sigmoid}(a+b\log q),
\]
则
\[
\Delta_{10\%-90\%}\log q=\frac{2\log 9}{|b|}.
\]
分析脚本三处使用 log(9)/|b| 并标为 10–90% 全宽，实际低报一半。这不消除断崖现象，但相关宽度数值应修正后再用于论文。

**C1-E03：“已收敛残差”尚未被识别。** 当前外循环只运行两轮，每轮 20 次内更新，见 driver_c1.py 第 272 行及 277–279 行的两次 refit 断言。P(SINR_1 < γ) 较小，最多削弱这一代理量所描述的启动失败解释；它不足以排除代理量失真、有限迭代、检测失配等原因。宜称“当前调度下的 cliff 前损失”，不能仅凭这项统计断言其唯一根因为收敛残差。

### A3. B 和 TDL 的范围

**C1-E04：B 对比存在容量混杂。** B 只保留最多 8 个 distinct delays，并且每 delay 一个 Doppler 中心；SPg 使用全部 genie delays、每 tap 8 列。因此 24/24 工况的 B 失效，支持这一受限接收机失效；尚不能单独识别簇模型失配的贡献，更不能推翻整个参数化方法类别。

需要的因果区分很具体：固定前端与资源口径，区分“8 槽限制”与“每 delay 单 Doppler 假设”。未提供容量匹配控制是当前因果主张的证据限制，不作为概念新颖性评分项。

**C1-E05：TDL 表格正确不等于完整标准实现。** 当前实现使用 TR 38.901 的 A/B/C 表，按最大延迟缩放到 30/60 samples 后四舍五入，再合并同一整数延迟；每个原 tap 用 1 + Poisson(3) 条有限射线及 ν = 2 cos θ 生成时间变化，按期望功率归一化。

这个模型适合标为“基于 3GPP TDL-A/B/C 剖面的整数延迟、有限射线实现”。表格与 [TR 38.901](https://www.etsi.org/deliver/etsi_tr/138900_138999/138901/16.01.00_60/tr_138901v160100p.pdf) 一致，也不自动证明延迟缩放、分数延迟、时间相关性及物理场景的全部标准一致性。本轮没有重新逐表核 PDF；表格核对依赖已保存证据。

**旧生成器缺陷不能一概外推到 C1。** D1/D2 的 stale cap、二次延迟量化属于旧生产生成器及复用它的 G0/G1。C1 map 与 TDL 使用单独生成代码，绕过该路径；也未采用旧路径的逐帧 Frobenius 归一化。因此不能说“必须先修旧生成器，当前所有 C1 数值才成立”。需要分别审计各自实际使用的生成路径。

### A4. 三种失败模式应怎样解释

| 层次 | 当前可观察对象 | 不应直接跨越的推断 |
| --- | --- | --- |
| 表示/支持获取 | 漏检、误检、遗漏能量、模型投影误差 | 不能用它证明 genie-support 的启动阈值 |
| 反馈能否改善 | 首轮误差及后续可靠性变化 | 单一初值门限不能替代动力学 |
| 给定调度后的残余损失 | 最终 FER、NMSE、LLR 校准与迭代状态 | 两轮结果不自动等于收敛固定点 |

8 dB 下，TDL 的 genie-support SP 在名义 K/K* < 1 时仍显著差于 True-H，值得保留：它显示“名义平均预算可行”并不等于“具有足够可靠的译码”。11 dB 部分工况没有显著差异，不能把上述结论扩展到所有条件。这应成为准则适用边界，而不是用措辞把所有损失都并入自举模型。

## 扩展 B：是否按 Claude 提案直接运行 N = 256/512

**建议：不要原样将这次运行称为决定性验证；先把要检验的命题固定。** N 缩放有价值，但同时缩短码长并重拟合 γ，会混合多个问题。

若针对每个 N，用同一份观测到的交叉点 K_c(N) 定义
\[
\gamma_N=
\frac{1-\rho}
{\sigma^2+\dfrac{K_c(N)s_N}{1+K_c(N)s_N}},
\]
那么再代回式 (6) 得到 K* = K_c(N) 是代数恒等式，不是预测。

若 γ_N 来自与待预测 cliff 数据分离的预先规定校准，则不是上述循环论证。但它检验的是“使用独立码/接收机校准后的预算迁移”，而不是一个不随 N 变化的通用 κ。纯 AWGN 的编码门限也未必直接等于含 SP 残差的检测可靠性门限。

一个有判别力的最小顺序是：

1. **先固定对象与坐标。** 明确 γ 对应的量、目标 FER、接收机调度、物理不变量与 BEM 选阶规则；分别保留原始和 post-hoc 终点。

3. **锁定校准再预测。** 若 γ 随码长变化，使用独立校准；在目标条件上不再用 cliff 反推参数。预测区间应包含校准和模型近似的不确定性。
4. **按因果问题设置小对照。** B 的容量与模型限制、停止轮数与真正反馈失败，各自需要能区分解释的对照；这些比仅增加 N 网格更有信息。

### C2. 标量模型：可以推出什么

令 \(k=K/N,\ a=1-\rho,\ n=\sigma^2>0\)，\(0<\rho<1,\eta>0\)，并令 \(M(q)\in[0,1]\) 为待独立测量的软符号误差曲线。Claude 的递推等价于
\[
v(e)=M\!\left(\frac{\eta a}{n+e}\right),\qquad
F(e;k)=\frac{k[n+av(e)]}{1+kn+a(k-1)v(e)}.
\tag{C1}
\]

完美数据反馈与无数据先验两个端点分别为
\[
e_L=\frac{kn}{1+kn},\qquad
e_U=\frac{k(n+a)}{\rho+k(n+a)}.
\tag{C2}
\]
\(e_L\) 只是误差下限；只有 \(M(\eta a/(n+e_L))=0\) 时才是固定点。\(kn\) 是低负载/低噪声近似，不能当精确好态。

若 \(M\) 连续可微且递减，记 \(D=1+kn+a(k-1)v(e)\)，则
\[
F_e=
\frac{k\eta a^2(1+n)[-M'(\eta a/(n+e))]}
{D^2(n+e)^2}\ge0.
\tag{C3}
\]
固定点须满足 \(F(e_*)=e_*\)；局部稳定条件是 \(F_e(e_*)<1\)。内部光滑折叠的候选条件为
\[
F(e_*;k_*)=e_*,\qquad F_e(e_*;k_*)=1,
\tag{C4}
\]
还须检查 \(F_{ee}\ne0,F_k\ne0\) 及有效域。冻结其余量时
\[
F_k=\frac{(1-av)(n+av)}{D^2}>0.
\]
若整个相关区间 \(\sup F_e<1\)，则唯一固定点，不存在双稳态。

**递推结构本身不保证双稳态。** 例如取合法的高斯符号 MMSE 曲线 \(M(q)=1/(1+q)\)，式 (C1) 成为 \((ue+v_0)/(we+z)\)，四个系数均正。固定点方程 \(we^2+(z-u)e-v_0=0\) 恰有一个正根。这是对“必然存在”的反例，不是对当前 LDPC 曲线的实测结论。

**旧 K* 却有一个清楚的动力学解释。** 取理想阶跃
\[
M(q)=\mathbf1\{q<\gamma\},\qquad b=\eta a/\gamma-n,\qquad 0<b<1.
\]
此时坏态自洽要求 \(e_U>b\)，好态具有双侧吸引邻域要求 \(e_L<b\)，于是
\[
\boxed{
k_-=\frac{\rho b}{(1-b)(n+a)},\qquad
k_+=\frac{b}{n(1-b)},\qquad
k_-<k<k_+.
}
\tag{C5}
\]
这是稳健双稳态窗口，须与估计模型的有效域（特别是等信息满列秩条件 \(k\le1\)）相交。固定 \(e_0=e_U\) 时，\(k\le k_-\) 进入好分支，\(k>k_-\) 留在坏分支；阶跃边界的等号按上述指标定义处理。

取 \(\eta=1\) 且 \(s=(n+a)/(\rho N)\)，便有
\[
\boxed{Nk_-=\frac{b}{(1-b)s}=K^*.}
\tag{C6}
\]
**这使旧预算成为“阶跃编码曲线 + 指定初始化”下的分支切换位置。** 这是值得保留的数学连接；不是新的通用容量定理。阶跃不可微，不能把 (C5) 直接叫光滑折叠；真实平滑曲线仍须检验 (C3)–(C4)。

连续单调 \(F\) 下，若从 \(e_U\) 开始，迭代单调下降并收敛到最大固定点：首次更新不超过上界，单调性维持递减序列，每次迭代又不低于任一固定点。因此 Claude 的“坏分支出现可能使 pilot-only 初始化失败”有数学依据，但依赖这一初始化和闭合模型，不能推广到任意接收机/初值。

最后，确定性均值递推不直接给出双簇占比，也不自动预测 FER=.5 交叉。必须预先规定从状态到 FER 的读出及所需随机性。不能把模型折叠点、有限轮次 FER=.5 点和原来的首遍代理交叉混为同一个 K*。

### C3. 比增加状态维数更先要做的事：检查标量是否闭合

**T1 只测 FER 不够。** 递推需要的是软符号误差，而非帧错误概率。对单位能量符号 \(d\) 与实际软估计 \(m\)，定义
\[
v=E|d-m|^2,\qquad r=E|m|^2,\qquad z=E[(d-m)m^*].
\]
恒等式为
\[
\boxed{1=v+r+2\Re z.}
\tag{C7}
\]
若 \(m=E[d\mid\mathcal I]\)，条件均值的正交性给出 \(z=0\)，保证 \(r=1-v\)。这是充分条件；单就这一能量恒等式，只需 \(\Re z=0\)，其他估计器也可能满足。因此同一个 \(v\) 能否同时表示“残余干扰”和“额外导频能量”，应直接检验。近似 BP、过度自信的错误码字、APP/外信息混用，都可能破坏闭合。

即使 \(z=0\)，软符号能量也不自动等于独立新增导频信息：设计 Gram、条件残差协方差以及同一观测的数据复用仍需满足相应近似。现有内层含 Onsager 型修正，不能仅因复用观测就断言标量模型不可能；应直接检验其一步预测。

T1 宜同时测实际软 MSE、报告方差、软均值能量、交叉项与 FER，并匹配冻结码矩阵、BP、LLR 处理和早停。明确采用 APP 还是外信息，以及“一轮”对应哪一个实际处理阶段。一个 True-H 的效率 \(\eta\) 只校准了正确 H 的边界，未自动识别有色、相关、失配 H 下的行为。

若相同 \(e_t\) 在不同历史/初始化下产生系统性不同的 \(e_{t+1}\)，先否定这个一维闭合；不等于否定反馈。只有简约模型失败后，才考虑增加一个可靠性或相关性状态。

### C4. AFDM 特异性：实际算子已否定“天然严格正交”

导频列的判据是
\[
G_{ij}=\langle H_i p,H_jp\rangle=p^H H_i^H H_jp,
\tag{C8}
\]
而不是 \(H_i,H_j\) 的非零元素落在不同位置。

本轮直接复用实际 dpss_rx.Design 与 physical.daft，做了三组确定性小矩阵计算。N=1024、ρ=.3、全域 root=7 ZC、\(c_1=5/2048\)、\(c_2=(\sqrt2-1)/(2N^2)\)、每 tap \(W=2.5,D=8\)、软数据均值为零。令 \(G=B^HB\)，\(C_{ij}=G_{ij}/\sqrt{G_{ii}G_{jj}}\)，理想对角为 ρN=307.2。

| 给定延迟支持 | G 的对角范围 | max 非对角 \(\lvert C_{ij}\rvert\) | \(G/(ρN)\) 特征值范围 |
| --- | ---: | ---: | ---: |
| [0] | 300.7093–308.0816 | .023222 | .929263–1.021144 |
| [0,1] | 300.7093–308.0816 | .026740 | .849225–1.042000 |
| [0,30] | 300.7093–310.2818 | .149830 | .820300–1.212527 |

单 tap 已不严格正交。这些是指定支持的算子例证，不代表 C1 所有随机帧；非零相关也不证明它主导了 cliff。首遍均值误差吻合 1–3% 仍支持一个有用近似，不能支持“严格精确”。

[Bemani 等，§III-D/E、式 (28)–(43)](https://arxiv.org/html/2204.12798) 区分整数与分数 Doppler；分数情形的行响应严格说全域非零，有限 bin 宽度是截断近似。[Zheng 等，SP-AFDM，Appendix C](https://arxiv.org/html/2404.10232) 的导频正交证明另外使用导频非零位置间隔，使相关乘积消失。因此：

- \((l_{\max}+1)(2\alpha_{\max}+1)\le N\) 是特定网格/排列的包络条件，不能一般等同于稀疏实际 \(K=\sum_lD_l\)。
- DPSS 系数数不是严格非零 DAFT bin 数；ZC 的循环自相关性质也不能直接替代 (C8)。
- 相关性修正须依赖导频、chirp、支持、基函数及噪声白化；不能声称只由 \(c_1\) 决定。
- 因而“SP 把 AFDM 的时延–多普勒容量缩减 κ 倍”应改为“特定接收机的估计/译码负载预算约为 κN”，先验证其适用域。

协方差扩展也不能简单二次代入：等信息条件下，匹配先验风险为
\[
\epsilon=\sum_j\frac{\lambda_j}{1+\alpha\lambda_j}
=\frac1\alpha\sum_j\frac{\alpha\lambda_j}{1+\alpha\lambda_j}.
\tag{C9}
\]
若把末项求和称有效维数，风险是该量除以 α；再把它放进 \(Ks/(1+Ks)\) 会重复收缩。当前导频并非随机序列；结构化随机导频也不能无条件套独立 Wishart 的 \(K/(N-K)\) 修正。

### C5. RF 实用性：方向判断合理，短块“就在断崖”尚未成立

按 Claude 给定算例直接计算：4 GHz、500 km/h 对应 \(f_D\approx1853.13\) Hz；\(f_s=1024\times30\text{ kHz}=30.72\) MHz。固定采样率时，N=1024 的归一化 Doppler 为 .06177，N=256 时降为 .01544，子载波间隔同时升至 120 kHz。

TDL-C 的 300 ns 是 delay-spread 缩放量，最大归一化延迟为 8.6523，故最大延迟约 2.59569 μs：
\[
2f_D\tau_{\max}\approx .009620,\qquad
2f_D\tau_{\rm DS}\approx .001112.
\]
当前 16 kHz、ν_max=2、最大 60 samples 的对应最大延迟乘积为 .234375。这个具体 RF 例子的扩展积确实更小；比较时必须统一最大延迟与 RMS/DS 口径。

若保留全部 24 个物理 taps，并暂假设每 tap 用 1–2 个系数，则 K=24–48，N=256 时 K/N=.09375–.1875。若沿用当前整数延迟合并规则，得到 18 个 distinct delays，则 K=18–36、K/N=.07031–.14063。后者不是完整分数延迟标准实现；两种计数都不足以证明真正需要 D=1 还是 2，更不能先固定 K≈40–50。

短块、低导频比例和低 SNR 是合理候选风险区。但须按表示误差容限决定 D，并计入码长、支持获取与 CPP 开销，才能判断是否真的触及边界。

一般 DPSS 维数的时间带宽近似是
\[
\frac KN\approx \frac{2L f_D}{f_s}+\frac{L\Delta_{\rm tol}}N,
\tag{C10}
\]
其中 \(\Delta_{\rm tol}\) 表示与误差容限有关的阶数余量。只有再假设密集延迟 \(L\approx\tau_{\max}f_s\)，第一项才近似 \(2\tau_{\max}f_D\)。稀疏 TDL 不能跳过这一步。

K 是给定表示的维数，不能无条件称唯一物理量。固定 ρ、SNR、码、调度和观测统计后，式 (C1) 只通过 k 依赖 K,N；这是模型的相似性。改变 N 会改变码曲线和归一化 Doppler；改变 L 会改变 True-H 分集/η，曲线未必只按 k 坍缩。ρ 过大又会耗尽数据能量，工作域也不一定能只用“最小 ρ”描述。

先做便宜的筛查与少量配对干预；后续网格只有在前一问题有答案时才展开。既有曲线的近似吻合可以支持预测用途；同观测、不同初值到达两个持续终态，并各自具有局部稳定性，才更有力地支持双稳态。只有干预已进入模型预测的另一吸引域、充分稳定后却仍合流，才削弱该双稳态预测；未跨越预测分界的合流没有这种判别力。

**修正 kill rule：**T0 单峰且 T3 六轮无改善，不能据此“彻底放弃自举”。若冻结的一维模型不能预测一步误差，且偏差随历史变化，应放弃这个一维闭合；若跨越预测吸引域分界的配对轨迹充分稳定后仍合流，应削弱该模型的双稳态主张。保留已经验证的反馈收益。若最后只剩经验等效 SNR 图谱，也要单独审查其相对已知工作的增量，不能预设备选稿达到 Transactions 标准。
