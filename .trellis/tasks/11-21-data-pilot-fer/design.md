# Design（v2：已按 Astra 审查修改，待 Eric 批）

Astra 审查：[research/astra-design-review.md](research/astra-design-review.md)。采纳的改动在各节标注"〔Astra〕"。

## 1. 现有接收机里，支撑是在哪一步定死的
`native_twofft.receive` → `pilot_front`（515 列整数字典上的贪婪最小二乘，最多 40 个原子）→ 第 0 轮 `twofft.time_refine`：按"每个时延的增益能量"取前 `max_paths = 8` 个时延（`twofft.py:87`），再细化分数多普勒 → 检测、译码 → 第 1 轮沿用这 8 个时延。之后只有 `CODELAY` 交换（每帧最多 2 次替换）能改支撑。
所以**第 0 轮的前 8 选择就是瓶颈**，候选只有在这里进入才有意义。

## 2. 两个阶段

### 阶段 A：上界（便宜，先做）
- **A-delay**：第 0 轮的 8 个时延直接用真时延；多普勒中心**仍用可观测量**（该时延上导频匹配滤波最大的整数列），增益仍由导频估。其余流程完全不变：F0 两轮，第 1 轮未通过校验时用本臂自己的状态触发 `CODELAY` 交换（2 次）。〔Astra：原设计把取整后的真多普勒也给了，增益就不能只归因于时延；而且细化只在中心 ±0.75 内搜索，给真多普勒会偏乐观。〕它回答："第 0 轮时延如果找全，低导频能不能比基线好出有用的量？"
- **判读：配对的低导频余量门槛**〔Astra〕。基线最优 = 基线在 {.05, .10, .15, .20, .25, .30} 上的最好穿越点；A 最优 = A-delay 在 ρ ≤ .20 上的最好穿越点（U/G 平均）。每次配对物理帧自助都重新取两个最小值，保留删失。余量 = 基线最优 − A 最优：
  - 95% 下界 > 0.3 dB → **继续**；
  - 95% 上界 < 0.3 dB → **停（无用）**；
  - 其余 → 不确定，由 Eric 定。
  - 最优 ρ 的集合单独报告，不进判读。旧 ρ 扫描里 .25 与 .30 的配对差只有 0.057 dB [−0.159, +0.263]，最优 ρ 的点估计太不稳。
- A 只是初始化上的乐观参照，不能保证是 B 最终 FER 的上界（迭代译码和条件交换都可能改变顺序）。

### 阶段 B：自相关候选（阶段 A 通过才做）
- **候选生成，只用观测量**〔Astra〕：
  - 锚 = 导频匹配滤波最大的那一列；
  - 在自相关图上取局部峰，**先**按峰值排序，再看真值；
  - 每个峰用导频在前后两个候选位置上的值选一侧，去掉重复的时延，最多取 K = 8 个；
  - 多普勒中心 = k̂_a ± f，取整后截到 ±2。

  第二步读数里的 .832 是"真格子是否进前 8 个竞争峰"，查看位置用了真值，所以不能当实现门槛。改为阶段 0 的预检（见 implement.md）。
- **两个臂**（最终都是 8 个槽，下游容量相同）：
  - **B-rank（主）**：先放锚，再按自相关估计功率（∝ 峰值 / |ĥ_a|²）放候选，不足的用导频原子按能量补满。〔Astra：B-union 会让弱候选再输一次导频能量，而且会改变已有原子的拟合；改用这个更能把候选送进去。〕
  - **B-challenge（次）**〔Astra〕：保留基线的前 7 个槽，第 8 个槽由最强的新自相关时延挑战，多普勒中心按同一规则取。它检验"多一个提名有没有用"。
- 下游完全不变：F0 两轮 + `CODELAY` 交换。

## 3. 设定
- 与 ρ 扫描相同：P1、U/G、N = 1024、LDPC (3,6)、QPSK、已知 σ²、F0 + CSTATE 管线（`rho_sweep_20261119`）。
- ρ ∈ {.05, .10, .15, .20, .30}；基线（F0 + CD）在 .05、.10 两格需要补跑，.15–.30 与新臂在同一批新帧上一起跑（同帧配对，不用旧存档）。
- 新的 400 帧块：按项目已有的存档帧扫描器选一块未用过的帧（G3）。
- SNR 网格按各格的穿越点附近选，沿用 ρ 扫描的选格规则；穿越点用 slot-mismatch 对数插值，按帧配对自助 20,000 次。

## 4. 主判读（阶段 B，冻结前可调）
- **P1 系统最优**：各臂在 ρ 上取最好的穿越点（U/G 平均）。B 臂最优 − 基线最优的 95% 区间上界 < −0.3 dB → **改善**；下界 > −0.1 → **无改善**；其余 → 不确定。
- **P2 最优导频比**：B 臂的最优 ρ 是否 ≤ .20（只描述，附自助区间）。
- 次要：每个 ρ 下 B 对基线的穿越点差；A-delay 与 B 的差距（自相关离"时延全对"还差多少）。
- **诊断**〔Astra〕：同一批帧上，记录第 0 轮、第 1 轮和交换之后三个时刻的漏径功率、按功率加权的多普勒误差、信息位错误数。用来看找回的径是否改善了第一次译码，以及这个改善能否经反馈保留下来。这些只是关联，不作因果结论。

## 5. 竞争假设
| 假设 | 预言 |
|---|---|
| H-acq：低导频崩塌主要来自第 0 轮漏径 | A-delay 大幅改善并把最优点移到 ρ ≤ .20；B 拿到其中大部分 |
| H-est：主要来自低导频下增益 / 多普勒估不准（低导频读数里，"支撑全对仍失败"在低导频下 1,580 帧中有 69 帧，与多普勒误差有关） | A-delay 改善有限；第 0 轮之后多普勒误差高的帧仍然失败 |
| H-loop：捕获够了，但第 1 轮的数据辅助回路在低导频下接不住 | A-delay 只在 ρ ≥ .15 有改善，再往下仍崩 |

## 6. Premortem
最可能的反向原因是 H-est：低导频下即使时延全对，导频估出的增益和多普勒太差，第 0 轮译码失败，回路起不来。阶段 A 正是为了先排除这一点而设，花钱最少。

## 7. 成本
ρ 扫描 3 臂、6 个 ρ、13 个 SNR、400 帧共 8.37 核时。本任务阶段 A 约为 2 臂 × 5 个 ρ，估计 4–6 核时；阶段 B 再加 2 臂，约 4–6 核时。冒烟后按实测外推，上限由 Eric 定。
