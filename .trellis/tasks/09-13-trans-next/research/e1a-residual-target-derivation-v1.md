# E1-A 残差与导频目标：推导及离线判别合同

## 目标、对象与假设

最终目标仍为合法接收机的译码性能—完整成本。本文件只解释固定完整前缀后的导频抵消误差这一局部代理；不从 NMSE 直接推出 FER。将当前观测和反馈冻结，允许它们彼此相关，不假定独立白噪声、正确软判决或真实信道处于有限字典。

H 为真实物理信道，Hc 为保存的估计，p 为已知导频，d 为包含数据功率缩放的真实数据，mu 为此次估计实际使用的软数据均值，n 为同一保存噪声。接收模型 y=H(p+d)+n。真值只进入离线诊断，不允许成为新算法输入。

对固定字典，Ax g 表示重建信道作用于 x=p+mu；g0 为 Hc 的字典投影系数，H0 为其重建矩阵。记 J=Hc-H0，ep=(H-Hc)p。实际拟合残差为 r=y-Ax g0。

## 推导图

接收模型 → 减去 Hc(p+mu) → 数据与信道误差分开 → 加回投影差 → 实际 ridge 输出 → 导频误差变化。全程固定同一状态，最后才讨论可能的统计解释。

## 恒等式 1：实际代理残差

代入后：

`r = ep + (H-Hc)mu + H(d-mu) + n + J(p+mu)`。

这五项通常相关。不能把能量平方简单相加，必须保留全部两两实部交叉项。实际浮点记录可能使保存的 noiseless 与 H(p+d) 不逐位一致；诊断额外保留 `epsilon_saved = y-H(p+d)-n`，并单独报告、限定其相对量级，不能将其藏入信道或判决误差。

## 恒等式 2：抵消误差的真实目标

令 Ap 将同一字典系数映射至导频响应。有限 lambda>0 的 ridge 增量为 Delta=(Ax^H Ax+lambda I)^-1 Ax^H r，P_lambda 为对应的映射 `Ap(Ax^H Ax+lambda I)^-1 Ax^H`。下文简记 P=P_lambda；P 是 N×N 映射，不是数据支撑集合，也不一定是正交投影。

更新后的抵消与原抵消差为 `delta_c = -Jp + P r`。于是：

`ep_new = ep + Jp - P r`。

若选择“不更新”，实际实现原样使用 Hc，delta_c=0；不能把重建投影误差作为一次无意更新。此特殊分支已在 GCV 回放中验证。

对任意实际 delta_c，恒等式：

`||ep_new||²-||ep||² = ||delta_c||²-2 Re(delta_c^H ep)`。

因此减少拟合残差 ||r-Ax Delta|| 不等价于减少 ||ep_new||。P、mu、Hc 都依赖同一个 y，未经额外论证不能把标准固定设计风险公式当作整链无偏风险。

## 条件化范围：为何不能直接将后验 V 当作独立残余噪声

以下是一个已知固定 H 的简化反例，用于限定工作模型，非 AFDM 新定理。对 y=H(p+d)+n，若 mu=E[d|y,H]、V=Cov(d|y,H) 是精确后验矩，则 n=y-Hp-Hd。因此：

`E[n|y,H]=y-H(p+mu)`，

`Cov(n|y,H)=H V H^H`，

`Cov(H(d-mu),n|y,H)=-H V H^H`。

于是 H(d-mu)+n 在给定 y,H 后是确定向量，其条件协方差为零。不能在这一条件化语境中既使用 d 的后验 V，又保留 n 的无条件 sigma²I 并假定两者独立。

这不意味着当前工作残差没有误差，或经典白化必然失败。实际 H 未知、矩为近似反馈，当前 C 的用途是构造一个工作权重；若某算法使用排除当前观测的信息形成 cavity/prior 矩，其假设也与上述精确后验不同。要认领概率意义上的协方差或风险保证，必须先说明消息排除了哪些观测、条件化了哪些变量，并处理对应交叉项。此次白化 GCV 仍按既定合同检验实际收益，不因该恒等式预判结果。

上述已知 H 的条件化恒等式已用 2 个 QPSK 符号的全部 16 个离散状态显式归一化后验核验；连同原分解测试共 5 项通过（0.105 秒）。这是小型代数验证，不新增 G1 结果。
