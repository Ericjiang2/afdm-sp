## 问题与恒等式

块 14 的 W_D_ALL 在整体 H 和 Hp 误差均未优于强对照时译码成功，不能据此断言“估计更准”。Frobenius 误差平均所有输入方向，而一次译码消费特定发送向量。先检验该方向上的误差及与噪声的相关性，再讨论图或消息机制。

对已保存终端输入，设真实信道 H、实际检测矩阵 B、抵消向量 c，已缩放数据 d、pilot p、实际噪声 n。保留数值保存缺口 e_round = y − H(p+d) − n，定义：

```
e_p = H p − c
e_d = (H − B) d
r = y − c − B d = e_p + e_d + n + e_round
e_clean = e_p + e_d
```

完整保存四项 Gram G_ij = <e_i,e_j>，包括所有交叉项；||r||² = sum_ij Re G_ij。分别报告 ||e_clean||² 与 ||r||²，统一除以 N sigma²。前者反映实际输入上的无噪失配，后者还包含自适应估计与噪声相关项，不能称为真实噪声方差估计。

配对 W_D_P/W_D_ALL 的 c 相同。设 delta = (B_ALL−Hc)d，则 r_ALL = r_P−delta，能量变化精确为 ||delta||²−2 Re<delta,r_P>。该恒等式定位实际数据方向的变化，不证明译码因果机制或可部署真值校准。
