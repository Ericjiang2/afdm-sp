# E1-A 软方差与协方差前提核查

目的：在使用已有经典 C=Hc diag(V) Hc^H+sigma²I 前，核对同一保存状态的软均值 mu、实际 CE 方差 V 和真实数据误差是否匹配。这里只诊断其工作假设，不把单块频率统计当作后验分布证明，也不以真值校准算法参数。

复用 G1 32 块×7/8 dB FULL 的末次 DALS9，读取原 mu、finite_variance、Hc，以及同一 physical raw 的 data/noise。真实 data 已含 sqrt(1-rho) 缩放，当前符号能量固定 0.5，不能再乘数据功率。

记录：

- 实际 |data-mu|² 与保存 V 的逐符号数组、总和及比值；零预测方差时比值为 null 并显式报告实际误差。
- 固定 V/0.5 分箱：[0,0.01)、[0.01,0.1)、[0.1,0.5)、[0.5,1]；报告每箱样本数、误差和与方差和，不据这些开发数据选择新阈值。
- |mu|²+V 与 0.5 的最大偏差，仅检查 QPSK 矩一致性；该恒等式成立不等于统计校准成立。
- 不构建 C、不做 Cholesky：利用 trace(Hc diag(V) Hc^H)=sum_j ||Hc[:,j]||² V_j，比较预测数据误差能量与实际 ||Hc(data-mu)||²；另记录实际 ||H(data-mu)||²。
- 同一实际噪声 n 下 ||Hc(data-mu)+n||²、交叉项及预测 trace(C)。保留 n 与决策误差的相关性，不能自动按独立噪声相加。

所有真值访问仅限外部诊断。32A、300 秒、64 MiB、SSH deinlab CPU 单线程；0 新 CE/SVD/F/T/D、外生块或参数拟合。先验证小型显式矩阵 trace、分箱、零方差及无效输入，再冻结脚本与输入哈希，分析后另进程回读。

判读：若软方差严重低估实际误差，不应把现有 C 当作已经校准的最优白化。即使标量能量吻合，也不证明完整协方差形状、反馈独立性或 FER 收益。下一项经典对照的矩阵、权重和强度必须在独立合同内定义，不能从本次真值结果直接拟合逐块权重。CONF/正式 COST 仍暂停。
