# 水声 N256 迁移检验独立限定范围审查

日期：2026-09-14。审查对象为冻结的水声 N256 物理生成、observed-only 接收适配器、LightRun 编排、原始回读审计、汇总 JSON 与结果报告。未审查或执行 RF 性能、独立 CONF、正式 COST、宽带时间伸缩或新训练。

## 结论

**限定范围 PASS。** 未发现需要重跑接收或修改数值结果的问题。320 个科学接收端点、30 个预登记配对比较、物理速率和成本换算均可由保存的逐块行精确重建。结果报告把开发信号、模型限制和非声明边界写清，没有把区间跨零解释为等价，也没有把 pZ 的整数 Gram 正交外推为分数频移下的端到端最优。

## 独立复核

- 从 320 条逐块行重算全部 20 个 `pilot × SNR × arm` 端点。每端点恰含 16 个信道、8192 bit；错误数、BER、错块数、逐块错误、平均时间、每 bit 时间、活动原子、BP 边数、信道 NMSE 与 pilot NMSE 均与结果 JSON 一致，浮点重算最大差为 0。
- 按冻结顺序和 RNG seed 重建全部 30 个比较：20 个同 pilot 方法比较及 10 个 pZ−p0 比较。逐块差、绝对与相对 BER 差、改善/恶化/相同块数、20000 次 percentile bootstrap 区间、低错误量标记、HEAD 实质退化标记和 ±0.002 批内界限标记均一致。
- 工程 2A/45F 与开发 14A/280F 合计 16A/325F/0D；其中 5F 为工程精确重复，320F 进入科学统计。保存记录 47+294=341，回读数组 445+2800=3245。
- N=256、Fb=4000 Hz 给出 64 ms 有效块；CPP=32 samples 给出 8 ms 前缀和 72 ms 总块。512 bit/64 ms=8000 bit/s，512 bit/72 ms=7111.111 bit/s。报告准确限定为名义未编码 payload rate，而非 goodput 或实时处理能力。
- 旧 N1024 与新 N256 的同名 p0 开发耗时换算正确。新批每块快 2.72–3.25 倍，但因每块 bit 数为四分之一，每 bit CPU 成本为旧批的 1.23–1.47 倍。两批物理场景和带宽不同，报告没有把它写成纯 N 因果加速。

## 科学边界核对

- 冻结物理量换算闭合：16 Hz × 64 ms=1.024，保守 `k_max=2`；6 ms × 4 kHz=24 samples；整数候选字典为 25×5=125，公开提名 K=40，扩容对照 K=44。
- 生成器按固定整数 namespace 重放时延、角度、增益、bits 与单位噪声；精确核对 bits/data 映射、p0/pZ、truth 参数副本及关键 metadata。CPP/DAFT 函数从冻结生产源码 AST 提取并绑定源码哈希，显式矩阵与直接传播最大相对闭合误差为 6.11891e-14。
- 接收接口只取得 `y, pilot, sigma2, constellation`。真实 H、路径参数、bits 和物理 metadata 仅用于生成及外部评分。setup 与 receive 的已枚举编码入口调用均为 0；模块导入期没有 LDPC 构造由静态源码路径支持。
- p0@10 dB 的 HEAD−BASE 和 pZ@10 dB 的 BASE−HARD 出现方向反转，但区间均跨零；报告只称观测反向。全部八个 HEAD−BASE/RESID 区间跨零，既未触发明确实质退化，也未形成 ±0.002 批内界限。
- pZ@20 dB 的五臂点估计相对 p0 改善 13.27%–15.37%，四臂描述区间低于零，RESID 区间跨零。该结果支持保留 pZ 为关键参照，不能证明一般分数频移 BER 最优。
- K+4 在 20 dB、p0/pZ 下分别增加 10.24%/10.84% BER，描述区间均高于零。该开发结果反驳“增加提名容量必然改善本场景性能”，但不排除其他经典选择或调度。
