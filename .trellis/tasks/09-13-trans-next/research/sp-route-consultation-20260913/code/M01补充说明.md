# M-01：link/free究竟证明什么

`prepare_from_frame`读取`frame._truth['params']`。共享集合I不是任意当前支撑：它是**当前支撑与真支撑的交集**；几何来自`taps/l_i/k_real`。`physical_cluster_weights`按G0的截断、剪枝、归一化规则建立物理簇。

`link`以已知几何的basis约束系数，从观测y拟合增益；不把真实增益送进LS。但位置和支撑交集均有oracle信息，因此整体不可部署。free同样使用这个共同oracle集合；比较可隔离该集合内的结构效应，不能直接对标正常未知支撑接收机。

源码没有名叫η的字段。本报告的η是抽象的路径几何参数；讨论其来源时应映射到`l_i/k_real`，不要把η误指为真实增益。

紧凑结果见`../evidence/m01-harvest-v2.json`：256开发块，7dB link/free BP FER为0.44140625/0.5859375；该结果支持结构约束值得诊断，不能证明连续参数可被合法而稳定地估计。另有局部物理簇拟合诊断代码，仍需逐项核对信息边界；本轮没有把“找到局部拟合函数”当成合格连续接收机。
