# 水声 N256 关键结论迁移结果 v1

日期：2026-09-14。状态：有限开发检验完成，未执行 RF、独立 CONF、正式 COST 或全量重跑。

## 裁决

**N256 已可运行，但本批不能判为“旧结论无实质变化”。** 冻结学习头相对 OMP/普通残差评分的八个配对区间全部跨零；没有触发预登记的明确实质退化规则，也没有任何比较达到 ±0.002 的批内差异界限。缺乏显著差异不等于等价。

观察到两处关键方向变化：p0@10dB HEAD 比 OMP 多 20 错误比特（+1.17% 相对 BER）；pZ@10dB 软反馈比硬反馈多 51 错误比特（+3.19%）。两者区间跨零，只报告观测反向。旧 N1024 的弱学习收益不能直接迁移为新场景优势。

pZ@20dB 五臂平均 BER 均比 p0 低 13.27%–15.37%；其中四臂未校正描述区间在零以下，RESID 跨零。这是配对试验中的导频效果信号，不是分数频移下 BER 最优证明。普通 K+4 在 20dB 两种导频下分别使 BER 增加 10.24%/10.84%，区间均在零以上；更大支撑预算不能视为必然有利。

当前仍未找到能稳定超越经典性能—成本前沿的合法方法。本批支持继续使用 N256 作为已明确模型边界的开发入口，并把同能量 pZ 与强经典接收机保留为关键参照；不据此修改历史接受主张，不通过调参数追求旧排序。

## 参数及公平性

| 参数 | 本批值 |

| 频率格 / 保守整数 Doppler cap | 15.625 Hz / 2 |
| 有效块长 / CPP / 总块长 | 64 ms / 8 ms (32 samples) / 72 ms |
| 数据 / 导频功率比例 | 0.5 / 0.5 |
| 字典 / OMP 与扩容提名预算 | D=125 / K=40 与 44 |
| 数据 | 每块 512 bit，真正未编码 QPSK |

16 个新独立信道，每信道在两种导频、两个 SNR、五臂之间共享物理路径、数据与单位噪声。p0 为 ZC root7，pZ 为 sqrt(N*rho)e0；均有 128 导频能量及 128 数据能量，无逐帧重标或裁剪。组合波形的实际能量可因数据—导频交叉项不同而变化；等资源指固定分量能量及相同期望总能量，不是每一帧瞬时总能量强制相等。SNR 是 sigma²=10^(−SNR/10)，不是 Eb/N0。

接收机只接触 y、pilot、sigma²、constellation；外部真值仅生成和评分。原 checkpoint 严格加载、没有重新训练，10 outer × 20 BP，F2P 两轮固定配方；新场景本身不是训练分布内确认。

水声信道使用整数采样时延与连续复指数频移，**不含宽带时间伸缩**。8 路径的指数平均功率/随机角度是明确选择的模型，不是实测拟合。物理依据、N 候选计算见 [参数设计](physical-parameter-design-v1.md)；精确实施合同见 [冻结合同](physical-transfer-v1.md)。

## 旧 N1024 的开发耗时对照

只比较同名原导频下的 OMP 和 HEAD、相同 10/20dB；旧批每块 2048 bit，新批 512 bit。旧/新信道不是配对，场景生成、带宽与离散化也改变，故以下是既有 CPU 开发测量对照，**不是纯 N 的因果加速比或正式成本前沿**。

| SNR | arm | 旧秒/块 | 新秒/块 | 每块加速倍数 | 新/旧每 bit 成本 |
|---:|---|---:|---:|---:|---:|
| 10 | OMP_BASE | 2.105550 | 0.666438 | 3.159 | 1.266 |
| 10 | F2P_HEAD | 2.141216 | 0.658072 | 3.254 | 1.229 |
| 20 | OMP_BASE | 2.206814 | 0.812180 | 2.717 | 1.472 |
| 20 | F2P_HEAD | 2.225154 | 0.811878 | 2.741 | 1.459 |

N256 每块更快，但上述每 bit 成本为旧批的约 1.23–1.47 倍。名义未编码有效数据速率 512/0.064=8000 bit/s，计 CPP 为 512/0.072=7111.11 bit/s；未计同步/前导/重传，不能称 goodput。这也不是实时处理能力：当前 Python CPU receive 每块耗时仍高于 72ms。

## 工程、物理核验与证据

13 项单元测试通过；工程 2A/45F、开发 14A/280F 均 exit0。合计 **16A/325F/0D，341 条保存记录、3245 个数组另进程回读 PASS**。其中 5F 是五臂工程重复，状态精确相等并排除科学统计；320F 构成全部20端点。build/receive 编码入口计数均为0，模块导入期无 LDPC 构造另由源码静态追踪支持。

- development: producer 219.703713s，audit 1.799548s；summary SHA `f59c84be6eff25c6a2a8ef3e7fd4469e16ec2e76b2f07f26ab39328b4d400367`；audit SHA `8497e6b79561703c924015d3c92fca89749061b676236c562b22d31f47fea20d`。

全16块最大 CPP/独立矩阵闭合相对误差 6.11891e-14。
p0: 组合波形 PAPR 5.664–8.210 dB，峰值功率 3.511–6.532；整数 Gram 最大相干 0.786701、条件数 12.3602。
pZ: 组合波形 PAPR 5.425–7.863 dB，峰值功率 3.642–6.384；整数 Gram 最大相干 5.80062e-14、条件数 1。

pZ 的整数 Gram 正交性已核对，不能把它外推为分数频移端到端最优。p0 最大相干性在这个新离散网格上较高；活动原子约90–99，占N的比例也明显高于旧配置。这些是后续解释的线索，当前没有单因素干预，不能把 BER 变化归因给其中一项。
