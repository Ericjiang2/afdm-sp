# 第一性原理与候选取舍

## 不变目标

目标是信息报文错误风险与完整计算成本，而非单独减小 NMSE、残差、局部二次目标或软比特 NLL。当前主张缺口是相对增强经典参考的可复用贡献。下列推导是研究设计，不是新增性能结论。

## 八条可检验路线

| 路线 | 可区分的解释 | 首个低成本判别 | 停止/后置条件 |
|---|---|---|---|
| CE 中介自信息 | 自身先验影响伪导频，再影响信道和自身外信息 | 同一冻结前缀，先验仅进入检测器 vs 同时进入 CE；两尺度中心差分 | 中介影响不稳定/很弱，或修正不改变风险 |
| 参数域线性响应/近似空腔 | 去除可计算的局部返回路径，而非统一降置信度 | 解析 CE 方向导数与有限差分对账，再与标量匹配控制比较 | 标量完全覆盖收益；需每比特重跑完整链才有效 |
| 参数不确定性传播 | 现有 Gamma 只作用于 CE，检测端仍把估计参数当确定值 | 合法侧信息/交叉拟合下的小参数协方差与候选度量 | 同一 y 后验冒充独立先验；协方差无法校准 |
| 精确移位图计算 | 稠密 H 的重复构建/扫描不是接收算法必需操作 | 参数域阻尼/阈值与原核相等，规则边布局与 BP 结果一致 | 位移碰撞或额外项破坏前提；完整成本收益过小 |
| 同预算跨模块调度 | 下一次 CE/BP/LDPC 的边际价值依赖状态 | 对照固定 REFRESH4/47、简单阈值与同平均预算组合 | 只是多译码获得收益，或控制器成本抵消收益 |
| 码字危险方向 | 同一 NMSE 的误差可能在码字边界方向产生不同风险 | 已有错误码字/合法候选的度量差、观测可测代理预测验证 | 依赖真发送比特才能作在线决定；仅相关性 |
| 小可枚举联合模型 | 工作 q 的错误而非局部代数导致 CE 更新失效 | 极小模型中精确外信息、自身先验不变性、点估计近似比较 | 只能解释小模型而不能预测 N=1024 的现象 |
| 软支撑/模型平均 | 单支撑压缩了有效后验歧义 | 候选覆盖与权重有效性先通过，再做完整风险 | 原池 oracle 无优势或 ESS 退化；不继续旧195-solve交换网格 |

排序：先自信息判别和精确计算；参数修正必须由机制支持；同预算调度是独立备选；参数不确定性、码字方向、小模型可辅助辨别；软支撑暂后置。大网络与连续多普勒不进入首批。

## 自信息应怎样被隔离

在独立比特先验的检测模块工作模型中，精确外信息对自身先验不变：对其它比特和信道参数边际化后的两项似然比不包含该比特的先验因子。有限 loopy BP 不自动满足此性质。

令检测输出为 `L_D,j = f_j(y, g_hat(L_A), L_A)`，`L_E,j = L_D,j - L_A,j`。固定支撑的实参数化下：

`d L_E,j / d L_A,j = partial f_j / partial L_A,j - 1 + grad_g f_j · d g_hat / d L_A,j`。

普通减先验只去掉显式加项。需要量出 CE 中介项，不能先假设它有害。首个实验只变更一次码反馈后的一个比特，比较两条后续单次 CE+BP：

1. 检测器先验扰动，CE 使用原来的码后均值。CE 输入和 H 必须与零扰动对照相等。
2. 相同扰动同时进入检测器和 CE 均值。两条输出的中心差分之差隔离该局部 CE 中介路径。

两条前缀、支撑、噪声状态和其它先验完全相同；禁止按真值选择比特。只选 `abs(channel+prior)<8` 的未饱和比特，并记录无合格比特的块。扰动大小 0.1 与 0.05，记录稳定性，零值不能自动解释为无历史自影响。此三轮前缀诊断不是最终完整接收性能。

## 结构化 CE 方向导数

冻结旧增益、噪声、支撑、lambda 和正则 Q，`B=A^H A+lambda I+Q`，`b=A^H y+lambda g_old`，则

`dg = B^{-1}(dA^H(y-A g) - A^H dA g)`。

若 Q 或 lambda 随扰动变化，还要显式加入其导数，不能漏掉。QPSK 未截断均值的实比特导数是 `a/2 * sech²(L/2)`，虚比特多一个 `i`。整数原子 `U_i x[n]=d_i[n]x[n-s_i]` 使单符号均值扰动只改变 A 的 K 个位置；可复用 K×K 分解。检测器 Jacobian 的成本另计，不能称整链梯度免费。

固定设计的行删除公式 `g_without_n = g - B^{-1} a_n r_n/(1-h_n)` 是标准恒等式。这里 A 本身来自 y，删一行不能删除 A 中继承的观测影响，因此不称严格空腔。

## 精确计算的可用前提

若活动整数位移模 N 唯一、原子相位模长为1，`H[n,n-s_i]=g_i d_i[n]`。支撑固定时，矩阵阻尼可移到增益；仅依赖幅度的阈值/软掩码可移到原子增益。BP 图可从规则循环边生成，无需每轮扫描 N² 个元素。

必须核对数值相位误差、相同位移的叠加、支撑交换、逐位置掩码和 learned 额外项。当前完整链实际使用软掩码，不能误写成单纯硬阈值。浮点求和顺序改变可能导致末位差异；代数等价、数值近似一致、逐位重复和 FER 非劣是四种不同证据。

## 晋级与止损

首批目的为机制判别和参考资格，不为显著性。中介候选需要：有限差分稳定；保持冻结输入/前缀；对无饱和比特具有可重复影响；其修正相对同输入标量控制在完整链上有连贯收益。否则停止具体构造，保留数据并改 CSV。最终确认固定样本，不因看过 p 值延长或换终点。


## MECH-01 固定状态推导合同（2026-09-13）

**Target / Status：COHERENT AS STATED，限单次 CE 的局部实方向导数。**
顶层目标仍为 FER 与完整成本；这里的对象是工作接收机的局部自身先验响应，不是风险改善定理。

- 固定量：同一 y、支撑、CE 前 H 与增益、sigma、lambda。只对译码后的交付先验 L_A,j 加实扰动 δ；译码输入和该次译码输出不变。
- 实验只用 mean CE，因此 Q=0。若之后研究 Gamma/ridge，必须另行计入 dQ 或 dλ，当前导数不能直接沿用。
- 记 B=AᴴA+λI，b=Aᴴy+λg_old，B 正定。实标量微分给 dB=dAᴴA+AᴴdA、db=dAᴴy（恒等式）。
- 微分 Bg=b 得 B dg=db−dB g，于是 dg=B⁻¹[dAᴴ(y−Ag)−AᴴdA g]（固定条件下命题）。
- QPSK 均值 m=.5[tanh(L_I/2)+i tanh(L_Q/2)]，未饱和 bit 的导数为 .25 sech²(L/2)，Q 分量另乘 i。整数原子将该单符号导数映射到每列一个已知位置（恒等式）。
- 以相同实扰动构造检测独占路径 d 与 CE+检测路径 c。两路径中心差分之差是此实验定义的 CE 中介总影响；它包含 CE 后阻尼、掩码、导频抵消与该次 BP，不称单独 ∂f/∂g 已被隔离。
- 另存 BP 第三次 capture 的 channel_llr；末端 BP/LDPC 只算实际资源和诊断输出。三轮接收不替代最终十轮性能确认。
- 选比特只看 channel+prior 与 prior 幅度，每个 I/Q 分量取最前合法索引；无合法 bit 单独登记，不按真值或已有错误选择。

**Verification map：** 独立增广最小二乘有限差分 → QPSK/整数原子有限差分 → 真实 tiny LDPC 交付语义测试 → N=1024 零扰动、冻结前缀/CE 与两尺度差分 → 完整方法证据（后续）。浮点 complex64 导数允许出现舍入平台；报告量化误差和绝对尺度，不强行把不稳定比率解释为机制为零。

**Open risks / Non-claims：** loopy BP 掩码/截断可不光滑；自信息响应非零不自动意味着有害；行删除不等于完整空腔；任何修正须与统一尺度控制比较。
