# E1-A 固定 G1 终端导频响应判别

用户“好”批准恢复 E1-A；独立确认与正式成本保持暂停。本协议先验证 oracle 是否有任务端收益，尚无合法估计候选，不宣称新方法。

复用已通过 raw 审计的32块 G1 FULL：同一原始直接 CPP 观测、Hc、最后一次合法 check prior、物理 sigma2、温度1、20步 BP、LDPC maxiter50/clip20。A0 输入 z=y−Hc p；A_ORACLE 输入 z=y−Htrue p。两臂数据算子始终 Hc，图阈值1e−4、先验和尺度相同。真值仅用于 oracle 导频响应与外部评分；oracle 不具部署资格。保存 cancellation、z、Hc、prior、graph、完整软硬译码输出及所有绑定哈希。

先原工程块0/20×7/8dB，两臂8T及8D，120秒、1GiB、CPU单线程；每块先精确复现 A0 的 mu/var/llr/decoded/info_hat/x_hard/decode_ok/raw_llr 及 finite_message。接线及另进程回读通过后，对其余30块执行同一脚本/接收机两臂120T/120D，600秒、4GiB。工程数据纳入32块一次，不重复已有调用。不在两块结果上筛选或调参。T含一次BP和一次LDPC；D为额外译码回放。另进程审计只复核保存数据/代数，不新增T或D。

全部128终端状态及128译码回放分别核验预约/文件/数组哈希、原输入身份、实际图H/边数、抵消代数、消费先验、APP/外信息、评分及精确D输出。A0不一致或任何身份不一致立即失败，保存失败预约与已完成记录，不放宽精确约束。开发必须绑定工程PASS及同一脚本哈希。所有输出位于新目录，冻结源码5c0fac1e不改动。

主判读为每个SNR的配对信息FER：列出旧失败、oracle失败、救回、新增错误与信息位错误。进入合法估计仅是开发筛选：至少一个SNR净减少失败，另一SNR不增加失败；否则停止此固定前缀导频响应路线。不得按显著性追加样本，不能将此筛选解释为统计确认。信息位错误/NLL/导频误差只解释，不替代FER门。32块及两个SNR共用外生变量，无独立确认声明。

即使oracle通过，也不代表真实Hp是有限BP的FER最优输入，不证明可实现收益；后续合法A-fine仍需面对相同表示A0、合理A-wide及普通A-scale。此次只改变终端；不能推广到重估前缀、先验或整链。耗时只是诊断成本，完整在线成本暂停。

工程 v1 在读取 FULL 元数据时错误索取仅 STOP 导出键 terminal_executed，0T/0D、3.824秒后退出1；失败原件保留。v2改用既有 check_calls 交叉核验实际 terminal_BP=1、LDPC_calls=4，再检查实际消费标记。该变更修正读取契约，未改变科学调用或数值阈值。

工程 v2 首个A0精确回放通过，1T/0D后在拼D来源时索取LightRun.call返回record不存在的sha256而失败（3.473秒）。v3从run.records中的文件entry取SHA；绑定旧T文件9c8074c3并复用，新增预算7T/8D，工程逻辑总8T/8D。旧失败及耗时保留，无科学原语修改或重复T。
