# 完整 CPU 接收机初次剖析

8 次原工程输入回放（2 块×7/8 dB×MEAN/REFRESH47）全部逐元素匹配既有数值输出，保存后回读也一致。源码提交 `2b695177`，现有计时观察器/图合同 18 项测试通过；远端退出码 0，外部耗时 30.95 秒。

平均每次接收机计时 1.6674 秒。其中 outer BP 为 1.0186 秒（61.1%），末端 BP 为 0.1033 秒（6.2%），H 重建为 0.0359 秒（2.2%），CE 设计矩阵为 0.0217 秒（1.3%），CE 小系统求解为 0.00335 秒（0.2%）。完整算子数据与哈希见 [structure-profile-v1.json](structure-profile-v1.json)。

这些是带原始诊断采集的工程时间。BP 时间包含图哈希/诊断回调，尚未单独测量；部分函数可嵌套，不能把表项相加当总成本。没有将剩余时间强行归因于稠密矩阵，也没有依据此结果宣称部署加速比。

72 个 CE 状态未出现模 N 位移碰撞，只证明所测状态满足这个前提，不保证任意支撑配置。结构路线仍需处理相位舍入、阻尼、软掩码、逐行边排序、额外项和完整输出。

裁决：只优化 H 重建的收益空间有限；后续优先分离 BP 图诊断开销，检查 BP 投影和图输入的等价计算。QPSK 的两个实分量因子化属于标准恒等式；若用于优化，必须保留原 BP 方程、方差地板、温度与阻尼语义，并与非圆/非 QPSK 路径明确区分。STRUCT-01 尚未完成，正式 COST 也未开始。
