# SYN-02：跨物理信道 Γ 的有界候选度量合同（设计审查）

## 裁决

**可做一个有界、可计算的 crossfit plug-in 诊断；它不是精确信道边缘似然，也不是新检测器收益实验。** 已审计的 N1024 UWA 共有16个物理信道，每信道 p0/pZ×10/20 dB 四条完整接收链，每链9个 CE observer 状态。任一目标信道 `b` 的校准只用其余15个物理信道在同一 `(pilot,SNR,t)` 条件的状态，目标 `b` 的两导频、两 SNR 和九轮状态全部排除。只评估预定 `t=1,9`、索引0–39的单符号候选对比，故16×2×2×2×40＝**5120个候选差**；不增加物理信道、F、BP或LDPC。

跨信道校准使 Γ 不由目标 `y` 拟合，但目标均值仍来自对同一 `y` 做的 CE，目标软数据和活动支撑也依赖该 `y`。下面的评分是固定这些选择后的**工作模型代数**；不能称 `p(y|c)` 的精确独立先验积分、独立后验、部署 LLR，或由5120个相关比较推出 FER/CONF 结论。

## 统一的 D275 坐标与误差样本

冻结 N1024 的 `c1,c2,q=2Nc1=11,W=5,l=0..24,k=-5..5`。整数列 ID 为 `11l+(k+5)`，共275列。物理位移为 `11l+k`，不是候选宽度产生的可调位移；这个域的275个 circular offset 互异。所有信道使用同一 AFDM Python/CPP 已验相位约定、同一 gain normalization 和同一物理字典。对每条已存 CE 状态，把 `support_delays/support_dopplers` 和 **CE-local `g_solution`** 零嵌到 D275，检验 support 唯一、合法、与 `A` 列数一致。不能用 `g_previous` 充当解；`g_solution` 是 `soft_gain_update` 后、tap correction 与 `gamma_h` 阻尼重建前的增益，不能冒充终端 `H` 的系数或独立后验。N1024 接收机只有 `cand_active_rel` learnable head，仍须核实该解与本状态 CE 残差对应。

其他15个信道的真实物理 `H` 只用于**离线校准**：按每个整数原子 `U_j` 的唯一位移/单位模相位计算 `g^proj_j=tr(U_j^H H)/1024`，用已审计 `H`、相同 `c1/c2` 和不截断的物理 CPP 约定；每原子只读取1024个矩阵元素，不构造275个 dense `U_j`。这是物理 `H` 在有限 D275 子空间的 Frobenius 投影系数，**不是**连续多普勒路径的真实参数。校验 `||H-P_DH||_F²=||H||_F²-1024||g^proj||²≥0` 的浮点容差，逐信道记录该支持外/表示尾项及相对于 `||H||_F²` 的比例。只把 active `g_solution` 零嵌 D275 会把未选但可表示的真系数放进估计误差；校准与评分都不得把这部分称为热噪声。

对目标 `(b,pilot,SNR,t)`，以另15个不同物理信道的同条件误差 `e_j=ĝ_j-g^proj_j` 为唯一训练样本。冻结 `m_e=mean(e_j)` 和中心化因子 `U=[e_j-m_e]/sqrt(14)`，于是 `Γ=UU^H` 为半正定、rank≤14；不根据目标真值、候选结果或 FER 调超参数，不加对角 jitter。目标 plug-in 均值为 `m_0=ĝ_b-m_e`，其中 `ĝ_b` 仍来自目标同帧 `y`。训练折的物理信道 ID、15个 A/F/NPZ 哈希、误差定义、`m_e/U` 哈希和目标被排除的四条件/九状态清单必须进入原始审计。p0/pZ 与10/20 dB 在同一个物理信道内相关，不能把60条链当60个独立 Γ 样本。

训练误差可能非圆对称。另存中心化伪协方差 `P=(1/14)Σ(e_j-m_e)(e_j-m_e)^T` 的 Frobenius 比 `||P||_F/||Γ||_F`、均值偏差 `||m_e||` 和 rank；**proper complex Gaussian** 评分忽略 `P`，这些量只作失配诊断，不倒推“已验证圆对称”。rank≤14使 D275 的多数方向无估计方差；这是一项显著限制，不能把低秩当完整后验。热噪声 `σ²=10^{-SNR/10}>0` 使下面的观测协方差即使 Γ 奇异也正定。

## 候选对与三项差分

每个目标状态先保存原 `mu_t`、`ĝ_b`、观测 `y,p,σ²` 和来源哈希；**评分接口不接收目标真 `H/data`**。索引0–39固定，未看错误后不重排。每个索引 `i` 的两个候选只改 `mu_t[i]`：实部固定为 `+0.5` 或 `−0.5`，虚部为 `0.5·sign(Im mu_t[i])`，虚部为0时固定取 `+0.5`；其他1023个符号保持原软 `mu_t`。这不是完整 QPSK/码字空间的候选搜索。**本工作评分省略候选先验，先验项按定义为0**；同帧软 `mu` 不支持断言真实两候选先验相同，更不能称 posterior odds。目标真数据若用于结果解读，只能在两分数和候选顺序保存后由独立评估步骤读取，不得进入校准或候选选择。

设 `D_x=[U_j(p+x)]_{j=0}^{274}`，`Z_x=D_x U`，`r_x=y-D_xm_0`，`C_x=σ²I+Z_xZ_x^H`。先在原软 `mu_t` 处固定 `C_0=C_mu`。以 `+` 减 `−` 为方向，保存三个**可加闭合**的差：

1. **固定协方差的候选均值项**：`Δmean = r_+^H C_0^{-1}r_+ − r_-^H C_0^{-1}r_-`。`r_±` 包含候选 `D_±m_0` 的变化，但 `C_0` 不变。
2. **逆协方差变化项**：`Δinverse = [r_+^H(C_+^{-1}−C_0^{-1})r_+] − [r_-^H(C_-^{-1}−C_0^{-1})r_-]`。
3. **logdet 变化项**：`Δlogdet = logdet C_+ − logdet C_-`。

检查 `Δtotal=Δmean+Δinverse+Δlogdet` 与直接 `[(r_+^H C_+^{-1}r_+ +logdet C_+)−(r_-^H C_-^{-1}r_-+logdet C_-)]` 在预先设定的 complex128 容差内闭合。这个分解对**给定** `m_0,U,σ²,mu` 的工作评分是代数恒等式；每项不等于真实 BER 机制，不能把 `Δinverse+Δlogdet` 单独归因为保留了真实后验不确定性。

## 低秩计算、成本与失配边界

不用1024×1024逆，也不用奇异 Γ 的逆。令 `K_x=I+Z_x^H Z_x/σ²`，其尺寸至多15；Cholesky `K_x=L_xL_x^H`，则

`r_x^H C_x^{-1}r_x=||r_x||²/σ²−||L_x^{-1}Z_x^Hr_x||²/σ⁴`，`logdet C_x=1024 logσ²+2Σlog diag(L_x)`。

候选改变单个输入符号时，q11/W5的275个物理 offset 互异，`D_±−D_mu` 每列只改一个已知输出行；先构造目标的 `D_mu m_0` 与 `Z_mu`，再按275个行位置散射更新均值和低秩因子。每候选必须重算自己的 `K_x`/logdet，不可固定白化矩阵后冒充候选相关项。数值预检核 `C_x` 正定、Cholesky 完成、Woodbury 与小 N dense 对照；不静默改用对角 ridge。

预算按**比较**记：64F×2状态×40索引＝5120次 `Δtotal`，两候选评分各一次为10240个候选协方差计算，另有128个状态的固定 `C_mu` 计算和128折统计 Γ 校准拟合；不要把10240个单分数说成5120个独立样本。工程2物理信道的640次比较包含在5120内，开发14信道剩4480；所有16信道的 A/F/raw audit 必须先完整 PASS，工程目标的训练也需要另外15个信道。单线程 CPU、阶段≤2小时墙钟、≤20GiB新增峰值磁盘与内存预检；失败、重试和 baseline `C_mu` 都单独计费。0新增物理信道、F、BP、LDPC或接收器/神经网络重训。

物理 `H` 含连续多普勒，`R=H-P_DH` 的候选响应没有进入 `C_x`；热噪声 `σ²I` 也没有吸收由同帧选支撑、软反馈误差与 `R(p+d)` 引起的相关性。本次只保存每物理信道 `||R||_F²` 与比例；不计算 `R(p+d)` 响应或交叉项，所以不能据本诊断确定它们的大小。若投影尾项或伪协方差大，只报告**工作模型失配线索**，不按结果加噪声 floor 或声称模型精确。

## 最小准入与报告

- 绑定 NSIZE 两阶段 `COMPLETE` summary、独立 raw-audit `PASS`、16个唯一物理 A、64个 F、每 F 九 CE observer 状态，以及本脚本/合同/来源 manifest SHA。先验证投影相位、D275 ID 与每条 CE support/A/g_solution 同一列顺序；真实 `H/data` 只给校准折和保存分数后的评估层。
- 在任何目标比较前，对16个物理信道分别验证训练集合恰是其余15个 ID，并按同 `(pilot,SNR,t)` 重算 `m_e,U`；每 fold 把完整信道所有条件排除。缺 NPZ、几何、真值血缘或数值正定证据即停止该 fold，不补跑链。
- 原始行逐目标/索引保存候选值、固定状态 SHA、训练15信道 SHA、`m_e/U` SHA、rank/伪协方差比、`σ²`、六个原始分数标量、三项差分、闭合误差和调用数。阶段保存墙钟与 CPU 时间。先报告16个**物理信道**各自的均值和分布；fold 训练重叠且每信道320个比较高度相关，不用 naive 5120行 bootstrap 或独立 CONF 区间。
- 评分结果即使倾向真符号，也只支持“在这16信道、已存同帧 CE 状态和固定单比特候选下，crossfit 校准的候选相关工作评分发生了何种差异”。没有对合法接收器反馈、FER、部署成本或真实条件后验作验证；阴性不排除其他 Γ、候选集合或方法。

本文件只给有界合同。当前 SYN 缺 Γ 记录仍然正确：已有 NPZ 不含独立 Γ；需要上述从其余物理信道的真值投影和 CE 状态派生的新**离线**校准证据，不能把原 `Q`、`finite_variance` 或同帧 CE 的 `g_solution` 直接改名为 Γ。
