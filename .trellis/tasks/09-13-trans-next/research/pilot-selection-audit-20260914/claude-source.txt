  二、三个新结果

  A. W=3 偶 b 族：0 dB、全 bin、正交、三环近零混叠——但总量几乎不变。

  b=338 或 686（时域 chirp，b 偶 → 5−b 奇 → DAFT 域全 1024 bin 非零）：单射，±4/±5/±6 环混叠 0/6/6（各 206 个尾原子）。把域外项和诱发偏差加总：

  │ 导频  │  W  │  域外   │ 诱发偏差 │  合计  │
  ├───────┼─────┼─────────┼──────────┼────────┤
  │ a=2   │ 4   │ 0.03803 │ 0.03669  │ 0.0747 │
  ├───────┼─────┼─────────┼──────────┼────────┤

  全部设计落在 0.068–0.075，相差 10%。原因：尾环在模 N 下稠密，护带只能吸收有限几环，更远的环必然重新落回字典频率；合计 ≈ 域外(W) + 占用率(W) × 护带外尾能量，对 W=4 是 0.038 + 0.905×0.033 ≈ 0.068，对 W=3 是
  0.049 + 0.704×0.030 ≈ 0.070。在固定字典 LS 这个指标上，"选择污染较小的导频"只有约 10% 余量，GPT 的 M3 目标函数把二阶量放在了一阶位置。

  B. 稀疏支撑下单路径的尾偏差为零，尾偏差是多径耦合量。

  把 S 限定为路径自身的 5 个 |m|≤2 原子，ν=0.37 与 0.15，对 p0、a=970、b=855、b=338 四种导频，诱发偏差均 ≤ 0.001×域外。原因：同时延不同 k
  的原子对任意周期自相关理想的导频都正交。尾偏差只在另一条路径的原子恰好占据本路径尾环的混叠频率时出现。GPT 的全字典 S 是这个耦合的上界，不是 24 原子接收机的实际值。推论：G1 失败块 7
  倍系数误差的三个候选解释（尾偏差、伪原子选入、错误反馈）中，尾偏差预计最小；伪原子选入的能量会直接计入"系数项"，需要单独分出来。三层 oracle 加分解仍是裁决实验，GPT 此前的判断成立。

  C. 组合波形 PAPR 不是判别量。

  300 帧随机 QPSK、ρ=0.5，A^H(p+d) 的 PAPR 均值 / 99 分位：p0 8.02/9.29，pZ 7.66/9.25，a=970 8.28/9.67，b=855 7.66/9.20，b=338 7.68/9.28，纯数据 8.68/10.56。数据主导，导频间差 0.6 dB。导频单独 PAPR 的 0 dB
  与 3 dB 之争在 SP 里没有实际权重。

  三、chirp 导频的真正杠杆在哪

  不在尾项，也不在 PAPR，而在首轮支撑选择。p0 在 ±4 字典上最大相干 0.824，首轮 OMP 在扩域上会把不同 (l,k) 混淆；chirp 导频使全字典正交，匹配滤波是一次 FFT，选择无混淆。这与 GPT 关于 FFT
  筛选的观察一致，但它应当成为 M3 的主指标而不是附带优势。反馈后 DA-LS 的设计矩阵是 U(p+μ)，正交性不再保持，所以导频的作用集中在首轮和支撑决策，后续轮次由数据主导。

  据此 M3 的预注册指标改为：首轮 OMP 真原子命中率与伪原子数、以实际 S 计算的 J 三项、以及 ±4 下的 s_{a|S} 分布；不再以尾污染排序为主。

  五、与 GPT 的分歧

  只剩一处实质性：M3 的目标函数。GPT 主张按尾项污染选导频；我的两个新结果表明尾污染在固定字典上近似守恒、在稀疏支撑上接近零，M3 的收益若存在只能来自首轮选择与可辨识性。其余全部一致，包括不把 a=2
  定为最终导频、不认领新颖性、文献边界。

  新颖性上补一句：时域 chirp 叠加于 AFDM 数据之上，与 AFDM-ISAC 中专用 chirp 导频的文献相近，需要专项核查；可辩护的差异只剩"固定数据 c₁，导频 chirp 率独立选取以满足整数字典单射"这一条，且 Zhang JSAC 定理 5
  联合设计 c₁ 与导频的框架必须逐式对比。
