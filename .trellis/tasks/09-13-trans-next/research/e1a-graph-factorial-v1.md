# 固定白化抵消的检测图二因素判别

依据：实际观测分解已完成，标量误差不足以解释块 2/14 的译码差异。停止追加同类均值分析，改为直接终端干预。此为经典机制判别，无新颖性或 Trans 达标声明。

## 固定设计

H0 是已保存 W_D_P 的检测矩阵，H1 是同状态 W_D_ALL 的检测矩阵。两者的 cancellation、z、物理 sigma²、最后 prior 必须逐数组完全一致。使用实际 CPU complex128 检测器的掩码 M0 = torch.abs(H0) >= 1e-4；不按 abs² 判边，不扫阈值。

```
G_REWEIGHT = where(M0, H1, H0)
G_ADD      = where(M0, H0, H1)
```

G_REWEIGHT 只更新原边域权重，保留域外原 H0；域外本就低于阈值。域内 H1 可能跌破阈值，因此必须称“原边域重加权/移除”，不能声称图完全相同。G_ADD 保留原活动边权重，只在域外采用 H1。与已有 H0/H1 构成两个因素的四个角；不重跑已经完成的端点。

四角均固定白化 cancellation，而不是按各自 H 重新计算 Hp。固定 BP20、温度1、LDPC50、LLR clip20、已有 checkpoint7 prior、原物理噪声。禁止阈值补偿、真值选边、噪声重估或重跑 CE。
