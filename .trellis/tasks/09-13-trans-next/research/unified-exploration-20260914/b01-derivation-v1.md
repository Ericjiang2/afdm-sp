# B：候选判决稳定性的条件与边界

## Target

严格验证固定有限候选集合上的欧氏度量扰动和 m/2 充分条件；区分合法可观测量、oracle 解释及实际 BP/有限码长译码。

## Status

COHERENT AS STATED。命题适用于其固定候选/唯一最佳/同一欧氏度量假设，不能直接认证 BP 或 BER。

## Invariant Object

候选 c 的完整接收残差能量 D_H(c)=||y-Hs(c)||²，其中 s(c)=p+d(c)。比较的是同一 y、pilot、候选集合及外生噪声下的判决，不是单独的 NMSE。

## Assumptions

- H、E、y、s(c) 均为有限维复数，H 与 H+E 作用于同一坐标。
- 候选集合 C 非空、有限、固定；候选包括已知 pilot。最佳候选 c* 在 C 中唯一。
- 原间隔 m=min_(c≠c*) [D_H(c)-D_H(c*)]>0。
- 接收器严格选择最小欧氏度量。若有相同固定先验，可将其明确加入基础度量；先验变化不在本命题内。

## Notation

r_c=y-Hs(c)，e_c=Es(c)，δ_c=D_(H+E)(c)-D_H(c)。所有范数为欧氏范数，矩阵2范数为谱范数。m 与 max|δ_c| 若以真 H 定义，通常仅在离线评分可得。

## Derivation Strategy

从全残差平方展开 δ_c，再比较任意竞争候选与 c* 的差；最后检查哪些信息无法由实际接收器取得。

## Derivation Map

1. r_c→r_c-e_c 的平方差（恒等式）。
2. 两候选差的三角界（充分条件）。
3. 固定集合、唯一性、覆盖和 prior 消费的反例。
4. 将可观测候选间隔限定为风险代理，保留到实际 BP 的待验证步骤。

## Main Derivation

**恒等式**：δ_c=(r_c-e_c)ᴴ(r_c-e_c)-r_cᴴr_c=-2 Re(r_cᴴe_c)+||e_c||²。二阶项不可省略后仍称恒等式；一阶式只在有误差控制的局部近似中使用。

**命题**：若 max_(c∈C)|δ_c|<m/2，则唯一最佳候选不变。因为对任何 c≠c*，D_(H+E)(c)-D_(H+E)(c*)≥m-|δ_c|-|δ_c*|>0。非严格 ≤ 只能保证不产生严格更小者，可能形成并列；不能保证同一 tie-breaking 输出。

**更直接的条件**：逐竞争者有 δ_c*-δ_c < D_H(c)-D_H(c*) 即足够。统一 m/2 界可能保守，特别是所有候选共有相同度量偏移时。不得把该条件不满足解释成判决必变。

**范数充分界**：若所有候选 ||s(c)||≤S、||r_c||≤R 且 ||E||₂≤η，则 |δ_c|≤2RηS+η²S²。真 η 未知时不能从两个估计器的分歧直接得到此证书；H_q-H_ref 只能描述二者差异，不自动上界任一相对真 H 的误差。

**同 NMSE 不同判决的显式例子**：标量复信道 H=1，y=0.05+0.8j，QPSK 候选实虚部各±0.5。E1=0.2 与 E2=-0.2j 有同样 Frobenius 范数；前者保持原最佳，后者改变其实部符号。误差方向和候选残差对齐，而非单独误差能量，决定交叉项。

## Remarks and Interpretation

- 在线允许 y、pilot、sigma²、已计算软消息和由它们构造的有限候选；候选间隔和生成异常可观测。
- 真 H、真发送向量、真实错误量与“真候选是否遗漏”仅在隔离的离线评分端。不能假设遗漏真值可在线识别；低间隔不是遗漏检测器。
- 可用同一符号域中两种合法 H 估计比较欧氏候选变化，但它只能预测候选度量的敏感性。要选择精度，还须证明对新信道的实际错误/成本有增量。
- 不同物理支撑可通过统一完整矩阵 E 比较；不能将不对齐的系数向量直接相减替代 E。

## Boundaries and Non-Claims

1. **并列**：H=0、y=1、候选{-1,+1}时m=0；任意小正扰动即可改变按固定索引选中的候选。
2. **候选遗漏**：H=1、y=2、C={0,1}时唯一最佳1在E=0下稳定，真实发送2却不在集合。稳定不等于正确。
3. **集合变化**：E=0也不能保证加入更好候选后输出不变；自适应候选生成须单独记账和验证。
4. **先验/消息饱和**：BPSK同一H、y下加入反向强prior可改变判决而E=0；APP先截断再减prior与先减再截断也不同。这些是消费边界的标量反例，不是已运行N256 BP的性能证据。
5. **BP**：loopy Gaussian BP、有限轮次、边阈值、阻尼、软方差、候选投影及其数值裁剪并非固定集合精确最小化。尚须验证最佳候选的一致性、proxy留出预测、额外计算和完整接收作用。
6. **LDPC**：译码器消费LLR和图迭代，原集合命题不能保证有限码长FER。本阶段实际新接收为未编码；旧编码结果只作历史机制，不混用端点。

## Open Risks

候选覆盖不足、BP输出不等于候选最小度量、只有oracle误差有解释力、代理的选择偏差及计算成本。B-02必须对照简单误差代理并保留所有救回与新增错误，诊断相关性不作因果主张。
