# 设计

## 1. 键与状态

键取 U/G × ρ.3 × {6, 7, 8} dB × 帧 4000..4049，共 300 个，与 E-3 主跑的帧重叠。重叠没有关系：本检查的结局是合成 NMSE，不是 E-3 的结局。

每个键按 E-3 管线依次运行：P1 帧，第 1 级导频 SBL，第 1 轮检测与译码。得到 μ、v、h_true（真径的时延、Doppler、增益）以及候选集；候选集与 E-3 第 2 级的构造方式相同，使用软均值字典。

## 2. 合成观测（模型匹配）

- 对每个 AF 域符号，x̃_n 从译码 APP 给出的 QPSK 逐符号后验中抽样：两个分量各自是 ±a 的二值分布，概率由 APP LLR 决定，a 与 `moments` 使用同一个尺度。这样 E[x̃] = μ、Var[x̃] = v（G1 断言）。
- Y_syn = B(pilot + x̃) h_true + CN(0, σ²)。B 与真径响应的构造方式和 E-3 的约定检查完全相同。
- 每个键独立抽 R = 3 次（seed 为固定函数），对 3 次的结果取平均。

## 3. 变体（只在合成观测上运行第 2 级 SBL）

| 变体 | 字典 | Γ_var |
|---|---|---|
| S-diag | B(pilot + μ) | Σv·I |
| S-cov | B(pilot + μ) | 完整 Γ(v) |
| S-hard | B(pilot + hard(μ)) | 0 |
| S-genie | B(pilot + x̃) | 0 |

每个变体的超参、筛选、输出选择都与 E-3 逐位相同。另外，在同一批键的**真实**观测上也运行 S-diag 和 S-cov，作为对照：应当复现 E-3 中标量 Γ 更好的方向。

## 4. 读数

- 信道 NMSE（dB）：由输出原子重建的信道与 h_true 的信道矩阵比较，口径与 E-3 相同。
- 同时延普查（口径同 E-3）。
- **EIV 目标的单调性**：每次 EM 迭代后计算 L(β, γ) = −log det(C) − YᴴC⁻¹Y，其中 C = β⁻¹I + B̄ΛB̄ᴴ。对含 Γ 的 EIV 模型，按其 EM 所对应的下界计算；执行者需写出该下界的具体形式并验证。统计下降违规的次数。

## 5. 冻结判据

- 主量 D = NMSE_dB(S-cov) − NMSE_dB(S-diag)：每个键先在 R 次之间平均，再对键做配对 cluster bootstrap（cluster = (场景, 帧)，跨 SNR 合并，20000 次，seed 20261018，百分位 95% CI）。
- 判定：
  - **CODE-CONSISTENT**：CI_hi(D) ≤ 0。模型正确时完整 Γ 不劣于标量，真实数据中的反转应归因于模型误设，而不是代码。
  - **SUSPECT**：CI_lo(D) > .2 dB。模型正确时完整 Γ 仍然更差，说明 SBL 中 Γ 的用法或交互有问题，必须排查。
  - **INCONCLUSIVE**：其余情形。
- 报告项（不进判据）：
  - 真实观测对照中的 D_real：应 > 0，以复现 E-3 的方向；
  - S-hard、S-genie 的 NMSE；
  - 单调性违规数；
  - 同时延普查。

## 6. 门

- G1：在 2000 次抽样上，x̃ 的经验均值、方差与 μ、v 的相对误差 ≤ 2%；按全帧合并评估。
- G2：v ≡ 0 时 S-cov = S-diag，逐位一致。
- G3：真实观测上 S-diag、S-cov 的输出原子在 10 个键上与 E-3 行逐位一致（E-3 行在 deinlab）。
- G4：确定性，并估计成本，上限 3 core-h。
