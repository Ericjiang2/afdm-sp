# 模型匹配合成检查：完整 Γ 在模型正确时是否不劣于标量

## Goal

E-3（res-20261017-03）中，数据辅助 SBL 的完整 Γ 版本（L-cov）的 FER 和 NMSE 都不如标量 Γ 版本（L-diag）。这一结果有两种可能：

- **代码或用法问题**：Γ 在 SBL 中的用法有误，或者 β 更新、ARD 与 EIV 罚项之间有不良交互。目前只在 v ≡ 0 时验证过，v > 0 时没有独立核对。
- **模型误设**：真实数据下，APP 后验不是 EIV 模型假设的样子。

本检查构造一个**模型匹配**的合成世界：数据按 APP 后验抽样生成，因此完整 Γ 在理论上就是正确模型。在这个世界里，完整 Γ 的信道估计必须不劣于标量。

与 Codex 负责的 E-3c 并行进行（用户 2026-10-18 指定），不触碰 E-3c 的任何文件。

## Requirements

- R1：使用真实 P1 状态（帧、信道、导频、第 1 轮 APP 矩 μ、v），合成观测为 Y_syn = B(pilot + x̃) h_true + n，其中 x̃ 按逐符号 QPSK 后验抽样，并且与 `moments(app, pd)` 一致。其余部分沿用 E-3 第 2 级的 SBL（只读导入，冻结代码不改）。
- R2：判据先冻结、提交，再跑。新代码只放在 `experiments/tf_mm_gamma_20261018/`。成本上限 3 core-h，同时最多 8 个进程，以 tmux 链无人值守运行，不轮询。
- R3：结果只出 draft 卡；结论限于"在模型匹配世界中"。
