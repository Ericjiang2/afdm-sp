# 保守配对 FER 比值区间：数值研究

日期：2026-09-06。范围：独立统计夹具研究；不是 S5 预注册、功效分析或样本量选择。未读取 Dtest，未改变生产分析器。

结论：可使用两个**双侧 97.5% Clopper–Pearson 边际区间**构造至少 95% 覆盖的 FER 比值区间；代价是明显保守，未利用配对信息收紧区间。此次 12 场景、每场景 20,000 次 Monte Carlo 未发现覆盖不足，最低比值覆盖为 99.81%。覆盖保证来自下述解析论证，有限场景模拟只验证实现与边界。

## 定义和保证

每个独立帧包含新方法与参考方法的配对二元失败结果。四格顺序为：a 两者均成功，b 仅新方法失败，c 仅参考失败，d 两者均失败。总数 n=a+b+c+d；边际失败数 Xnew=b+d、Xref=c+d。帧间须独立且边际概率固定；不要求同一帧两个失败指标独立。跨 SNR 重用帧不能直接累加为独立 n。

目标 R=pnew/pref，先假设 pref>0。对每个边际，用 αm=0.025，即每尾 αm/2=0.0125：

```
L(k,n) = 0                                  if k=0
         BetaQuantile(.0125; k,n-k+1)        otherwise
U(k,n) = 1                                  if k=n
         BetaQuantile(.9875; k+1,n-k)        otherwise
```

每个区间分别覆盖至少 97.5%。由 union bound，不论两者相关性如何，同时覆盖概率至少 1−.025−.025=.95。在同时覆盖事件上，由非负性及比值单调性：

```
R ∈ [Lnew/Uref, Unew/Lref].
```

Lref=0 时上界设 +∞；有限 n 下 Uref>0，因此下界不出现 0/0。观测两边均零失败得到 [0,+∞]，不能按“无误码”判定改进。真 pnew=0、pref>0 时 R=0，有效覆盖；真 pref=0、pnew>0 可明确采用扩展值 R=+∞；真 pnew=pref=0 时参数 0/0 未定义，不计算 RR 覆盖。

这里“双侧97.5%”不是“双侧95%”，也不是“每尾2.5%”。此置信分配保证一个指定比较的双侧比值覆盖；多个比较、选择后报告或 G3 同时伤害控制的置信分配须另行定义。

## 重现和结果

同目录脚本 `statistics-conservative-coverage.py` 仅依赖 NumPy/SciPy，本地 CPU 执行。NumPy 2.1.3、SciPy 1.15.3；各场景 seed 为 `SeedSequence([20260906,9,case_index])`。实际数值部分约 0.068 秒，进程配置 60 秒上限。脚本保存完整概率、MC 计数、置信区间与软件版本到同名 JSON。

```sh
/opt/anaconda3/bin/python .trellis/tasks/09-06-minimal-repair-mechanism/research/statistics-conservative-coverage.py
```

最低 RR 覆盖为 19,962/20,000，其模拟比例的双侧 95% CP 区间为 [99.7393%,99.8655%]。全部 20,000 次覆盖也不表示总体 100%：模拟比例的双侧 95% CP 下界为 99.9816%。这些 MC 区间描述本次模拟误差，不替代解析覆盖保证。

在真 R≥.9 的场景中，以“上界<.9”作 G1 式判定，最高观测误放行率为 16/20,000=.08%（中等误码、不重叠场景）；其 MC 95% 区间 [.04573%,.12988%]。稀有非重叠 n=192、R=.9 场景出现 1/20,000。其他受检场景均零次；零次的 MC 95% 上界 .01844%。这是诊断指标，未提出预注册门槛或功效结论。

先前渐近 profile 危险边界 b=0,c=3,d=0，此方法区间为：n=32 时 [0,8.42890]，n=192 时 [0,9.10178]，n=1000 时 [0,9.21559]。因此不会由仅三次参考失败错误产生上界<.9，但也直观显示其低误码区间宽度代价。

## 采用边界

该替代方法可作为有覆盖保证的候选；不声称是最窄区间，也不声称现有样本量足够。正式 S5 仍需冻结比较/多重性、目标效应与功效模拟，且须使用实际分析器验证。若保守区间功效不足，应如实记录预算不可行，不能根据已观察 Ddev 结果选择较宽松算法或缩减门槛。
