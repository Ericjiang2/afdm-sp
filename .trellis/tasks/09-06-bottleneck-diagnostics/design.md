# S2 实现设计

唯一研究协议为 parent design.md / implement.md。当前批次优先建立可复用的诊断接口，随后运行 I1、I4、I6；I2/I3/I5保留在完整任务范围内。

- 在现有 `ClassicalJointUnrolled.forward` 添加明确的可选离线干预接口。默认 None 路径保持旧数值行为；不复制接收算法，不修改MP/LDPC。
- I1：对接收机实际簇扩展支撑，在同一DAFT算子表示下拟合真 H；将用于 BP 的 H 替换为固定支撑最佳拟合，完整重跑后续检测。支撑和噪声模型不主动改变；下游自适应状态自然演化。记录oracle额外成本，不当在线方法。
- I4：F2-P原动作 vs keep/无保护。保留共同 OMP 初始支撑和外环数；keep 只替换初次支撑修复动作。真实活跃容量可能不同，作为机制诊断标签，不能混入同容量主表。
- I6：仅把 DA-LS 构造 sensing matrix 的反馈换成真缩放数据符号；不把真符号直接当检测输出，不改噪声残差接口。若需要另一种同时更新噪声的oracle，单独命名。
- 记录最终实际支撑、NMSE、原始与译码错误、时间、输入哈希和具体干预位置。暂不宣称完整全局oracle上界。
- 种子遵守parent SeedSequence([20260905, split_id, replicate_id, frame_id, stream_id])，D_dev=1；物理信道、数据、噪声、运行顺序分流。所有看过的帧只能进入开发。
- 初始 coded SNR7/8/9，3随机流各64帧。先2帧工程smoke再按已登记分母运行；smoke不作为统计样本。uncoded15/20及池内逐候选反事实另登记子批次，合用本阶段预算。

I2/I3 的候选ID共享、簇匹配容差和 I5 真连续位置与当前截断生成器的模型差异，须在各批次运行前写清。不得把未实现项打勾。
