## Reading rule added at freeze (mechanical, no code change)
The verdict code labels each layer `supported`, `not established` or `not evaluable`. When the card summarises a layer as **not
supported**, it does so only if at least one component sits in its frozen negative category:
- V1 `replay did not replicate`;
- V5 `mirror opposite`, or either half on the wrong side;
- V2 `does not recover`;
- V3 `inferior`;

Otherwise a layer that is not supported is reported as not established. This follows §4's "不成立" rule and does not override §10.1.
