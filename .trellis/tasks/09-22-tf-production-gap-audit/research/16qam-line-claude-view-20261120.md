## 1. 这条线原本问什么（出处）

## 2. 已有理论能直接回答多少
- 【据】Prop 1（[theory-astra-v2.tex](proofs-20261119/theory-astra-v2.tex) 式 af-full）：(Γ_F)_ij = 相位 · D_N(Δν + a₁d) · v̂[d mod N]，a₁ = 2Nc₁，d = ℓ_j − ℓ_i。
  - d = 0 时为 u·D_N(Δν)，对任意 v ≥ 0、任意星座成立。
  - 因此在 AFDM 里，保持 u 不变、只重新分配方差，同延块分毫不变。这是定理，手构检验在 AFDM 上只能检验代码。
- 【据】冻结设定（2Nc₁ = 5，P1 的真实径对 |Δν| ≤ 4）下，d = ±1 的跨时延核最大为 0.217（第一旁瓣）；OFDM 没有平移，为 1（[读数 §1](zero-cost-readouts-20261119.md)）。
- 【据】真实 APP 方差（1,000 个失败帧，F0 第一轮）：|v̂[1]|/u 中位 .023，最大 .249；AFDM 异时延原子对上 |Γ_ij|/u 中位 .00061、最大 .0082；同几何的 OFDM 反事实中位 .039、最大 .305（[读数 §4](zero-cost-readouts-20261119.md)）。
- 【推】AFDM 的完整评分要随方差重新分配而改变，必须同时满足两件事：(i) 方差序列在 d = ±1 处有大的谱分量；(ii) 帧里有相邻时延、多普勒差落在共振位置的候选对。真实后验不满足 (i)（中位 .023），P1 的真实径对不满足 (ii)。只有专门对着 v̂[1] 去造的对抗构造才可能翻转，而那属于 Astra 说的"矩阵差异"级证据。
- 【推】16-QAM 会让 v 的离散程度变大，但 DAFT 指标上的 v 并没有结构（每个符号都经历全部路径），所以 |v̂[d]|/u 预计仍是 √N 量级的随机起伏除以 N，而且仍被 chirp 压住。这是推断，没有测过。
- 【推，物理读法】在真实支撑上，hᴴΓ_F h = Σ_n v_n‖g_n‖²，其中 g_n 是 Σ_i h_iU_i 的第 n 列，‖g_n‖² 即第 n 个符号经历的信道能量。所以"对任意 v，标量都精确"等价于"每个符号经历的信道能量与 n 无关"。chirp 让 AFDM 满足这一点（只差核尾）；OFDM 每个子载波的能量就是频率响应的模平方，不平坦，而且译码方差与它负相关。这是 Prop 1 的另一种说法，不是新定理。

## 4. 首检方案（草案，均未冻结；按 research-checkpoint 第 1 时刻）
**方案 A：原样的 16-QAM 手构检验，跨三种波形（Astra 方案，作为第 2 篇的种子）**
- 做法：取冻结生成器的帧，数据换成 16-QAM，用标量观测模型产生逐符号后验（μ, v）。对每个 μ_n，先用 16 点上的线性规划求出可实现的方差区间。在保持 u 不变的前提下，求让两个指定候选得分差变化最大的可实现方差分配（一阶 LP 加精确复核）。波形取 AFDM（a₁ = 5）、OFDM（a₁ = 0）、矩形脉冲 OTFS。只算评分，不需要 16-QAM 译码器。
- 竞争假说：
  - H0：被丢弃的方向在三种波形上都够不到决策裕量；
  - H1：OTFS 与 OFDM 能翻转，AFDM 不能；
  - H2：AFDM 也能翻转，经由 d = ±1 共振。
- 预测【假】：
  - AFDM 可实现的最坏摆幅翻转的决策 < 1%：P = .9；
  - OTFS 可实现摆幅翻转的决策 ≥ 5%：P = .5；
  - OFDM 同条件：P = .55。
- 设计效度：
  - (a) 每次对比只改方差分配；
  - (b) 杠杆：AFDM 一侧已知近零，判别力全在 OTFS/OFDM；
  - (c) 统计单元为信道实现；
  - (d) "可实现"指存在 16 点上的分布，使均值与方差都对上；对抗构造不代表真实译码器会产生的后验。
- 预想失败：最可能是只在近平局处能翻转，即 Astra 说的弱证据。补救是同时报告"翻转所需摆幅 / 实测裕量"的分布，以及真实（非对抗）后验下的摆幅。
- 代价【假】：约 2 人日编码，CPU 分钟级。产出属第 2 篇，不进本文主线。

**方案 B：a₁ 扫描的决策层检验（本文内唯一带风险的版本）**
- 做法：在冻结管线上只改 c₁，在每个 a₁ 内配对比较 `CODELAY` 与完整 Γ_F 的支撑决策和 FER。
- 预测：a₁ = 5 时分歧接近 0（已知 0:0）；a₁ 下降时分歧上升，并集中在有共振径对的帧上。
- 【推】我的先验偏向无效：§3 显示 a₁ ≥ 1 时方差已经平坦，|v̂[1]|/u 约 .02，即使核落在主瓣上，跨时延项也只有约 2% u，大概率够不到决策裕量。只有 a₁ = 0（OFDM）才可能有决策差别，而冻结管线的检测器依赖 DAFT 稀疏结构，a₁ → 0 时可能整体失效，对比就失去意义。
- P(全部 a₁ 上决策分歧都接近 0) ≈ .65【假】。
- 代价：先花半天核查管线能否在 a₁ ≤ 3 下工作；跑数未估。11-19 的 [devin 收获稿](idea-harvest-devin-20261119.md) 已把它记为"需新计算，超出范围"。
