# "妙"的两件零成本检查：结果（2026-11-19 晚）

Eric："先做这两个零成本检查再问其他模型咋样"。两件都只用已有材料：推导只读，读数只用 deinlab 上已存的行，没有新仿真。都是**事后**结果，不能当作已接受的结论。

## 1. 一比特重述（候选 §3.1）：Astra（high）推导
[Astra 回答](onebit-astra-20261119.md)

- **[derived] 等价成立。** 在冻结的高斯工作模型中，门控"方差没减半"严格等价于"这一帧关于该对比方向的互信息不到 1 bit"，即 I = log₂(pᴴV₀p / pᴴV₁p)，取等号时不加下限。
  - 模型：先验 h ~ CN(0, cV₀)，c 在交换阶段取 σ²，在 SBL 初始化处取 λ + u/N。
  - 限制：这是在冻结设计下对 y 取平均的信息，不是某一帧实际给出的信息。
- **[derived] SBL 证据中有对应的行列式项。** 精确重合时，差模没有任何波形信息，加下限会给它增加一份行列式代价。所以"精确块去掉了差模的那份代价"在这个极限下成立。
- **但 SBL 反转并不能由此推出。** II 型学习还会改变拟合、增益方差、噪声精度和剪枝。"缺失的行列式代价介导了反转"只是低置信度的猜想。
- **[derived] 只是换说法。** 它推不出新的 FER 符号、块大小归因或 SNR 预言。提高比特阈值只会在两个阶段都多加下限，至于对误帧率的影响，没有排序结论。
- **[derived] 幻影的编码代价解释。** 重合时，标量把一条径平分成两半，二次不确定度代价从 u|H|² 降到 u|H|²/2，即省下 βu|H|²/(2 ln 2) bit；精确块在两种表示下都收 u|H|²。"幻影是同一波形的更短描述"是一个类比，完整的描述长度比较还需要支撑编码等项。

**结论**：适合写进正文的解释段落，给出"一个数、两个方向、一比特"的说法。它满足"压缩现象"，不满足"新预言"，所以本身不是"妙"。

## 2. 导频分配律（候选 §3.2）：崩塌门限读数
判据在计算前写定：[criteria](collapse-threshold-readout-criteria-20261119.md)（`38c332cb`）。数据为 ρ 扫描已存的 62,400 键，其中触发帧 18,009 个。

### 2.1 冻结判据的结果
| 候选量 X | 跨 ρ 救回率极差的中位数（≤ .10 为过） | 阈值形状 | 判据 |
|---|---:|---|---|
| X1：F0 信息位误码率（用真值） | 0.044 | 是 | 过 |
| X2：F0 校验子重量（在线） | 0.087 | 是 | 过 |
| X3：u/N（在线） | 0.085 | 是 | 过 |

按预写的映射，"X2 或 X3 过"是最强结果：存在一个在线可观测的门限。

### 2.2 削弱它的两点（事后补充，不在判据内）
- **X3\* 随数据 SNR d 变化，不是常数。** 救回率 50% 的位置：d = 2 / 3 / 4 dB 时为 0.156 / 0.168 / 0.152，较稳定；d ≥ 5 dB 时降到 0.03–0.11，但这些档样本少。
- **留一 ρ 预测**（用其余 ρ 的 (u/N, d) 救回表去预测被留出的 ρ，40 格）：
  - 中位绝对误差 0.072，最大 0.183；
  - **ρ = .15 系统性高估**：在 5–8 dB，预测 .91–.98，实际 .77–.85。

  所以 u/N 解释得了 SNR 方向的瀑布，解释不了 ρ = .15 的救回率平台。

### 2.3 ρ = .15 平台的来源（事后，按 agy I3 的判据）
在 SNR ≥ 6 dB 的触发帧上看 CD 用完交换之后：
- **ρ = .15 的失败帧**（177 个）：93% 仍漏掉至少一个真时延，而且几乎都用满了 2 次交换；漏 2–3 个的居多。
- **ρ = .15 的救回帧**：81% 也漏掉至少一个真时延，但多为漏 1 个（弱径不一定影响译码）。
- **对照 ρ = .5 的失败帧**：只有 54% 漏径。

agy 的否证规则（"≥ 60% 的失败帧同时用满 2 次交换且仍漏径"）**没有触发**，所以"交换预算用尽"这个解释仍然成立。但这只是相关性；早先在 ρ = .3 把交换次数从 2 加到 4 毫无收益（D₄/D₂ = 1.000）。

**由此给出一个可证伪的预言**（未检验）：交换预算只在导频极低时才是瓶颈。在 ρ = .15 把 max_edits 从 2 提到 4，应能把 6–8 dB 的救回率从约 .8 提到 ≥ .9；在 ρ = .3 则不变（已有结果）。
- 这是一个随导频比翻转的预言，可以用新帧做一次干预检验，约 1–2 核时。
- 如果成立，设计规则就是"交换预算应随导频不足程度增加"，而 ρ\* 由"u/N 门限 + 预算"两条共同决定。

## 3. 两件检查合起来
- **一比特**：漂亮、正确，但只是换说法，作为正文的解释段落。
- **导频律**：在线可观测的门限存在（u/N，按冻结判据），解释了瀑布；低导频平台另有原因，最可能是交换预算。这里有一个真正可能失败的新预言（ρ = .15 加交换次数），是目前离"妙"类型 D 最近的一个。
- 两件检查都没有改变"现在写正文"的建议。
