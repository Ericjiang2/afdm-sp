## 3. 推荐
**先做一个同帧决定性检验，再在 A 和 C 之间选。**
- 检验（≤ 12 核时、约 1 天）：在同一批帧上同时跑 HG、HG + 第 0 轮真多普勒（或第 0 轮全真信道）、两遍 CD，ρ ∈ {.10, .15, .20}。问题：Huang 式重搜之后，第 0 轮多普勒还值多少 dB？顺带补上两遍 CD，堵住"CD 外环少一遍"这个口子。
- 若"重搜之后仍剩"的 95% 下界 ≥ 0.5 dB → 走 C，限时 3 周做半盲第 0 轮多普勒估计器，用 A3 的代理指标先筛、再跑 FER。
- 若上界 < 0.3 dB → 低导频线在 Huang 之后没有空间，写 A 收尾，目标 TVT；原理级目标另起。
- 其余 → 由 Eric 定。
- **置信度：中。** 最强的替代方案：直接写 A（最快落地第一篇一作，代价是放弃"原理级"）。会改变推荐的证据：同帧检验显示剩余 < 0.3 dB；或查新发现单帧半盲多普勒估计在 OTFS/AFDM 编码接收里已有。

## 4. 顶层检查
- 重要性（Hamming）：叠加导频的卖点是省导频开销；"导频降到多少还能用、卡在哪一步"是这类系统真实的设计问题，有合理的下手办法（下界 + 门槛 + 同帧上限都已能测）。
- 可行性 × 兴趣（Alon）：A 可行性高、兴趣低（Eric 会觉得别扭）；C 可行性中、兴趣高。
- Heilmeier：现在怎么做——导频比按首轮 SINR 定，失败后重搜或局部修补；新在哪里——把剩余损失定位到第 0 轮多普勒并给出可达界；谁关心——做 SP-OTFS/AFDM 低开销接收机的人；风险——估计器达不到下界；中期检验——同帧剩余余量、代理指标。
- 外部视角（估计，未核）：移植 + 系统测量类论文多落在 TVT / 快报；"界 + 门槛 + 有 FER 收益的构造"在 TCOM/TWC 有先例，没有 FER 收益时多落快报。
