# Astra（gpt-6.2-astra）答复：决策窗口的 ρ/SNR 增益地图（2026-11-18）

> 简报：[astra-gain-map-brief-20261118.md](astra-gain-map-brief-20261118.md)。原文由 Eric 转贴，本文件是 Claude 整理的要点。
> Claude 手算复核了 Q1 的数值（λ、上下界）；Q2 的蒙特卡洛没有复跑。

## 要点
- **Q1（由代码推导）**：
  - 记 `a_ρ = 1/(2(1−ρ))`，内部 λ = a_ρ/γ（γ 为线性 SNR）。
  - QPSK 下 `u = N v̄`，`E + u = N a_ρ + C`，C 为导频与软均值的交叉项，地图中取 C = 0。
  - 记 `x = 2(1−ρ) v̄`（未解出的数据不确定度占比），零间隔窗口为
    `1 + 2(1−x)/(x + 1/(Nγ)) < R < 1 + 2Nγ`。
  - 上界约为 8154（6 dB），实际上不起约束，所以窗口近似**单侧**：只要强弱径功率比 R 超过下界，标量就偏向幻影。这与 Fable 的 `θ_sc ≈ v̄/(2 − v̄)` 一致。
  - ρ 越低，x 越大，下界越低，窗口越宽。v̄ = .15、6 dB 时，下界在 ρ = .3 为 8.52，在 ρ = .5 为 12.31。
- **Q2（蒙特卡洛，50 万个信道，只抽信道律，假设只漏最弱的一条径）**：窗口占比随 ρ 降低而升高，例如 6 dB、v̄ = .15 时：

  | ρ | .2 | .3 | .4 | .5 |
  |---|---|---|---|---|
  | 窗口占比 | 96.6% | 95.2% | 93.2% | 90.2% |

- **Q3（事后检验）**：**方向对，量级对不上。** 同一 SNR 和 v̄ 下，ρ = .3 与 .5 的窗口占比只差 1–11 pp；实测救回差距相差 36–42 pp。窗口只描述局部偏好，救回还要经过"交换被接受""译码成功""预占"这几步转换，窗口本身给不出这些概率。
- **Q4（前瞻）**：ρ = .2 的占比为 74–100%，ρ = .4 为 66–99%（取决于 v̄）。区间太宽，不构成有判别力的检验。
- **Q5（主要偏差）**：
  - 漏两条径时占比明显下降（ρ = .3：95% → 83%）；
  - 有限间隔 .25 bin 会使占比下降（95% → 89%）；
  - 帧间 v̄ 的分布比帧内方差异质性重要得多。

## 对候选 #1（"理论预测增益集中在哪里"）的判断（Claude）
- 只得到**定性**结论："导频比越低，窗口越宽，越需要同延迟修正"，并附闭式 `x = 2(1−ρ)v̄`。可以作为论文中的一句推论或注记。
- **不值得为此开新的 ρ 实验**：量级解释不了，前瞻区间又太宽，新实验能检验的东西很少。
- 候选 #1 按野心标准**基本落空**，只剩一个写作层面的小推论。
