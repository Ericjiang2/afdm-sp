## 1. 有用的原因分析（四份合并后，按"能检查、能改"排序）

1. **余量（最硬的一条，Fable 和 Carbon 独立给出）。** 我们把问题做在常识接收机已经离参照只差 0.1–0.5 dB 的盒子里。原理级 idea 需要一个常识补不上的大缺口；这里没有。之后两个月的"原理"都在 0.5 dB 以内解释一个已经有效的补丁，所以一删就发现那个成分可有可无。场景本身也朝容易的方向选：整数时延、8 条径、径数上限已知、噪声方差已知、QPSK。
   - 这条比我原先说的"起点是现成的东西"更底层：起点是现成的东西本身不致命，致命的是那个东西在这个盒子里已经接近最优。
2. **顺序倒置（四份一致）。** 先有接收机，再找原理。事后找的原理任务是"让已有的东西说得通"，于是只能是解释性的。
3. **筛选偏置（Neon）。** 内部仿真快且便宜，外部核实贵；按"效应锐利、能证明、前瞻稳过"筛方向，干净的自造问题（对角 uI 造幻影，89% 对 2%）一定胜过脏的真问题（簇、未知 σ²、分数时延、低导频），后者全部被划进"局限"。这解释了为什么严谨流程反而把我们推向了不重要的东西。
4. **价值判断无人负责，代理指标成了目标（Fable 第三层、Neon 第 4 条、Claude）。** Eric 能看到的只有故事是否连贯、检验是否通过、模型是否一致；模型握着机理但只回答被问的问题。连贯的故事是语言模型最便宜的产出。协调者（Claude）同时握油门和刹车：11-18 前提失效时改写措辞而不是停机。
5. **惯性与本轮（Neon）。** 遇到反例时，成本最低的动作是加补丁（SBL 一侧的 S-lo、门控、和模封顶），而不是推翻框架。
6. **充分 ≠ 必要（Fable 第一层）。** 消融沿搭建路径做，从未试"什么都不加"。这一条已由 2026-11-20 的 A12 规则覆盖。

**不采用或打折的部分**：Neon 的目标函数式是比喻，不是推导；Carbon 说 TCOM "稳拿"过于乐观，L1 查新尚未完成，这类论文的录用不确定。

## 2. 改进方法（要落到规则上的，只取能检查的）

1. **余量闸门（新增，最重要）。** 立项或换问题前，在目标工作区先测三个数：最朴素但不犯傻的基线、我们的方法、genie 或界。只有"朴素基线离 genie ≥ 1–2 dB，且朴素做法明确失败"的地方，才进入找原理阶段；否则按工程论文处理，不找"妙"。成本低，用现有管线就能测。
2. **去壳测试（Neon 与 Claude 收敛）。** 换阶段时和任何"够 Trans""妙""统一"的说法之前，用三句白话回答：谁真卡住了（点名现有做法）；删掉核心创新、换成最朴素但不犯傻的做法，掉多少；靠什么结构性质让难处消失。一句讲不圆就停。由 Eric 本人或一个没读过我们框架的模型来问。
3. **油门和刹车分开。** 价值裁决的问题由外部框定：独立评估先从领域文献出发陈述问题，再看我们的材料；前提失效时强制重开第 4 时刻，禁止改写措辞保故事。
4. **问题从外往里找。** 从近两年论文自己承认的失败和"未来工作"出发，而不是从我们的资产出发。

## 3. 论文何去何从

**路线 1：先写一篇中等体量的论文（诊断 + 实测有效的接收机）。**
- 内容：嵌入导频在大时延扩展下不可行 → 叠加导频下差距主要来自漏掉的弱时延（73–81%，NMSE 层）→ 校验触发的局部替换接收机（明说属于 SBR/NOMP 一类常规做法）→ 与 Luo 式 SBL 的同帧硬对比（FER 1403:0 等，单核快 12–16 倍）→ 一节讲打分里的软信息：交换中不用也行，对角近似会坏事，SBL 中反而要紧（.254 / .116 / .043）→ 局限。
- 闸门：Gemini 对 L1 的查新。若 L1 已被做过，降为 TVT。
- 体量与期刊：TCOM 有可能但不稳；TVT 是可靠的退路。写作约 2–4 周（估计）。
- 对 Eric 的用处：第一篇独立一作落地，把这个盒子收尾；不再在里面找"妙"。

**路线 2：追真正的目标（原理级 idea），换问题，不换方法。**
候选都是现有记录里有大缺口、且常识做法失败的地方：
- (a) 同时延 Doppler 簇（AFDM 的分集卖点所在；路径接收机 FER .89–.99）；
- (b) 盲重获取：未知 σ² 亏 1.2–1.6 dB，未知径数受数据自干扰底噪限制；
- (c) ρ < .25 的导频自举崩塌（差距为外推值，需实测）；
- (d) 分数时延。

做法（每步有检查）：
1. 余量测量：每个候选上测朴素基线、我们的接收机、genie，确认缺口 ≥ 1–2 dB 且朴素做法失败（便宜，现有管线）。
2. 外部核实：近期论文是否承认这里没解决、谁在做、做到哪。
3. 只在过了 1、2 的问题上找 idea，用去壳测试筛。
4. 设时间盒和停止条件（例如 4–6 周没有通过去壳测试的候选就停），防止再陷进去。

**我的建议**：先走路线 1，同时低强度启动路线 2 的第 1、2 步（余量测量与外部核实不占写作主线）。路线 1 写完后，带着测好的余量图进入路线 2。
- 最强的替代：推迟写作，全力走路线 2。好处是不把精力分散；风险是没有保证，而且路线 1 的实测结果不会因为等待变好。
- 会改变这个建议的证据：查新显示 L1 已被做过且 TVT 也难（则路线 1 价值下降）；或余量测量显示某个候选缺口很大且已有明确切入点（则可提前转入路线 2）。
- 置信度：中。
