 往下挖有三层，最底下一层是个逻辑错误，上面两层解释它为什么几个月没被发现。

 最底层：我们证的是充分，说的是必要

 "接收机需要精确的同延块"是一个必要性主张。它要求证明：凡是没有这个块的做法都会失败。我们手里的证据是另外两种：

   •  CODELAY  有效，且与完整 Γ 逐键相同（充分性）；
   • 标量 uI 失败（一个替代方案失败）。

 从"A 有效、B 失败"推不出"A 里的那个成分是必要的"。要推出它，必须检验不含该成分的最简单做法，也就是 Γ = 0。这个臂一直没人跑，所以必要性从头到尾没有证据。后面的
 0:0、前瞻镜像、门控都很严谨，但它们加固的全是充分性那一边。

 第二层：对照是沿着搭建的路径取的

 为什么没人想到零？看发现的顺序：

   1. 先搭了完整 Γ（最复杂的东西）；
   2. 再做消融，去掉非对角项，得到标量臂；
   3. 标量臂很坏，于是结论是"耦合不可少"。

 消融只会从已搭好的东西上拆零件，所以对照天然继承了搭建时的前提（"不确定度总要以某种方式加进去"）。真正的零点在这条路径之外。这是通病，不是这个项目特有的：沿路
 径做消融，得到的永远是"我的东西少一块"，而不是"什么都没有"。

 预注册和多模型复核防的是在一个假设之内做手脚，防不了假设空间选错。严谨用在了错的层级上，反而让人更相信这个框。

 一、主要原因：这个设定下，常识已经几乎做满了

 原理级的 idea 需要一个常识补不上的缺口。看已有数据里，最好的接收机离"已知真实信道"还差多少（穿越点，dB）：

 主实验做在 ρ = .3 和 .5。那里"失败时换几条径"这个常识做法已经把差距压到 0.1–0.5 dB，剩下的空间装不下一个原理。几个月里所有的"原理"都是在这 0.5 dB 以内解释一个
 已经有效的补丁，所以 Γ = 0 一测就发现补丁里那个成分可有可无。

 设定本身也是往容易的方向选的：整数时延、8 条径、径数上限已知、噪声方差已知、QPSK。每一条都去掉了一个可能逼出新想法的困难。

 二、次要原因：顺序是先有接收机，后找原理

 这条线的实际顺序是：搭接收机，找差距，打补丁，补丁有效，再去解释它。这样得到的原理是事后的解释，它的任务是让已有的东西说得通，而不是回答一个事先摆在那里的问
 题。你要的那种"能串成主线的原理"通常是反过来的：先有一个说不通的现象或一个算得出的极限，再有方法。

 10-17 那个现象（硬判决和完整 Γ 打平、标量在 SBL 里反而更好）本来是这样一个入口。当时它被当成需要圆过去的麻烦，而不是问题本身。

 三、次要原因：出题和判题的人都不握着机理

 这一条你上次打断了，但它是事实。你定目标、判方向，靠的是故事连不连贯、检验过没过、模型之间是否一致。模型握着机理，但只回答被问的问题，而且会顺着"要原理"的要求
 把解释说大。几个模型读同一份骨架，复核的是同一个前提。

 这种分工能产出核对严密的增量，产不出你要的东西。那种 idea 需要同一个脑子里既有问题又有机理，并且放得够久。

 这个东西对你有什么用

   • 一篇能投的一作文章。 它不是你想要的那种，但对比是硬的。
   • 一张地图。 现在知道这个问题里哪里已经做满，哪里还空着。
   • 一道工序。 任何新部件先跑"删掉它"的臂。这次晚了一个月，成本只有 1.8 核时。

 如果目标不变，该换什么

 该换的是问题，不是方法。只有差距大于 1–2 dB、且常识做法明确失败的地方，才可能长出原理。从上表看，候选是：

   • ρ < .25 的崩塌区。 那里导频不够自举，多给交换次数只救回 0.6–0.9 dB（res-20261119-08）。
   • 去掉简化假设的情形：分数时延、每抽头多径、未知噪声方差。骨架已经把这些划到范围之外。
