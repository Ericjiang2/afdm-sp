## 要回答的问题
`CODELAY` 相对 F0 的优势随 ρ 从 .5 降到 .3 而变大（P1 +1.26 dB）。两种可能：
- (a) F0 在低 ρ 下失败得更多，所以可救的帧更多；
- (b) 每次触发的救回率本身在变。

## 观察
1. **不是 (a)**：
   - 同一 SNR 下，ρ = .3 时 F0 的触发率**低于** ρ = .5。例如 5 dB 时，U 为 .22 对 .998，G 为 .28 对 .99。
   - 原因是数据分到更多功率，LDPC 瀑布区整体左移到更低的 SNR。
2. **是 (b)，但要按"失败类型"来理解**：
   - 在 5 dB：
     - ρ = .3 时，CD 每次触发救回 .93（U）与 .91（G）；A2 只救回 .33 与 .29。
     - ρ = .5 时，CD 只救回 .02 与 .005，A2 为 .01 与 0。
   - ρ = .5 时，要到 5.5–6 dB，CD 的救回率才升到 .25–.75。
3. **A2 救回率低的原因与谱机制一致**：在 4.5–5 dB，A2 已接受的第一步编辑中，幻影占 .89–.99；CD 只占 .01–.07，其余几乎都是真时延。
4. **ρ = .25 与 .30 几乎相同**：5 dB 时 U 的触发率分别为 .195 与 .220，CD 救回率为 .92 与 .93。这与 CD 穿越点在 .25 不损失一致。

## 解释（未检验，置信度 M）
- 降低 ρ 把"数据功率不足"这道门槛移到更低的 SNR。在新门槛和旧门槛之间，F0 的失败主要来自导频初估不准，尤其是漏掉弱径，这类失败可以通过重获取支撑救回来。
- `CODELAY` 救回了其中九成以上，于是把数据功率的增益兑现成穿越点的改善。F0 兑现不了，标量 A2 被幻影挡住，只能兑现一小部分。
- 在 ρ = .5 的低 SNR 端，失败受数据功率限制，任何信道估计的改进都救不了，所以优势变小。
- **局限**：
  - 本次扫描没有真信道参照臂，所以"ρ = .5、5 dB 处的失败受数据功率限制"是推断，依据是 CD 与 A2 的救回率都接近 0，并没有直接测量。
  - 这是事后描述。
  - 要确认，可在下一次扫描中加入 TRUE_GEOMETRY 参照臂。

## 补充（2026-11-19 晚，Astra 在想法挖掘中指出，Claude 已逐数核对）
"ρ = .5 时低 SNR 端的失败受数据功率限制"原本是推断，现在有了**独立的归档证据**。
- 来源：10 月的参照实验，每格 2,000 帧，帧与本次不同；见 `experiments/tcom_reference_frame_20261015/out/p1/analysis_with_timing/P1_RESULTS.md` 的 5 dB 行。
- ρ = .50 时，F0 分别错 1,992 帧（G）和 1,988 帧（U）；**真信道接收机 A3 也错 1,886 帧和 1,883 帧（约 94%）**。所以即使给出完整的真信道，最多也只能救回 F0 错帧的约 5.7–5.9%。
- ρ = .30 时，F0 错 520 帧和 467 帧；A3 错 1 帧和 0 帧；只给真时延的 GS-set 错约 90 帧（G，FER .045）。也就是说，只给真时延就至少能救回 F0 错帧的约 83%。
- 两档的数据功率在固定总功率下相差 10·log10(.7/.5) = 1.46 dB，与 10 月真信道接收机穿越点的位移（1.47–1.51 dB，Astra 读数）相近。

**结论的强度**：机制读数的解释由"推断"升为"有独立归档证据支持"，帧与接收机版本都不同，但仍是事后对照。卡片 res-20261119-06 相应更新。
