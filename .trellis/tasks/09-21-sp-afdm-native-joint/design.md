# Integration design

- Isolated working package: `experiments/sp_afdm_native_joint_20260921/`; results: `results/sp_afdm_native_joint_20260921/`. Preserve imported results and all predecessor paths unchanged. Archive ZIP is immutable rollback/source reference.
- Numerical authority: supplied twofft.py/native_twofft.py and frozen handoff settings. Integrate with the qualified corrected baseline31d5ec0d, preferably via explicit source-root imports; reuse its serialization, generator/decoder and provenance where contracts match. Do not modify the old baseline or old staged runner. No numerical setting changes; necessary evidence hooks must prove unchanged decisions.
- One central ledger/schema and validator drive resume, gates and summaries. Save observation/truth once per frame, truth unavailable to receivers. Completed checkpoint callback persists bits/input APP/extrinsic and absolute complete ready times before next round. On later numerical exception keep earlier decision, actual elapsed cost, diagnostics and exception; no fabricated checkpoint or fallback.
- Stage A: first5 arms x12; PBI first6; FIXED first4, exactly70 calls. Stage B gated: TF+selectedEP at32 new6.5dB and16 new8dB; POINT/PBI first8 of6.5dB,112 calls. Primary TF never relabeled. New seed tuples exactly handoff or explicit component collision-free translation; no reuse of supplied exploratory or predecessor observations.
- Freeze p90 as NumPy linear empirical quantile; deterministic arm rotation, no concurrent timed receivers. Freeze D and selected EP before opening Stage B. Follow all handoff numeric gates. Any propagated numerical exception fails advancement; deadline scoring still uses valid earlier completed decisions.
- Interval convention fixed before observations: report exact95% Clopper-Pearson on rescue probability conditional on discordant pairs; additionally report conservative >=95% paired failure-rate-difference interval from97.5% exact binomial intervals for rescue and harm counts out of paired n, subtracting opposite endpoints (Bonferroni). Positive difference is FER_EP minus FER_TF=(rescues-harms)/n. Label conservative, include r/h/n, never treat frame bits as independent or call small-count equivalence. The8dB guard uses primary deadline D; also report unrestricted guard counts, never select a secondary deadline after results. No post-result interval choice.
- CPU deinlab only, one numerical process, existing AFDM Python, CUDA disabled, BLAS/Torch intra/inter-op1; all remote writes/temp/cache under /data/guoyikun/. Persistent g_ tmux; whitelisted env, argv, PID, deadline, exit/time receipts. No installs, no GPU allocation or external logging. Stage0 max60min, A/B max30min each; evidence safety cap512MiB per campaign, retain triggering failure then stop rather than discard it. Source/docs/.trellis remain local except necessary execution payload; no remote Trellis state.
