# 低导频漏径：译码反馈何时能找回漏掉的路径（两周限时）

Eric 2026-11-20 决定（采纳 Astra 版，[分歧表与决定](../09-22-tf-production-gap-audit/research/retrospective-20261120/divergence.md)）。时间盒：**2026-11-20 至 2026-12-04**。

## 为什么有这个任务
Eric 的目标是一个有原理、能改变设计的 Transactions 级 idea。现有接收机所在的工作点（导频占比 ρ = .3–.5）已经接近参照，那里找不到这种原理。低导频处还有缺口，而且有一个可能被推翻的具体问题。

## 问题
导频不够时，初始信道估计会漏掉路径。译码反馈什么时候真能把漏掉的路径找回来，什么时候多搜几次也救不回来？能否用**接收机当时就能算出的量**提前预言这一点，并据此改变导频或计算分配？

## 起点（待检验，不是结论）
- Astra 提出的假设：漏径之后，译码器把那条路径的一部分影响吸收进了自己的符号估计，再把符号反馈给接收机时，漏径反而更难被看见。
- 按 research-checkpoint 第 4 时刻：先用自己的话重述问题，并提出至少一个不需要这个假设的竞争解释（例如：只是搜索次数不够）。

## 做法与验收
- [ ] 第一步零仿真：用已存数据区分"搜索次数不够"与"反馈已无法提供独立证据"两种解释；写清每种解释对已有数据的预测。
- [ ] 若有候选判别量：它必须由接收机当时可见的量算出（不用真实路径），并在**未参与推导**的条件（另一种信道或另一个导频比例）上事先写下预测，再按 research-checkpoint 第 1 时刻冻结检验。比较对象包括：Γ = 0 的简单重搜、固定 4 次重搜、各自选过导频比例的方案。
- [ ] 价值判断前过余量与白话三问（handbook A13）：先说明判断的是哪一层（整机、重搜动作、判别量）。

## 停止条件（任一成立就停，结果记入否定台账或开放线索并附复活条件）
- 两周内只能再画一条扫描曲线；
- 判别量必须知道真实路径才算得出；
- 只在没人会选的工作点有大改善，实际会选的工作点不改善；
- 简单基线（只看导频比例、信噪比和固定搜索次数）已能预测同一现象。

## 关闭（Eric 2026-11-20 验收归档）
- 结果：按停止条件 3 停。ρ ≤ .20 时残留弱径在同一份反馈里看不见、多搜无用；实际工作点 ρ = .30 失败帧不缺路径。可见量探针不确定（功效不足）。
- 留下的东西：[第一步读数](research/step1-readout-20261120.md)、[探针规则](research/visible-probe-rules-20261120.md)与[读数](research/visible-probe-readout-20261120.md)、[框架](research/framing-20261120.md)；代码与输出在 `experiments/lowpilot_missed_readout_20261120/`；否定台账条目 "Low-pilot missed-path line" 含复活条件。
- 未了结：吸收还是底噪没有分开（已存行无残差）；"重新译码后再搜"从未测过。两者都只在复活条件成立时才值得做。
