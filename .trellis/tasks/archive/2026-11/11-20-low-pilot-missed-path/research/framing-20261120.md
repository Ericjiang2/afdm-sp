## 1. 用自己的话重述问题

接收机先用叠加导频（功率占比 ρ）做初始估计 F0，得到 8 个路径槽位（P 已知作上限）。F0 译码失败（syndrome > 0）时，
交换阶段用 F0 第 1 轮的软符号 μ、方差 v 当作"额外导频"，对槽位做至多 max_edits 次换位（`reopen_geometry`），
**所有换位共用同一份软符号**，最后只做一次检测和译码（`e1_driver.run_branch`，已对照代码核实）。
所以已有数据里的"多搜几次"= 在同一份反馈证据上多换几个槽位，不包含"重新译码后再搜"。

问题拆成两层：
- 物理层：漏掉的那条路径，在反馈后的残差里还看不看得见？看不见的原因是什么？
- 决策层：接收机能否在交换开始前，用自己算得出的量判断"这一帧多搜有用 / 没用 / 需要别的东西"，
  并且这个判断能改变导频比例或计算分配？

## 2. 竞争解释（每个都写出对已有数据的预测）

| 代号 | 解释 | 需要 Astra 的吸收假设吗 | 对已有数据的预测 |
|---|---|---|---|
| H_S | 搜索不够：证据在，换位次数不够用 | 否 | 预算 2→4→6 持续多救；多出的换位主要落在真时延上；饱和后剩余失败很少 |
| H_E | 证据耗尽：失败译码的软符号把漏径的一部分"解释"掉（吸收），或整体过拟合，残差不再指向剩下的真时延 | 是（广义版） | 预算饱和后仍有失败；失败帧里仍缺真时延且缺的功率不小；多出的换位落在"其他"位置而不是剩下的真时延上 |
| H_W | 不是漏径问题：剩下的失败帧支撑已基本齐全（或缺的径很弱），失败来自增益/频偏误差或检测本身 | 否 | CD4 失败帧里残余漏径功率很小；真时延 genie 也救不回多少 |
| H_Q | 反馈太差：软符号几乎不含信息（|μ| 小、v 大），所以没有独立证据，但没有偏差 | 否 | 失败帧残差功率高于噪声（r_norm > 1）、软符号置信度低 |

H_E 与 H_Q 的区别：前者"自信地错"（残差低于噪声），后者"不自信"（残差高于噪声）。
H_S 与 H_E 的区别：前者靠加预算可解，后者只有新证据（更多导频或重新译码）才可能解。

## 3. 第一步读数计划（零仿真；判读规则在算之前写定）

数据：`edit_budget_lowrho_20261119` 已存行（deinlab，fresh 帧 6400–6799，ρ ∈ {.15, .20, .30}）。
主人群：ρ = .15、6–8 dB 的触发键（与 res-20261119-08 的主分析相同）；ρ = .20 同 SNR、ρ = .30 的 4.5/5 dB 作对照。

- **R1 支撑完整度**：CD4 失败键中，最终状态仍缺真时延的比例，以及缺失功率占比（真增益 |g|² 之和）。
  - 判读：若 ≥ 50% 的 CD4 失败键缺失功率 < 5%，H_W 为主，漏径问题在低导频处不是主要瓶颈 → 倾向停止。
  - 若 ≥ 50% 的失败键缺失功率 ≥ 5%，漏径仍是主因，继续区分 H_S / H_E。
- **R2 预算饱和**：CD4 → CD6 的帧结果翻转与多出换位的类别（已有汇总：4 救 4 伤；1,276 次多接受的换位里真时延 +63）。
  - 判读：若 R1 显示失败键仍缺真时延，而 CD6 的多余换位不落在这些真时延上，H_S（换位次数不够）在 ≥ 4 次后被排除。
- **R3 入口漏径与结局**：按入口缺失真时延数 / 缺失功率分层，CD4 救回率是否单调下降（真值量，只用来定位，不能当判别量）。
- **R4 接收机可见的基线**：在同一 (ρ, SNR) 格子内，F0 的 syndrome 权重对 CD4 失败的 AUC。
  - 这是最便宜的接收机可见量。任何新判别量必须在格子内超过它；若 syndrome 已达 AUC ≥ .80，
    "简单基线已能预测"这一停止条件按此读（PRD 停止条件 4 的扩展：把 syndrome 也算作简单基线，理由见下）。
  - 理由：syndrome 是译码器本来就给出的量，不加任何新原理；一个"原理级"判别量若打不过它，就没有设计价值。

已有数据不能回答的：残差在漏径列上的投影（需要重跑接收机，属于新计算，须冻结协议并获 Eric 批准）；
ρ = .15 处真时延 genie 的救回率（R-D 只有 ρ = .3/.5）；"重新译码后再搜"（迭代）在低导频处的效果。

## 4. 价值层面的先验（余量，A13 第一问；判断层 = 整机系统）

功率约定：发射 = √ρ·导频 + √(1−ρ)·数据，总功率 1，码率不随 ρ 变。降低导频的唯一收益是数据功率：
ρ .30 → .25 / .20 / .15 的理想收益为 0.30 / 0.58 / 0.84 dB（10·log10((1−ρ)/.70)）。
- 真信道参照 A3 在 G、ρ = .3 的 1% FER 穿越 4.69 dB（res-20261118-05，帧 11000–11999）；CD 在 ρ = .30 为 5.00 (U) / 5.20 (G) dB（res-20261119-06）。
- 由此粗推（不同帧块，未检验）：ρ = .15 的真信道上限约 3.85 dB；今天 CD4 在 ρ = .15 为 8.16 dB（res-20261119-08，pooled）。
- 系统层面的全部低导频奖金 ≤ 0.84 dB（相对 ρ = .30 的真信道），其中 ~0.5 dB 已能在 ρ = .30 本身去拿（CD 与 A3 之差），不需要降导频。
- 要让 ρ = .15 超过今天的 ρ = .30 最优点，低导频接收机须收回 8.16 − 5.15 ≈ 3.0 dB 中的绝大部分；ρ = .20 须收回 5.60 − 5.15 ≈ 0.45 dB。

先验判断（H/M/L = M）：整机层面的奖金小（≤ 0.3–0.6 dB 量级）且只在 ρ ≤ .20 才存在；
若有价值，更可能在"计算分配"一侧（判断哪一帧值得继续），而那与论文任务（继续迭代还是重搜）重叠。
