## 0. 先核实的系统事实（决定"多搜"是什么意思）
交换阶段的所有换位共用 F0 第 1 轮的同一份软符号 μ、v，最后只做一次检测和译码（`tf_cstate_e1_20261017/e1_driver.py::run_branch`）。
因此已有数据里"多搜" = 同一份反馈证据上多换位；"重新译码后再搜"没有被测过。

## 2. 预写规则的判读（第二层；不改标签）

- **R1**：规则为"若 ≥ 50% 的 CD4 失败键 m4 < 5%，判 H_W 为主"。ρ = .15 为 78%，**按规则判 H_W 为主**。
  - **规则本身的缺陷（自己的错，明说）**：5% 是按信道总功率定的，没换算到噪声尺度。6–8 dB 时 σ² ≈ .16–.25，
    5% 的信道功率相当于 0.2–0.3σ²，并不小。在噪声尺度上，ρ = .15 的失败帧中位仍留 0.19σ² 的未建模径
    （若把它当高斯干扰，约等于把有效 SINR 拉低 0.75 dB），成功帧中位为 0；且仍缺径的键里 m4 的 AUC 为 .87。
    所以"支撑已基本齐全、失败另有原因"的 H_W 在 ρ ≤ .20 处**不应被采信**；R1 标签保留为"按规则 H_W"，但我不据此下结论。
  - 在 ρ = .30，两种尺度一致：失败帧 100% m4 < 5%，中位 0.012σ²。实际工作点上的失败不是漏径。
- **R2**：失败且仍缺 ≥ 5% 功率的键上，CD6 找回 0/19、救回 0/19，多出的换位全落在"其他"位置。
  **H_S（换位次数不够）在 4 次之后被排除**。
- **R3**：ρ = .15 救回率随入口缺失功率单调下降（96.5% → 57%）；按缺失个数不单调。漏得多不要紧，漏得"重"才要紧。
- **R4**：ρ = .30 时 syndrome 已能在格内预测 CD4 失败（AUC .81）；ρ = .15 时 syndrome 无效（.44），只有真值量（入口缺失功率 .83）有效。

## 3. 解释（第三层；未检验）

- **ρ ≤ .20 的残余失败：同一份反馈里看不见剩下的弱径（H，M）**。多搜无用（R2）、弱径与失败强相关（AUC .87）。
  "看不见"有两种互不需要对方的解释，现有数据**分不开**：
  - H_E（吸收/过拟合）：失败译码的软符号把弱径的一部分"解释"掉，残差在那一列上的投影被压低。
    旁证：ρ = .3/.5 强制漏径时投影只剩 .50–.64（res-20261119-01）；ρ = .3 DD 臂失败帧残差低于噪声（r_norm 中位 .80，R-F）。两者都不在 ρ = .15。
  - H_F（底噪）：投影无偏，但被"噪声 + 强径的数据误差泄漏"这一底噪淹没；ρ = .15 失败帧的软符号方差大，底噪高。不需要吸收。
  - 区分的关键预测：H_E 下，基于残差能量的接收机可见量（残差减去 σ² 与不确定度后的余量）**看不到**残余弱径（AUC ≈ .5 甚至反向）；
    H_F 下它能看到（AUC 高）。这个检验同时回答"接收机能否预知"。
- **ρ = .30 的残余失败不是漏径（M-H）**：残余缺失功率中位 0.012σ²，与十月 GS-set 只救 85% 一致，剩下的是增益/频偏重拟合或单次译码的问题。

| 条件 | 判读 |

| 简单基线已能预测同一现象 | 在 ρ = .30 成立（syndrome AUC .81，但那里的现象不是漏径）；在 ρ = .15 不成立 |

价值层面的余量（整机层，A13 第一问；数字来自不同帧块，粗推）：降导频的唯一收益是数据功率，ρ .30 → .20 / .15 理想上只多 0.58 / 0.84 dB。
今天 CD4 在 ρ = .15 为 8.16 dB、ρ = .20 为 5.60 dB，都比 ρ = .30 的 5.15 dB 差；要让低导频成为新的最优点，ρ = .15 须先收回约 3 dB，ρ = .20 须收回约 0.45 dB，
而其中漏径能解释的只是一部分（ρ = .15 主格内 CD4 FER 85/3200，残余缺失功率 ≥ 5% 的只有 19 键）。

## 5. 建议

**停**（置信度 M-H，约 .75），依据停止条件 3。原问题的物理现象是真的（ρ ≤ .20 时剩下的弱径在同一份反馈里看不见，多搜无用），
但它不在任何人会选的工作点上，不能改变导频或计算分配的设计。

- 最强的替代：做一次冻结的机制检验（确定性重放 ρ = .15/.20 的触发键，约 1,000 键、预计 < 1 核时）：
  (a) 残余弱径列上的残差投影与真增益之比（H_E 偏小 / H_F 无偏）；(b) 把缺失真时延补进 CD4 支撑后再译码（genie 补全）能救回多少；
  (c) 接收机可见的残差余量对 m4 的 AUC，与 syndrome 比。
  - 会让我改为"继续"的证据：genie 补全救回 ≥ 70% 的 ρ = .15 失败，**且**可见残差余量 AUC ≥ .80 并在 ρ = .20 上事先写下的预测成立，
    **且**能说明它为何会把最优 ρ 从 .30 移开。前两项成立而第三项不成立，产出也只是论文局限节里一段机制说明。
- 交给论文任务的信息（不改该任务，只登记）：在 ρ = .30，CD4 失败帧支撑已齐全、syndrome 能预测失败（AUC .81），这支持"失败后继续迭代而不是重搜"的写法。

**否定台账草稿（Eric 确认停止后再写入台账）**：
低导频漏径线（11-20 两周限时）停止。观察：ρ ≤ .20 的 CD4 失败帧残留未建模弱径（中位 0.19σ²），CD6 多搜找回 0/19；ρ = .30 失败帧不缺路径（0.012σ²）。
按停止条件 3 停。复活条件：(i) 出现导频开销占用速率或 ρ ≥ .30 不可行的系统设定（例如多用户导频功率受限、P 更大），使 ρ ≤ .20 成为会选的工作点；
或 (ii) 论文任务的迭代数据里出现可见量能预测残余弱径（格内 AUC ≥ .80）。
