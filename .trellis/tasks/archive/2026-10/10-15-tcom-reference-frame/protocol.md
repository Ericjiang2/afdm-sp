## 3. P1 新确认（主实验）

### 3.1 设计

| 因素 | 取值 |
|---|---|
| 信道场景 | U = 修正后的 UWA 律（D1、D2 修复，正多普勒）；G = 修正后的几何多普勒律（D1、D2、D3 全修） |
| ρ | .3（设计最优点，见 e_rho P1）；.5（生产参考） |
| SNR | 4.5, 5.0, ..., 8.0 dB（8 个点） |
| 帧数 | 每个 (场景, ρ, SNR) 2000 帧；信道、比特、噪声在 ρ 和 SNR 之间共享（与 e_rho 相同的配对设计） |
| 熵 | 新的 256 位 OS 熵，在冻结 commit 中记录；domain 常数与已有流不同 |
| 系统 | N=1024，QPSK，LDPC (3,6) n=2048，总功率为 1，sigma2 已知（与前瞻一致） |

### 3.2 接收机臂

| 臂 | 定义 | 角色 | 平均耗时（单进程，已有测量） |
|---|---|---|---|
| F0 | 导频前端 + TF_J20_R2 | 基准 | ~.33–.35 s |
| B | F0 + CSTATE20（仅在 F0 失败时触发，F0 作为前缀不另计时间） | 主方法 | ~.34–.37 s |
| LOCAL | F0 + LOCAL20（CSTATE 核，max_edits = 0） | 消融：全局重开是否必要 | ~.36 s |
| C = F1 | 冻结的 NOMP 强前端 + TF_J20_R2 | 审稿风险对照：用更强的前端代替救援 | ~.67 s |
| D = F1+CSTATE | C + CSTATE20 | 只报告 | ~.67 s |
| A3 | true-H 固定，TF20R2，不 refit，不 CSTATE | 参照上限（genie CSI） | ~.3 s（待测） |

计时：另跑一个安静的计时子集（每格 100 帧，8 个分片），作为唯一的耗时证据；正式运行时的耗时只描述，不作结论（沿用前期经验）。

### 3.3 预注册假设与判定

每个 (场景, ρ) 是一个"格"，共 4 格。

- **H1（B 优于 F0，主假设）**：对 F0 的 FER 落在 [1e-3, .5] 的 SNR 点，用配对精确 McNemar（单侧）检验，在格内做 Holm 校正，alpha = .05；
  同时用帧块 bootstrap 计算 @FER 1e-2 的 dB 增益及 95% CI。
  **PASS**：4 格中，每格至少 75% 的合格 SNR 点显著，且 dB 增益的 CI 不含 0。
  **FAIL**：任何一格的 dB 增益 CI 含 0 或为负，则 CSTATE 主线在该信道上不成立。停止并报告，不换方法补救。
- **H2（离 genie 多远）**：报告 B → A3 @1e-2 的 dB 差距及 CI。只有当某格的 CI 上界 ≤ .5 dB 时，论文才在该格写"距 genie-CSI 0.5 dB 以内"。
- **H3（对强前端）**：@1e-2 时，B 的穿越 SNR 不劣于 C 超过 +.1 dB（CI 上界），且 B 的安静平均耗时 ≤ .65 × C。
  PASS 时可写"以约 X 倍更低的成本达到强前端的可靠性"；FAIL 时 CSTATE 只能定位为"低成本救援"，不写可靠性持平。
- **H4（全局重开）**：B 对 LOCAL 的配对比较，只报告，不作必要性主张（沿用 SCOPED）。

### 3.4 成本

约 8 SNR × 2000 帧 × 4 格 = 64k 帧。每帧所有臂合计约 1.4 s，共约 25 core-hours；在 30 个分片、×1.5 的竞争开销下，实际约 1.3 h。
计时子集另需约 1 core-hour。

## 4. P2a Zheng 2025 复现与移植

### 4.1 来源与已知细节

- 正式版：K. Zheng et al., "Joint Channel Estimation and Data Detection for AFDM With Superimposed Pilots," GLOBECOM 2025,
  pp. 1298–1303, DOI 10.1109/GLOBECOM59602.2025.11432016（会议论文，付费墙）。
- 预印本 arXiv 2404.10232（本会话已读）：
  - 导频：DAFT 域等间隔冲激，间距 ≥ Q+1，Q = (l_max+1)(2α_max+1) − 1。
  - 估计：在 Q+1 个整数时延-多普勒网格点上做 LMMSE（数据干扰按 Gaussian 噪声处理）；阈值 γ = 3·sqrt(σ_ŵ²/σ_p²)。
  - 检测：MP 检测器（**更新规则未给出**）。
  - 迭代：减去重构的数据后重估信道，BER 结果用 2 次迭代。
  - 设定：N=512，P=3，l_max=2，α_max=2，整数多普勒，**不编码**，导频 SNR 固定 50 dB，扫数据 SNR。
- 缺失：MP 的细节、软/硬反馈、阈值是否取模。若能拿到 GLOBECOM 全文，以全文为准（§9 D5）。

### 4.2 复现 gate（在它自己的设定里）

- G-Z1：true-H 时，MP 检测器的 BER 与 LMMSE 检测器参照一致或更好（N=512，P=3）。
- G-Z2：信道 MSE 随迭代单调下降，并趋近"已知支撑"的 LMMSE 界。
- G-Z3：从 arXiv 图中读出 2–3 个 BER 点（标注为读图值），复现值在 1 dB 以内。若读不出，记为"仅定性复现"。
- MP 实现：没有全文时，采用标准 AFDM MP（Bemani 等 2023 的 MP 检测器，在实现说明里写明），并标注"按预印本 + 标准 MP"。

### 4.3 移植到 P1 的场景

在我们的信道里，Q+1 = 103 × 5 = 515，所以 N=1024 中最多只能放 1 个冲激导频。移植版使用：
- 单个叠加冲激导频，导频能量 = ρN（与 ZC 导频总能量相同）。
- **Z-faithful**：整数网格（515 个点）+ LMMSE + 阈值 + MP，2 次迭代，最后一次检测后做一次 LDPC 译码。
- **Z-adapted**：同上，但网格换成多普勒步长 0.25 的分数网格（与 CSTATE 的 2575 原子银行同尺度），以适应分数多普勒。
- **Z-turbo**（我们的修改，单独标注）：每次迭代都用 LDPC 外信息作软反馈。
- 比较方式：同场景、同 ρ、同 SNR 网格、同一批帧（共享信道、比特、噪声），报告 FER–SNR 和平均耗时。
- **H5**：@1e-2 时，B 的穿越 SNR 低于 Z-faithful 和 Z-adapted，且 CI 不含 0。若对 Z-adapted 不成立，论文不得声称优于该基线。

## 5. P2b 嵌入导频（EP）

- **主场景不可行（解析）**：EP-AFDM 需要导频加两侧保护带共 2Q+1 个符号（分数多普勒还要加 ξ）。
  l_max = 102、α_max = 2 时，2·514 + 1 = 1029 > N = 1024，保护带超过整帧。论文据此说明叠加导频的必要性，这是一个计算结论，不需要仿真。
- **缩小时延跨度的场景 S**：l_max = 25（Q = 129，保护带 259，占 25.3%），其余同场景 G。
  - EP：单导频加保护带（Bemani 等 2023 的阈值估计），LDPC 用 (3,6) 规则码，长度 n = 2·(1024 − 259) = 1530，由同一构造器生成；同总能量。
  - SP：B 和 F0，ρ ∈ {.3, .5}。
  - 指标：goodput = 信息比特 × (1 − FER) / 帧，按 SNR 报告；另报告 FER–SNR。
  - **H6**：goodput 差的 CI 不含 0 的 SNR 点至少 3 个时，才写"在该场景下 SP 优于 EP"；否则写"持平"或"EP 更好"。
