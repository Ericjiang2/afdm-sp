# E-3 技术设计

## 1. 问题

H* 说的是：数据辅助的支撑决策中，同一时延上各原子的译码不确定性是相干的；标量化会产生同时延幻影原子，而投影协方差 Γ 能消除它们。E-1/E-2 只在 CSTATE 的离散交换搜索里验证过这一点。E-3 换一个与 CSTATE 无关、按文献风格搭建的估计器（Luo 式 EM-SBL），检验两件事：

- 幻影是否同样出现；
- 改用 Γ 后，幻影是否消失、FER 是否改善。

可能出现三种结果，含义各不相同：

1. 文献式接收机同样出现幻影，Γ 能修复：H* 是领域通行近似的缺陷。
2. 出现幻影，但 Γ 修不好：H* 依赖搜索结构。
3. 根本不出现幻影：H* 只适用于离散交换搜索，SBL 的连续 ARD 机制可能天然抑制幻影。

## 2. 接收机（所有变体共用）

信号与约定沿用 P1 管线和 `geometry_reopen.py`：观测 Y 与 `reopen_geometry` 相同；原子响应 B = `_responses(xt, atoms)`；Γ = `_gamma_cross(atoms, atoms, vf, c1)`，其中 vf = fft(v)。这些都从冻结文件只读导入。

**原子网格**：时延 0..`l_max_cap`，Doppler 在 [−3, 3] 内以 .25 为步长，共 K = 2575 个原子，与 CSTATE 重开核和 Zheng 移植的 'frac' 网格相同。

**EM-SBL 核心**（Luo 式。字典含不确定数据时，按 EIV 的期望二阶矩处理）：
- 先验：h_k ~ CN(0, γ_k)，噪声精度 β。
- E 步：Σ = (β(B̄ᴴB̄ + Γ_var) + diag(1/γ))⁻¹，μ = β Σ B̄ᴴ Y。
- M 步：γ_k = |μ_k|² + Σ_kk。
- 精度更新：β⁻¹ = (‖Y − B̄μ‖² + μᴴ Γ_var μ + tr((B̄ᴴB̄ + Γ_var) Σ)) / N。
- 停止：最多 100 次迭代；γ 的相对变化 < 1e-4 即停。
- 剪枝：γ_k < 1e-6 · max γ 的原子被移除。

**筛选**（偏差：Luo 在 ℓmax = 12、N = 256 上使用全网格；本移植中 K = 2575 太大）：每级先用 |B̄ᴴY| 取前 M = 256 个原子作为候选集，再对候选集运行 SBL。

**输出选择**：保留 |μ_k|² ≥ 1e-3 · Σ|μ|² 的原子，最多 24 个（按能量取最大者），允许同时延。这些原子组成 `Channel` 交给检测器。

**两轮流程**（结构对应 Luo 的两阶段；检测/译码换成本项目的同一组件）：

1. **第 1 级（只用导频）**：B̄ = B(pilot)，Γ_var = 0。数据当作白干扰，β₀ = 1/(σ² + (1 − ρ))，与 Zheng Lemma 1、Mishra 的标量模型一致。所有变体共用这一级。
2. **第 1 轮检测与译码**：`scalar_joint(..., gain_mode='fixed', prior=None, iterations=20, damping=.3)`，再接 `decoder_messages(maxiter=50)`。由 `moments(clip(app), 1 − ρ)` 得到 μ_d 与 v。
3. **第 2 级（数据辅助）**：
   - 候选集 = 软均值字典 B(pilot + μ_d) 的前 256 个原子，再并入第 1 级保留时延上的整行 Doppler（25 个原子/时延）。
   - 四个变体共用同一候选集。
   - 各变体按 §3 运行 SBL。
4. **第 2 轮检测与译码**：`scalar_joint(..., gain_mode='fixed', prior=clip(check), iterations=20, damping=.3)`，再接 LDPC。读出 FER。

## 3. 变体（只在第 2 级不同）

| 变体 | 字典里的数据 | Γ_var | β₀ | 含义 |
|---|---|---|---|---|
| L-hard | 硬判决重调制 Mod[Demod(μ_d)] | 0 | 1/(σ² + mean(v)) | Luo 原样（Alg. 1 第 11 行；式 (24) 各向同性） |
| L-diag | 软均值 μ_d | Σv · I（= diag Γ） | 1/(σ² + mean(v)) | 标量化，对应 E-1 的 A2 |
| L-cov | 软均值 μ_d | 完整 Γ | 1/(σ² + mean(v)) | 投影协方差修正，对应 A1 |
| L-genie | 真数据 | 0 | 1/σ² | 网格失配基线（无数据不确定性） |

## 4. 帧与 SNR

**帧**
- P1 生成器：U/G × ρ ∈ {.3, .5}。主跑用帧 4000..4399；校准用帧 6000..6099。执行者需查证这两段帧此前未被使用。
- 主跑对全部帧运行，读出**无条件 FER**，不以 F0 失败为条件。

**SNR 网格（冻结规则，只看 L-hard）**
- 在校准帧上扫描候选网格 {4, 5, …, 14} dB。
- 每格取 L-hard 的 FER ≤ .9 的最小 SNR 记为 s0，网格为 {s0, s0+1, …, s0+5}，超过 14 dB 的点截断。
- 若某格到 14 dB 时 L-hard 的 FER 仍 > .9，该格判为 UNINFORMATIVE，不跑主跑。

## 5. 读数与冻结判据

**普查口径**（与 E-1/E-2 一致）
- 显著原子：输出选择后保留的原子。
- 同时延对：两个显著原子时延相同。
- 每帧对数记为 n_pair。对每对记录 |Δν|、|D_N(Δν)|，以及该时延是否为真时延。
- 幻影超额 E_v = mean(n_pair | v) − mean(n_pair | L-genie)。

**统计**：cluster bootstrap（cluster = (场景, ρ, 帧)，20000 次，seed 20261017，百分位 95% CI）；精确单侧 McNemar（α = .05），只用 log10 p 报告。凡"CI 含 0"一律附注 "not significant != equivalent"。

**判据**
- **X1 幻影存在**：CI_lo(E_L-diag) > 0 **或** CI_lo(E_L-hard) > 0。两者都报告，分别记为 X1-diag、X1-hard。
- **X2 修正去除幻影**：比值 R_ph = E_L-cov / E_L-diag 的 CI 上界 ≤ .25。只有 X1-diag 成立时才评估；否则 X2 判为不可评估。
- **X3 FER 改善**：主对比是 L-cov 与 L-diag（两者都用软数据，只差 Γ）。要求同时满足两条：
  - 合并全部 (格, SNR) 单元后，单侧 McNemar（L-cov 优于 L-diag）显著；
  - FER 差 (L-diag − L-cov) 的 CI 下界 > 0。
- **报告项**（不参与判定）：
  - L-cov 对 L-hard 的 McNemar 与 FER 差；
  - FER 达到 1e-2 处各变体的穿越点；
  - L-genie 的 FER，作为健全性检查；
  - NMSE；
  - 成本。

**判定**（按顺序，互斥）
1. ABSENT：X1-diag 与 X1-hard 都不成立。
2. NO-FIX：X1-diag 成立且 X2 不成立。
3. MECHANISM-ONLY：X1-diag、X2 成立，X3 不成立。
4. GENERAL：X1-diag、X2、X3 都成立。
5. HARD-ONLY：只有 X1-hard 成立。此时幻影只来自硬判决，不评估 X2/X3。

## 6. 门

- **T1 SBL 正确性**：合成数据上，原子在网格上、无噪声时精确恢复支撑；v ≡ 0 时 L-cov = L-diag = 以 μ_d 为字典的标准 SBL，三者逐位一致。
- **T2 Γ 正确性**：
  - diag(Γ) = Σv（容差 1e-10）；Γ 为 Hermitian、半正定。
  - 在一个合成帧上，Γ 与蒙特卡罗估计 E[(B(x) − B(μ))ᴴ(B(x) − B(μ))]（x 按软后验抽样 4000 次）的相对 Frobenius 误差 ≤ 5%。
- **T3 下游接线**：用真信道路径、`gain_mode='fixed'` 时，检测与译码调用在 P1 帧 0..19 上复现 P1 ledger 中真信道臂的决策；如定义不匹配，执行者需说明并改用等价核对。
- **T4 确定性**：四个变体同输入两次，结果逐位一致。
- **T5 成本**：smoke 计时后估计总核时，上限 40。

## 7. 局限

- 细网格 on-grid 是对 Luo off-grid 方法的简化：分数 Doppler 会带来网格失配分裂，所以必须扣除 genie 基线。
- 检测器与译码器沿用本项目组件，不是 Luo 原文的检测器。
- 只有一个外部估计器族（SBL）。若判定为 ABSENT，结论只说明 SBL 不出现该现象，不推广到所有文献接收机。
