# 编排者跑前预期（2026-10-17，冻结前、主跑前）

这是我看过 smoke 计数之后、主跑之前写下的预期，只用于事后对照，不是判据，也不改变协议。smoke 计数为：8 dB，32 个键，FER 依次为 L-hard / L-diag / L-cov / L-genie = 2/0/2/0；每帧平均同时延对数 n_pair 依次为 6.84/30.47/5.53/5.34。

## 推导：标量 Γ 会奖励"把一条径拆开"

EIV 期望残差为 E‖Y − B(x)h‖² = ‖Y − B̄h‖² + hᴴΓh。考虑两个同时延原子 i、j，记 D = D_N(Δν)，则 Γ_ij = Σv·D·相位。

- **完整 Γ**：惩罚项为 Σv(|h_i|² + |h_j|² + 2Re(D h_i* h_j))。当 Δν → 0 时 D → 1，惩罚变为 Σv|h_i + h_j|²，只取决于两者之和，所以拆分没有任何好处。
- **对角 Γ**：惩罚项为 Σv(|h_i|² + |h_j|²)。若总增益 g 固定，把它平分到 k 个近重复原子上，惩罚就从 Σv|g|² 降到 Σv|g|²/k。拆分直接获得奖励。
- **Γ = 0**（硬判决或真数据）：没有这一项，也就没有拆分奖励。

两个原子等分时，对角 Γ 相对完整 Γ 多出的虚假奖励为 Σv|g|²·Re(D)/2（相位对齐时）。它在 |D_N| → 1 时最大；在 |D_N| < .5 时仍不为零。

## 由推导得出的预期

1. **幻影只出现在 L-diag**，形式是同一时延上一条真径被拆成若干近重复原子；L-cov、L-hard 都接近 genie。v 越大（低 SNR）拆分越多。这与 smoke 一致（30.5 对 5.5、6.8、5.3），也与 E-1 中 A2 的伤害集中在 4.5–6 dB 一致。
2. **在 SBL 中这些幻影大概率无害**：拆出来的原子响应近乎相同，检测器会把它们相干相加，合起来的信道近似不变。所以 X3（FER 改善）多半不成立，预期判定为 MECHANISM-ONLY。
3. **在 CSTATE 中有害**是因为路径槽位固定（8 个）：交换出一个幻影，必然挤掉另一处的真径。由此推论：凡是容量受限的估计器（已知 P 的 OMP、top-P 门限、固定槽位交换），伤害都应该出现；无容量约束的 SBL 则不会。
4. **这同时给出了决策层理论的雏形**：解释 E-2 中 R 族 |D_N| < .5 的幻影（A2n 只恢复了 G_n = .815）。

## 若主跑与预期不符

- X3 成立（L-cov 的 FER 优于 L-diag）：说明拆分在 SBL 中也有害，第 2、3 条要修正。
- X1-diag 不成立，或 R-iter 显示幻影依赖迭代预算：第 1 条要修正。
