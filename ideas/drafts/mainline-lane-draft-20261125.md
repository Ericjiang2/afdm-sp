# 草案：漏斗「贴主线」通道（`[主线贴合]`）

状态：**第十二轮试行**（Claude 2026-11-25 起草；同日 Eric 先澄清漏斗目的不是服务主线、标为不采纳，随后决定仍在第十二轮小规模试行，见 [`../prompts/round-12.md`](../prompts/round-12.md) 第四节。试行结果出来前不并入 `FUNNEL.md`）。

## 1. 为什么要这条通道
- 现行规则（第 10–11 轮）只收「AFDM 专属、挂在已发表论文痛点图上」的题：停用锚点 B（自家接收机读数）、高要求组要求净赢 `OFDM (c1=c2=0)`、放宽组规定「设 $c_1=0$ 代码不改照跑即判 (2)」。
- 漏斗至今唯一 promoted 的卡 [`I-20261121-l02`](../cards/I-20261121-l02.md)（码与叠加导频接收环路失配）在这三道门上都会被杀：锚点是自家 EXIT 曲线；按检测器曲线设计码对叠加导频 OFDM 同样成立；母方法（ten Brink 2004 EXIT 曲线拟合）直套就是它本身。
- 但 l02 的难处是**叠加导频编码接收专属**的（译码反馈同时改善信道估计和数据对导频的干扰，内环曲线特别陡），而叠加导频 AFDM 编码接收正是主线。现行规则会系统性地挡掉这类从主线系统里长出来的跨层题。

## 2. 什么题进这条通道（三条同时成立）
1. **系统**：叠加导频（SP）AFDM/OTFS 编码接收，处在主线关心的区间：低导频比 $\rho \le .30$、编码 FER 悬崖、迭代检测–译码–信道估计闭环。
2. **机制**：难处来自 SP 结构或编码迭代闭环本身（例如导频–数据互扰随反馈变化、首轮起步门槛、码与内环的匹配、闭环的触发与重试），而不是某个外围模块的工程毛病。
3. **不重复**：不重开已按预注册关闭的线，也不重复现稿内容。已关闭：第 0 轮多普勒线（A1–A6，11-25 `STOP`）、低导频漏径线（11-20）、候选一「导频只管捕获」（11-21）、协方差作为原理（11-20）；现稿内容：CD2 对 HG 的迭代 vs 重搜、对角 Γ 陷阱、Stein 噪声估计。动笔前查 [否定台账](../../.trellis/tasks/09-22-tf-production-gap-audit/research/discovery_negative_results_ledger.md)。

## 3. 入口门（替代「Paper-Figure First」与锚点 B 禁令）
- **允许锚点 B**，但必须过「公开体制复现门」：痛点要在至少一个已发表的 SP-OTFS/AFDM 编码接收机设定下复现（例：Kanazawa 等 arXiv 2501.15935 的参数与现成 LDPC），或在本项目冻结主线接收机上复现、且该接收机在一个已发表设定点上与原文读数一致（同红线 1 的口径）。只在私有代码接口里出现的毛病照旧不收。
- **对手**：同一 SP 体制下最强的已发表接收机，加上主线当前最强配置（CD2，同轮数、同重试预算、同译码调度），两者取较强。**不要求净赢 OFDM**；「设 $c_1=0$ 照跑」也不作为淘汰理由。
- **专属性改为描述性读数**：报告「把叠加导频换成等开销正交/嵌入导频后，增益还剩多少」。增益基本不剩，说明机制确实在 SP 结构里；仍有大部分增益，就如实写成「通用编码接收结论，在 SP-AFDM 上验证」，交 Eric 判断，不自动淘汰。

## 4. 账本与门槛
- **主账**：主线帧上的编码 FER 交叉点（1% 为主、10% 为辅），配对帧自助法。主判据：相对第 3 节对手的增益 95% 下界 `≥ 0.5 dB`（与 11-24 分歧表两方一致采用的门槛相同）；或在同 FER 下把触发后耗时降到 `≤ 1/3`。
- **产出档次写明**：这条通道的合格产出是「主线论文的一节或配套快报」，不要求 Transactions 独立成篇；卡面 `value` 允许为 2。
- 其余纪律全部照旧：预注册与样本量估算（含「差一点」交 Eric）、零真值泄漏、对称初始化、`PASS_PRIMARY == false` 当场结案、L2 前 Sol 代码快检、第 8 步异族终审。

## 5. 配额与归属
- 每轮至多一个 runner 的 25% 时间，或单独一个短会话；卡面筛选记录首行标 `[主线贴合]`。
- 过 L2 并经第 8 步终审的卡不自动升 L3，由 Eric 决定并入主线论文、写成配套快报，或封存。

## 6. 回溯检验：l02 在本草案下会怎样
- 第 2 节：系统符合（SP 编码接收，$\rho = .30$，K = 224）；机制符合（内环陡、门槛型码只认起点）；不重复（码设计不在现稿与已关闭线中）。
- 第 3 节：锚点 B 需补「公开体制复现门」，当年没做，需要在 Kanazawa 设定下补一次；对手为规则 (3,6) LDPC 加十轮主线调度，当年已对比。
- 第 4 节：六点 CRC 真闭环在 L28、10% FER 处净赢 0.87 dB（扣有效比特能量后），点估计过 0.5 dB；但 1% 交叉点「增益区间无有限界」，按本草案主判据（1% 为主）会落在「差一点」或未过，应交 Eric 定（收窄到 10% FER 的论点即可用）。
- 结论：l02 在本草案下能进门、能跑到 L2，最终大概率是「收窄后可用」，与它实际的收官结果（短快报线）一致。草案没有把它放宽成 Transactions 卡，也没有错杀它。

## 7. 风险
1. **后门风险**：锚点 B 当初被禁，是因为太多题只是私有代码的毛病。靠「公开体制复现门」加冻结主线接收机来防，但仍要盯第一批卡的复现质量。
2. **目标变宽**：漏斗同时用三套标尺（高要求、放宽、贴主线），runner 容易混用。靠卡面首行标签和查新提示词显式写组别来防。
3. **抢主线资源**：主线下一步是写论文；这条通道的产出应当服务论文，而不是另起新线。
