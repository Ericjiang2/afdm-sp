# 本地第 4 轮 L2 读数 1 的跑前判据（卡 I-20261122-l32；2026-11-22 16:45，runner l）

背景：兜底评审（`ideas/reviews/neon-fallback-gate-l32-20261122.md`）判 REVISE，点名三处：复算漏了生成器的 D1 截断（最大时延 ≤ 102 的重抽）；没有按物理帧的区间；没查 F0 在高信噪比的非对称残余平台。本读数只做算术：把 ρ 扫描存档的逐帧误帧（deinlab `experiments/rho_sweep_20261119/out/main_20261119/rows_shard*`，62,400 键，已抽成 `ideas/l2/out_r4b1/rho_sweep_fail_F0_CD.json.gz`，远端 md5 42918b0829bfa91a6751a9355c58c517）按总能量分布做卷积。不跑接收机。

已经看过的：第一版复算（无 D1 截断、无区间）的点估计：固定 ρ = .30 的 F0 − CD 单位能量 +1.71 dB、衰落后 +0.65–0.69 dB；评审自己的复算 +0.67 dB、P1 +0.41 dB。所以下面的判据是对"区间"和"敏感性"写的，点估计不再是预测。

设定（写死）：
- 总能量分布两种：等权 8 径 Gamma(8, 1/8)；项目功率谱（指数到达间隔均值 0.8 ms、10 ms 衰 20 dB、fs 16 kHz、8 径，最大时延超过 102 抽头的抽样重抽——时延按 `delay_index − 1` 计，这是对生成器 D1 规则的近似，不含多普勒对时延索引的修正），逐帧条件均值为 1。
- 卷积：单位能量曲线在 SNR 网格上按 log10 线性插值；低于第一个点记 1；零误帧点按 10⁻⁵ 处理；高于最后一个点保持最后一个值。穿越点：1% 误帧率，U、G 分别求再取平均（与存档口径一致）。
- 区间：对 400 个物理帧做整群自助（同一帧的全部 ρ、SNR、场景、臂一起抽），2,000 次，95% 百分位区间。
- 平台敏感性：只给 F0 在 SNR ≥ 9 dB 的点加残余平台 0 / 0.1% / 0.25% / 0.4%，CD 不加。

判据：
1. "明显收窄"：项目功率谱下，固定 ρ = .30 的（单位能量差距 − 衰落后差距）的 95% 区间下界 > 0.3 dB → 成立；区间含 0 → 不成立；其余 → 方向成立、幅度不定。
2. P1 双重差分（定义照 `experiments/rho_sweep_20261119/PROTOCOL.md`，脚本里从该文件核对后实现；若实现不出与存档 +1.26 dB 相差 0.1 dB 以内的单位能量值，就不报 P1）：同上规则。
3. 平台敏感性只报数，不设门槛。
4. 预测（主观概率）：判据 1 成立 .80；平台 0.4% 时衰落后差距回到 ≥ 1.0 dB .50。
