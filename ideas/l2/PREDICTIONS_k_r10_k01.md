## 2. 主判定规则（`PASS_PRIMARY`，严格 ≤ 2 条硬条款，不得事后改口）

- **Clause 1（真实过采样 3D 双基地移动场景核心破壁 + 2×2 DiD + 校准虚警检测增益）**：
  在主场景 `S1`（`LOS=+18 dB, Clut=+28 dB, v_T=220 m/s, v_car=25 m/s`）与静态对照 `G0`（`v_T=0`）的预锁定非饱和目标工作点 **`SNR_t = -11 dB`**（配对 `N_pos = 60` 场景，独立校准 `P_fa = 10^{-3}`）上，相对所有等 `12.5%` 导频预算 OFDM 对手（`OFDM-Comb`、`DBU/Group-OFDM 2604.10296`、`OFDM-BlkPil(1/8) MultiSym-JointEM`）中的**最强者**：
  1. `S1` 配对检测输出 SCNR 增益的 **95% 置信下限 `≥ +1.0 dB`**（开发集预期 `~+12 至 +14 dB`）；
  2. `2×2` 差中之差 `DiD = (SCNR_AFDM - SCNR_OFDM_best)_S1 - (SCNR_AFDM - SCNR_OFDM_best)_G0` 的 **95% 置信下限 `> 0.0 dB`**；
  3. 预锁定非饱和工作点 `SNR_t = -11 dB` 处，经验 `P_fa = 10^{-3}` 检测概率增益 `ΔPd = Pd_AFDM - Pd_OFDM_best` 的 **95% 置信下限 `> 0.0`**（开发集预期 `~+0.70 至 +0.90`）。
- **Clause 2（真实过采样 RRC 物理泄漏机制 + 静态退化检验）**：
  1. 在 `OSR = 8, β = 0.25` 真实 RRC 连续时间信道（30 个 3D 弯曲杂波散射点 + 2D 横向展宽，`30` 独立试验）上，`Matched Centered Ridge-AFDM (+μ/2N)` 的数据到导频泄漏功率比 `OFDM (0)` 低 **`≥ 15.0 dB`** 且比反号失配 `(-μ/2N)` 低 **`≥ 20.0 dB`**；
  2. 在静态对照 `G0 (v_T=0, μ=0)` 等激活子载波（`193` bins）下，`Ridge-AFDM (c1=0)` 与 `OFDM-Comb (193 bins)` 的配对平均 SCNR 差绝对值 **`≤ 0.20 dB`**（严格验证物理对偶退化）。
