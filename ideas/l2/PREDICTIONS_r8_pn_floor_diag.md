# 预注册：相噪找径地板·6 帧定位诊断（2026-11-24，执笔 Claude Opus 5.5；任何诊断臂运行之前）

上游：`ideas/l2/PREDICTIONS_r8_pn_floor.md`（提交 `78212afb4`），结果 `ideas/l2/out_r8_pn_floor/summary.json`，判定 `FLOOR_CANDIDATE`（只说明"值得查"）。本诊断不建卡、不改任何卡片；余量检验的 `PASS_PRIMARY = false` 不变。

## 要回答的问题
在 σ² = 0.0164、ρ = .30 的设定下，有 6 帧 `BEST`（全盲找径）从 7 到 12 dB 每档都错，而白送第 0 轮真径的 `BESTGA` 每档都对：
- U 场景：54058、54268；
- G 场景：54090、54094、54112、54203。

本诊断回答两个问题：
1. 失锁卡在找径的哪一步：相位初值、径位置，还是后面的链路？
2. 用更强的现成盲方法能否救回来？救得回来说明是实现偏弱，这条线收官；救不回来，再看是否存在"仅凭导频分不开"的结构性模糊。

## 零成本预查（已做，Claude，2026-11-24 13:40，本机内联计算，只用 `theta()` 与 `truth`，没有调用接收机）
- 被检验的假设是 H_edge：相噪的整体线性斜坡等效于所有径一起平移多普勒，把径推出 `pilot_front` / `seg_init` 的整数多普勒网格（−2…2）。
- 读数：6 帧的整体斜坡（折合多普勒格）|dk| = 0.22 / 0.48 / 0.72 / 1.18 / 1.77 / 0.65，平移后最大 |k + dk| = 1.13 / 1.91 / 2.33 / 2.79 / 3.36 / 2.22；去斜坡后的残余相位标准差为 0.54–1.24 rad。
- 对照：每场景从未出错的帧（U 293 帧、G 282 帧）中，|k + dk| 的 p99 约 3.2、最大 3.4–3.5，残余相位标准差中位数约 0.95、p90 约 1.4。
- 结论：失败帧在这三个量上都落在正常帧的分布之内，H_edge 不成立，也找不到单一的帧级特征。因此需要逐步定位。

## 第 1 阶段：逐步定位（臂表）
所有臂都在同一帧上共用同一组信道、噪声和相噪轨迹。

| 臂 | 用了哪些真值 | 内容 | 作用 |
|---|---|---|---|
| `A0 BEST` | 无（仅打分） | 上游 `best_blind` 原样 | 确定性复现：6 帧 36 键必须全错 |
| `A1 BESTGA` | 真径（位置 + 增益） | 上游原样 | 复现：36 键必须全对 |
| `L1 G_PHASE` | 真实相噪轨迹 θ（只用于初值） | 用 `yt·e^{−jθ}` 代替 `seg_init` 的输出，之后 3 遍 `pilot_front` ↔ 跟踪及后续链路与 `BEST` 相同（单一变体，取冻结常数的 `mode`，S 不用） | 失败是否出在相位初值 |
| `L2 G_SUPPORT` | 真径位置（`l_i`, `k_real`），不给增益 | `seg_init` 照常；第 0 轮导频模型取真径位置的 `regressors`，增益用最小二乘拟合当前解旋信号，交替 3 遍（每遍只重拟增益、重跟踪相位）；之后链路与 `BEST` 相同 | 失败是否出在径位置估计 |
| `S1 WIDE` | 无 | 先跑上游 4 个变体；全部不过时，再加 `seg_init` 分段长 {16, 128} × {sp, kf}（`top-K = 8`），然后 8 种分段 × {sp, kf} 配 `top-K = 16`；按校验式通过即停 | 搜索更宽能否救回 |
| `S3 DA_REACQ` | 无 | 先跑上游 4 个变体；全部不过时，取最终校验重量最小的那次尝试，用其 APP 软符号 `mu` 构成"导频 + 软数据"参考（`o['pilot'] = pilot + mu`，`pilot_front` 直接读 `observed['pilot']`），重做 `seg_init`（原子换成该参考的 `regressors`）和 3 遍 `pilot_front`；至多 2 次，校验式通过即停 | 数据辅助重捕获能否救回 |
| `S_PLUS` | 无 | 上游 4 个变体 → `S1` 新增部分 → `S3`，校验式通过即停 | 最强盲组合，主判据用它 |

另有两项测量，在 `A0` 与 `A1` 上记录，不算臂：
- `M1` 第 0 轮径匹配：`A0` 每个变体 3 遍 `pilot_front` 后得到的径，与真径比，记录匹配条数（时延相同且 |Δk| ≤ 0.5）和匹配径占真径总功率的比例；同时按上游 `diag` 模式的 `pv()` 记录 `pv_r0` / `pv_end`（`A0` 与 `A1` 都记）。
- `M2` 导频拟合残差：对 `A0` 第 0 轮结束时的导频模型 m_blind 和 `A1` 的 m_true，用同一跟踪器（冻结 `mode`、单极点常数 `A0 = 0.06`，即脚本里的模块常量）解旋，计算 J = mean|解旋后 yt − m|²。Δ = (J_blind − J_true) / σ²_n，σ²_n 为该键的 `obs['sigma2']`。如果 `A0` 有 4 个变体，取 J_blind 最小的那个。
  - 标定规则（跑前定）：先在对照帧 12 dB 上算 Δ（盲找径找对时 Δ 应接近 0）；判别阈值取 max(0.5, 3 × 对照帧 |Δ| 的最大值)。

"救回一帧"的定义：该帧在 6 档 SNR 中至少 5 档译码零错，而且 12 dB 必须零错。

### 第 1 阶段判定（跑前锁定）
- **先决条件**：`A0` 在失败帧 36 键中全错，`A1` 全对；对照帧上 `A0` / `A1` 全对。不满足说明流水线不确定或复现失败，停机报告，不给判定。
- **`BLIND_RESCUES`**：`S_PLUS` 救回 ≥ 5/6 个失败帧，且在对照帧 36 键中出错 ≤ 1 个。进入第 2 阶段。
- **`STRUCTURAL_CANDIDATE`**：`S_PLUS` 救回 ≤ 1/6，且 `M2` 在 12 dB 上至少 4/6 帧满足 Δ ≤ 阈值，即错误解对导频的拟合不比真解差。含义是仅凭导频分不开，搜索得再好也没用。不进入第 2 阶段，报告后由 Eric 决定是否写成卡片草稿。
- **`SEARCH_GAP`**：`S_PLUS` 救回 ≤ 1/6，且 `M2` 在 12 dB 上至少 4/6 帧满足 Δ > 阈值，即存在拟合明显更好的解，但现成的搜索找不到。仍属实现层面，记一条教训后收官。
- **`MIXED`**：其余情况。如实报告，不做后续。
- 定位结论（与主判定并列报告，只是描述）：
  - `L1` 救回 ≥ 4/6，说明卡在相位初值；
  - `L2` 救回 ≥ 4/6 而 `L1` 救回 < 4/6，说明卡在径位置；
  - 两者都 < 4/6，说明要同时给增益或整条链路才行，记为"链路耦合"。

## 第 2 阶段：新帧确认（只在 `BLIND_RESCUES` 时运行）
第 1 阶段的盲臂是在挑出来的 6 帧上评估的，有选择偏差，所以需要在全新帧上确认地板是否消失。
- 帧：55000–55299，U 与 G 各 300 帧；SNR 10 / 11 / 12 dB；臂 `BEST`、`BESTGA`、`S_PLUS`。
- **`CLOSED_IMPL`**：两场景 `S_PLUS` 在 11 dB 与 12 dB 的错帧数都 ≤ 1/300，且 G 场景 `BEST` 在 12 dB ≥ 3/300（新帧上复现了地板）。结论：地板来自实现偏弱，用现成部件可修，这条线收官。
- **`FLOOR_NOT_REPRODUCED`**：G 场景 `BEST` 在 12 dB < 3/300。新帧上没有复现地板，同样收官，并注明上游的 4 个固定错帧可能是小样本现象。
- **`FLOOR_PERSISTS`**：其余情况。如实报告残余地板的大小，由 Eric 决定。

## 竞争假设与预测
1. **H_search（实现偏弱）**：盲找径落入局部最优，真解对导频的拟合明显更好。预测：`M2` 中 Δ 远大于阈值，`S1` 或 `S_PLUS` 能救回，第 2 阶段 `CLOSED_IMPL`。
2. **H_ambig（导频层面的结构性模糊）**：这些帧里相噪轨迹与多径组合，使错误解对导频的拟合与真解一样好。预测：`M2` 中 Δ ≤ 阈值，`S1` 救不回，`S3`（引入数据）可能救回。
3. **H_chain（不是找径本身）**：第 0 轮的径大体正确（`M1` 匹配功率比 ≥ 0.9），但相位残差或后续编码链路发散。`L2` 仍然失败，只有全部真值才能救回。

跑前预测（Claude）：
- H_search 55%，H_chain 25%，H_ambig 20%；
- `S_PLUS` 救回 ≥ 5/6：55%；
- `L1` 救回 ≥ 4/6：40%；
- 第 2 阶段若运行，得到 `CLOSED_IMPL` 的概率为 70%。

## 设计有效性
- **单因子**：`L1` / `L2` 相对 `A0` 只替换找径中的一步（相位初值或径位置），其余链路完全相同；`S1` / `S3` 相对 `A0` 只增加尝试，每一步都是盲的，并且按校验式选择，与上游 `best_blind` 的选择规则一致。
- **白送臂的含义**：`L1`、`L2` 用了真值，只用于定位，不代表可实现的性能；主判据只用盲臂 `S_PLUS`。
- **统计单元**：以帧为单元。第 1 阶段是 6 个固定帧的个案诊断，不做总体推断；总体结论只来自第 2 阶段的新帧。

## 事前验尸
- 如果 `S_PLUS` 救回了，但第 2 阶段是 `FLOOR_PERSISTS`：说明第 1 阶段的 6 帧不能代表全部失败模式，或者 `S_PLUS` 在新帧上引入了新的错误。报告时要分开列出：新帧上 `BEST` 错、`S_PLUS` 对的帧，与反过来的帧。
- 如果判 `STRUCTURAL_CANDIDATE`：最可能的误读是 `M2` 的跟踪器对两个模型的过拟合程度不同，导致 J 不可比。因此跑前用对照帧标定阈值；即使判定成立，也只说明"值得写草稿"，要再过公共痛点门。另外，第八轮已测过多天线接收会把这个缺口平均掉，所以价值只限于单天线、强相噪这一档。
