# L2 云端 runner c 第 1 批：跑前判据与预测（2026-11-22 写，正式运行之前冻结）

卡 `I-20261122-c02`（含子卡 c05 的读数）。脚本 `ideas/l2/l2_c02_fused.py`，输出 `ideas/l2/out_c20261122b1/`。

## 设定
- 项目接收机（阶段 A2 的 `f0_true(..., 'ls')` 注入：第 0 轮用给定的时延与多普勒，增益为 time_refine 的导频 LS 解，之后 F0 + A1 分支原样）。ρ = .10，SNR 4.5 / 5.5 dB，U/G 两场景，帧 41000–41059（卡片探针用的是 57000–57049，这里没看过）。
- 三臂同帧同噪声，第 0 轮都给真时延：`ldop`（真多普勒，= A2）；`pilot`（逐径导频匹配滤波网格估计，.05 bin 网格、±3 bin——与接收机 time_refine 的多普勒边界一致；首次启动用 ±4.6 时第 1 个任务即因越界报错、没有产出任何行，改后重跑）；`fused`（c02：导频谱 + 以导频最强径为锚的数据滞后谱，归一化后相加取峰；锚径本身用导频）。估计只用接收信号、导频和真时延，不用真多普勒。
- 读数：误帧（最终 errors > 0）率，两个 SNR 合并；以及第 0 轮多普勒功率加权平均误差。

## 判据（写死）
- 缺口 = FER(pilot) − FER(ldop)，收复比例 = (FER(pilot) − FER(fused)) / 缺口；帧级配对 bootstrap 2000 次。
- 若缺口 < 5 个百分点 → 未决（该 SNR 下区分不了）。
- **通过（L2 候选）**：收复比例 ≥ 0.5，且 FER(pilot) − FER(fused) 的 95% 下界 > 0。
- **淘汰**：收复比例 < 0.2，或差值 95% 上界 ≤ 0。
- 其余：停放（需更大帧数）。
