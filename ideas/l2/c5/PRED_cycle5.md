# 第五轮循环 5 预注册（跑之前写）

设定：真实 `stageA`，snr 450，单核；新帧 55000–55399（之前没用过），每档 400 帧；场景 U 和 G 都跑（G 的真多普勒双边对称，见 `probe5.py`）。每臂：前端 → F0（rounds=2）→ 若校验子非零跑 A1。脚本 `cycle5.py`，分析 `ana7.py`。单卡上限 5 核时（本机 CPU）。
标准判据（同前）：两组合并 b − c ≥ 6 且精确双侧符号检验 p < .05，且各组 FER 都不升 → L2；任一组 FER 升 ≥ .05 或合并 b − c ≤ 0 → 淘汰；其余停放。小样本报 Wilson 区间。

- c62（c57 子卡，可部署窄窗在双边多普勒上）：场景 G，rho ∈ {100, 150}，adapt（同 c57 定义）对 g25 用标准判据。场景 G 上"只是不亏"按判据算停放。
- c63（c60 子卡，列数剂量反应）：场景 U，rho ∈ {100, 150}。w13：.25 网格只覆盖 [−1, 2]（13 点/时延），对 g25 用标准判据。另报告 i4（整数 {−1, 0, 1, 2}）对 base。L2 的含义是"去掉一部分不可能的列也有收益"。
- c64（新根，A1 的重开窗）：场景 U，rho ∈ {100, 150}。a1w：前端与 F0 同 base，A1 的 `reopen_geometry` 多普勒范围从 [−3, 3] 改为 [min(−2, r1 最小多普勒), max(2, r1 最大多普勒)]（不用真值，只去掉生产前端字典之外的列）。对 base 用标准判据。场景 G 的同样比较仅报告。
- c65（新根，能量图定窗，双边可用）：先在整数网格上算每列归一化相关能量，按多普勒 bin 求和，取能量最大的 3 个 bin，只保留 .25 网格中四舍五入（floor(k + .5)）落在这 3 个 bin 的点。场景 G 两档 rho 对 g25 用标准判据；场景 U 仅报告。
- c66（新根，按能量删时延）：整数网格上每个时延取最大相关能量，只保留前 52 个时延（共 103 个），在这些时延上用完整 .25 网格。对 g25 的判据按四组合并（U/G × rho 100/150）：合并 b − c ≥ 6 且 p < .05 且四组 FER 都不升 → L2；任一组 FER 升 ≥ .05 或合并 b − c ≤ 0 → 淘汰；其余停放。
