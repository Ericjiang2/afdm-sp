# 第五轮循环 2 预注册（跑之前写）

背景：生产前端 `pilot_front`（`sp_afdm_frozen_reviewed_20260921/src/receiver.py`）第 0 轮字典的多普勒只取整数 {-2..2}（步长 1 bin），B0 贪心选 40 个原子；A1 的几何重开用 .25 bin 网格。真多普勒是分数的（c13：约 54% 被截在 2.0）。

设定：真实 `stageA`，U，snr 450，rho ∈ {100, 150}，新帧 45000–45059（未用过），单核。每臂：自定义前端 → F0（rounds=2）→ 若校验子非零跑 A1。比较对象一律是同帧的基线臂（生产前端 → F0 → A1）。
臂：
- base：生产前端。
- g50（c47）：多普勒网格步长 .5（9 点/时延），40 原子。
- g25（c48）：步长 .25（17 点/时延），40 原子。
- r0re（c49）：生产前端后，只用导频（数据 mu=0、v 按 1−ρ）跑一次 A1 同参数的 `reopen_geometry`，作为第 0 轮初值。
- g50re（c50）：步长 .5 前端之后再做 r0re 的导频重开（两者组合）。（原计划的 60 原子臂不可行：`BaselineInitializer` 把容量固定为 40，跑前改掉。）
判据（每臂对 base，两档 rho 分别）：
- 主量：A1 后 FER；配对不一致帧 b（臂成功 base 失败）、c（反之），精确双侧符号检验。
- 支持：两档 rho 的 FER 都下降，且合并后 b − c ≥ 6 并且符号检验 p < .05 → L2 候选。
- 淘汰：任一档 FER 上升 ≥ .05，或合并 b − c ≤ 0。
- 其余：停放（需更多帧）。
- 成本：前端 CPU 秒数相对 base 的倍数，同时报告。
- c51（c43 子卡：A1 为什么能救）：同帧（45000–45059，两档 rho），只在 F0 失败帧上比较 A1（几何网格 .25、局部细化 2 遍）与两种变体：A1g1L（网格 1.0、局部细化 2 遍）、A1g1（网格 1.0、无局部细化）。判据：A1g1 恢复率比 A1 低 ≥ .20 且 A1g1L 与 A1 差 ≤ .10 → "救回靠的是连续多普勒细化"，支持；A1g1 与 A1 差 ≤ .10 → 救回不靠多普勒精化（靠重估支撑/增益），也算有信息的结论，记 L2；其余停放。（跑前写）
