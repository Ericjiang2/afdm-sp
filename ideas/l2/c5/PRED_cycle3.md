# 第五轮循环 3 预注册（跑之前写）

设定：真实 `stageA`，场景 U，snr 450，单核；新帧 49000–49199（之前没用过），每档 200 帧。每臂：前端 → F0（rounds=2）→ 若校验子非零跑 A1。对照一律为同帧 base 臂（生产前端：整数多普勒网格，OMP 24 原子）。脚本 `cycle3.py`，分析 `ana5.py`。
配对判据（下称"标准判据"）：两档合并 b − c ≥ 6 且精确双侧符号检验 p < .05，且两档 FER 都不升 → L2；任一档 FER 升 ≥ .05 或合并 b − c ≤ 0 → 淘汰；其余停放。

- c52（c48 子卡，c48 是否推广到别的工作点）：rho ∈ {75, 200}，臂 base、g25。对 g25 vs base 用标准判据（两档是 75 和 200）。
- c53（c51 子卡，第 0 轮原子数是不是瓶颈）：rho ∈ {100, 150}，臂 n40（整数网格，OMP 40 原子，B0-p3）、g25n40（.25 网格，40 原子）。n40 对 base、g25n40 对 g25 各用标准判据；只要有一个过 → L2。两个都 b − c ≤ 0 → 淘汰。
- c54（新根，c48 的收益是否来自失配）：rho ∈ {100, 150} 的 g25 vs base。每帧算真值失配 m = 相关径（|g|² ≥ .5σ²）上按功率加权的 |k − round(k)|。按全部 400 帧 m 的中位数分成高、低两半（中位数按规则取，不挑）。判据：高半 b − c 减低半 b − c ≥ 6 → 支持"收益来自失配"，L2；差 ≤ 0 → 淘汰；其余停放。
- c55（新根，细网格的收益出现在 F0 还是 A1 之后）：rho ∈ {100, 150} 的 g25 vs base。F0 层的配对 b0 − c0（按 f0_err 是否为 0）与 A1 后的 b − c 比较。判据：F0 层合并 b0 − c0 ≤ 2 且 A1 后 b − c ≥ 6 → 支持"细网格不减少 F0 失败而是让失败帧更可救"，L2；F0 层 b0 − c0 ≥ 6 → 收益在 F0 已出现，淘汰本卡的假说；其余停放。另报告两臂在各自 F0 失败帧上的 A1 救回率（Wilson 区间）。
- c56（新根，pit：场景 U 的多普勒全为正）：rho ∈ {100, 150}，臂 pos25（.25 网格只覆盖 [0, 2]，9 点/时延，24 原子）对 g25 用标准判据。L2 的含义是"接收机为不知道多普勒符号付了可测的代价，结果对场景的单边多普勒敏感"，属于前提检查；b − c ≤ 0 → 淘汰（符号先验不值钱）。
- 每张卡的 CPU 成本都会报告；单卡上限 1 核时。
