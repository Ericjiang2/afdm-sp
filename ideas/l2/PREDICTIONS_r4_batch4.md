# 本地第 4 轮 L2 第 4 批的跑前判据（卡 I-20261122-l36；2026-11-22 18:28，runner l）

问题：阶段 A2 的 `full` 臂在第 0 轮注入真时延、真多普勒、真增益，但第 0 轮的检测器是联合增益模式，会把注入的增益重写。把第 0 轮检测器换成固定增益（真增益不被改动；第 1 轮与失败后的交换不动），"给全真信道"的穿越点是多少？固定增益下，把真增益换成无偏的导频最小二乘增益要付多少？

已经看过的：A2 的归档读数（`full` 最优 3.45 dB、`ldop` 3.45 / 3.48 / 4.07、ρ = .05 全败；探索性的 20 键：ρ = .05、12 dB 固定增益 0/20 失败）；卡片的探针（32 个信道的第 0 轮未编码软输出：固定增益下 `full` 好于联合）。没有看过：任何固定增益第 0 轮的编码误帧率曲线。

设定（写死）：
- 脚本 `ideas/l2/l2_r4_a2_fixed.py`，deinlab；`stageA` / `stageA2` 的管线原样导入。新跑两臂：
  - `full_fix0`：第 0 轮 = 真 (l, ν, g)，第 0 轮 `scalar_joint` 用 `gain_mode='fixed'`；其后不动。
  - `pls_fix0`：第 0 轮 = 真 (l, ν)，增益取无偏导频最小二乘（`time_refine` 在真 (l, ν) 上、数据方差项置零、`rounds=0`），第 0 轮检测器同样固定增益。
- 帧 41000–41149（A2 同批帧的前 150 帧），U 与 G；ρ ∈ {.05, .10, .15}；SNR ∈ {1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 4.5, 5.0, 6.0} dB，共 8,100 键。归档臂 `full`、`ldop`（联合增益）取 A2 的行，同键配对（它们的网格从 2.0 dB 起）。
- 实现门（跑前）：(G1) 包装器不改增益模式时，8 个归档键上 `full` 臂的校验子、F0 错误数、最终错误数与归档相同；(G2) `full_fix0` 的第 0 轮输出增益等于真增益（8 键）。不过就不跑。
- 读数：1% 穿越点（信息位误帧率，log10 插值，U / G 平均，与 A2 相同；越界按网格端点截断并报截断比例）；按 150 个物理帧整群自助 2000 次。
- 估计算力 2–4 核时（上限 5）。

判据：
1. "3.45 dB 不是全真信道的上限"：Δ1 = [归档 `full` 在这 150 帧上的最优穿越点（对 ρ 取最小）] − [`full_fix0` 的最优穿越点]。Δ1 的 95% 下界 > 0.3 dB → 成立；上界 < 0.3 dB → 不成立（上限基本不变）；其余 → 未决。
2. "ρ = .05 的墙来自检测器"：`full_fix0` 在 ρ = .05 的 1% 穿越点落在网格内（≤ 6.0 dB）→ 成立；否则不成立。
3. "没有联合重估时增益精度值钱"：Δ2 = `pls_fix0` − `full_fix0` 在 ρ = .10 的穿越点差。95% 下界 > 0.3 dB → 成立；上界 < 0.3 dB → 不成立；其余 → 未决。
4. 不做的事：不改第 1 轮与交换；不测"固定增益贯穿所有轮"；不动 A3 / A4 的读数。
