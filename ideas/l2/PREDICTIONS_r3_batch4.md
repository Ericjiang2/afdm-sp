# L2 本地第 3 轮第 4 批：跑前判据与预测（2026-11-22 02:13 写，正式运行之前冻结；runner l）

本文件只装这一批：卡 `I-20261121-l14`（等峰值功率下 SP-AFDM 对带前缀单载波）。脚本 `ideas/l2/l2_r3_peak.py run`（发射链 `l2_r3_peak_chain.py`），输出 `ideas/l2/out_r3b4/`。写本文件时只跑过发射链的本机标定和 1 帧冒烟（看到的数写在最后）。

## 设定
- 新帧 49000–49119（120 帧，此前没有检验用过），场景 U 的 8 径信道（记 P1）和由它造的同时延 4 射线簇信道（每条径拆成 4 条同时延、多普勒 2·cos θ 的射线，做法同 l09 的检验）。完美信道、l09 的软抵消 LMMSE + LDPC 迭代（10 轮）。
- 两种波形发同一份编码数据和同一条单位模 ZC 导频（导频功率占 ρ = .25）：单载波把它们放在时域，AFDM 放在变换域。发射链：4 倍过采样、滚降 .25 的根升余弦成形，门限 1.5 dB 的两步限幅滤波（带外为零），接收端匹配滤波。按发射信号 99.9% 样点功率对齐峰值：噪声方差 = 峰值功率 / γ_peak。接收机已知信道、导频和线性增益 α，把限幅失真按标定的方差算进噪声。
- 每个波形的 α、失真方差、峰值功率由 400 个独立随机块标定（不是评估帧）。
- 读数：每帧每臂在 5.0–11.0 dB、步长 0.25 dB 的 γ_peak 格点上二分，找能译对的最小格点（假定对 γ 单调；译不出记为 11.25）。配对差按帧自助 4,000 次。
- 五臂：P1 上单载波、AFDM；簇上单载波、AFDM、AFDM 加判决导向的限幅失真重构（每轮用软符号重建发射波形、重算失真并扣除）。

## 实现门
- 时域信道变到变换域后与帧里的信道矩阵相对误差 < 1e-9；不限幅时发射链是恒等（本机已核 1.4e-15）。

## 主判据（卡片跑前写的两条，原样执行）
- (i) P1 上，AFDM 的门限减单载波的门限（配对均值，dB）≥ 0.8：卡片"单载波在独立时延信道上稳赢"成立；< 0.8 则这半边被推翻。
- (ii) 簇信道上，AFDM 加失真重构的门限减单载波的门限 ≤ 0.5 dB：卡片"强簇上 AFDM 仍有存在区间"成立；> 0.5 则推翻。
- 两半各自定案；无论哪种结果，本卡是 l09 的子卡，去向是把等峰值口径的数并入 l09 或单独交放行，由结果的清晰程度定。
