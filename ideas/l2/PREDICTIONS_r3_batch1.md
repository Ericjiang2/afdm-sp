## 主判据（跑前写死；全部按帧配对，4,000 次按帧重采样，三个信噪比合并计数）
记 E(p, c) 为导频 p、上限 c 的 CD 错帧总数（600 个帧次），基准 E0 = E(ZC, 102)。
- 回收比例 R = 1 − [E(随机, 400) − E0] / [E(ZC, 400) − E0]。
- **通过**（孪生点是主因，卡进放行）：R 的点估计 ≥ 0.5 且 95% 下界 > 0.25；并且按 dB 读，"随机导频、上限 400、6 dB"的 CD 误帧率减"ZC、上限 102、5 dB"的 CD 误帧率，配对差的 95% 上界 ≤ +3 个百分点（即剩余损失不到 1 dB）。
- **淘汰**（损失来自字典变大，不是孪生点）：R 的点估计 < 0.25，或 R 的 95% 上界 < 0.5。
- 其余记为未决，写明区间，不升不杀。
- 如果 E(ZC, 400) − E0 的 95% 下界 ≤ 0（父卡的损失在新帧上没有复现），本检验无效，先回到父卡。
