## 否决线（卡片的一级方向线，按下面的统计量执行；任一不成立即淘汰本卡）
- 方向一（重搜的优势随码率增大）：定义 adv(R) =（R3 错帧数 − CD 错帧数）/ F0 错帧数，ρ = .25 与 .30、四个信噪比合并。要求 adv(3/4) − adv(1/2) 的 95% 下界 > 0，且 adv(1/2) − adv(1/4) 的点估计 > 0。
- 方向二（高码率下低导频悬崖右移）：定义 pen(R) = [CD 在 ρ = .25 的错帧数 − CD 在 ρ = .30 与 .40 里较少的那个] / 帧次。要求 pen(3/4) − pen(1/2) 的 95% 下界 > 0。
- 区间按帧自助 4,000 次。
- 两条都成立才看卡片的二级定量线。任一不成立：淘汰本卡，把"现稿结论在码率 1/4–3/4 上不变"作为一行稳健性事实记下。
- 附读：各码率下 CD 错帧最少的 ρ；最高信噪比点上 R5 的错帧数（卡片预言码率 3/4 时固定支撑有误帧平台）；TH 与 CD 的差。
