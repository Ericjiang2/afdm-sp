# L2 本地第 3 轮第 6 批：跑前判据与预测（2026-11-22 02:30 写，正式运行之前冻结；runner l）

本文件只装这一批：卡 `I-20261122-l08`（前导 + 后导给逐径多普勒，c14 的子卡）。脚本 `ideas/l2/l2_r3_marker.py run`，输出 `ideas/l2/out_r3b6/`。写本文件时只在本机跑过单径自检和一个手造的 8 径例子（看到的数写在最后）。

## 设定
- 信道真值（8 条径的整数时延、多普勒、复增益）取自项目生成器，新帧 50000–50199（200 帧），场景 U 和 G；4 dB 和 6 dB（噪声方差 = 径总功率 / 信噪比）。
- 分组：标记 A、保护间隔、102 点前缀 + 1024 点数据（独立复高斯，功率与标记相同）、保护间隔、标记 B。标记是随机相位恒模序列。接收机知道 8 个真时延和两段标记，不知道数据、多普勒和增益；只用两段标记窗（各延长 102 点以收全多径）里的样本，逐径交替估计（每条径在 ±2.2 bin 的整个范围内搜索，4 遍，再细搜到 0.001 bin）。
- 臂：每端 256 点、两侧各留 102 点静默；每端 256 点、不留静默（数据直接串入标记窗）；每端 128 点的同样两臂；对照臂"只有前导、512 点"（与两端各 256 点的标记总能量相同，检验收益来自两端的长基线而不是标记能量）。
- 读数：按径功率加权的多普勒绝对误差（不截尾），按帧平均并给按帧自助的 95% 区间；误差超过 0.30 bin 记为整周选错，另报选错径的功率占比。

## 实现门
- 单径、径功率 1/8、6 dB、无串入：估计的均方根误差与卡片闭式下界相差不超过 20%，300 次里没有整周选错（本机已核：.0083 对 .0091，0 次）。

## 主判据（卡片跑前写的，原样执行）
- 两条 256 点的臂里，只要有一条在 U、G × 4、6 dB 四格的功率加权绝对误差均值的 95% 上界都低于 .04 bin → **通过**（"两端标记能把第 0 轮多普勒压到目标线以内"成立，值得接 ρ = 0 的译码对照）。
- 两条 256 点的臂在四格里的 95% 下界都高于 .04 → **淘汰**"只用两端标记替代叠加导频"。
- 其余未决。

## 次读数
- 128 点臂（卡片预言整周常错）；只有前导的 512 点臂；有无静默的差别。

## 跑前预测
- 256 点 + 静默：四格均值约 .015–.03，通过概率 .65。卡片算过 4 dB 下径功率要占 9.3% 以上整周才稳；真实径功率是指数衰减的，弱径会选错整周，但它们功率小，对功率加权误差贡献有限。
- 256 点不留静默：比留静默差不到一倍，四格都过 .04 的概率 .45。
- 128 点：整周选错的功率占比 > 10%，均值 > .04（.85）。
- 只有前导的 512 点：均值在 .02–.05，比两端各 256 点差 1.5 倍以上（.70）。
- 本机手造例子（一组随机 8 径、4 dB）：256 点留静默 .009，不留 .013，128 点 .18–.20，只有前导 .026。
