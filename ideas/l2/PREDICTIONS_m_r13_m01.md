## 一、物理系统模型、净吞吐与能量账本
- **标准任意无理数 $c_2$ EP-AFDM 帧结构**：$N = 256$，$2Nc_1 = 7$，$c_2 = \frac{1}{2\sqrt{2}N}$，Bemani 对称保护带 $Q_g = 47$（单嵌入导频 $k_p = 0$，能量 $x_p^2 = 50.0$；载荷格 $N_d = 161$，保护+导频格 $95$；每突发 $K = 4$ 符号、**零额外前导帧**）。
- **物理因果线性卷积前端**：扩展 `CPP` 长度精确为 $L_{\mathrm{cpp}} = l_{\max} + L_f + L_g = 2 + 3 + 3 = \mathbf{8}$ 样点，经因果 3 抽头频选发端 IQI $(f_1, f_2)$ $\to$ 3 径分数多普勒时变信道（时延 $[0,1,2]$、多普勒 $\nu_p \sim \mathcal{U}[-0.85, 0.85]$、瑞利功率谱 $[0.5, 0.3, 0.2]$ 归一）+ 独立块首 `AWGN`（长 $N+L_g-1$） $\to$ 因果 3 抽头频选收端 IQI $(g_1, g_2)$ 后去 `CPP` 得物理观测 $\mathbf{r}_{\mathrm{phys}}$。
- **宽带频选收发 IQI 工况**：
  - `mod18`（中等失配 `IRR ≈ 18 dB`）：$f_1, g_1 = [1, 0.035 e^{j\theta}, 0.015 e^{j\theta}]$，$|f_2|, |g_2| = [0.085, 0.075, 0.045] \times \mathcal{U}[0.85, 1.15]$ 随机相位；
  - `strong13`（未校准宽带直变频 RF `IRR ≈ 13–14 dB`）：$|f_2|, |g_2| = [0.145, 0.125, 0.075] \times \mathcal{U}[0.85, 1.15]$ 随机相位。
- **精确净吞吐与每比特能量核算（按实际 $L_{\mathrm{cpp}} = 8$，含精确前缀能量）**：
  - 本法（零前导，$4$ 符号）：`644 / (4 × 264) = 0.60985` 载荷符号/信道使用；含前缀总能量 `844 × (264/256) = 870.375`；
  - 正式对手 (a) `Huang arXiv:2606.17439`（`1` 全知前导 + `4` 载荷符号 = `5` 符号）：`644 / (5 × 264) = 0.48788` 载荷符号/信道使用（本法净频效高 **`+25.0%`**）；含前缀总能量约 `1134.375`（同标称 SNR 下 `Huang` 每比特能量高 **`+1.1505 dB`**）；
  - 正式对手 (b) `Narasimhan JSTSP'09 §IV-B/V-A`（`2` 帧 Scheme-A 正交训练前导 + `4` 载荷符号 = `6` 符号）：`644 / (6 × 264) = 0.40657` 载荷符号/信道使用；按冻结波形计入每帧前导 `8` 样点 `CPP` 实测能量 `22.21` 后总能量 `1426.80`（较本法含前缀能量高 **`+2.1466 dB`**，不含前缀标称 `+2.0592 dB`）。
  - 主检验中免费赠送两对手前导；另在非门控 `SCOPE_EqualEbN0` 中将两对手标称 SNR 分别**降低精确含前缀差值 `1.1505 dB` 与 `2.1466 dB`** 对齐本法 $E_b/N_0$，并在 `SCOPE_EqualNetThru` 中**仅将本法（及消融）载荷缩至 `Nd = 129`（`Q_g = 63`，`0.48864` 符号/信道使用）**而保持 `Huang` 与 `Narasimhan` 维持原载荷 `Nd = 161`（`Q_g = 47`，`Huang = 0.48788`）实现真正等净吞吐对照。
