## 要算的两样东西
1. **信息账**（纯计算）：I(X;Y) ≥ I(X;Y|θ) − I(θ;Y|X)。θ 分三项，按每帧比特数给上界：增益 Σ log2(1 + N·p_i·γ)（同功率下高斯先验最大）；多普勒 Σ ½·log2(1 + R² / (12·σ_i²))，σ_i² = 6 / ((2π)²·N·p_i·γ) 是数据全知时的下界、R 是多普勒先验范围；支撑 log2 C(103, 8)。径功率和多普勒范围取自项目生成器的新帧 56000–56199（场景 G、U）。比特换成 dB：除以 N，再除以 QPSK 互信息在该信噪比处每 dB 的斜率。
2. **已知信道基准**（项目接收机）：同一批帧上，现接收机从真信道起步（ρ = .10，只读 F0）在 2.5 / 3.0 / 3.5 / 4.0 dB 的错帧数。10% 误帧率穿越点 T_true 用相邻两点 log10(FER) 的线性插值（0 个错帧记 0.5 / 200）；T0 = T_true − 0.46 dB（去掉 ρ = .10 的导频功率，折成"不发导频、信道已知"）。
- 现接收机的实际代价 L_rx = T_std − T0，T_std 取第 12 批已有读数（场景 G、ρ = .25、帧 54000–54199、CD 错帧 27 / 2 / 2 @ 4.5 / 5.0 / 5.5 dB），同一插值规则得 4.56 dB。这个数已经看过，不是新测量。
- 信息账的总价 B 取离 T0 最近的整数 dB 档。

## 判据（跑前写死；场景 G 为主，U 附读）
- **通过**（这把尺子有用）：B ≤ L_rx − 0.5 dB，且支撑一项 ≤ 0.4 dB。含义：理想接收机为"不知道信道"至多付 B，现接收机付 L_rx，差值是所有导频、捕获、配码类想法合起来能争的奖池下限；支撑在信息上是最便宜的一项。
- **淘汰**：B > L_rx − 0.2 dB（上界不比实际代价小，尺子量不出东西）。
- 其余未决。
- 方向与定量分开：方向 = 支撑在信息账里最便宜，而在现接收机的低导频区最贵（对照已有读数：ρ = .10 时给真时延与不给相差 1.6 dB 以上）；定量 = B 与 L_rx 的差。

## 这把尺子默认了什么（LESSONS 规则 15）
- 互信息是遍历意义下的；每帧一个码字、码长 2048 时，把"每符号多要多少比特"按互信息斜率折成 dB，默认码离容量的差距不随信噪比变。
- 增益按高斯先验、多普勒按高斯近似，都是往大里估（上界）；支撑按 103 选 8 的均匀分布。
- 三项相加默认各径的回归量近似正交（时延互不相同时成立到 1/√N）。
- T0 用的是"真信道起步的现接收机"，它本身未必是已知信道下最好的接收机；l09 的另一套迭代接收机在场景 U 上给出 3.06 dB（ρ = .10 口径），可对照。
