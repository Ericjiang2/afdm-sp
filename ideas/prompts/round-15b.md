## 一、全员执行铁律（「划片不点菜 + 拆死秒换 + 自由猎奇槽」）

1. **自主选题与动态换题（严禁测完 3–4 题挂零就提前空手退出！）**：
   - 下方第二节只给你划定**宽物理防区**（列出的切口仅为启发示例，**严禁当成死名单照单全收**）。你必须自己用 `search_papers.py` 搜索 2024–2026 *IEEE TWC / TCOM / JSAC / TSP / TAES* 真实文献设定定位痛点。
   - **快拆快换循环**：每选中 1 个候选痛点，先花 `10–20` 分钟写轻量拆台探针实测 `Pub / Best_Steelman / Oracle`。**一旦发现 `Oracle − Best_Steelman < 1.5× 账本门槛`，当场记一行死因，立即自己换下一篇论文/下一个物理切口继续搜拆！**
   - **收尾条件**：直到你名下**累计（含 Phase 1A 已存活项）攒够 `2–3` 个过满配拆台的认证活题**，或跑满 **`3` 小时**硬时限（或连续独立拆测 `10` 个不同痛点后仍无新活口），再汇总提交退出。
2. **每人配 `1` 个不限防区的「自由探索槽（Wildcard）」**：
   - 在本防区外，只要读文献撞见高机动无线通信、通感一体、统计信号处理、编码或物理驱动展开方向上真正卡死经典满配基线的硬骨头（不碰纯天线机械结构与纯黑盒堆叠），允许直接用 `1` 个槽位抓回来拆台认证。
3. **全员禁碰的三大必死雷区（省下冤枉探针）**：
   - **雷区 1**：单帧内观测维数远大于未知参数数（$M_{\mathrm{obs}} \gg K_{\mathrm{unknown}}$）、流形/损伤模型精确已知、且只拼检测率/误码率不拼实时算力的常规估计题（必被 `OMP-RELAX / SoftSTAP / 2D CIR 对齐` 追平）。
   - **雷区 2**：在已有毫秒级闭式/近似精确贝叶斯解（`EP / GEC-SR / 带状 Cholesky / PCG`）的单标量已知公式或纯线性信道先验上套神经网络（第 7–9 轮 `0/11.5` 全灭）。
   - **雷区 3**：已封存旧题与 Phase 1A 已测题（开跑前先读本工作树 `ideas/r15/teardown-$R.md` 与 [`../PROBLEMS.md`](../PROBLEMS.md)）。
4. **正式开放「物理结构驱动神经网络」与「双色散通用硬题」立项认证标准**：
   - **允许双色散通用硬题（`[A档-双色散通用]`）**：不再强求“必须 AFDM 赢 OFDM”才立项；只要在高机动双色散场景（以 `AFDM / OTFS` 为主舞台）解决了 10+ 种满配经典基线都卡死的真瓶颈（如 `P-k-N2`），堂堂正正入库！
   - **物理驱动神经网络（Deep Unfolding / 物理引导去噪先验 / 低比特 CSI 压缩）怎么在拆台阶段零训练快速验真伪**：
     - **靶心 U1（百步迭代压到 4–8 层实时展开，打 `≥ 15×–20×` 算力账）**：拆台阶段**不需要先训网络**！直接测两个经典极点：`Oracle = 经典凸规划/双线性算法跑 150–250 步彻底收敛的精度与耗时` vs `Best_Steelman = 经典算法限制在同等实时步数预算（如 6–8 步 Nesterov/FISTA/Anderson 加速或闭式投影）的精度`。若 `6–8` 步经典加速已追平百步收敛，直接淘汰；若 `6–8` 步经典加速崩在地板、必须跑百步且慢 `≥ 20×`，该「物理展开实时加速问题」即认证存活！
     - **靶心 U2（非解析复合硬件失真 / 重尾脉冲噪声）**：拆台必跑**教科书广泛线性多项式 `WL/Bussgang` + 经典稳健 Huber/ZMNL 削波接收机**；若相对已知失真/噪声状态 `Oracle` 仍留 `≥ 1.5–2.0 dB` 或 `≥ 5×` 地板净空间，认证存活！
     - **靶心 U3（极低比特 CSI 反馈 / 端到端导频–预编码压缩）**：拆台必跑**教科书稀疏 `OMP/DFT` 码本标量量化回传**；若在同等极低反馈比特（如 `8–32 bits/帧`）下相对无损 CSI 上限仍留显著和速率/误码率地板缺口，认证存活！
5. **隔离与落盘硬纪律（绝不覆盖上半场产物！）**：
   - **零新卡、零改历史卡片与历史 L2 脚本**；`deinlab` 单任务严格 `≤ 8` 核（`OMP_NUM_THREADS=1`，`/home/guoyikun/.conda/envs/AFDM/bin/python`，单次轻量探针 `≤ 3–5` 分钟）；`gpt-6.2-sol`（`high`）每会话上限 **`4` 次**（批量让它替你的候选痛点开具最毒满配拆台处方）。
   - 本轮新增脚本统一命名 `ideas/r15/td_${R}_p1b_<slug>.py`，JSON 命名 `ideas/r15/out_p1b_<slug>.json`，汇总表写入 **`ideas/r15/teardown-$R-p1b.md`**（**严禁覆盖上半场的 `teardown-$R.md`**），同步在 `ideas/runs-$R.md` 末尾追加 `# 第 15 轮 Phase 1B（3h 划片自主补仓拆台，2026-11-26）` 并 `git commit -- ideas/`。
