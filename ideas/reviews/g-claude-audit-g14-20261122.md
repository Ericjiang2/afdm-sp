## 1. 闭式律：系数是 1/(2T)，但卡面理由写错了

**零空间。** 无噪声下，`g[n] = r_L − r_0 = x[n−L] − x[n]` 对所有 n 已知，所以 `w[n] − w[n−L]` 已知，其中 `w` 是 x 的增量。因此每个"相位 j"上的 K 个副本增量，只差已知量。未知的只剩一个 L 维的周期向量 c（x → x + c[n mod L]）。`r_0` 已知，所以 y = x − r_0 随之确定，y 没有额外自由度。目标 `x[n−d] − y[n] = x[n−d] − x[n] + r_0[n]`，其中只有 `c[(n−d) mod L] − c[n mod L]` 不可知，两点在圆周上相距 δ。

**先验信息。** Δy = Δx − Δr_0，所以 y 的先验对 c 的二次型与 x 的完全相同。c 的精度矩阵是 `(2K/q)·D'D`，D 是 L 点圆上的差分，K 是副本数。圆上两点间的有效电阻是 `δ(L−δ)/L`。于是方差为：

`(δ(L−δ)/L) · q/(2K) = qδ(L−δ)/(2T)`，T = KL。

数值核对：T=300、δ=16 时得 1.707×10⁻⁴，与卡面一致。

**逐项结论：**
- 系数 `1/(2T)` 正确，只用 x 的话是 `1/T`。
- 但"x、y 两条晶格共 2 倍信息"的说法不准确。这里没有两个晶格。准确说法是：`r_0` 把 y 的增量绑到 x 的增量上，每个增量同时有 `N(0,q)` 和 `N(e,q)` 两票，后验方差是 q/2。一般式为 `q_x·q_y/(q_x+q_y)`。
- 卡面步骤 4 说"两个括号端点的布朗桥因子"也不对，只有一个桥因子 `(L−δ)/L`。
- T 是有效观测样本数。L2 里 T = N−L = 992，所以 δ=16 时无噪声极限是 **5.2×10⁻⁵**，不是卡面算例的 1.7×10⁻⁴。

## 3. 最强反对意见与适用边界

**(a) 这次 L2 只测了功率，没测决定。**
- 相干损失只有 `e^{−σ²}`：σ²=0.010 时约 0.04 dB，0.0024 时约 0.01 dB，可忽略。
- 真正改变决定的只有两种情形（均为估算）：
  - **测速：** 相噪残余与热噪声相当时，即每样本信噪比在 `[1/σ²_单参考, 1/σ²_g14]` ≈ 20–34 dB 之间。低于 20 dB 时热噪声主导，没有收益。L2 的 28 dB 在窗口内。
  - **检测：** 相噪残余在其他强杂波上的裙边抬高底噪。以杂波 38 dB、门限 13 dB 为例，积分信噪比 `M·SNR_t` 必须落在约 25–31 dB 的 6 dB 窗口里，此时 M=922 对应每样本信噪比 −4.5～+1.5 dB。L2 的目标远高于此，所以检测决定不会因这次改进而改变。
- 因此卡面"改变决定"的说法目前没有 L2 证据。要么改成"降低不相干功率"，要么补做 CFAR 或多普勒估计子实验。

**(b) PLL 边界。**
- 令 ω_c = 2π f_loop / fs，边界参数 Λ = ω_c (d−L)。
- 单参考基线的误差在 Λ≳1 时饱和，对应 f_loop ≈ fs/(2π·48) ≈ 53 Hz。热噪声底下 5 dB 门槛的穿越点约在 55–80 Hz（Λ≈1–1.5）。
- 另一个条件：副本间距 L 要短于相关时间，即 ω_c L ≲ 1，对应约 80 Hz，否则 K 个副本的平均不再是 1/K。
- 150 Hz 的 3.43 dB 主要是热噪声底的问题：无限信噪比下增益约 8.3 dB，20 dB 每样本信噪比时只剩约 1 dB（均为估）。
- 按卡面自己的致命判据"合理 PLL 环路带宽下 <5 dB 则淘汰"，150 Hz 已经触发。预注册只要求 30 Hz，所以判定仍是 PASS，但卡面必须写明适用范围 f_loop ≲ 50–60 Hz。
- 若环路带宽达 kHz 量级，慢时间尺度上相噪是有界、近白的，随机游走前提不成立，本卡不适用。

**(c) 杂波微动。**
- GLS 和 TDI 对参考 L 的慢相位会放大：TDI 放大 m 倍，GLS 约放大 d/L 倍（d=80 时约 2.5 倍）。单参考基线只有 1 倍。放大量按功率是 m² 或 (d/L)²。
- 相对单参考的盈亏点：`(d/L)² − 1` 倍的微动方差要小于 `E_s − E_g`，即微动 rms ≲ 0.036 rad（64 ms 帧内，约 0.3 Hz 量级）。
- L2 的 `sway = 0.015 rad` 全帧斜坡，对应 `m²Φ²/12 ≈ 7.5×10⁻⁵`（m=2），只有热噪声底的约 3%，基本没被激励。
- 另外只有参考 L 带漂移，参考 0 没有，也不真实。

**(d) 周期残余的杂散线（未验证，置信度 M）。**
- GLS 的核心误差来自 c 的估计误差，它按 L 周期重复，会在 fs/L = 500 Hz 的整数倍处形成相干线谱。
- 在 M=922 的相干积累下，线谱峰值比等功率白裙边高约 M/L ≈ 29 倍（14.6 dB）。
- 在 L2 里这一部分很小，因为无噪声项约 5×10⁻⁵，但值得检查 `a_est − a_true` 的频谱。
