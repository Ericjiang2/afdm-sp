  1. **多普勒搜索格数翻倍打破 $\rho\cdot N$ 守恒**：物理最大多普勒 $f_{d,\max}$ 固定时，独立多普勒格数 $M_D \approx 2 f_{d,\max} N / f_s + 1 \propto N$ 随 $N$ 翻倍（项目字典 [receiver.py](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/experiments/sp_afdm_frozen_20260920/src/receiver.py#L124) 中 $k_{\max}: 2 \to 4 \to 8$，二维字典列数从 $515 \to 927 \to 1751$）。按 Rife–Boorstyn 理论，维持相同离群率要求 $\gamma_p N$ 按 $\text{const} + 2\ln M_D \sim \Theta(\ln N)$ 增长（$N$ 每翻倍多需约 $+1.39$，在 $\gamma_p N\approx 10$ 时约 $+14\%$），且离群后的 bin 误差幅值也随搜索跨度 $\propto N$ 放大。用与 [probe_nscale.py](file:///Users/guoyikun/.cache/idea-funnel/afdm-20261122-l4/probe_nscale.py) 完全相同的信道与随机种子，仅将作弊的固定 $\pm 0.75$ bin 窗改为真实物理跨度 $[-k_{\max}, +k_{\max}]$（仍给真时延），实测结果立刻证伪守恒律：

     - $\rho N = 128$：`(1024, .125)` `0.151 bin / 离群 17.7%` → `(2048, .0625)` `0.228 bin / 22.5%` → `(4096, .03125)` `0.442 bin / 25.4%`（误差暴涨近 3 倍）。
  2. **数据自干扰分母破坏 $\gamma_p N$ 守恒**：即便不看离群、只看局部 CRB，$\gamma_p = \frac{\rho|h_p|^2}{(1-\rho)P_{\text{tot}}+\sigma^2}$ 的分母随 $\rho$ 减小而增大。在 4 dB（$\sigma^2=0.398$）下，保持 $\rho N = 256$ 不变，`(1024,.25) → (2048,.125) → (4096,.0625)` 的有效 $\gamma_p N$ 实际从 `27.87 → 25.14 (-0.45 dB) → 23.96 (-0.66 dB)`（高 SNR 干扰受限区亏高达 `-0.97 dB`）。综合第 1、2 项，帧长翻倍时保住同等第 0 轮质量，最优 $\rho^*$ 按 $\Theta(\frac{\ln N}{N})$ 而非精确 $1/N$ 缩减（$N=2048$ 处约需 $.15\text{–}.16$ 而非 $.125$），数据功率净红利约 `0.45–0.55 dB`，低于卡里算的 `0.67 dB`。

  4. **加速度门槛 $N_{\max} \propto a^{-1/2}$ 的数值换算错误**：虽然 $q=\alpha T^2 \propto a N^2 \implies N_{\max}\propto a^{-1/2}$ 的标度幂次成立，但卡里 L33 用 RMS 失配套 A3 恒频偏 0.04–0.05 bin 门槛算出 `a ≤ 1 / 0.26 m/s²`，沿用了**早已被 [I-20261121-11.md](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/ideas/cards/I-20261121-11.md#L39) 跨模型评审和 [I-20261122-l26.md](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/ideas/cards/I-20261122-l26.md#L78) 否决的错误换算**。直接数值计算二次相位相干损失：$q=0.131$（$N=1024, a=1\text{ m/s}^2$）仅亏 **`-0.0041 dB`**，$q=0.524$（$N=2048, a=1\text{ m/s}^2$）仅亏 **`-0.0655 dB`**（比恒频偏 RMS 损失小 5 倍），且公共加速度在 AFDM 中可被 1D 修改 $c_{1,\text{rx}}=c_{1,\text{tx}}-q/(2N^2)$ 精确吸收。真正限制 $N$ 的是**径间差分伸缩、路径增益相干时间 $T_c$（快衰落/径内展宽）、以及系统时延约束**。
