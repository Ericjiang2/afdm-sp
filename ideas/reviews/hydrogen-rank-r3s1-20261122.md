# Hydrogen 两两比较排序：本地第 3 轮第 5 次统一筛选（2026-11-22；agy gemini-4-hydrogen-high，plan 模式；提示 ~/.cache/idea-funnel/afdm-20261122-l3/rank1_hydrogen.prompt）

RANKING: l14 > l12 > l05 > l07 > l01 > l04 > l02 > c16 > l06 > l15

l14：最强点是把真实功放/换能器的连续峰值上限与带外掩模带入编码链路，直接考验“单载波脉冲型削峰伤 LDPC 还是 AFDM 幅度压缩亏 1.7 dB”这一无法靠公式猜的波形生死线；最弱点是若系统工作在线性回退充足的非峰值受限区，该硬件惩罚就不触发。
l12：最强点是揭示实测浅海 12–32 ms 时延扩展与相干时间触发的 N 无关三难挤压，且 L2 首轮已实测出 25 ms 下 2 dB 估计退化与 1 dB 前缀税，决定单块水声 AFDM 的真实适用边界；最弱点是其估计侧 2 dB 损失是否被换导频（l05）救回尚未拆分，贸然在之前跑几十核时有重复风险。
l05：最强点是只换随机相位导频即可将孪生相关从 .84–.85 压到 ≤ .10，若成立便能把 AFDM 的无混叠墙从单斜率导频瓶颈改写为可解的工程问题且输赢全有决定性；最弱点是按实际 2Nc1=5 重算后孪生点变弱（自估通过率仅 0.45），且只对稀疏信道有效、消不掉 28% 前缀税与相干时间墙。
l07：最强点是将光学 SPADE 改造成恒模 π-阶跃三联体与 ΣΔ 相移量化，直击单射频链/无源 RIS 纯功率 RSRP 的散斑瑞利诅咒，独立成 Trans 论文潜力最大；最弱点是公式假定噪声方差 σ² 已知（弱亚瑞利区极敏感）且跨距 δ0=0.5σu 依赖未知真值 σu，且现有检验仅需 0.05 核时而不足以直接上长仿真。
l01：最强点是从 χ²4 下界证明第 0 轮不可检与首轮仅损 0.2 dB 同源，并用纯奇偶校验外信息切断双线性估计的 APP 自证偏置，能解开 l13 分数时延定阶死结；最弱点是仅影响近邻双径占比较小的帧且 0.2 dB 收益窄，而“用外信息不用 APP”本身接近标准 Turbo 接收机常识。
l04：最强点是用等逐格功率去相干对照把时频邻道相干泄漏从总干扰里干净剥离，检验设计精准且可证伪；最弱点是只停在第 0 轮线性拟合误差（无编码 FER），核心参数 θ、η 尚未从矩阵算出，且高斯脉冲已知即使真信道也难检测（arXiv:2502.03904）。
l02：最强点是给出一套可在单帧内用前缀局部反相拆解折返的构造，且最便宜检验明确配了周期宽带导频与同导频单载波对照；最弱点是全套数字基于误读的 2Nc1=9，且无论 l05 成败都在相关性（.64 对 .10）与 2.17 dB 导频损上被 l05 支配（除非硬保 FFT 峰快捕）。
c16：最强点是指出真实水声 modem 常配 2–4 个水听器、单通道捕获瓶颈可能被硬件设定放大；最弱点是把非相干合并增益误写成 10log10(M) dB、忽略阵元间距与跨阵元相关性矛盾，且无便宜致命检验、未读核心文献 JASA 2026 160(5):3877。
l06：最强点是给出双候选在带内一阶匹配而带外相消的严谨下界与对照检验；最弱点是结论被锁死在 δ∈[5.1,5.5] ns、|r|≤0.05 且同向精确导数匹配的极窄参数角落，且“FDD 不能全靠上行外推而需补少量下行导频”在 5G/Massive MIMO 里本已是标准做法。
l15：最强点是把 ZC 根号与 c1 写进了统一数论模糊格并给出 Minkowski 必要界；最弱点是未读两篇核心文献而未过深度核查、自身相位表与项目真实 DAFT 不一致（已被 l05 实测推翻）、当前 r=7 已属最优类对主线零改动且整体被 l05 支配。
