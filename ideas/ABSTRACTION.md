## 1. 去掉代号

| 代号 | 它实际做的事 |
|---|---|
| AFDM | 一种多载波波形：用 chirp（频率随时间线性变）做基，参数 c1 选得合适时，整数多普勒下每条径在变换域里落到彼此分开的位置，信道矩阵稀疏且结构已知；分数多普勒时会向邻近位置扩散 [推断，教科书性质] |
| SP（叠加导频） | 已知序列直接叠加在未知数据上，不占专门的时频资源；导频和数据互为干扰，导频功率比例 ρ 决定"认路的力气"和"传数据的力气"怎么分 [核实：本项目设定] |
| F0 / CODELAY / 第 0、1 轮 | 先只靠导频找路径（捕获），再用译码出的数据当额外导频精修（跟踪）；失败后决定继续迭代还是重搜 [核实：native_twofft.receive 与现稿路线] |

## 2. 分层

| 层 | 本项目的现状 | 稀缺、未知或受限的是什么 |
|---|---|---|
| 物理 | fc 12 kHz，B 4 kHz（带宽/载频 = 1/3），fs 8 kHz，帧 N = 1024（约 128 ms）；P1 场景 8 条径 [核实：运行日志与 stageA 设定] | 真实时延是连续的；平台会加速；宽带下多普勒其实是时间伸缩 [推断] |
| 信号模型 | y = Σ_i g_i H_i(l_i, ν_i)(导频 + 数据) + 噪声；阶段 A–A4 的管线里时延 l_i 是整数抽头 [核实：physical.regressors 与 truth['l_i']；其他仿真未逐个查] | 少数几个参数（每径时延、多普勒、增益）决定整个信道 [核实] |
| 推断结构 | 双线性：信道未知 × 数据未知，叠加已知导频；数据有码约束 [核实] | 第 0 轮没有数据信息，只能靠导频；ρ = .05 时检测器的增益相位锁不住 [核实：A2 探索性，20 键] |
| 算法 | 第 0 轮：导频贪婪找径 + 每径多普勒细搜；检测器 P-BiG-AMP；译码；第 1 轮用译码数据精修 [核实] | 第 0 轮多普勒精度有门槛（A3）；现有估计器比自身下界差 1.6–1.9 倍（A4）[核实：读数] |
| 系统目标 | 固定码率下达到 1% 误帧率所需 SNR 尽量低，导频开销尽量小 [核实] | 最优 ρ 现在由第 0 轮捕获决定：.25 → 理想第 0 轮下 .10 [核实：A/A2；"由捕获决定"是解释，属推断] |
| 评价 | 编码误帧率穿越点；NMSE 只作参考 [核实] | NMSE 与误帧率的排序可能相反 [卡片 08，跨模型评审要求补对照] |

一句话的抽象问题：从一帧观测里，联合估计一个只由少数参数决定的稀疏线性算子，观测里叠加了已知探测信号和受码约束的未知符号，接收机可以迭代地把译码结果当额外探测信号；难点是第 0 轮的"起步" [推断：本文作者的概括]。

## 5. 值得怀疑的前提（track `pit` 的一个来源，不是全部）

- 阶段 A–A4 管线里时延是整数抽头 [核实]；c06 称换成分数时延后每径摊到约 2.45 个抽头、现有估计误差翻倍 [卡片]。
- 窄带多普勒模型：B/fc = 1/3 [核实]，按理属于宽带、多普勒应是时间伸缩；仿真是否处理了 [未查]。
- 只用 QPSK；目标 1% 误帧率；单帧 N = 1024；已知 σ²；ZC 导频 [核实：设定]。是否代表真实系统 [推断]。
- P1/P2 信道剖面离真实水声信道有多远 [未查]。
- 叠加导频是不是这个场景的对的选择（云端 c03 说文献结论矛盾）[卡片]。
- AFDM 相对 OFDM、OTFS 在这个信道上的优势，论文能不能讲清 [推断]。
