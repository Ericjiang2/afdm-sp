## 1. 去掉代号

| 代号 | 它实际做的事 |
|---|---|
| AFDM | 一种多载波波形：用 chirp（频率随时间线性变）做基（DAFT：两次二次相位调制夹一次 DFT），加 chirp 周期前缀后，每条径变成一个已知结构的算子；参数 c1 选得合适时，整数多普勒下不同时延、多普勒的径落到变换域里分开的位置，分数多普勒时向邻近位置扩散，几个峰可能来自同一条回声 [核实：physical.py；Bemani 等 2022]（C/A/N） |
| SP（叠加导频） | 已知序列和未知编码数据按功率比 ρ : (1 − ρ) 叠加在全部 N 个符号上，不占专门资源；ρ 越小数据能量越多，但接收机越难凭导频认出回声 [核实：本项目设定与 stageA4]（C/A/N） |
| 接收机各阶段 | 第 0 轮只用导频在整数网格上贪婪找径，保留能量最大的 8 个时延；每轮做变量投影（消去增益后对每径多普勒在 ±0.75 bin 内细搜），再做标量方差的双线性消息传递检测，再 LDPC 译码，把译码结果当额外导频回送；整帧校验失败时才重开路径搜索、允许换径（CSTATE/CODELAY）。两类修错动作：把已找到的回声估准，和承认一开始找错了回声 [核实：native_twofft.py、twofft.py、res-20261118-03]（A/N） |

## 2. 分层

| 层 | 本项目现状 | 真正稀缺、未知或受限的是什么 |
|---|---|---|
| 物理 | 单通道合成水声信道：fc 12 kHz，B 4 kHz（带宽/载频 = 1/3），fs 8 kHz，N = 1024（约 128 ms），8 条离散径 [核实：运行日志、stageA 设定]；为让时延落在搜索窗内，48.6% 的自然样本被重抽，每帧路径总功率归一 [核实：res-20261015-02]（A/N） | 真实时延连续；平台会加速；宽带下多普勒是随路径不同的时间伸缩（仿真按窄带频移合成）[推断]（C/A/N）；同时延多普勒簇（Jakes）信道下现有接收机误帧率 .873（真信道 .002）[核实：res-20261008-02]（N）；缺目标海况的实测数据 [推断]（A） |
| 信号模型 | y = Σ_i g_i H_i(l_i, ν_i)(导频 + 数据) + 噪声；阶段 A–A4 管线里时延 l_i 是整数抽头 [核实：physical.regressors、truth['l_i']]；已知 σ²、已知路径数（固定 8 槽）[核实]（C/N） | 真实路径数未知：真 P = 10 而槽位 8 时多付 1.28–1.64 dB；σ² 未知时多付约 1.19 dB [核实：res-20261118-04]（N）；两条在一帧内波形几乎相同的径，加细网格也分不开，受观测时长和带宽限制 [推断]（A） |
| 推断结构 | 双线性：信道未知 × 数据未知，叠加已知导频；数据有码约束 [核实]（C/A/N） | 第 0 轮没有数据信息；ρ ≤ .20 时纯导频信息不足 [核实：A3/A4]；ρ = .05 检测器增益相位失锁，此时"给真信道"测到的是接收机失稳而不是信息极限 [核实：A2 探索性 20 键]（C/A/N）；数据协方差含 H H^H：单条理想径时它是常数乘单位阵、读不出多普勒，多径时才有交叉项可用 [推断]（A） |
| 算法 | 见 §1；单帧 CPU 约 250–280 ms [核实：res-20261118-03]（N） | 第 0 轮多普勒有门槛（A3）；现有导频估计器比自身下界差 1.4–1.9 倍，半盲下界 .037–.040 bin 刚压在 .04 的目标线上 [核实：A3/A4]（C/A/N） |
| 系统目标 | 固定码率下 1% 误帧率所需 SNR 尽量低、导频开销尽量小 [核实]（C） | 导频是发射前付出的成本，重搜只花在校验失败的帧上，两种成本发生时机不同 [推断]（A）；逐帧冷启动，丢掉了帧间相关 [推断]（N） |
| 评价 | 编码误帧率穿越点、配对自助区间 [核实]（C/N） | 每格 400 帧时 1% 误帧率只对应约 4 个错帧，尾部证据单薄 [推断，按帧数算]（A）；NMSE 与误帧率的排序可能相反 [卡片 08]（C）；高斯注入的多普勒误差与真实导频误差刻度不一致 [核实：A3 读数]（N） |

底下的抽象问题，三种说法并列（不选一个）：
- 起步：从一帧观测里联合估计少数参数决定的稀疏算子，观测里叠加了已知探测信号和受码约束的未知符号；难点是第 0 轮先捕获到足够准的参数，迭代才接得住 [推断]（C）。
- 排除：只看到一份被未知算子变形的编码消息，至少要放多少已知参考，才能在有限时间内排除那些会把消息解错的解释 [推断]（A）。
- 三个耦合瓶颈：离散支撑捕获、亚分辨连续参数估计、近似推断的不确定度自洽，以最小导频能量把系统推过译码悬崖 [推断]（N）。

## 4. 开放问题（三方合并；只作提示，不是出题清单）

0. **【头号悬赏靶，Eric 2026-11-22 批示留题换招】无前导单帧下打破低导频（$\rho \le 0.12$）第 0 轮捕获悬崖**：不研究“选 $\rho$ 公式”（离线扫一遍 $\rho=0.25$ 泛化已极稳，门限 `4.95 dB`），而是以「现有接收机最优扫描 $\rho=0.25$ 的 `4.95 dB`」为硬基线，在同总发射能量、无额外前后导开销下，利用未知数据并非高斯白噪声、而是穿过同一稀疏算子的离散星座/码字结构（含物理结构驱动的轻量深度展开网络或非平凡半盲算子），在 $\rho \le 0.12$ 下正面击败 `4.95 dB` 基线至少 `0.8 dB`（真值第 0 轮在 `3.45 dB`，扣 `0.84 dB` 信息税仍有 `0.8–1.2 dB` 净奖池）。
1. **歧义与最小导频**：给定码本和路径族，哪些不同的"消息 + 信道"会产生几乎相同的接收波形？消除会导致错帧的那些歧义，最少要多少导频能量？（A；与 C 的"最小导频比例由什么决定"相通）
2. **够译码就行的信道精度**：哪些弱径、哪些误差分量可以安全忽略？估计器该用什么指标比？（A；C 卡 08）
3. **耦合信息论界**：支撑检测 + 连续估计 + 有限码长译码一起，最优 ρ 能压到多低（类似非渐近 Ziv–Zakai 界）？（N）
4. **第 0 轮半盲估计器**：单帧、非渐近条件下逼近半盲下界、复杂度仍为 O(N log N) 级的多普勒估计器（A4：导频单独 .060–.074，半盲 .037–.040）[核实：读数]（C/A/N）
5. **极低导频下检测器的相位歧义**：如何用极少导频或码结构打破旋转、尺度歧义而不牺牲跟踪能力（C/A/N）
6. **跨帧追踪 vs 逐帧冷启动**：多径时延骨架在帧间缓变时，偶尔一帧强参考与每帧弱叠加导频，哪种在同等能量和时延下交付更多正确比特？（A/N；云端 c02）
7. **离散径与连续簇的统一表示**：不预设路径数 P，在离散径和同时延多普勒簇之间无损切换（N）
8. **宽带时间伸缩下的 AFDM**：chirp 参数与重采样前端如何适配随路径不同的时间伸缩，这是"水声 AFDM"名副其实的前提（N；C 卡 05 查到已有工作）
9. **尾部失败的逐帧预报与动作选择**：哪种逐帧可测的量能预报尾部失败；失败时继续迭代、换径还是停，哪个每毫秒救回最多帧（A；与现稿路线相关）
10. **公平基线**：在同一批信道、相同净码率和算力下，换成单载波判决反馈均衡、OFDM、OTFS，收益还剩多少；能否区分 AFDM 本身的作用与通用译码反馈的作用（A/N）

## 5. 值得怀疑的前提（track `pit` 的来源之一）

1. **仿真替接收机做掉了最难的筛选**：48.6% 的自然样本因时延超出搜索窗被重抽，每帧功率归一；真实最难的 1% 若正是窗外回声或整帧深衰落，现在的误帧率尾巴回答的是另一个问题 [核实：res-20261015-02]（A/N）
2. **物理保真度**：窄带频移、整数时延、精确 CPP 是否代表真实水声；B/fc = 1/3 [核实]；时延整数 [核实：阶段 A–A4 管线]；分数时延下现有估计误差翻倍 [卡片 c06]；簇信道下接收机崩塌 [核实：res-20261008-02]（C/A/N）
3. **为什么非要叠加导频 AFDM**：嵌入导频在 N = 1024 时放不下（保护带 1029 > N）[核实：res-20261015-03]；但从未与水声主流的单载波判决反馈均衡、多块 OFDM、OTFS 在同等总开销下对决 [推断]（A/N）
4. **压低 ρ 值不值**：理想盒子里压低 ρ 最多换 0.5–1.5 dB [核实：A/A2]，而 σ² 未知要付约 1.19 dB、路径数超出槽位要付 1.28–1.64 dB [核实：res-20261118-04]；先解决模型失配可能回报更高 [推断]（N）
5. **逐帧冷启动**：每帧当作独立抽样；允许跨帧先验，第 0 轮漏径与弱导频多普勒精度可能退化为追踪问题 [推断]（A/N）
6. **逐径精确恢复、精确协方差未必必要**：Γ = 0 与 CODELAY 等效；近距双径上一种方法更常保住真双径，误帧率却等效 [核实：res-20261120-01、res-20261120-03]（A/N；已有证据，相关主线已关闭）
7. **只用 QPSK、1% 误帧率、单帧 N = 1024、ZC 导频** 是否代表真实系统 [核实设定；代表性为推断]（C/N）
