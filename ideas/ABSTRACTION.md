# 第一性原理地图：AFDM-SP 底下到底是什么问题

> Claude 2026-11-21 起草（draft）。漏斗每轮的反思可以修订这份文件（改动写进 runs.md 的反思行）；大的改动交 Eric 看。
> 用法：出题前读；每个深想 idea 要说清它打的是哪一层、属于哪类抽象问题；卡住时回到这里换层或换领域（METHODS.md 的 F、G12）。

## 1. 去掉代号

| 代号 | 它实际做的事 |
|---|---|
| AFDM | 一种多载波波形：用 chirp（频率随时间线性变）做基，参数 c1 选得合适时，每条径（一个时延、一个多普勒）在变换域里落到彼此分开的位置，信道矩阵稀疏且结构已知 |
| SP（叠加导频） | 已知序列直接叠加在未知数据上，不占专门的时频资源；代价是导频和数据互为干扰，导频功率比例 ρ 决定"认路的力气"和"传数据的力气"怎么分 |
| F0 / CODELAY / 第 0、1 轮 | 先只靠导频找路径（捕获），再用译码出的数据当额外导频去精修（跟踪）；失败后决定继续迭代还是重搜 |

## 2. 分层

| 层 | 本项目的现状 | 稀缺、未知或受限的是什么 |
|---|---|---|
| 物理 | 水声参数：fc 12 kHz，B 4 kHz（带宽/载频 = 1/3，属宽带），fs 8 kHz，帧 N = 1024（约 128 ms）；P1 场景 8 条径 | 真实的时延是连续的；平台会加速；宽带下多普勒其实是时间伸缩 |
| 信号模型 | y = Σ_i g_i H_i(l_i, ν_i)(导频 + 数据) + 噪声；仿真里时延全是整数（c06 指出） | 少数几个参数（每径时延、多普勒、增益）决定整个信道 |
| 推断结构 | 双线性：信道未知 × 数据未知，叠加一个已知导频；数据有码约束 | 第 0 轮没有数据信息，只能靠导频；可辨识性随 ρ 下降而变差（ρ = .05 检测器相位锁不住） |
| 算法 | 第 0 轮：导频贪婪找径 + 每径多普勒细搜；检测器 P-BiG-AMP；译码；第 1 轮用译码数据精修 | 第 0 轮的多普勒精度有门槛（A3）；现有估计器比自身下界差 1.6–1.9 倍（A4） |
| 系统目标 | 固定码率下达到 1% 误帧率所需的 SNR 尽量低，导频开销尽量小 | 导频开销与可靠性的权衡；最优 ρ 现在由第 0 轮捕获决定（.25 → 理想第 0 轮下 .10） |
| 评价 | 编码误帧率穿越点；NMSE 只作参考 | NMSE 与误帧率的排序可能相反（卡 08） |

一句话的抽象问题：从一帧观测里，联合估计一个只由少数参数决定的稀疏线性算子，观测里叠加了一个已知探测信号和受码约束的未知符号，接收机可以迭代地把译码结果当作额外的探测信号。核心难点是"起步"：第 0 轮必须先捕获到足够准的参数，迭代才接得住。

## 3. 别的领域谁在解同一类问题（G12 方法迁移的起点）

| 领域 | 同构的地方 | 可借的东西 |
|---|---|---|
| GNSS 信号捕获与跟踪 | 码相位 × 多普勒的二维搜索，然后进入跟踪环；导频通道与数据通道分开（如 GPS L5、Galileo E1 的导频功率分配） | 捕获门限与虚警的设计方法；相干积分长度与多普勒误差的权衡；"数据剥离"延长相干积分（对应第 1 轮用数据精修）；导频/数据功率分配的工程经验 |
| 单频频率估计的门限效应 | 最大似然频率估计在门限 SNR 以下会出现离群值，误差突然变大（Rife–Boorstyn 1974） | 粗搜加细搜的结构；门限 SNR 的预测方法，直接对应 A3 的多普勒门槛 |
| 码辅助（turbo）同步 | 迭代相位、频偏估计有"捕获范围"，超出就收敛到错的点（Herzet、Noels 等，约 2005–2007） | 捕获范围的分析方法（云端 c01、c07 已用） |
| 雷达、声呐波形设计 | 模糊函数的旁瓣决定弱目标能否被看见 | 低模糊区序列设计（卡 10） |
| 半盲与盲信道辨识、相位恢复 | 用数据的二阶统计辨识信道（Tsatsanis–Giannakis）；从强度相关恢复多径（Ranieri 等） | 已被做过（Gemini 查新），只作工具，不作新意 |
| 脉冲星闪烁 | 二次谱在时延–多普勒平面上出现弧线，用来反推散射屏（Cordes 等） | 从数据相关结构看多径几何 |
| OFDM 子载波间干扰分析 | 频偏导致的 ICI 与 SINR 损失有闭式（Pollet 1995） | 云端 c07 用来解释 A3 门槛的前半段 |
| 离网稀疏恢复与超分辨 | 分数时延、多普勒不落在网格上（原子范数、离网 SBL） | 连续参数估计的方法和分辨率极限 |
| 双线性推断与 EM | BiG-AMP、EM 的初值依赖与吸引域 | 初始化理论；相位歧义的处理 |
| 编码理论的门限 | 密度演化、EXIT 图给出迭代译码的收敛门限 | 把"第 0 轮够不够准"写成一个迭代收敛门限问题 |

灵感阅读轮换的领域：IEEE TSP、TWC、TCOM、JSAC 与 arXiv eess.SP、cs.IT 近 12 个月；每次另加一个远一点的领域（GNSS 的 NAVIGATION 期刊或 ION GNSS、IEEE TAES 雷达、IEEE JOE 水声、天文信号处理、光学相位恢复、机器学习里的 EM/AMP 理论）。

## 4. 本项目的开放问题清单（Hamming 式，M1）

1. 编码叠加导频接收机的最小导频比例由什么决定：第 0 轮捕获门限，还是检测器可辨识性（卡 01、02）？
2. 第 0 轮多普勒怎样逼近半盲下界（A4：导频单独 .060–.074，半盲 .037–.040）？
3. 哪种信道误差分量真正伤译码，估计器该用什么指标比（卡 08）？
4. 时延连续时，现有接收机的收益还剩多少（c06）？
5. 时延连续时大量出现的近邻径对怎么处理（c11；与已关闭的同延主线相关，是否重开由 Eric 定）？
6. 译码失败后继续迭代还是重搜（现稿路线）。
7. 迭代接收机里噪声方差未知（Stein 估噪，Eric 定为论文附注）。
8. 为弱径捕获设计叠加导频序列（卡 10）。
9. 叠加导频加分数多普勒下 c1 的选择（卡 09）。
10. 帧内多普勒变化（平台加速度）（卡 11，已有 Zakharov 等先例）。

## 5. 值得怀疑的前提（track `pit` 的来源）

- 仿真里时延全是整数（c06：换成分数时延后每径摊到约 2.45 个抽头，现有估计误差翻倍）。
- 窄带多普勒模型：本项目 B/fc = 1/3，按理属于宽带，多普勒应是时间伸缩；仿真是否处理了？
- 只用 QPSK；目标 1% 误帧率；单帧 N = 1024；已知 σ²；ZC 导频。
- P1/P2 信道剖面离真实水声信道有多远。
- 叠加导频本身是不是这个场景的对的选择（对比嵌入导频，云端 c03 说文献结论矛盾）。
- AFDM 相对 OFDM、OTFS 在这个信道上的优势，论文能不能讲清（"为什么是 AFDM"）。
