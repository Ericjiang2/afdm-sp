## 1. 去掉代号，这个项目在做什么
- 物理：一个宽带发射信号经过少数几条离散传播路径到达接收端，每条路径有自己的到达时间、自己的径向速度（载波上表现为频移，宽带上表现为时间伸缩）和一个复增益。8 条径、每条 4 个实参数，一共约 32 个实未知数；一帧有 1024 个复观测、载 1024 个信息比特。信道"知道它要花多少"按信息量算很便宜（22-l15：至多 0.84 dB），真正的差距是算法没走进正确的解。
- 波形（AFDM）：发射端把符号放在一组线性调频基上。数学上是把时延–多普勒二维平面沿一条斜线投影到一维指标上（位置 = 多普勒 + 2N·c1·时延），使每条径在变换域里变成一次循环移位（分数多普勒时摊成一个 Dirichlet 核）。它不创造信息，只决定"径之间在观测里怎么重叠"。
- 叠加导频：已知序列与数据同时同频发送，占总功率的 ρ。导频不占时间和带宽，只占功率；代价是导频和数据互为干扰。
- 接收机（F0 + CSTATE / CODELAY）：第 0 轮只用导频找径（把数据当噪声），随后"检测 → LDPC 译码 → 用软符号重估信道"循环；译码失败后重开支撑搜索（同时延的不确定度按整块处理）。这是一个自举环：每个环节都要靠另一个环节的输出起步。

## 2. 分层与每层稀缺的东西
| 层 | 内容 | 稀缺或限制 |
|---|---|---|
| 物理 | 稀疏双色散信道，欠扩展（时延扩展 × 多普勒扩展 ≪ 1） | 自由度不稀缺；稀缺的是"整帧相干"：多普勒误差 0.16 bin 就让帧两端相位差约 1 rad |
| 信号模型 | y = H(θ)(√ρ·p + √(1−ρ)·d) + w，对 (θ, d) 双线性 | 数据是信道估计的自干扰：每样点导频对数据功率比 ρ/(1−ρ)，靠 N 倍处理增益才看得见弱径 |
| 推断结构 | 信道 32 个连续参数（时延、多普勒非线性进入）；数据 1024 比特、离散、受码约束 | 起点：好码的"全有或全无"让环路要么起来要么起不来；联合后验是多峰的 |
| 算法 | 分阶段、每阶段用点估计 + 标量不确定度传给下一阶段 | 第 0 轮的多普勒精度与弱径捕获；阶段之间丢掉的软信息（只传点估计） |
| 系统目标 | 同总能量、同帧长下的误帧率 | 导频功率是唯一开销；已知最优 ρ ≈ .25–.30，真信道上限比它好约 1.5 dB |
| 评价 | 单一码率 1/2、QPSK、整数时延、P 已知、每径多普勒独立 | 评价设定本身（多数已被前几轮的 pit 卡查过） |

## 3. 抽象问题类与别的领域
1. **带离散码本先验的稀疏参数化双线性反问题**（盲 / 半盲解卷积 + 码）。同类：非相干通信容量（先付信道的信息税）、盲均衡（CMA、Bussgang 类）、压缩相位恢复、盲解混（demixing）、自校准（射电天文）。
2. **自举环的起步问题（成核）**。同类：空间耦合（一小块先译出、向外推进）、退火与同伦延拓（从容易的问题连续变到难的问题）、课程式解码（先译低阶、低码率的部分）、种子矩阵压缩感知、蛋白质折叠的成核。
3. **低每样点信噪比下的频率 / 时延捕获门限**（离群概率主导，而不是局部精度）。同类：GNSS 弱信号捕获里未知导航比特限制相干积分时长（平方损失、数据擦除、辅助捕获）、深空通信的载波同步与码辅助同步（code-aided / turbo synchronization）、雷达的相干–非相干积分折中（只借数学，不做雷达题）。
4. **阶段间只传点估计造成的信息丢失**。同类：列表译码与延迟决策（保留多个候选到有更多信息时再裁决）、粒子 / 多假设跟踪、期望传播里保留协方差。
5. **模型失配下的稳健推断**（分数时延、未知成形、硬件失真）。同类：模型驱动深度展开、带残差方差自校准的 EM、在线字典学习。

## 4. 我认为值得打的开放问题（自己的清单，M1）
- Q1 第 0 轮能否不把数据当高斯噪声：数据是"有限字母表 + 码约束"的，同一稀疏算子同时作用在导频和数据上。难点：多径把 QPSK 混成 4^P 个点，逐样点的四次方类非线性失效；需要先部分均衡或利用变换域结构。（悬赏靶：ρ ≤ .12 正面击败 4.95 dB。）
- Q2 起步靠"先易后难"的发射端结构而不是多给导频：帧内不等保护 / 分层码率 / 耦合，让一小部分数据先译出来充当导频（l03 用 UEP 做过一版并被白送真值上限否掉——要弄清它死在"上限"还是死在"那种 UEP"）。
- Q3 第 0 轮输出保留多个假设（列表）而不是一个点估计，后面的译码当裁判：与现稿"失败后重搜"相邻（已在做，慎碰），但"第 0 轮就并行保留"与 c73 / c77 的或分集已覆盖。
- Q4 导频与数据的功率在帧内（变换域或时间上）怎么分布：现在是均匀叠加；导频能量集中在一部分资源上（部分叠加）时，数据自干扰、捕获门限与译码起点三者的折中。
- Q5 码辅助同步的理论：EXIT 面积视角下"信道估计器 + 检测器"作为内码，与外码的匹配（l02 已在 L3，等 Eric 的生死检）。
- Q6 模型驱动的轻量网络切入"闭式算法卡死"的环节：第 0 轮的检测统计量（数据自干扰是非高斯、带结构的）、连续时延核与残差方差自校准（c06 / c08 的后续）、展开的 F0 环里学习阻尼和不确定度传递。
- Q7 同类问题在别的双色散系统（低轨卫星、高速铁路）里用它们自己的参数重算后还在不在（规则 5）。
