# I-20261122-l09 出题者（gemini-4-carbon）的第一性原理拆解（原样）

1. 物理传播层：声波或无线电波经离散散射体产生时延、多普勒频移（及宽带时间伸缩）与复衰减；稀缺量是相干时间 $T_c$ 限制下的无混叠时延–多普勒自由度预算与发射峰值功率，可疑前提是整数时延网格、窄带纯频移近似与人为截断的短时延扩展。
2. 信号与酉算子层：发端把已知参考探针（前导或叠加导频）与经酉基 $\mathbf{U}$（如二次调频变换 DAFT 或 Zak 变换）扩展的未知编码符号送入线性时变算子 $\mathbf{H}=\sum_p g_p\mathbf{D}_{\nu_p}\boldsymbol{\Pi}_{\ell_p}$；稀缺量是有限帧长内的正交观测维数，恒模酉基在换取多径分集的同时把符号能量与误差摊满全帧。
3. 双线性推断结构层：接收观测关于未知稀疏路径参数 $(\boldsymbol{\ell},\boldsymbol{\nu},\mathbf{g})$ 与受稀疏校验图约束的离散码字呈双线性耦合；线性复增益可变量投影消元，真正卡住系统的往往是对称性简并（如多源叠加零空间）与非凸离散支撑归属。
4. 迭代算法层：接收机用首轮探针粗捕支撑，再在软抵消线性检测与置信传播译码之间循环并按需重搜几何支撑；稀缺量是首轮跨过外码启动门限的有效互信息与不受模型自证偏置污染的外信息自由度。
5. 系统目标与同构类：用户支付带宽、能量、前缀与算力以换取目标误包率下的净吞吐，而非信道均方误差；底层属于“带离散编码流形约束的双线性算子盲/半盲自校准逆问题”，与盲源分离、相位恢复、冷冻电镜多类重构及尖峰随机矩阵（Spiked Random Matrix）社区检测数学同构。
6. 本题打击层次：打第 3 层（双线性推断的对称性破缺），用前导一阶和与载荷二阶跨径相关的非加性耦合（G5），消解免授权接入前导碰撞中的多径归属简并（G10）。
