# I-20261122-l40 出题者的第一性原理拆解（gemini-4-carbon，未读 ABSTRACTION.md）

1) 物理与算子层：双色散水声/高速信道将时域波形映射为 $P=8$ 条连续时延-多普勒路径的叠加；AFDM 通过双 chirp 酉变换（DAFT，$2Nc_1=5$）把整数时延-多普勒对角化为周期移位，但分数多普勒在 DAFT 域产生全帧 Dirichlet 核慢衰减旁瓣（$\pm 4$ bin 仍漏 $1.6\%\text{–}2.8\%$ 能量），时域则是严格无截断的 $P$ 路稀疏移位调相算子。
2) 双线性推断与自由度层：单帧复观测自由度为 $N=1024$，未知量为离散编码符号 $x_d\in\mathcal{Q}^{N_d}$（受校验矩阵约束，信息自由度 $k$）与信道连续参数 $\{\ell_p,\nu_p,g_p\}_{p=1}^P$（$8$ 个离散时延槽 $+ 8$ 个实多普勒 $+ 8$ 个复增益，共 $24$ 个实/复连续自由度），构成带编码先验约束的参数化双线性逆问题 $y = \sum_{p=1}^P g_p \Xi(\ell_p,\nu_p)(x_p + x_d) + w$。
3) 导频与数据的干扰比瓶颈：叠加导频（SP）把导频能量 $\rho N$ 与数据能量 $(1-\rho)N$ 混叠在同一酉空间，首轮纯导频估计的有效信干噪比被锁在 $\text{SINR}_0 = \rho / [(1-\rho) + \sigma^2] \le \rho/(1-\rho)$（$\rho=0.3$ 时上限仅 $-3.68\text{ dB}$，$\rho=0.5$ 时 $0\text{ dB}$），高信噪比下纯导频估计必受自干扰地板限制。
4) 外环软回送与检测内环耦合层：要突破首轮 $-3.68\text{ dB}$ 自干扰天花板，接收机必须依赖「检测 $\to$ LDPC 译码软外信息回送 $\to$ 数据干扰抵消与增益重估」的涡轮（turbo）不动点外环，且内环检测需显式传播增益后验不确定度以避免把残余信道误差当作热噪声。
5) 编码速率与开销记账层：嵌入导频（EP）用 $N_{\text{oh}}=2Q+1$ 个零保护符号换取导频区零数据干扰与数据符号功率抬升 $E_d=(1-\rho_{\text{EP}})N/(N-N_{\text{oh}})$；同总能量同帧长下的公平有效吞吐（goodput）比较要求双方在目标频谱效率 $\eta = k/N$ 上速率匹配，而非在扣掉 $25.3\%$ 符号后仍把码率锁死在 $1/2$。
6) 本卡切入层（G11 前提反查）：跨领域涡轮均衡与基准评测要求「比较前端或导频体制时，固定外环轮数、检测器增益接口与目标净荷比特数」；对 Zheng、EP、F1 三条基线逐层核查可见，F1 满足对称性不变量，而 Zheng 移植断开了已写进代码的第二轮译码外环并绑定截断固定增益 MP，EP 则用锁死 $1/2$ 码率制造了人为的 $767$ 比特吞吐封顶。
