## 1. 剥掉代号：底下物理与数学上到底在做什么

- **物理层（水声/双选传播介质）**：发射波形 $s(t)$ 经 $P$ 条宏观声线（及表面/底面微散射簇）到达接收端，每条声线的时变传播延迟为 $\tau_p(t) \approx \tau_p - a_p t$（压缩因子 $a_p = v_p/c$）。仅当帧内时间伸缩量 $a_p B T \ll 1$ 时，宽带时间压缩才退化为窄带相位斜坡（频移 $\nu_p = f_c a_p T$），离散基带模型简化为线性时变（LTV）算子
  $$\mathbf{H}(\boldsymbol{\theta}, \mathbf{g}) = \sum_{p=1}^P g_p \mathbf{\Delta}_{\nu_p} \mathbf{\Pi}_{\tau_p},$$
  其中 $\mathbf{\Pi}_{\tau_p}$ 在连续时延 $\tau_p \notin \mathbb{Z}/f_s$ 时不是置换阵，而是带限插值核（sinc/RRC 拖尾）。
- **波形层（`AFDM` = 酉基坐标变换 $\mathbf{A} = \mathbf{\Lambda}_{c_2}\mathbf{F}\mathbf{\Lambda}_{c_1}$）**：发送端令时域信号为 $\mathbf{x}_{\text{time}} = \mathbf{A}^H \mathbf{x}$，接收端乘 $\mathbf{A}$。酉变换严格不改变信道容量 $\log\det(\mathbf{I}+\gamma_d\mathbf{H}^H\mathbf{H})$、不改变平均线性最小均方误差 $\frac{1}{N}\mathrm{tr}(\mathbf{Q})$、也不改变导频与数据的总能量比。它真正改变的只有两件事：
  1. **后验等效信噪比跨符号方差（对角均衡化）**：把不同 $(\ell_p, \nu_p)$ 映射到一维环面 $\mathbb{Z}_N$ 上的不同循环移位 $2Nc_1\ell_p + \nu_p \pmod N$，抹平频选与时选深衰落；代价是一维环面总容量固定为 $N$，扩展超界立即发生模 $N$ 折返混叠。
  2. **时域包络峰值分布**：把单符号能量摊到全帧 $N$ 个采样上，峰值均值比（PAPR）从单载波的 $O(1)$ 升至 $O(\ln N)$。
- **导频层（`SP` = 线性叠加 $\mathbf{x} = \sqrt{\rho}\mathbf{p} + \sqrt{1-\rho}\mathbf{d}$）**：省掉了正交保护带开销（在大时延–多普勒扩展 $(L+1)(2k_{\max}+1) \sim N$ 时嵌入导频保护区会吃光自由度），换来**双线性乘性自干扰**：
  $$\mathbf{y} = \sqrt{\rho}\mathbf{\Phi}(\mathbf{p})\mathbf{h} + \sqrt{1-\rho}\mathbf{D}(\mathbf{d})\mathbf{h} + \mathbf{w}.$$
  未知信道 $\mathbf{h}$ 同时乘已知导频 $\mathbf{p}$ 和未知数据 $\mathbf{d}$。在第 0 轮 $\mathbf{d}$ 未知时，$(1-\rho)$ 的数据能量构成信号相关的结构化干扰，单径初始信干噪比被锁死在 $\lesssim \frac{\rho}{1-\rho+\sigma^2} N |g_p|^2$。
- **推断与接收机层（`F0` + `CODELAY` + `LDPC`）**：本质是在求解带离散奇偶校验硬约束的非凸双线性逆问题
  $$\hat{\boldsymbol{\theta}}, \hat{\mathbf{g}}, \hat{\mathbf{b}} = \arg\max_{\mathbf{C}\mathbf{b}=\mathbf{0}} p\big(\mathbf{y} \mid \boldsymbol{\theta}, \mathbf{g}, \mathbf{d}(\mathbf{b})\big).$$
  - `F0` 用第 0 轮导频贪婪选支撑并局部精修 $\nu_p$，随后固定非线性几何 $\boldsymbol{\theta}$，在“检测器（重估线性增益 $\mathbf{g}$）$\leftrightarrow$ 译码器”之间做消息传递。
  - `CODELAY`/`CSTATE` 利用 LDPC 校验子 $\mathbf{C}\hat{\mathbf{b}}\neq \mathbf{0}$ 提供的**近零虚警单侧验证器（NP witness）**触发几何重搜，并在软符号均值 $\boldsymbol{\mu}_d$ 与剩余方差 $\mathbf{v}_d$ 下剔除伪重径（幻影）。

## 3. 所属抽象问题类与跨领域同构（用于方法迁移 G12 与锚点 D）

1. **带强结构先验的双线性盲/半盲逆问题** $\mathbf{y} = \mathcal{A}(\boldsymbol{\theta})\mathbf{x} + \mathbf{w}$：
   - **冷冻电镜三维重构（Cryo-EM，RELION / cryoSPARC）**：未知投影姿态 $\boldsymbol{\theta}$（对应时延–多普勒几何）+ 三维密度先验 $\mathbf{x}$（对应稀疏码字）。关键武器：低信噪比下**对姿态 $\boldsymbol{\theta}$ 做边缘化而非点估计**（避免点估计锁死假姿态）、黄金标准半集独立交叉验证（防过拟合自证，对应奇偶外信息）、渐进对称性分岔。
   - **射电天文干涉自校准（Radio Interferometry `selfcal`）与散斑成像**：天线复增益/大气相位与天空图像双线性耦合。关键武器：**闭合相位（Closure Phase / Bispectrum 三阶量）与闭合幅度**——无需估计单条路径/天线的相位，代数相乘直接消掉未知单端相位或公共频偏！
   - **地震全波形反演（FWI）与盲相位恢复/叠层成像（Ptychography）**：振荡核 $e^{j2\pi\nu t}$ 的 $L_2$ 匹配天然有波长级局部极小，FWI 用最优传输（Wasserstein/ Sobolev 度量）或震源子波消去法（Variable Projection + 交叉卷积不变量）改变目标函数几何。
2. **拥有廉价单侧精确验证器（One-sided Exact Verifier / NP Witness）的搜索问题**：
   - **SAT/SMT 求解器（CDCL 冲突驱动子句学习）**：校验子 $\mathbf{C}\hat{\mathbf{b}}\neq \mathbf{0}$ 不只是一个“0/1 失败铃声”——**哪些校验方程违背了（unsatisfied check syndrome pattern）本身携带局部化空间/图结构诊断信息**，而且一次失败搜索留下的排除区域（nogood / conflict clause）应约束下一次搜索，而不是无记忆重抽。
   - **计算机视觉几何估计（RANSAC / PROSAC / LoiSAC）**：面对“85% 内点很准 + 15% 重尾大离群值”（这正是 `c01/c35` 实测出的第 0 轮导频多普勒分布！），最小二乘全集联立会被 1–2 个离群值拉垮，而最小子集随机一致性采样 + 全局内点校验能对重尾离群免疫。
3. **有限环面/多周期采样上的超分辨与解混叠**：
   - **多脉冲重复频率（Staggered-PRI / Multi-PRF）脉冲多普勒雷达与双光梳光谱（Dual-Comb Vernier Spectroscopy）**：单个周期采样必受模糊墙限制，两个微差周期（游标卡尺效应）或非周期跳变可在不拉长总帧长的情况下把无模糊范围乘性放大。
4. **双稳态自举相变与成核传播（Nucleation & Spatial Coupling）**：
   - **统计物理成核理论与空间耦合 LDPC（Kudekar–Richardson–Urbanke 阈值饱和）**：均匀耦合系统卡在动力学自旋节线（spinodal / BP 门限），而 `l03` 之所以失败是因为在全孔径酉变换域加 20% 已知符号没有形成局部高信干比界面；真正的成核机制要求**检验图与物理干扰局部化耦合**（波前逐层剥离干扰，零全局码率损失达到 MAP 面积门限）。

## 4. 本项目哪些默认前提可疑（`pit` 候选）

1. **单帧孤立无记忆前提**：水声数据包通常连续发数帧或自带同步前导，帧间几何演化遵循刚体运动学约束而非每帧独立重抽。
2. **把校验子仅当作标量早停开关**：LDPC 有 $m = 1024$ 条稀疏校验方程，违背方程的拓扑分布与时域/仿射域局部干扰结构之间的映射完全未被利用。
3. **信道与波形参数绑定在单水听器、理想线性功放、窄带纯频移、小最大时延 `l_max=102`**：多项已在 `c06/c12/c14/c25/l09/l12/l14` 立卡，新卡应避开重复，转向**跨领域机制迁移（G12）、文献矛盾消解（G13）以及相邻/探索赛道的独立原理问题**。
