# I-20261122-l19 出题者（gemini-4-neon）的第一性原理拆解（原样）

- L0 物理层：波动传播形成稀疏多径/色散信道；发射机受总功率、带宽、功放峰值约束，接收机受前端硬件（本振相位噪声/功耗或无本振平方律包络检波）与热噪声约束。
- L1 信号与算子层：AFDM/OFDM 是在 $N$ 维酉基下把数据与已知参考映射到时频/啁啾域，经连续参数化线性算子 $\mathbf{H}$ 作用；当接收端去掉本振改为单二极管直接检测时，观测退化为非线性强度平方 $I[n]=|x[n]+z[n]|^2$，丢失全部载波相位。
- L2 推断与耦合结构层：本项目主线是“未知信道 $\times$ 未知编码数据”的双线性耦合；其广义同类是“非线性/缺相位观测下的复信号恢复”，关键瓶颈不是噪声方差，而是零点跨越单位圆引起的 $O(2^K)$ 组合非唯一性（Blaschke 模糊）与雅可比矩阵自由度临界奇异（$\gamma_{\text{dof}}\to 1$）。
- L3 算法与动力学层：解析反演（如 Kramers–Kronig 希尔伯特变换）只在高载信比最小相位区内精确，局部非凸求解（Gauss–Newton/Wirtinger Flow）在临界自由度比下会被 Blaschke 假极小锁死；必须靠参考几何设计把求解拉入全局良态吸引域。
- L4 系统目标与评价层：必须在同总发射功率、同总带宽、同采样率、同单检波器硬件与同净频谱效率下衡量总信噪比门限，而非只看数据段信噪比或局部下界。
- 抽象问题类与远域映射：一维带限单强度流复场恢复 $\leftrightarrow$ X 射线相干衍射成像（CDI）的全息参考设计与傅里叶相位恢复；本项目可疑前提之一是“必须配备高耗电相干 I/Q 本振”，而无本振单管接收社区又默认“参考只能是单频边带 CW 载波”。
