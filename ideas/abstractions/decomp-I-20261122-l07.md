# I-20261122-l07 出题者（gemini-4-neon）的第一性原理拆解（原样）

1. 物理层与信号模型：AFDM 项目本质上是用固定酉基 $\mathbf{U}=\mathbf{A}$（DAFT 啁啾基，块长 $N=1024$）将叠加导频与编码 QPSK 符号映射到时域，穿过稀疏时延–多普勒线性时变算子 $\mathbf{H}=\sum_{p=1}^P g_p\mathbf{\Delta}_{\nu_p}\mathbf{\Pi}^{l_p}$；其关键物理假设（整数时延、纯频移窄带近似、独立抽样径速、等均功而非峰功受限）决定了问题边界。
2. 推断结构层：属于“低初始信干比双线性耦合逆问题”——连续稀疏信道参数 $\{(\tau_p,\nu_p,g_p)\}$ 与离散编码符号 $\mathbf{x}_d\in\mathcal{C}$ 互相耦合，软译码后验异方差 $\mathbf{v}$ 经信道算子映射为结构化非白协方差 $\mathbf{H}\mathbf{U}^H\mathrm{diag}(\mathbf{v})\mathbf{U}\mathbf{H}^H$。
3. 算法与系统层：第 0 轮冷启动捕获（支撑+粗多普勒）→ 外层 Turbo 均衡/LDPC 译码/数据辅助重估 → 校验子触发的离散几何重开（`CSTATE`）；目标指标是固定净频谱效率下的 1% 编码误帧率，而非孤立的信道 NMSE。
4. 跨领域抽象问题类：去掉波形代号后，本项目背后的共性抽象问题是“受硬件/测量维度或观测接口压缩（如仅标量统计、单通道、非相干或部分信息接口）约束的波场线性算子参数分辨与估计”，以及“观测基/感知算子选择如何通过消除共模信号自干扰（方差塌缩）来改变 Fisher 信息标度律”。
5. 本卡切入点（`explore` + G12）：跳出水声 AFDM 主线，把量子光学超分辨社区的**空间模式解复用（SPADE）**迁移到无线物理层**单射频链模拟相控阵与无源 RIS 的纯功率（RSRP/RSS）亚瑞利分辨与角度扩展估计**；这一问题直接落在“波场投影基选择 + 统计估计下界（FIM/CRB）+ 硬件恒模/低比特相移约束”的交叉点，可独立成一篇 IEEE TSP / TWC 论文。
