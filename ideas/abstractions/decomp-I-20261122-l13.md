# I-20261122-l13 出题者（gemini-4-carbon）的第一性原理拆解（原样）

(1) 物理与算子实质：系统在 N=1024（fs=16 kHz，体帧 64 ms）样点上将码率 1/2 的 LDPC 编码 QPSK 数据与已知导频按 (1-ρ):ρ 叠加，经酉啁啾基（2Nc1=5）加 102 点前缀送入 P=8 径水声信道；信道施加整数延迟移位 l_i∈[0,102]、连续多普勒旋转 exp(j2πν_i t/N) 与指数衰减瑞利复增益（∑|g_i|²=1）。
(2) 分层稀缺性：物理层受限于尾径功率匮乏（指数功率谱叠加瑞利起伏使动态范围跨 15–20 dB）；信号模型层受限于固定总能量与时隙下“边界标记 2L、帧内叠加导频 ρ、载荷数据”三者的预算争抢及无保护边界（G=0）的数据串入；推断结构层面对带约束双线性盲反卷积，离散支撑漏检把真径能量变成结构化干扰，多普勒越过 0.04 bin 破坏全帧相位跟踪；算法层受限于第 0 轮输出必须把首轮检测互信息推过规则 LDPC 启动门槛 I*=0.577，失败才触发 CODELAY 最多 2 次槽位交换；系统评估层看等总能量每信息比特下的 1% 误帧率穿越点与算力，而非信道均方误差。
(3) 抽象问题类与跨领域对偶：属于高动态范围稀疏回波串在强边界干扰下的联合支撑检测、两尺度参数消歧与迭代译码自举；与脉冲多普勒雷达双驻留检测（非相干积累对相干搜索）、射电干涉成像 CLEAN 逐源消旁瓣、水声突发前导同步同构。
(4) 可疑前提与本题攻击点：父卡 I-20261122-l08、I-20261122-l12 在证明“两端标记 + ρ=0.10 省 1 dB”时直接给了 8 个真时延，根卡 I-20261121-c14 则在零多普勒下假设现成 LFM 前导可无损给时延；本题同时打信号模型层（标记序列在有限窗内的时延–多普勒耦合）与算法第 0 轮推断层（未知时延下批式两步法与逐径消旁瓣两步法的检测门限落差）。
