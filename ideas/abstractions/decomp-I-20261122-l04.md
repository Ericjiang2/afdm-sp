# 独立拆解记录 — I-20261122-l04（gpt-6.2-sol，第 3 循环 adjacent 根卡）

1. 物理层。传播把发射波形变成若干延迟、移频的副本，收发脉冲决定接收机能看见哪些副本。
2. 表示层。AFDM 用离散啁啾变换组织这些副本。Zak-OTFS 用 Zak 变换把符号组织到时延–多普勒网格。两者的信道都可写成作用于整帧波形的线性算子。
3. 推断层。叠加导频与未知数据经过同一个算子。导频提供已知参照，同帧数据既能干扰首轮估计，也能在后续提供信息。
4. 多址层。基站用各用户的匹配滤波器分开接收。每个滤波输出仍含其他用户经传播和滤波留下的残余。
5. 算法层。首轮拟合只使用接收向量的部分线性组合，因此干扰在这些组合里的功率决定了拟合会受多大影响。
6. 系统层。需要决定哪些用户可以独立启动信道估计，哪些相邻用户值得联合拟合导频。最终收益按正确交付的数据量计。
7. 本卡打首轮推断层。抽象问题是从叠加观测中拟合弱信号时，如何判断一个被省略的强信号是否会使估计偏移。
