# AFDM 项目第一性原理独立拆解（本地第 2 轮 runner l2，Gemini 4 Carbon，读 ABSTRACTION.md 之前）

## 1. 剥离代号：物理与数学上到底在做什么

- **AFDM（$\mathbf{A}=\mathbf{\Lambda}_{c_2}\mathbf{F}\mathbf{\Lambda}_{c_1}$ + CPP）**：本质是在离散时间向量空间 $\mathbb{C}^N$ 上选取一组线性调频（chirp）正交酉基。物理上，双色散信道把发射信号变成若干条经过“时延移位 $\mathbf{\Pi}^\ell$ + 频率调制 $\mathbf{\Delta}_\nu$（更准确说是时间尺度伸缩）”的回波之和；数学上，DAFT 利用时频相空间的线性剪切（斜率 $2Nc_1$），试图把二维参数 $(\ell,\nu)$ 编码进一维循环移位环 $\mathbb{Z}_N$ 的对角位移 $s \equiv 2Nc_1\ell + \nu \pmod N$，使不同 $(\ell,\nu)$ 的路径落在矩阵的不同循环对角带附近。当 $\nu\notin\mathbb{Z}$ 或 $\tau\notin\mathbb{Z}T_s$ 时，每条路径不再占单条对角线，而是按 Dirichlet 核 $D_N(\cdot)$ 和 sinc 核向邻近位置扩散。
- **SP（叠加导频）**：发端在同一段长度 $N$ 的信号里线性叠加已知向量 $\sqrt{\rho}\mathbf{p}$ 与未知编码数据符号 $\sqrt{1-\rho}\mathbf{d}$。原因不是数学上比正交导频干净，而是大时延扩展水声中，正交保护区 $(2k_{\max}+2\xi_\nu+1)\ell_{\max}$ 会吞掉半帧甚至整帧时频自由度（EP 不可行）；代价是第 0 轮信道估计被迫在强未知数据自干扰（功率占比 $1-\rho$）下工作。
- **F0 + CSTATE / CODELAY**：求解双线性耦合半盲反问题 $\mathbf{y} = \mathbf{H}(\boldsymbol{\theta})(\sqrt{\rho}\mathbf{p}+\sqrt{1-\rho}\mathbf{d}) + \mathbf{w}$（且 $\mathbf{d}\in\mathcal{C}$ 受 LDPC 码本约束）的一套两阶段启发式近似：
  1. 先把未知 $\mathbf{d}$ 当作零均值独立同分布干扰，在离散整数网格上做贪心正交匹配追踪（OMP）找粗支撑，再固定整数时延做有界坐标下降的变量投影（VarPro）细化连续多普勒，随后在“近似信道已知”下做软抵消检测 + LDPC BP 译码（`F0`）；
  2. 利用通信特有的零成本精确单侧验证器（校验子 $\mathbf{H}_{\text{code}}\hat{\mathbf{b}}=\mathbf{0}$）判断成败；若失败，用当前译码软均值 $\boldsymbol{\mu}$ 与方差 $\mathbf{v}$ 构造期望残差准则（保留同延不确定度块或令 $\mathbf{\Gamma}=\mathbf{0}$ 的自洽准则），在候选网格上做少量离散支撑增删交换（`CSTATE`）。

## 2. 六层拆解与各层稀缺资源/根本瓶颈

| 层次 | 核心对象与算子 | 真正稀缺或卡脖子的量 |
|---|---|---|
| L1 物理传播层 | 慢声速（$c\approx 1500\text{ m/s}$）多边界反射、平台运动与海面波浪调制：$\tau_p(t)=\tau_p(0)-a_p t-\frac{1}{2}\dot{a}_p t^2$，外加漫散射混响与非平稳噪声 | ① 相对带宽大（$B/f_c\approx 1/3$），多普勒本质是时间伸缩而非纯频移；② 信道扩展因子 $S=2\tau_{\max}f_{d,\max}$ 逼近或越过 1（Kailath 欠扩展极限）；③ 海面散射相干时间 $T_c$ 从上方锁死单帧时长 $T$；④ 声学换能器与功放的严格峰值功率上限 |
| L2 信号与算子表示层 | 酉调制基 $\mathbf{U}\in\{\mathbf{I},\mathbf{F},\mathbf{U}_{\text{OTFS}},\mathbf{A}\}$、脉冲成形与循环前缀 | 有限帧孔径 $N\approx BT$。任意酉基都保持高斯互信息 $\log\det(\mathbf{I}+\gamma\mathbf{H}^H\mathbf{H})$ 不变；$\mathbf{U}$ 只改变三件事：① 发射时域峰均比（PAPR，决定限幅回退后实际入水功率）；② 等效信道矩阵的非零带稀疏度；③ 单符号后验 SINR 的跨符号方差（Jensen 损失）。此外 AFDM 的一维打包受模 $N$ 折返边界 $(2k_{\max}+2\xi_\nu+1)\ell_{\max}<N$ 限制 |
| L3 统计推断与可辨识性层 | 双线性观测 $\mathbf{y}=\mathbf{H}(\boldsymbol{\tau},\boldsymbol{\nu},\mathbf{g})(\mathbf{p}+\mathbf{d})+\mathbf{w}$，离散码本先验 $\mathbf{d}\in\mathcal{C}$ | ① 第 0 轮数据自干扰天花板 $\text{SINR}_0 \le \frac{\rho}{1-\rho+\sigma^2}$（$\sigma^2\to 0$ 也不消失，且单帧特定码字与导频存在 $O(1/\sqrt{N})$ 样本互相关涨落）；② 双侧边缘化不对称：信道侧用软均值/方差对 $\mathbf{d}$ 做了二阶边缘化，检测侧却把点估计 $(\hat{\boldsymbol{\tau}},\hat{\boldsymbol{\nu}})$ 当零误差真值代入，忽略了帧首帧尾相位误差随 $(t-t_0)^2$ 二次增长的非平稳不确定度 |
| L4 算法与计算动力学层 | 贪心支撑选择、非凸 Dirichlet 主瓣精修、Turbo 检测–译码不动点与重搜调度 | ① 非凸多峰似然面（分辨率 $1/T$ 与旁瓣局部极小）上的初值依赖；② BP 译码器陡峭门限造成的全或无启动悬崖；③ 唯一的正向不对称武器是 LDPC 校验子提供的“零成本单侧正确性证书” |
| L5 系统与链路目标层 | 分组帧结构（前导 + 前缀 + 载荷）、半双工 ARQ、多水听器阵列、功放限幅 | 真实水声分组并非孤立单帧 SISO 理想线性信道：前导码同步已是沉没成本，2–4 元水听器阵列极常见，功放峰值受限会惩罚高 PAPR 多载波/chirp 波形 |
| L6 评估与实验基准层 | 单位帧能量 $\|\mathbf{g}\|_2^2=1$、已知径数上限 $P=8$、已知 $\sigma^2$、截断短时延下的 1% FER 穿越点 | 代理指标与工程真实排序可能脱节：均功 SNR 掩盖峰值功率约束下的 4–6 dB PAPR 差距；固定 $P=8$ 离散径忽略水声漫散射连续尾（diffuse tail）；固定帧能量掩盖慢衰落中断率斜率 |

## 3. 抽象问题类别与跨领域同构（G12）

1. **双线性半盲反演与非对称边缘化（Bilinear Semi-Blind Inverse Problem & Marginalization）**：
   - 结构：同时恢复低维连续算子参数 $\boldsymbol{\theta}$ 与高维离散码字 $\mathbf{d}$，交替点估计易陷假不动点或因未边缘化另一侧不确定度而失真。
   - 同类领域：盲图像反卷积（Levin et al. CVPR 2009 证明联合 MAP 必败，唯有对图像信号边缘化才能正确恢复模糊核）、射电天文干涉仪自校准（Selfcal 与闭合相位不变量）、冷冻电镜（Cryo-EM）低信噪比多参考对齐（对未知姿态角积分的期望最大化）、非线性计量经济学中的工具变量/Berkson 误差模型。
2. **配备廉价精确单侧验证器的非凸搜索（Nonconvex Recovery with a Cheap One-Sided Certificate）**：
   - 结构：正向求解 $\boldsymbol{\theta}$ 是高维非凸组合搜索，但给定候选 $\hat{\boldsymbol{\theta}}$ 后，一次线性检测 + BP 译码即可通过奇偶校验子 $\mathbf{s}=\mathbf{0}$ 近乎零虚警地验证真伪。
   - 同类领域：计算机视觉几何估计中的 RANSAC / PROSAC（最小样本生成假设 → 全局内点检验）、纠错译码中的 GRAND / OSD / SCL+CRC 列表验证、SAT 求解器中的冲突驱动子句学习（CDCL）。
3. **有限孔径超分辨与折叠解模糊（Finite-Aperture Super-Resolution & Aliasing Unfolding）**：
   - 结构：在有限带宽 $B$ 和观测时长 $T$ 内分离密集或越界的时延–多普勒原子，对抗模周期混叠与离网泄漏。
   - 同类领域：脉冲多普勒雷达的参差重频（Staggered PRF / 多速率中国剩余定理解速度距离混叠）、无网格原子范数/Beurling LASSO 超分辨、雷达/声呐自适应脉冲压缩（RMMSE / IAA）。
4. **峰值受限/低精度非线性硬件下的波形与迭代接收（Peak-Limited / Nonlinear Transceiver Processing）**：
   - 结构：高 PAPR 调制信号通过限幅功放或低比特 ADC 产生非高斯结构化失真，与信道估计及迭代检测耦合。
   - 同类领域：OFDM 限幅噪声迭代抵消（Bussgang 定理 + 判决导向重构）、1-bit / Modulo ADC 信号恢复、光通信非线性薛定谔方程数字反向传播。

## 4. 可疑前提排查（Pit 视角）

1. **理想线性功放与等均功比较前提**：水声换能器驱动功放受严格峰值电压/空化阈值限制。SP-AFDM 帧峰值功率比带循环前缀单载波（SP-SC-CP）高出约 6–8 dB；若按真实发射端相同峰值功率或相同限幅门限（Clipping ratio）比较，AFDM 要么入水平均功率白亏数 dB，要么限幅失真直接破坏 DAFT 域导频与数据的结构。
2. **信道严格 $P=8$ 离散稀疏且接收机预先知道 $P_{\text{cap}}=8$**：真实浅海冲激响应由少数镜面主径加一段连续衰减的海底/体积漫散射尾（diffuse reverberation）组成，并非严格 8-sparse；固定小名额会把漫散射尾当成未建模白噪或引发错误占位。
3. **信道几何假设簇**（前轮卡片已覆盖其中四项，需注意边界与合成效应）：整数时延（`c06`）、纯频移无时间伸缩（`c12`）、每径独立大速度（`c25`）、忽略分组前导（`c14`）、时延扩展硬截断在 6.375 ms（`c7-neon`）。
4. **检测端对连续几何误差的“零不确定度插件”假设**：信道估计把多普勒定在帧起点 $k=0$（而非帧中心 $k=(N-1)/2$！）做相位基准 $\exp(j2\pi k\nu/N)$；一处小的多普勒误差 $\delta\nu$ 造成的等效符号相位误差随 $k$ 线性增长，在时域帧尾的等效失配方差是帧首的数倍，在时域/单载波与变换域呈现截然不同的非平稳结构，而现有检测器以均匀标量 $\sigma^2$ 平摊。
5. **孤立单通道单帧假设**：忽略实际水声 modem 标配的 2–4 水听器空间孔径（跨阵元共享多径时延支撑与公共多普勒，仅阵元间相位独立）及半双工往返双向帧结构。

## 5. 自持开放问题清单（METHODS M1，供本轮灵感阅读持续对照）

1. **峰值功率/限幅约束下的波形反转与接收修复（L1+L2+L5，pit/adjacent）**：在换能器峰值功率受限（或固定限幅门限 CR）下，SP-AFDM 的限幅失真如何冲击第 0 轮稀疏捕获与编码 FER，相对天然低 PAPR 的 SP-SC-CP 是净亏还是可通过限幅感知接收追回？
2. **未知信道下 SP-AFDM 对 SP-SC-CP 的估计层公平对决（L2+L3，pit/adjacent，`l09` 子问题）**：完美信道下两者检测差距仅 0.1–0.2 dB；加入叠加导频与未知分数多普勒后，时域无 Dirichlet 泄漏的单载波信道估计对比 DAFT 域估计，端到端 1% FER 究竟谁占优？
3. **时间基准中心化与几何不确定度一阶边缘化（L2+L3，core/adjacent）**：把多普勒相位中心移至帧中点、或在检测器侧对多普勒估计不确定度做一阶切空间边缘化（秩-1 相位斜坡协方差更新，Woodbury $O(N)$），能否在不改导频的条件下吃掉低导频多普勒误差损失？
4. **单侧验证器（LDPC 校验子）驱动的极小假设集几何恢复（L3+L4，core/explore）**：能否用类似 RANSAC / 列表假设测试的思想，识别导致译码卡住的 1–2 个关键几何自由度（如离群径多普勒跳变或漏检径），以极少次数验证撬开非凸局部极小？
5. **主径 + 连续漫散射尾（非严格稀疏）水声信道下的模型阶数自适应与背景分离（L1+L3，pit/adjacent）**：当信道含占总能量 10%–25% 的连续指数散射尾时，固定参数化稀疏估计器的崩溃点在哪，如何把离散镜面径与连续协方差背景解耦？
6. **少阵元（2–4 水听器 SIMO）下的联合稀疏捕获与单阵元难题消解边界（L3+L5，adjacent/pit）**：量化 2–4 元水听器联合群稀疏（Group-sparse）第 0 轮捕获把导频门槛 $\rho^\star$ 压到多少，单通道低导频捕获难题在多阵元下还剩什么真瓶颈？
7. **低精度量化 / 非线性前端下的时延–多普勒超分辨与编码通信（explore）**：面向宽动态范围声呐/无线接收的 1-bit 至 3-bit 量化或折叠采样下，叠加导频/编码波形的可辨识性与最优接收结构。

## 6. 读完 `ABSTRACTION.md`（第二版）后的分歧与补充

1. **物理层参数核实更正**：`ABSTRACTION.md` §2 物理层写 `fs 8 kHz，N = 1024（约 128 ms）`，与阶段 A–A4 及参考帧实际运行配置（`fs = 16 kHz`，帧体 `64.0 ms`，$c_1 = 2.5/1024$，`S0_NOTES.md:37`）不符；涉及时间伸缩、相干时间与绝对时延毫秒数换算时均应以 `16 kHz / 64 ms` 为准。
2. **漏掉了发射端峰值功率/限幅这一决定波形选型的硬约束**：地图 §2 与 §5 第 3 条在问“为什么非要叠加导频 AFDM”时只谈平均信噪比和自由度开销，忽略了任意酉基保持高斯容量不变、而把单载波换成 AFDM 会把发射端峰均比抬高 6–8 dB；在峰值受限的水声换能器/功放上，功放回退或限幅失真会直接改写波形对比方向。
3. **双线性推断只看了一半边缘化**：地图 §2 推断结构聚焦“第 0 轮信道估计缺数据信息”，未指出对偶侧的不对称——检测器把连续多普勒点估计 $\hat{\nu}_p$ 当作零方差真值，且相位中心定在帧首 $k=0$ 而非帧中点，导致剩余多普勒误差产生的符号相位失配沿时间呈确定性斜坡增长。
4. **跨领域类比漏掉了“零成本单侧验证器”这一通信独有杠杆**：冷冻电镜、地震反演和射电天文都没有零成本的真解判别器，而编码接收机有奇偶校验子 $\mathbf{H}_{\text{code}}\hat{\mathbf{b}}=\mathbf{0}$；这使问题同构于带精确内点验证的 RANSAC 或列表译码，而非纯盲最小二乘。
5. **物理稀疏性前提漏掉了漫散射尾与无混叠折返墙**：地图 §2 只写了“真 $P=10$ 对槽位 8”和同延 Jakes 簇，漏掉了实测水声两点结构性冲突：① $12\text{–}32\text{ ms}$ 时延扩展越过 $N=1024$ 的 DAFT 一维无混叠界（已由 `c7-neon` 立卡）；② 镜面主径之外存在连续衰减的海底/体积漫散射尾（非严格有限径稀疏）。
