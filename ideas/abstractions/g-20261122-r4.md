## 1. 去代号还原（物理与数学到底在做什么）

1. **物理与算子层（什么叫 AFDM / 双色散信道）**：
   - 时域发射块 $\mathbf{s} \in \mathbb{C}^N$（带啁啾周期前缀 CPP，长 $L_{\mathrm{cpp}} \ge \ell_{\max}$）经线性时变（LTV）多径信道作用：
     $$\mathbf{y}_{\mathrm{time}} = \sum_{p=1}^P g_p \mathbf{\Delta}_{\nu_p} \mathbf{\Pi}_{\ell_p}^{\mathrm{cpp}} \mathbf{s} + \mathbf{w}_{\mathrm{time}}.$$
   - 所谓 `AFDM`，是选一组由啁啾参数 $(c_1, c_2)$ 决定的酉变换（离散仿射傅里叶变换 DAFT）$\mathbf{F}_{c_1,c_2} = \mathbf{\Lambda}_{c_2}\mathbf{F}_N\mathbf{\Lambda}_{c_1}$，把符号向量 $\mathbf{x}$ 映成 $\mathbf{s} = \mathbf{F}_{c_1,c_2}^H \mathbf{x}$，接收端再左乘 $\mathbf{F}_{c_1,c_2}$，得到等效观测：
     $$\mathbf{y} = \mathbf{H}(\boldsymbol{\tau}, \boldsymbol{\nu}, \mathbf{g})\mathbf{x} + \mathbf{w}, \qquad \mathbf{H} = \sum_{p=1}^P g_p \mathbf{T}(\tau_p, \nu_p).$$
   - 当 $(\tau_p, \nu_p) = (\ell_p, k_p)$ 落在整数格点时，$\mathbf{T}(\ell_p, k_p)$ 是移位步长为 $\delta_p = (2Nc_1 \ell_p + k_p) \bmod N$ 的单位模循环置换阵；当 $\nu_p$ 为连续实数时，能量按 Dirichlet 核 $D_N(\Delta\nu)$ 沿多普勒维泄漏；当 $\tau_p$ 为连续实数（配带限成形滤波器）时，能量按脉冲自相关核跨相邻整数时延抽头扩散，且同一物理径派生的相邻抽头共享同一个 $\nu_p$。
2. **叠加导频（什么叫 SP）**：
   - 双色散信道若用正交嵌入导频（EP），无混叠保护区需占 $(2k_{\max}+1)\ell_{\max}$ 个符号；当 $\ell_{\max} \approx 102$、$2k_{\max}+1 \ge 5\text{–}9$ 时保护区吃光整帧 $N=1024$。
   - `SP` 改为线性叠加 $\mathbf{x} = \mathbf{p} + \mathbf{d}$，其中已知导频 $\|\mathbf{p}\|^2 = \rho N$，未知编码数据符号 $\mathbb{E}\|\mathbf{d}\|^2 = (1-\rho)N$，$d_i \in \sqrt{1-\rho}\,\mathcal{X}$（如 QPSK），且底层比特满足稀疏奇偶校验约束 $\mathbf{H}_{\mathrm{ldpc}}\mathbf{b} = \mathbf{0} \pmod 2$。
3. **接收与推断（什么叫 F0 / CODELAY / P-BiG-AMP / Deep Unfolding）**：
   - 单帧观测的精确贝叶斯对象是耦合了**连续非凸几何 $\boldsymbol{\eta}=(\boldsymbol{\tau},\boldsymbol{\nu})$、条件高斯复增益 $\mathbf{g}$、以及离散编码格点 $\mathbf{b}\in\mathcal{C}$** 的三元联合后验：
     $$p(\mathbf{b}, \boldsymbol{\eta}, \mathbf{g} \mid \mathbf{y}) \propto \mathbb{I}(\mathbf{H}_{\mathrm{ldpc}}\mathbf{b}=\mathbf{0})\,p(\boldsymbol{\eta},\mathbf{g})\exp\!\left(-\frac{1}{\sigma^2}\big\|\mathbf{y} - \mathbf{A}_{\mathbf{p}+\mathbf{d}(\mathbf{b})}(\boldsymbol{\eta})\mathbf{g}\big\|^2\right).$$
   - 现有 `F0 + CSTATE(CODELAY)` 是分阶段坐标交替近似：第 0 轮把 $\mathbf{d}$ 当作零均值复高斯白干扰 $\mathcal{CN}(\mathbf{0}, (1-\rho)\mathbf{I})$ 做贪心 OMP + 局部连续多普勒精修；检测侧固定几何用 `P-BiG-AMP` / LMMSE-SIC 求软比特送 `(3,6)` LDPC 译码；若校验子非零，用译码软均值/方差做同延协方差正则的支撑交换（`CODELAY`）。
   - 现有 `ClassicalJointUnrolled` 是把整数网格 `OMP + PIC + DA-LS` 展开成可微计算图，但 `omp_sparse_torch` 中支撑选择 `argmax` 被截断梯度（detached），实际只学了标量步长与阻尼等外围旋钮。

## 2. 六层拆解与各层真正的稀缺瓶颈

| 层次 | 核心数学对象 | 真正稀缺/卡死的地方 | 现有做法付出的隐性代价 |
|---|---|---|---|
| **L1 物理与模拟硬件层** | 带限连续时延核、收发非线性（PA 压缩/相位噪声）、宽带多普勒伸缩 | 相干时间–带宽积与峰值功率预算（IBO/ACLR） | 用理想线性功放和整数采样掩盖了连续波形与硬件失真；一旦放开，传统手工参数模型失配崩塌 |
| **L2 算子与导频表示层** | 酉基 $\mathbf{F}_{c_1,c_2}$、导频 $\mathbf{p}$、连续流形字典 $\mathbf{T}(\tau,\nu)$ | 酉性守恒总能量：若只看二阶功率，单帧固定 $\rho$ 下导频信干噪比被数据功率 $(1-\rho)$ 锁死在 $\frac{\rho N |g_p|^2}{(1-\rho)\|\mathbf{g}\|^2 + \sigma^2}$ | 在单通道固定 $\rho$ 下单改导频序列相位无法突破数据自干扰底（除非越界混叠） |
| **L3 统计可辨识与信息预算层** | $I(\boldsymbol{\theta};\mathbf{y})$ vs $I(\boldsymbol{\theta};\mathbf{y}\mid\mathbf{d})$、非高斯离散星座 $\mathcal{X}^N$ 与码子空间 $\mathcal{C}$ | **信息论极限与第 0 轮高斯假设的巨大鸿沟**：未知信道的真实信息税仅 $\lesssim 0.8\text{ dB}$（`STAGEA4` 全知数据下界 `.015 bin`、高斯半盲 `.040 bin`），但把 $\mathbf{d}$ 当高斯白噪声丢掉了离散星座的模/相位刚性与局部校验结构 | 低导频 $\rho \le 0.12$ 时第 0 轮多普勒误差高达 $\sim 0.16\text{ bin}$、漏径近半，卡在动力学启动前 |
| **L4 迭代动力学与深度展开层** | 状态演化不动点、外信息正交化（Onsager 散度消去）、可微几何更新 | **第 0 轮自举悬崖 + 自证偏置（Self-Confirmation Bias）**：(1) 传统 `OMP` 硬截断梯度使深度展开摸不到占误差 80% 的几何捕获；(2) 带误差的软符号回灌信道重估时，未做散度消去（divergence-free / Onsager 校正），错误码字把信道“拉偏自锁” | 2026-07 审计发现旧展开“学习收益 $\approx 0$”，根因是旧网络只学固定整数网格上的标量阻尼，没碰连续几何与外信息去相关 |
| **L5 信道编码与接收环路匹配层** | 内环传递函数 $\phi_{\mathrm{inner}}(I_a; \rho, \mathrm{SNR})$ 与外码度分布 / 图结构 | 面积定理要求外码曲线贴合陡峭的信道重估内环斜坡，而标准 AWGN 好码是高起点平坦台阶 | 用 $(3,6)$ 规则码在起点 $I_0 < 0.577$ 时直接熄火，白白浪费内环曲线下充足的互信息面积，被迫把 $\rho$ 抬到 $0.25\text{–}0.30$ |
| **L6 系统总账与公平评测层** | 等总能量、等帧长（含一切前缀/标记）、等峰值功率、固定算力上限下的编码 FER | 局部指标（NMSE、真值处局部 CRB、碰撞后条件恢复率）与端到端净吞吐脱节 | 很多“改进”一算同总能量开销税或去掉真时延神谕就归零甚至倒亏 |

## 3. 所属抽象问题类与跨领域同构（谁在解同一个数学结构）

1. **双线性盲/半盲稀疏逆问题中的“边缘化 vs 点估计自锁”**：
   - *抽象形式*：观测 $\mathbf{y} = \mathcal{A}(\boldsymbol{\theta})(\mathbf{p} + \mathbf{d}) + \mathbf{w}$，其中弱先验变量 $\mathbf{d}$ 维数高（$N$ 维）、结构参数 $\boldsymbol{\theta}$ 维数极低（$3P \ll N$）。
   - *别的领域怎么解*：自然图像盲去模糊（Levin et al., *CVPR* 2009 / *TPAMI* 2011）严格证明联合极大后验 $(\hat{\boldsymbol{\theta}}, \hat{\mathbf{d}})_{\mathrm{MAP}}$ 因维数不对称必然塌缩到错误冲击解，唯一正道是**先对高维信号 $\mathbf{d}$ 做近似边缘化（Laplace / EP / 变分自由能）再估低维核 $\boldsymbol{\theta}$**；冷冻电镜（Cryo-EM `RELION`，Scheres 2012）在极低信噪比下绝不硬选单条姿态，而是对候选姿态网格做软概率加权边缘化直到中轮自然坍缩。
2. **非高斯离散先验下的精确状态演化与散度消去展开（OAMP / VAMP / Expectation Consistency）**：
   - *抽象形式*：在非酉或含参数估计误差的线性算子与非线性去噪器（离散星座 + 软校验 / 轻量神经去噪器）之间传递消息，如何阻止同一份噪声在“检测 $\to$ 信道重估 $\to$ 再检测”闭环里二次放大？
   - *别的领域怎么解*：统计物理 TAP 方程与 Vector AMP（Rangan, Schniter & Fletcher, *IEEE TIT* 2019）、双线性 GAMP / Bilinear VAMP、以及深度展开 OAMPNet2 / Lista-CPSS：通过显式雅可比迹（Onsager 散度项 $\mathrm{div}\,\eta$）保证每轮输入近似高斯且与历史误差正交，只需几十至几百个物理结构化参数即可在有限长下打穿传统交替最小化的假不动点。
3. **无网格连续谱估计的物理结构化神经展开（Deep-NOMP / SubspaceNet / Neural Hilbert-Schmidt）**：
   - *抽象形式*：连续参数族 $\{\mathbf{a}(\tau,\nu)\}$ 在未知脉冲滚降、功放非线性或低导频强干扰下，手工格点分裂与硬核绑定双双失效（如 `g15` 中硬绑核输给多抽头软增益 `-46.5 pp`）。
   - *别的领域怎么解*：计算成像与线谱估计中的展开牛顿流（Deep-NOMP / ADCG-Unfold）与协方差子空间网络（SubspaceNet，Shlezinger 组 *IEEE TSP* 2023–2025）：保留物理 Vandermonde/Chirp 算子骨架，仅用极轻量可解释模块学习残差核校正或软候选提议分布。
4. **辛几何 / Zak 相空间与编码调制联合设计**：
   - *抽象形式*：群表示下的时频/时延-多普勒局部化算子与纠错码图结构的耦合动力学（Polar 信道极化跨内环联合分裂、非均匀度分布/原型图 LDPC、多级编码 MLC 在叠加导频自举中的非对称信息解锁——注意须先过 `l03` 白送真值成本账！）。

## 4. 本项目哪些前提最可疑（及对应的切入准则）

1. **可疑前提 A（第 0 轮“只能把数据当高斯白噪声”假说）**：在 $\rho \le 0.12$ 下，单靠线性匹配滤波 $\mathbf{A}^H\mathbf{y}$ 的二阶信干噪比确实不够；但观测协方差子空间（半盲二阶矩 `STAGEA4` 已到 `.040 bin`）加上 QPSK 恒模非高斯似然与轻量可微展开前端，是否真不能在不加任何前导/开销的同总能量口径下正面击穿 `4.95 dB`（$\rho=0.25$ 扫描最优基线）？
2. **可疑前提 B（“深度展开在本项目注定零增益”的泛化外推）**：2026-07 审计证伪的是“冻结整数 OMP 支撑、只学 PIC/DA-LS 标量步长”的旧模型；当传统闭式算法因**非凸低导频盲捕获、信道重估误差自证相关性、连续时延未知成形核或发射功放非线性失真**而卡死时，物理算子驱动的深度展开恰恰拥有可微端到端梯度优势。
3. **可疑前提 C（“信道估计器只向检测器交一个点估计 $(\hat{\boldsymbol{\eta}},\hat{\mathbf{g}})$”的单点接口）**：低导频或近邻多普勒模糊下，第 0 轮后验在多普勒轴上是多峰的（Ziv–Zakai 离群尾正源于选错次峰）；保留极少数（如每条径 2–3 个主/次瓣候选）软边缘化包络或变分精度，计算量远小于多次全跑重搜，却可能直接切掉第 0 轮离群尾。
