# I-20261121-l12 出题者（gemini-4-neon）的第一性原理拆解（原样）

1. 物理层：水声信道是慢声速（$c\approx 1500\text{ m/s}$）、浅海多边界反射与海面波浪调制共同作用的双色散线性时变（LTV）介质，关键物理不变量是最大有效时延扩展 $\tau_{\max}$、多普勒扩展 $f_{d,\max}$、相干时间 $T_c$ 与扩展因子 $S_{\text{ch}}=2\tau_{\max}f_{d,\max}$；本项目用 8 条离散整数径 + 6.375 ms 硬截断 + 帧内恒增益来近似它。
2. 信号算子层：AFDM 用 chirp 参数 $c_1$ 做 1D 时延–多普勒剪切，将二维路径 $(\ell,\nu)$ 打包进长度 $N$ 的一维 DAFT 移位环 $\mathbb{Z}_N$（$\delta = 2Nc_1\ell + \nu \bmod N$）；该打包成立的前提是 Bemani 无混叠不等式 $(2(k_{\max}+\xi_\nu)+1)\ell_{\max}+2(k_{\max}+\xi_\nu)<N$ 且前缀 $L_{\text{CPP}}\ge \ell_{\max}$。
3. 推断结构层：叠加导频（SP）把导频与全部数据叠在同一帧里，第 0 轮面对未知数据干扰从字典中稀疏捕获支撑，译码后用软均值/方差重建期望 Gram（`CODELAY` 依赖“跨时延移位永不模 $N$ 折返”的 Prop 1(2) 来只修同延块）。
4. 算法与系统层：`F0`（515 列欠完备整数网格 OMP + 2 轮联合检测译码）+ 校验子门控的 `CSTATE`（2575 原子支撑交换），以 $N=1024$、1% FER 穿越点与单核耗时为目标。
5. 抽象问题类：在有限时频孔径 $N=BT$ 内，把双色散 LTV 算子无混叠地嵌入低维参数化坐标系；同类问题在脉冲多普勒雷达/声呐（距离–多普勒过扩展模糊与参差 PRF）、Gabor/Weyl-Heisenberg 欠扩展信道理论以及 Zak-OTFS 结晶条件（$\tau_p>\tau_{\max},\,\nu_p>2f_{d,\max},\,\tau_p\nu_p=1$）中被系统研究。
6. 现有可疑前提排查：剔除已立卡的整数时延（c06）、宽带时间伸缩（c12）、每径独立速度（c25）与前导（c14），每帧功率归一主要平移绝对 SNR 轴而按尺度不变性大体保留 `CODELAY` 对 `F0` 的水平 dB 差；与海试统计差距最大且结构性击穿 AFDM 算子层与论文结论的，是**时延扩展被人为压缩到 $\le 6.375\text{ ms}$（RMS 仅 $1.1\text{–}1.5\text{ ms}$）**。
7. 本文打的是**物理层 → 信号算子层 → 推断/算法层**的跨层断裂：实测浅海时延扩展直接越过 $N=1024$ 下的 AFDM 无混叠上限（$12.75\text{ ms}$），且试图增大 $N$ 又会触发 $N$ 无关的扩展因子下界与相干时间墙，使论文关于无混叠、Prop 1(2) 跨时延压制、低导频/高吞吐与低复杂度的多条核心结论站不住。
