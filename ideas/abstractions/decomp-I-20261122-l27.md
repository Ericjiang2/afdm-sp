# I-20261122-l27 出题者的第一性原理拆解（gemini-4-neon，未读 ABSTRACTION.md）

1. 物理与信号算子层：单帧 $N=1024$ 叠加导频 AFDM 将已知导频 $\mathbf{p}$（功率 $\rho$）与编码 QPSK 数据 $\mathbf{d}$（功率 $1-\rho$）叠加于 DAFT 域，经 $P=8$ 条整数时延 $\ell_p\in[0,102]$、连续多普勒 $\nu_p\in[-2,2]$、复增益 $g_p$ 的时变算子 $\mathbf{T}=\sum_p g_p\operatorname{diag}(\mathbf{c}_p(\nu_p))\mathbf{P}_{\ell_p}$ 作用，观测 $\mathbf{y}=\mathbf{F}\mathbf{T}\mathbf{F}^H(\mathbf{p}+\mathbf{d})+\mathbf{w}$。
2. 推断结构与稀缺量：未知数为 $3P=24$ 个稀疏信道几何/增益参数与 $N=1024$ 个满足双重离散约束的符号 $\mathbf{d}\in\mathcal{A}_{\text{QPSK}}^N\cap\mathcal{C}_{\text{LDPC}}$；当 $\rho=0.10$、$\text{SNR}=4\text{ dB}$ 时，单采样导频信干噪比仅 $-11.1\text{ dB}$，纯导频多普勒 CRB 卡在 $0.074\text{–}0.085\text{ bin}$（远差于 A3 容忍线 $0.040\text{ bin}$），且弱径漏捕严重。
3. 抽象问题类：带连续非线性谱参数、未知稀疏支撑与离散/码字先验的高维双线性逆问题（Parametric Bilinear Sparse Inference with Discrete Alphabet & Parity-Check Priors），与射电自校准、盲反卷积、低温电镜“模型偏置（Einstein-from-noise）”及神经展开双线性消息传递（OAMP-Net / JCDDNet / BiG-AMP）同构。
4. 现有路线的结构缺口：正在做的二阶高斯半盲（`STAGEA4`）把 $\mathbf{d}$ 视为圆对称高斯噪声（切向相位信息 $\eta_\phi\equiv 0$），在 $\rho=.10$ 仅勉强贴线 $0.040\text{ bin}$ 且零余量；而现行接收机把第 0 轮信道估计与离散星座/LDPC 割裂，且在软符号反馈的 EM/VarPro 步（`time_refine`）中将同一矩阵 $\mathbf{Q}=\mathbf{B}^H\mathbf{B}+\boldsymbol{\Gamma}(\mathbf{v})$ 混用于支撑发现、多普勒寻优与增益更新，触发“$\beta=1$ 增益系统性收缩（$|g|\approx 0.12\to 0.84$）vs $\beta=0$ Stein 噪声回声爆炸（$|g|\approx 1.60\text{–}1.85$）”的双重陷阱。
5. 可疑前提与攻破层：现行接收机假定“译码失败前无法用未知数据做连续多普勒与支撑重估”以及“标量 P-BiG-AMP 足以替代精确带状时域 LMMSE”。本卡直接打**第 0 轮双线性推断与参数化 M-step 接口层**：跨领域迁移非线性去噪器的 Stein 散度校准、免矩阵带状时域 CG-VAMP 与轻量物理驱动深度展开（仅 $\sim 40\text{–}64$ 个可解释层参数），不改发射端波形、码图与总能量，在 $\rho\le 0.12$ 下直接释放离散 QPSK 相比高斯先验 $3.0\times$ 的信道 Fisher 信息。
