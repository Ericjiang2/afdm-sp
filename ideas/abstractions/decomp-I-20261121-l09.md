# I-20261121-l09 出题者（gemini-4-neon）的第一性原理拆解（原样）

1. 去代号：AFDM 是酉预编码矩阵 $\mathbf{A}=\mathbf{\Lambda}_{c_2}\mathbf{F}\mathbf{\Lambda}_{c_1}$ 加单段长前缀（CPP，$L=102$）；SP 是线性叠加已知导频 $\mathbf{x}=\sqrt{1-\rho}\mathbf{U}^H\mathbf{d}+\sqrt{\rho}\mathbf{p}_{\text{time}}$；Turbo/CSTATE 是单帧（$N=1024$，$64\text{ ms}$）上的双线性迭代“时变信道估—软均衡—LDPC 译码”。
2. 六层拆解：物理层（水声慢声速→大时延 $6.375\text{ ms}$、宽带伸缩与海面同延多普勒展宽）→ 信号算子层（同一时域 LTV 矩阵 $\mathbf{H}=\sum_{p=1}^P g_p\mathbf{\Delta}_{\nu_p}\mathbf{\Pi}^{l_p}$ 经不同酉基 $\mathbf{U}\in\{\mathbf{I},\mathbf{F},\mathbf{U}_{\text{OTFS}},\mathbf{A}\}$ 共轭，加不同分段前缀数 $K$）→ 推断层（第 0 轮导频捕获 + 软数据辅助重估）→ 算法层（Turbo-LMMSE/TF/DFE 均衡矩阵稀疏性与复杂度）→ 系统目标层（固定净频谱效率 $\eta_{\text{net}}$、总发射均功与峰值功放回退 PAPR 下的 1% FER）→ 评测层（现文献普遍缺公平基线）。
3. 抽象问题类：固定线性时变算子 $\mathbf{H}$、共享同一外部纠错码与总开销下，**发射酉基 $\mathbf{U}$ 与帧分段 $(K,L)$ 对“盲/叠加导频捕获 + 迭代 Turbo 均衡”究竟能提供多少真实增益**；无线界（Gaudio–Caire TWC'22）曾对 RF 嵌入导频 OTFS/OFDM 拆解过一次，但从未覆盖叠加导频、AFDM 与水声单载波 Turbo 均衡。
4. 可疑前提：本项目及大多数 AFDM/OTFS 论文默认“双色散分集 + 低导频开销”是 DAFT/DD 波形独有优势；但只要把同样的时域 ZC/chirp 叠加导频、单段 CP 与 LTV Turbo 均衡器配给单载波（SP-SC-CP），酉等价性意味着第 0 轮数据干扰协方差、Gaussian 容量、前缀开销甚至无同延多径时的匹配滤波界（MFB）全部与 SP-AFDM 一致。
5. 本题攻击层：信号算子层 × 系统目标层（用精确对角色散恒等式把 SP-AFDM 相对三类水声主流基线的差距拆成“前缀/导频开销项”与“同延时间衰落色散项 $\mathcal{V}_{\text{time}}(\mathbf{H})$”，并用实测 Watermark 信道与 P1/簇信道定出谁赢、赢多少、何时输）。
