# runner c 第一性原理拆解（2026-11-22，开轮前、未读 ABSTRACTION.md）

## 1. 去掉代号
- AFDM：发射端对 N 个数据符号做离散仿射傅里叶逆变换（chirp 调制的 DFT），使双色散信道（时延 × 多普勒）在 DAFT 域变成"每条径一个可分离的平移块"；本质是给每条径一个不同的二维循环移位，路径在 DAFT 域互不重叠的条件 = c1 选得让 (时延, 多普勒) 映射到不同的一维位置。
- SP（叠加导频）：导频不占独立资源，以功率比 ρ 直接加在数据上。代价：数据功率 1−ρ、数据对导频估计是"自干扰"（未知随机载荷）。
- F0 / CSTATE / CODELAY：编码 turbo 接收机——第 0 轮只用导频（数据当噪声）估信道支撑与增益 → 检测器（LMMSE/软干扰消除）→ LDPC 译码 → 用软符号当"扩展导频"重估信道 → 迭代。CODELAY = 同延簇的协方差接口。
- 第 0 轮 = 一个稀疏双参数（时延、连续多普勒）线谱估计问题，观测被未知数据（功率 1−ρ 的 i.i.d. 星座）污染。

## 2. 分层与稀缺量
| 层 | 在做什么 | 稀缺/限制 |
|---|---|---|
| 物理 | 多径传播、平台/介质运动 → 每径时延 τ_p 与多普勒 ν_p（宽带时还有伸缩） | 径数、径间间隔、多普勒扩展相对 1/T 的比 |
| 信号模型 | y = Σ_p h_p Δ_{ν_p} Π_{τ_p} (x_d + x_p) + w | 分数多普勒产生泄漏；整数时延是简化 |
| 推断结构 | 未知：{τ,ν,h}（连续，少量）+ 数据（离散，大量）；双线性耦合 | 冷启动只有 ρ·E 的导频能量；数据自干扰比 (1−ρ)/ρ 决定第 0 轮 SINR |
| 算法 | 导频匹配/OMP → 检测 → 译码 → 重估；失败后重搜 | 第 0 轮离群（漏径、假径、多普勒跳格）决定 turbo 能否起飞；起飞后固定点近真信道 |
| 系统目标 | 同总能量与时长下最低 FER / 最高吞吐 | 导频能量税 ρ、算力/时延 |
| 评估 | FER vs SNR、穿越点 dB | 瀑布陡，0.2 dB 级效应即 10 pp FER |

## 3. 抽象问题类
- 冷启动的"半盲双线性反问题"：盲反卷积 / 相位恢复 / 字典学习 / 自校准（Ling–Strohmer）同类；关键量是"已知锚点能量 vs 未知部分的维度"。
- 第 0 轮是门限区的谱估计：频率估计的阈值效应（Rife–Boorstyn、Ziv–Zakai），离群主导。
- turbo 起飞 = EXIT/密度演化的隧道是否打开；固定点分析。
- 别的领域：GNSS 弱信号捕获（相干/非相干积分、数据位翻转）、深空通信的 code-aided 同步（Noels、Herzet）、MIMO 半盲信道估计、雷达稀疏重构（但雷达本身禁做）、天文的干涉成像（自校准 selfcal：先粗模型→校准增益→再成像，迭代——与 turbo 重估同构）、地震学的周跳（cycle skipping）。

## 4. 可疑前提
- 整数时延 + 独立每径多普勒（已被 c06/c25 质疑）。
- 数据被当高斯噪声（第 0 轮）：实际是有限星座，有结构（QPSK 的四次方去调制、恒模）——第 0 轮完全没用这个结构。
- 每帧独立冷启动：实际链路有帧间连续性（但"上一帧"已被判为常识，规则 9）。
- FER 指标在瀑布陡区放大小效应。
