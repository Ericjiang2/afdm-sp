# I-20261122-l36 出题者的第一性原理拆解（gemini-4-neon，未读 ABSTRACTION.md）

1. 物理与数学层：SP-AFDM 单帧接收信号为双线性模型 $\mathbf{y} = \mathbf{H}(\boldsymbol{\ell},\boldsymbol{\nu},\mathbf{g})(\mathbf{x}_p+\mathbf{d})+\mathbf{w}$，总功率固定为 $1$（导频占 $\rho$、数据占 $1-\rho$）。第 0 轮译码前 $\mathbf{d}$ 未知，所有信道估计与检测都在同一观测里解耦 $(\boldsymbol{\ell},\boldsymbol{\nu},\mathbf{g})$ 与 $\mathbf{d}$。
2. 现有接收机分层：L1 导频前端找粗支撑 → L2 `time_refine` 在固定软矩 $(\boldsymbol{\mu},\mathbf{v})$ 下用岭正则化 $(\mathbf{B}^H\mathbf{B}+\boldsymbol{\Gamma}(\mathbf{v})+\sigma^2\mathbf{I})\mathbf{h}=\mathbf{B}^H\mathbf{y}$ 做多普勒坐标搜索与增益拟合 → L3 `scalar_joint`（标量 P-BiG-AMP）在固定 $(\boldsymbol{\ell},\boldsymbol{\nu})$ 下做 20 轮数据与增益联合迭代（`gain_mode='joint'`，先验 $\mathcal{CN}(\mathbf{0},\mathbf{I}/P)$）→ L4 LDPC 译码与第 1 轮数据辅助重估 → L5 校验子门控 `CODELAY` 支撑交换。
3. 抽象问题类：带噪声干扰的双线性推断（bilinear inference / semi-blind JCD）里的「组件消融混淆」——当下游模块（L3）自带参数重估（`gain_mode='joint'`）时，上游（L2）的注入只充当非凸/迭代不动点的初值 $\mathbf{h}^{(0)}$，而非持久生效的估计量。
4. 跨领域对应：在 Parker–Schniter P-BiG-AMP 及联合估检文献中，双线性消息传递只要导频锚足够强（破除全局相位旋转不变性），就会忘记初值并收敛到自身的联合不动点；一旦导频低于相位锁定阈值，则发生相位漂移崩塌。
5. 可疑前提与定位：Stage A2/A3/A4 试图测「第 0 轮时延、多普勒、增益各自值多少 dB」以指导下一阶段估计器立项，但未检验 L2 实际输出的究竟是无偏导频 LS 还是强收缩岭解，也未隔离 L3 `gain_mode='joint'` 对第 0 轮增益的重写，导致把「L3 双线性检测器在 $\rho\ge 0.10$ 对初值 $\mathbf{h}^{(0)}$ 不敏感」误归因为「第 0 轮增益精度几乎不值钱（H）」。
