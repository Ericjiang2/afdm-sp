> 说明：本文件按 16:00 更新后的协议补写。我在 15:32 已读过 ABSTRACTION.md 的第一版（当时协议要求先读它），所以这份拆解不算完全独立；下面第 6 节列出我与地图不一致的地方，其中三条有本轮 L2 的实测。

## 1. 去掉代号
- AFDM：把 QAM 符号用一组 chirp 基做酉变换后发出去。时域看，每条径做的事是"平移 + 乘一个线性相位"；chirp 域看，每条径把符号搬到 ν + 2N·c1·l 的位置，分数多普勒按 Dirichlet 核泄漏。
- 第 0 轮估计与波形无关：数据符号独立同分布时，任何酉变换后的时域数据都是白的，导频看到的干扰只有功率 (1 − ρ)。波形只在两处起作用：检测（均衡的结构），以及译码符号的不确定度怎样折算成信道估计的噪声。
- 叠加导频：已知波形加在未知波形上。导频对白色数据干扰有 N 倍处理增益；ρ 扣的是数据的信噪比，不占自由度。
- 接收机：一个可分离的非线性最小二乘。非线性参数是每条径的时延和多普勒，线性参数是增益，另有一个离散未知量（码字）。第 0 轮只用导频解非线性部分；之后把译码结果当作更多的已知波形重解。

## 2. 分层，每层缺什么
| 层 | 稀缺或受限的东西 |
|---|---|
| 物理 | 连续时延、时间伸缩、平台加速、径的生灭；仿真只取了其中很窄的一块 |
| 信号模型 | 未知参数很少（8 条径 × 时延、多普勒、复增益），观测有 1024 个复数：信息上，信道知识很便宜 |
| 推断结构 | 贵的不是信息，是起步：时延–多普勒上非凸，要先落进对的吸引域；码字未知时是半盲问题 |
| 算法 | 环路由两个"门槛器件"串成：非线性估计器有捕获范围，门槛型码有瀑布区。两个门槛都要在第 0 轮同时过 |
| 系统目标 | 固定净速率下的可靠性；允许重发、跨帧记忆、换码时，目标函数本身会变 |
| 评价 | 单帧 1% 误帧率；对比基线只有同一接收机的变体，没有别的波形或别的码 |

## 3. 抽象问题类
在一个可分离非线性模型上，给"估计器 + 译码器"这个由两个门槛器件组成的环路找起步条件。可以从三边动：抬高起点（更准的第 0 轮，本项目一直在做）；放宽估计器的捕获范围（由粗到细、多假设）；改码的门槛形状（让码能利用内环曲线的斜率，本轮卡 l02）。

## 4. 别的领域谁在解同类问题
- turbo 均衡、BICM-ID 的码设计：外码按内环 EXIT 曲线拟合，不按白噪声门槛选。
- 变量投影（Golub–Pereyra 的可分离最小二乘）：线性参数每步重解，只有非线性参数的初值算数。
- 射电天文 CLEAN、雷达逐目标扣除：贪婪地扣掉强源连同它的旁瓣，弱源才露出来（本项目 F0 前端就是这个结构）。
- GNSS 捕获与跟踪、码辅助同步：捕获范围与牵引。
- 相位恢复的谱初始化：先用二阶统计给一个落在吸引域里的初值，再迭代。
- 增量冗余 HARQ：门槛过不去时补冗余，而不是把每一帧都设计成一次必过。

## 5. 我认为可疑的前提
- 码是给定的（(3,6) 规则 LDPC，n = 2048）。整个"起步"问题的门槛 I* = .577 是这个码的性质。
- 每帧独立冷启动，没有重发。
- 整数时延、窄带多普勒、已知路径数上限。
- "为什么是 AFDM"：第 0 轮与波形无关，AFDM 的作用只能在检测那一步找。

## 6. 与 ABSTRACTION.md（第一版）不一致的地方
1. 地图 §2 写"可辨识性随 ρ 下降而变差（ρ = .05 检测器相位锁不住）"。实测不是可辨识性：检测器增益固定后 ρ = .05 在 ≥ 4 dB 零失败，而且比 ρ = .10 好（`ideas/l2/out/summary.json` c02）。失稳来自检测器对增益用平先验。开放问题 5"用极少导频或码结构打破相位歧义"因此不成立为独立问题。
2. 地图 §2 评价层写"NMSE 与误帧率的排序可能相反（卡 08）"。实测：只在检测器重解增益时成立；增益固定时，同样 NMSE 的增益误差与多普勒误差伤害相近（c08）。这是变量投影的性质，不是译码的性质。
3. 地图 §3 把"低模糊区序列设计（卡 10）"列为可借的东西。实测：换成图钉形模糊函数的随机相位导频，整条管线反而变差；单冲激导频与 ZC 相同（c10）。真实前端逐径扣除，导频模糊函数不是瓶颈。
4. 地图把"编码理论的门限"放在最后，只当作描述第 0 轮的语言。我认为它应该排在前面：码是设计变量，实测的内环曲线在 K = 224 时起点 .375、面积 .586，码率 .5（卡 l02）。
5. 地图的开放问题大多在"抬高起点"这一边。三边里另外两边（放宽捕获范围、改码形）以及"改变系统目标"（重发、跨帧）覆盖得少。
