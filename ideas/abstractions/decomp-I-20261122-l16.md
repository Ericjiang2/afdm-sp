# I-20261122-l16 出题者（gemini-4-carbon）的第一性原理拆解（原样）

1. 剥去代号后，本项目系统分五层：(L1) 换能器与水声物理波导 → (L2) 含前缀的离散线性时变多径算子 H(l, ν, g) → (L3) 未知信道参数与未知编码载荷相乘的半盲双线性逆问题 y = H(√ρ p + √(1−ρ) d) + w → (L4) 两阶段算法（固定首轮时延支撑的外迭代 F0，对校验子触发的离散支撑交换 CSTATE/CODELAY）→ (L5) 链路编码速率与 1% 误帧率（FER）交点评估。
2. 各层稀缺量：L2 受限于离散网格与有限支撑槽位；L3 第 0 轮受限于未知载荷自干扰 (1−ρ)+σ² 对导频信干噪比的封顶；L4 受限于固定支撑未建模残差对检测信干噪比的硬上限；L5 受限于外码译码门限 s₀(R) 与校验节点度 d_c 决定的软反馈启动斜率。
3. 抽象问题类别：带奇偶校验验证器的双线性半盲逆问题，与冷冻电镜未知姿态三维重构、射电天文不完整天空模型自校准及自适应重传链路速率控制同构。
4. 可疑前提：除已检的整数时延、窄带频移、独立速度、无前导外，全库仿真与现稿把外码钉死在单一码率 R = 1/2（QPSK, d_v=3, d_c=6），默认最优导频比 ρ* 与“继续迭代还是重搜”对码率不敏感；别的领域（自适应水声 OFDM、卫星 ACM）通过随信噪比切换码率（1/4 至 3/4）运行，且根据译码门限同步重配导频开销。
5. 本题攻打 L5 与 L3/L4 的耦合边界：翻转“码率固定为 1/2”这一未检前提，推导漏径信干比奇点 ε_crit(R, ρ) 与未编码导频噪底/高阶校验启动墙的双侧挤压，直接检验现稿三条核心结论在 R ∈ [1/4, 3/4] 上是否翻转及变幅。
