# I-20261122-l31 出题者的第一性原理拆解（gemini-4-carbon，未读 ABSTRACTION.md）

1. 物理层：水声、低轨卫星（NTN）与高频无线信道同时施加两类乘性畸变——多径时延与路径多普勒扩展（慢变几何），以及本振失锁、介质瞬变或锁相环周跳引发的「平时平稳、偶尔剧烈跳变」突发相位噪声；稀缺资源是相干时间–带宽积与总发射能量。
2. 信号与算子层：`AFDM`（双啁啾酉变换 $\mathbf{A}=\boldsymbol{\Lambda}_{c_2}\mathbf{F}\boldsymbol{\Lambda}_{c_1}$）、`OFDM` 与 `Zak-OTFS` 用恒模酉基把时变多径对角化或稀疏化，代价是把时域局部突发相位跳变 $\mathrm{diag}(e^{j\boldsymbol{\phi}})$ 变成变换域全体符号共享的相干衰减加稠密跨载波干扰（ICI）；`SP`（叠加导频）免去保护带，但令未知载荷对时域相位探针形成 $0\text{ dB}$ 自干扰。
3. 推断结构层：本质是「离散码字约束 + 混合跳变隐状态（平稳态 $G$ / 突发态 $B$）× 圆周连续相位 $\mathbb{S}^1$」的双域双线性逆问题；难点在于未知载荷压低单样点导频信干噪比，使平滑滤波与跳变定位陷入测不准死锁，且硬相位投影在突发段内把 ICI 能量翻倍。
4. 算法与调度层：项目现行管线（`pilot_front` $\to$ `F0` $\to$ `CSTATE`）默认一帧内每径相位斜率恒定，低秩基展开（BEM）面对阶跃型周跳有 $1/k$ 吉布斯尾巴，而差分编码直接牺牲全部平稳段的信噪比。
5. 系统目标与可疑前提：真实口径是固定总能量、净码率与帧长下的误帧率（PER/FER）穿越点；「靠差分编码防周跳」和「一帧内无相位瞬变/周跳」都是可被双域切换推断替代的可疑前提。
