# I-20261122-l37 出题者的第一性原理拆解（gemini-4-neon，未读 ABSTRACTION.md）

1. 物理与数学实质：单帧叠加导频 AFDM（`N = 1024`）把时延–多普勒信道辨识与编码数据检测耦合在同一 1024 维向量观测上，第 0 轮仅靠能量占比 `ρ` 的导频把其余 `1-ρ` 编码数据当未知方差噪声，第 1 轮再用 LDPC 译码后的软均值 `μ` 与软方差 `v` 重构几乎无干扰的数据辅助观测。
2. 层次拆分：L1 支撑获取（时延集合 `l` 与整数多普勒粗搜）→ L2 连续变量投影精修（固定 `l` 上最小化关于分数多普勒 `ν` 的非线性目标，线性消去增益 `h`）→ L3 联合软检测与增益重估（`scalar_joint`）→ L4 LDPC 译码与外轮反馈。
3. 抽象问题与跨领域对应：L2 是带周期 Dirichlet 核旁瓣（主瓣半宽 1 bin、第一旁瓣在 ±1.43 bin）的可分离非线性最小二乘（Variable Projection, VarPro）多正弦频率估计，在雷达/阵列/编码辅助同步中已知存在经典的“门限效应 / 旁瓣离群陷阱”（Rife–Boorstyn threshold outliers）：一旦初值落出主瓣，任何局部单峰优化都会被旁瓣极小值锁死。
4. 可疑前提定位：L1→L2 的第 0 轮到第 1 轮接口存在未检验常数——`arms.refine_fixed_delays` 与 `twofft.time_refine` 在第 1 轮把搜索区间硬锁在 `[r0_nu - 0.75, r0_nu + 0.75]` 且仅对 `missing` 槽位执行 `COARSE_GRID` 粗扫；而第 0 轮已填满全部 8 个真时延槽，导致第 1 轮永远跳过粗扫。
5. 本卡打击位置：只打 `pit`（论文边界与归因修正），不造新算法——检验 `res-20261016-03` 把 `GS-set` 在 `ρ = .3` 下 `4.5–5.3 dB` 残差归因于“低导频功率与正则化增益下的 refit 误差”是否实为 Round-1 局部锁死窗口 `±0.75` 的实现产物，并同时核查它是否影响盲接收机 FER 与 E-1 结论。
