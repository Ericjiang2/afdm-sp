## 1. 去掉代号
- AFDM：把 N 个符号骑在 N 条正交线性调频上发（时域 = 调频 × IDFT，包络与 OFDM 同为近高斯）。一条（时延 ℓ，多普勒 ν）的径在调频序号域是一次循环移位 `loc = (ν + Kℓ) mod N`（K = 2N·c1）外加一条随序号 q 走的相位斜坡 `exp(-j2π qℓ/N)`。**位置只给出 ν + Kℓ 这一个数，ℓ 本身藏在斜坡里**。
- 叠加导频（SP）：已知序列按功率份额 ρ 压在数据上，不占自由度，付功率税并与数据互扰。嵌入导频（EP）：一个冲激加保护带，付自由度，观测干净；保护带长 ≈ K·ℓ_max + 2k_max，全分集取 K = 2k_max + 1 时 ≈ 时延–多普勒支撑面积 L·V。
- 接收环路：导频找径（支撑、多普勒、增益）→ 带软不确定度的检测 → LDPC → 判决回送重估。它是一个双线性推断：未知信道参数 × 未知码字。

## 2. 分层与各层稀缺量（松绑后）
| 层 | 松开前提后新出现的稀缺或限制 |
|---|---|
| 物理 | 连续时延（脉冲成形把一条径摊到多个抽头，摊法由已知脉冲决定）；同一时延上的多普勒簇（每抽头约 2ν_max·T + 1 个复自由度，而不是 1 个）；径数未知；回波可长过前缀；功放只认峰值不认均值。 |
| 信号模型 | 一维折叠：支撑面积 L·V 接近或超过 N 时（水声 L≈200、V≈5），不同 (ℓ, ν) 落到同一 loc；分数时延在序号域是间隔 K 的梳状泄漏；超前缀回波 = 上一块尾巴 + 本块循环性缺失（秩 ≤ 超出长度的修正项）；削峰 = 时域逐样点非线性，在序号域是稠密的、由数据决定的失真。 |
| 推断结构 | 稀疏（少数径）与稠密（每抽头一个带限随机过程）两种先验并存且事先不知是哪种；位置歧义是离散的（每条径至多 2k_max + 1 个候选时延），不是连续的；失真与跨块干扰都是「译出数据后即已知」的确定函数。 |
| 算法 | 导频第 0 轮只需把环路送过自举门槛，其后由码接管；任何「数据译出即已知」的量（跨块干扰、削峰失真、位置歧义的正确假设）都可以让码来付，不必让导频或保护带付。 |
| 系统目标 | 同净频效、同峰值功率（而不是同平均功率）下每焦耳每秒交付的比特；保护带、前缀、导频功率、回退量是同一本账上的四项开销。 |
| 评价 | 编码后误帧率穿越点与净吞吐；未编码分集阶数在有码时不是目标量（最优接收下互信息对酉预编码不变）。 |

## 3. 抽象问题类与同类领域
- **欠采样 + 离散歧义消解**：一维折叠 = 用一条斜线对二维稀疏支撑做哈希。同类：FMCW 雷达的距离–多普勒耦合（上下扫频消歧）、多重 PRF 解模糊、稀疏 FFT 的分桶 + 相位编码定位、互素采样。它们都用「第二次不同斜率的观测」消歧；通信里多出一样雷达没有的东西——**一个带校验的码字**，可以充当第二次观测。
- **双线性 / 多层广义线性推断**：削峰信道 = 线性混合 → 逐点非线性 → 线性信道（多层 GLM，ML-VAMP 一类）；跨块无前缀流 = 由信道记忆耦合的码字链（空间耦合 / 滑窗译码一类）。
- **模型阶数未知的收缩估计**：离散径对簇 = 线谱对连续谱；同类：阵列里的点源对分布源、谱估计里的线谱加有色噪声。
- **开销的统一记账**：Hassibi–Hochwald 式训练分配，推广到「导频功率 / 保护带 / 前缀 / 功放回退」四种货币。

## 4. 我认为可疑、值得打的前提（第 7 轮候选靶）
1. 「c1 必须取全分集值」是未编码准则。有码时分集由码收割，c1 的真实代价是保护带长度与检测带宽（都 ∝ K）；降 K 留下的是**每径有限个候选时延的离散歧义**，可由第二个弱导频或码字本身消掉。（靶区 ④ + ②，通道 B/A）
2. 「回波必须落在前缀内」把最长回波的代价固定成前缀开销。水声里 L/N≈20%，前缀税约 1 dB；跨块干扰在上一块译出后是已知量。问题在于这是否只是 OFDM 无前缀对消的硬套。（靶区 ④）
3. 「功放线性、比较按平均功率」。峰值受限下导频与数据在时域叠加的方式决定回退量；已知 l14 的读数是 AFDM 比单载波多亏 1.29 dB。可疑点：这 1.29 dB 是波形固有的，还是接收机没有利用「削峰失真是数据的确定函数」。（靶区 ③）
4. 「信道 = 少数离散径」对「每抽头一个带限过程」：现有两类估计器各在对方的信道上崩（参数化 .873；宽基在离散径上亏 0.87–1.07 dB）。可疑点：两者之间有没有一个由导频信噪比决定的闭式切换边界，使「先窄后宽」不必靠试。（靶区 ①）
5. 评价口径：「全分集」「保护带内零干扰」是未编码、第 0 轮的性质；编码迭代接收下它们各值多少 dB，文献大多没有算。
