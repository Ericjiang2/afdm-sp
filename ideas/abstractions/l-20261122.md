## 1. 去掉代号后，这个项目在做什么
- 物理：水里声速只有约 1500 m/s，收发相对运动 1 m/s 就是 7×10⁻⁴ 的时间伸缩（无线电是 10⁻⁸ 量级）；声波经海面、海底多次反射，到达时间相差几毫秒到几十毫秒；每条反射路径的入射角不同，所以各有各的伸缩；海面在动，每条路径自身还在随机起伏。可用带宽只有几 kHz（吸收随频率升得快），带宽与载频同量级。
- 信号：发的是一组线性调频（chirp）基上的符号（"AFDM"），好处是每条"时延 + 频移"路径把一个符号搬到变换域里一个互不重叠的位置，信道矩阵是几条平移的对角线。导频不单独占位置，而是和数据叠在同一批位置上发（"叠加导频"），占总功率的 ρ。
- 推断：收到 y = H(θ)(p + d) + w。未知的是路径参数 θ（8 条径 × 时延、频移、复增益，约 32 个实数）和数据 d（受码约束）；已知的是导频 p、码本、信道的稀疏结构。H 和 d 相乘，是双线性问题。
- 算法：第 0 轮只靠导频在网格字典上找径（此时数据是干扰）；之后"检测 → 译码 → 用软符号当加长的导频重估信道（`CODELAY` 是把软符号不确定度引起的有色噪声按同时延结构算进去）→ 增删路径（交换）"循环；译码失败后要么继续迭代，要么重搜。
- 目标与评价：每焦耳、每赫兹、每秒送到的正确比特。论文里用"误帧率到 1% 所需信噪比"（穿越点）和导频比例来代表；评价在自建仿真器里做（整数时延、每径独立频移、窄带、已知噪声方差、径数恰为名额数）。

## 2. 每层真正稀缺的是什么
| 层 | 稀缺的东西 | 说明 |
|---|---|---|
| 物理 | 相干时间 × 带宽里的自由度；模型真不真 | 稀疏镜面径模型下 32 个未知数对 2048 个实观测，严重超定；若每条径其实是一小片漫散射，超定就没有了 |
| 信号 | 可分性与分辨率 | 时延分辨率 1/B、频移分辨率 1/T；chirp 斜率把时延和频移耦合成一个位置，无混叠只装得下约 112 个抽头（l12） |
| 推断 | 进入吸引域所需的起步信息 | 码本身已让信道几乎可辨识（见下条）；导频的作用是让迭代算法起得来，起来之后是码在出力 |
| 算法 | 每帧算力与时间；自我诊断是否可靠 | 继续迭代还是重搜（现稿主线） |
| 系统 | 峰值功率、带宽、时间（往返几秒，重传很贵） | 误帧率之外还有峰均比、算力、时延 |
| 评价 | 仿真前提与真实海洋的距离 | 已有 L3 的 5 张前提卡都在这一层 |

## 3. 我认为最根本的一个量：统计下限与算法门槛之间的缺口
- 统计上：码率 1/2、码本已知时，不发导频信道也几乎可辨识，只剩码的对称性带来的歧义。(3,6) 规则码每个校验的度数是偶数，全 1 是码字，QPSK 转 180° 把码字映成码字，所以至少有相位歧义；消掉它只需要极少的导频能量。
- 算法上：现在的接收机在 ρ < .25 就崩（res-20261119-06），需要的导频比"消歧义"多出一到两个数量级。这段差距不是信息不够，是迭代算法进不了吸引域。它是"统计–计算缺口"类问题，本项目所有 core 卡（起步门槛 .577、第 0 轮多普勒 .04 bin、低导频漏径）都在这道缺口里，只是各看一个截面。
- 由此得到的出题判据：一个 core idea 要么缩小缺口（换起步方式、换码、换导频的放法），要么证明缺口的某一截面是下限。只在缺口内部调接收机参数的题是上一轮的"自造问题"。

## 4. 抽象问题类与别的领域
| 抽象问题 | 同类领域 | 它们的做法（可借的） |
|---|---|---|
| 双线性反问题（未知算子 × 受约束的未知信号） | 射电天文自校准（selfcal）、MRI 免校准并行成像、冷冻电镜、盲反卷积、多参考对齐 | selfcal 早就知道"交替估计会造出鬼源"；冷冻电镜用边缘化而不是点估计；MRA 给出低信噪比下样本复杂度随 1/SNR³ 增长的下限 |
| 迭代译码的门槛 | 空间耦合码（门槛饱和）、成核与相变 | 一小段已知种子让译码波从一端推进，把 BP 门槛推到 MAP 门槛；导频可以看成种子，问题变成"种子放哪、放多少" |
| 有色、与信号相关的干扰里做稀疏参数估计 | 雷达恒虚警、引力波全局拟合（重叠源）、核磁谱 | 全局拟合里漏掉一个源会偏置其它源的参数（22-l04 已借） |
| 训练与数据的资源划分 | 非相干容量、Hassibi–Hochwald | 最优训练量随相干时间和信噪比的定标律；编码 + 迭代接收下的定标律没有同样干净的结果 |
| 仿真器与现实的差距 | 机器人 sim2real、气候模式评估 | 先找"哪个假设一改结论就翻"的敏感度排序，而不是逐个假设补 |

## 5. 我认为可疑的前提（按我的把握排序）
1. 每条径是一条"线"（单一频移）。海面反射径在帧长 64 ms 内自身有起伏，是一小片而不是一条线；一旦如此，"8 条径 32 个未知数"的超定性和 AFDM"每径一个位置"的好处都要重算。（c25、c12 管的是径间差异，这条管的是径内展宽，目前没有卡。）
2. 每帧冷启动。真实链路是连续的，几何在帧间只慢变；冷启动只发生在一次通信的第一帧。c02 因"已被做过"淘汰，但"论文的难点只在第一帧"这个前提本身没有被检查过。
3. 叠加导频"不占开销"。有编码时导频功率是从数据信噪比里拿的，嵌入导频占的位置可以用码率补；两者的公平比较按净码率做（c03 淘汰时说资产里已有实测，写新卡前先核 `P2B_EP_NOTE`）。
4. 目标工作点：码率 1/2、QPSK、4–6 dB。水声是否真在这个点上工作，决定"低导频悬崖"值不值得论文篇幅。
5. 单水听器、白高斯噪声、已知噪声方差、径数已知且等于名额（各已有卡或 Eric 已定，不再提）。

## 6. 本轮的开放问题清单（M1；灵感阅读时逐条对照）
1. 统计–计算缺口：编码叠加导频系统"最少要多少导频"的统计下限是多少，现有迭代接收机离它多远，哪种结构（码、导频放法、起步算法）能缩小它。
2. 种子问题：同样的导频能量，集中成一小段"种子"与均匀叠加，哪种让迭代起得来（空间耦合的门槛饱和能不能搬过来）。
3. 径内展宽：每径不是线而是一小片时，稀疏参数模型何时输给统计模型（散射函数）。
4. 仿真前提的敏感度排序：哪个前提一改，现稿结论（继续迭代还是重搜）就翻。
5. 自校准的鬼源：别的领域怎样证明或避免交替估计造出的假成分，能否给"幻影径"一个不依赖本接收机的判据。
6. 多帧与跨帧：第一帧之外，导频还剩什么用。
7. 峰值功率与带外约束下，chirp 基相对单载波到底差多少（l14 在做）。
8. 同一批数学在别的系统上：OTFS / Zak-OTFS 叠加导频、通感一体的双基地感知、多用户上行。
