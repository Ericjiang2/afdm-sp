# I-20261122-l14 出题者（gemini-4-neon）的第一性原理拆解（原样）

1. 物理层：本项目底层是用单个有限时长观测窗 $T=N/f_s$ 里的线性时变算子 $H=\sum_p g_p \Delta_{\nu_p}\Pi^{\ell_p}$ 捕获连续延迟与多普勒；剥去 AFDM/SP 代号，其核心是在有限时间-带宽孔径内分离多个互相耦合的线性/非线性相位斜坡。
2. 信号与波形层：酉基变换（AFDM/OTFS/OFDM/SC）在各向同性噪声下不改变总 Fisher 信息，只改变坐标间的耦合结构、旁瓣/混叠几何与峰均比；真正决定可辨识性与下界的是探测算子在目标参数与干扰参数子空间上的投影正交性。
3. 推断结构层：单通道双线性或带未知干扰（未知数据、未知频偏/多普勒、未知增益）估计的根本瓶颈是“目标参数切空间与干扰参数切空间的共线度”（Schur 补信息损失）以及有限信噪比下的非局部旁瓣/栅瓣跳变（全局极大似然门限）。
4. 算法与系统目标层：现有接收机多围绕静态或局部曲率（局部 CRB / 局部精修）做优化，缺两类原理级工具：跨无量纲尺度区的相变诊断（G7）与兼顾局部下界及全局歧义墙的边界刻画（G14）。
5. 抽象问题类与外部对应：本题属于“受物理约束的时空采样算子设计，以最小化消去多项式相位干扰后的 Schur 补估计下界并避开全局模糊峰”，跨通信（SP-AFDM 频偏/多普勒耦合）、移动天线感知（MA trajectory CRB）、虚拟阵列测向（VAA + LOFO）与雷达/声呐机动测向（TMA / FMCW）。
6. 攻击层次：本卡不碰本项目的水声仿真前提或通感星座/前传，而把“切空间共线度 + 尺度区切换 + 局部 CRB 对全局旁瓣墙”这套诊断框架打到物理层移动天线连续轨迹测角（explore 赛道）的尺度律层，解决移动天线 CRB 轨迹社区与虚拟阵列频偏可观性社区之间尚未连通的定量断层。
