# I-20261122-l08 出题者（gpt-6.2-sol）的第一性原理拆解（原样）

水下每条传播路径都让信号晚到，并因声程变化而使相位随时间转动。真实信号还会发生时间伸缩。  
项目把每条径写成一次延迟、一次相位旋转和一个复增益。AFDM（仿射频分复用）改变这些回波在接收机里的表示。  
第 0 轮还没有译码结果，只能从已知波形找出径的时延、多普勒和增益。父卡提供了时延的来源。  
给定同一条径的时延，两次相位观测把多普勒估计变成一个有整周歧义的斜率估计问题。  
脉冲雷达也遇到同样的问题。它用不同的脉冲间隔补足整周信息，长间隔负责精度，另一个间隔负责消歧。[Liu et al., 2021](https://www.weizmann.ac.il/math/yonina/sites/math.yonina/files/Unambiguous_Delay-Doppler_Recovery_From_Random_Phase_Coded_Pulses.pdf)  
本卡在分组与估计两层检验父卡的假设。如果标记段内部的样本已经能分清整周，就可以检验数据是否值得继续让出功率给叠加导频。  
系统层按同一载荷、时限和发射能量比较。估计层同时看局部误差和整周错判，后者在少数帧上就可能影响译码。
