# I-20261121-l13 出题者（gpt-6.2-sol）的第一性原理拆解（原样）

1. 物理层。每条回波带来连续时延、复增益和帧内相位转速。一个分数时延回波经采样能铺到多个整数抽头，两条近邻回波也能在同一片区域重叠。
2. 波形层。仿射频分复用（AFDM）用酉变换在扫频基上收发。第 0 轮可拿已知导频去匹配波形，同帧未知数据也经信道到达，因此匹配残差随信道变化。
3. 推断层。一条连续时延径只能沿着增益、时延和多普勒四个实自由度改变波形。双径能否被识别，取决于减去这四种可解释变化后还剩多少证据。
4. 算法层。现有前端按离散候选花找径名额，后端才用译码反馈细化。这里要决定的是第 0 轮何时花第二个名额，以及证据不足时是否保留原表示。
5. 系统层。译码器需要的是能作用在整帧数据上的信道算子。两条物理径有时可以用一条近似得很好，径数猜错和信道算错应分别计量。
6. 抽象问题是两个相干源碰近时的模型选择。谱分析用局部导数检测第二个源，成像用噪声下的可行模型判断源数。本题迁移的是这套分辨思想，再把合并的容许误差放到数据算子上。
7. 最可疑的前提是同一阈值能从单径、单边多普勒搬到多径、双边多普勒。其它径的拟合残差、导频实际形状和两条径的相对增益相位都会改写阈值。
