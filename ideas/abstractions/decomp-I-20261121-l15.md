# I-20261121-l15 出题者（claude-sonnet-4.6）的第一性原理拆解（原样）

- 物理层：浅海稀疏多径，每条径是（时延 ℓ，多普勒 ν，复增益）。载频 12 kHz、帧长 N = 1024，一个 DAFT 格点约 15.6 Hz。
- 信号模型层：AFDM 的 c1 = 5/(2N) 把时延和多普勒压进一维索引 loc = ν + 5ℓ (mod N)，这是**数据检测器**看到的混叠线。导频是 DAFT 域的 ZC 序列 exp(−jπ r m²/N)，对 N 为 2 的幂、r 为奇数，它经 IDAFT 后在时域仍是一条 chirp（高斯和），所以导频有**它自己的**模糊函数，和数据的混叠线是两套几何。
- 推断层：第 0 轮只用导频的匹配滤波/贪婪拟合找支撑。导频原子对 (ℓ,ν)、(ℓ',ν') 的相干系数就是可辨识性的直接度量，1/(1−c²) 是联合估计两条径时的噪声放大。
- 抽象问题类：带模糊格的探测信号设计（雷达模糊函数的"脊"，LTE PRACH 的 Doppler 导致的 d_u 偏移峰）。其他领域的处理：PRACH 限制循环移位集合，雷达用图钉形或 Costas/Welch 序列。
- 每层缺什么：项目只在 ℓ ≤ 102 内检验过导频（c10 换了随机相位和单冲激，结论是没差别），没人问过 ℓ 超过 102 之后 ZC 导频在哪里开始分不开，以及根号 r 是不是被"碰巧选对"了。
- 可疑前提：把过扩展（ℓmax 超出 102）的限制全归给 DAFT 打包界 (2k+1)ℓmax < N（l12 的论点）。我的数值显示导频还有一个独立的上限，位置不同（113、143、256，而不是 205）。
