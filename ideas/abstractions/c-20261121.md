## 1. 去名字
- AFDM：用二次相位（chirp）把 N 个符号铺到时频平面上，使时延和多普勒在 DAFT 域里成为可分开的平移。本质是"让双扩展信道在某个变换域里近似稀疏、可分辨"。
- SP（叠加导频）：已知序列和未知数据同时同频发送。导频不占资源，但对数据是干扰，数据对导频估计也是干扰。
- F0 / CODELAY：先用导频单独粗捕获（支撑 + 多普勒），再用译码后的软数据当作额外导频迭代精估。即"捕获 → 数据辅助跟踪"。

## 2. 分层与每层缺什么
| 层 | 在做什么 | 本质稀缺/未知 | 现有卡攻击的层 |
|---|---|---|---|
| 物理 | 水声多径：每条径是时延 + 时间伸缩（B/fc≈1/3，宽带） | 每径伸缩因子不同 | 几乎没有（05 已淘汰为方法） |
| 信号模型 | 仿真里每径 = 整数时延 + 纯频移（窄带近似） | 模型失配本身未量化 | c06（分数时延） |
| 推断结构 | 双线性：信道 × 未知编码数据，已知导频提供锚 | 第 0 轮只有导频能量 ρ | c01/c07/c08 |
| 算法 | 贪心支撑 + 有界多普勒精修 + LDPC + 迭代 | 第 0 轮初值落进吸引域 | c01/c07/c08/c10 |
| 系统目标 | 1% FER 下的 SNR，导频功率开销 | 真实分组还有前导、重传、时延预算 | 几乎没有 |
| 评估 | 单帧 FER、NMSE、穿越点 | FER 目标与吞吐/时延不等价 | 几乎没有 |

结论：上一轮 34 个深想全挤在"推断/算法层"的第 0 轮多普勒精度上。物理、系统、评估三层几乎空白。

## 3. 抽象问题类
- 已知探针 + 未知编码符号下，稀疏参数化线性算子的半盲辨识，需要迭代自举（bootstrapping）。
- 同类问题的其他领域：GNSS 捕获/跟踪（码相位 + 多普勒）；冷冻电镜 / 多参考对齐（MRA，未知平移 + 未知信号，EM 自举，低 SNR 下"Einstein from noise"模型偏置）；地震盲反褶积；相位恢复（谱初始化决定能否进吸引域）；声纳宽带模糊函数（时延-伸缩）。

## 4. 可疑前提（pit 候选）
1. 窄带多普勒：`physical.py` 的 `Channel.apply` 每径只乘 `exp(2jπkν/N)`，没有时间伸缩。fc/fs≈1.5 时，ν bin 的多普勒对应整帧 ν/1.5 个抽头的时延漂移。
2. 第 0 轮只靠 SP 捕获：真实水声分组几乎都带 LFM 前导，用于检测、同步、伸缩因子，有的还用它估多径时延。若前导已给时延，第 0 轮支撑问题部分是自造的。
3. 1% FER 单帧目标：有 ARQ 时目标应是有效吞吐/时延，最优 ρ 可能不同。
4. 信道帧内不变：128 ms 量级帧内伸缩率漂移（加速度）未建模。
