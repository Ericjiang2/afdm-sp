## 问题（一句话）
`STAGEA2_READOUT.md`（及后续 `STAGEA3_PROTOCOL.md`）依据 `ldop ≈ full` 下结论称「`ldop` 的增益用导频 LS，且第 0 轮增益精度几乎不值钱（H）」，但代码里 `ldop` 实际得到的是被数据方差项收缩到约 $\rho$ 倍的强偏岭解（$\text{NMSE}\approx(1-\rho)^2=0.64\text{–}0.90$），且下游 `scalar_joint(..., gain_mode='joint')` 立刻用 20 轮双线性更新把该增益彻底重写，因此该实验只证明了联合检测器在 $\rho\ge 0.10$ 对初值不敏感，既不能支持「增益精度不值钱」，也使 `full` 本身在 $\rho\le 0.10$ 并非真增益上限。

## 白话与类比
好比想测试「厨师切菜的刀工（第 0 轮增益精度）值不值钱」，设了两组对照：A 组直接给机器切好的标准菜（`full` 真增益），B 组号称给「徒手切好的菜（导频 LS）」，结果 B 组实际塞进锅里的是一团几乎没切过的碎末（幅值只剩真值的 $10\%$）；偏偏下锅后第一步是把两组的食材全都扔进一台自动料理机（`scalar_joint(gain_mode='joint')`）重新打碎搅匀 20 遍，再比较端上来的成品。在食材够多（$\rho\ge 0.10$）时，料理机把两边都搅成了几乎一样的泥（甚至塞一个全 `0.01` 的瞎猜初值都差不多），于是实验报告把「料理机自己重做了」误写成「刀工几乎不值钱（高置信度）」。可一旦关掉料理机的重打功能（`gain_mode='fixed'`），或者食材太少导致料理机自己失灵（$\rho=0.05$ 相位锁不住），有没有精准刀工的差距立刻全面暴露。

## 去壳三句
- **谁真卡住了、用什么卡住**：做低导频 SP-AFDM 第 0 轮半盲信道估计器设计与立项评估的研究者（即本项目 `11-21-data-pilot-fer` 线后续工作），直接按 `STAGEA2_READOUT.md:31` 的「增益精度几乎不值钱（H）」把增益排除在估计目标外，只追求第 0 轮多普勒精度，同时沿用 `scalar_joint(gain_mode='joint')` 作为检测器。
- **改正边界陈述后改变什么设计决定，及最朴素替代损失多大**：改正后，不再把 `ldop ≈ full` 解读为「第 0 轮增益无所谓」，而是明确区分「靠 `scalar_joint(joint)` 在 $\rho\ge 0.10$ 隐式完成半盲增益重估」与「无联合重估时的真实增益敏感度」。若后续设计改用固定增益检测器（例如为绕开 $\rho=0.05$ 相位失锁墙）或只靠最朴素的无偏导频 LS 提供第 0 轮增益，32 信道只读探针显示 4–6 dB、$\rho=0.05\text{–}0.15$ 上第 0 轮软输出已比真增益损失 `0.05–0.16` bit/coded-bit log-loss（`+1.9–5.5 pp` uncoded BER）；而若误把 `time_refine(rounds=0)` 当「导频 LS」直接馈给固定增益检测器，更会因 $\rho$ 倍岭收缩损失 `0.31–0.50` bit log-loss（`+8.7–10.2 pp` BER）。
- **难处的结构**：这不是一条新算法，而是双线性迭代接收机中的**归因可辨识性边界（pit）**——上游信道估计（岭回归）与下游联合检测（P-BiG-AMP `gain_mode='joint'`）共享同一组增益变量 $\mathbf{g}$；在不固定下游变量或显式解耦先验时，上游对 $\mathbf{g}$ 的消融测到的是下游不动点的吸引域半径，而非物理量 $\mathbf{g}$ 本身的信息价值。

        print(f'  FIXED: LL full={m["f_full_ll"]:.4f} ldop={m["f_ldop_ll"]:.4f} LS={m["f_ls_ll"]:.4f} | BER full={m["f_full_ber"]:.4f} ldop={m["f_ldop_ber"]:.4f} LS={m["f_ls_ber"]:.4f}')
