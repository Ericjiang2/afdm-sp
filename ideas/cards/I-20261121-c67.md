## 问题（一句话）
.25 网格再细到 .125（33 点/时延，3399 列），第 0 轮 FER 相对 g25 变好（失配仍有余量）还是变坏（列数 → 假原子）。

## 白话与类比
尺子再细一倍，看是刻度精度在起作用还是格子太多在添乱。

## 锚点（出处）
- D：c63/c60（删列有效）、c54（失配分层不支持失配解释）。

## 去壳三句
1. 谁真卡住了：c48 的机制在跨模型审时必须说清。
2. 解决了会改变什么：若变坏，"列数"解释成立，前端应在 .25 停；若变好，应继续加密。
3. 难处的结构：两种效应方向相反：失配损失从 .25 网格最坏 .125 bin 降到 .0625 bin，噪声最大相关从 sqrt(2 ln 1751) = 3.87 升到 sqrt(2 ln 3399) = 4.03（+.35 dB）。

## 推导（项目数字）
- 失配：.25 网格残余失配均匀分布在 ±.125 bin，sinc 主瓣能量损失约 π²δ²/3 ≈ 5.1%（δ = .125）最坏、平均约 1.7%；.125 网格平均约 .4%（−.06 dB 量级）。噪声列：+.35 dB。按此粗算 g125 应略差。
- 实测（g125 vs g25）：U .10 .318 → .325（b 13, c 16）；U .15 .115 → .107（10, 7）；G .10 .323 → .305（15, 8）；G .15 .117 → .128（2, 6）。合并 b − c = 3，p = .82。F0 CPU .39 → .58 s。
- 解读：两种效应在 .25 → .125 之间大致抵消或都已很小；既不支持继续加密，也不足以证实列数解释（列数翻倍并未显著变差）。
