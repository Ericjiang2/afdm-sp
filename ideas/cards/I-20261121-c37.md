## 问题（一句话）
既然 `c35` 实测证明第 0 轮内点多普勒已贴近局部 `CRB_white`、差距全由少量离群径（`|e|>0.25`）造成，能否在第 0 轮用可观测的相对估计功率 `|g_hat_i|^2 / sum|g_hat|^2` 门控剔除低置信弱径，从而降低 `r0_errors` 与最终 `FER`？

## 白话与类比
如果一张照片的模糊主要来自几个噪点，直接把暗像素一刀切掉会不会变清晰？实测发现不会：暗像素里混着真正的弱目标，硬切把弱径一起切掉了，反而让整张图失真。

## 锚点（出处）
- `A` 锚点：子卡深化 `I-20261121-c35`（真实 `stageA` 实测内点误差 `.0675` ≈ `CRB_white=.0678`，但 `6.0%` 离群径误差达 `.6789` bin）。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：`pilot_front` 在低 `rho` 下输出约 `24` 条候选径，其中包含大量旁瓣离群径与假径，导致直接用于第 0 轮均衡时多普勒尾误差拉大。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：若相对功率门控即可剔除离群径，则无需改动导频结构或增加多峰搜索即可在低 `rho` 降 FER；最朴素替代就是保留 `orig_front` 全部 `24` 条输出。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：用简单公式设门限 `tau_rel` 过滤 `p_rel_i = |g_hat_i|^2 / sum_j |g_hat_j|^2 < tau_rel`。然而实测 `inlier_rel_pw = 0.092–0.107`，`outlier_rel_pw = 0.049–0.050`，与真实弱径功率分布高度重叠，硬门控会同时砍掉真实弱径。
