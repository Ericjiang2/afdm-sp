## 问题（一句话）
父卡 `I-20261121-l13` 要求仅凭第 0 轮弱叠加导频把“结构合并损失 $L(H_2)\ge 8\%$ 的近邻双径”以 $\le 10\%$ 误并率拆开，但在 $\rho=0.15\text{–}0.25$、$4.5\text{ dB}$ 下这受限于 4 实自由度非中心 $\chi^2_4$ 信息论下界（假合并率下界达 $35.3\%\text{–}52.9\%$）；能否利用“未建模算子能量 $\mathcal{E}_{\text{unmod}}=P_{\text{loc}}L(H_2)$ 同时控制第 0 轮不可检性与临时合并信干噪比损失”的同源对偶，在第 0 轮故意粗合并保自举、到第 1 轮只用**纯奇偶校验外信息**（`raw_check_extrinsic`，避开检测器 `raw_app` 吸收模型误差造成的自证衰减偏置）做二阶残差渐进分岔拆径？

## 白话与类比
父卡 `l13` 想在最黑暗的起步阶段（第 0 轮，只有 15%–25% 导频微光、其余 75%–85% 全是未知数据噪声），就一眼分清远处紧挨着的两个影子到底是“一个人的模糊重影”还是“并排走的两个人”，并规定只要并错会丢掉局部 8% 以上能量的双人影，漏拆率不能超过 10%。但一算物理信噪比账就会发现这是强人所难：那丢掉的 8% 局部能量放到整帧里只有全帧能量的 2%（$-17\text{ dB}$），在 85% 数据自干扰底下，任何检测器在保住 80% 真单径不误拆时，都会漏掉 **35%–53%** 的这类双径。

好消息是，这件事正反两面被同一个物理量锁死，不存在死角：**凡是第 0 轮微光看不清的双径，暂时当成一条径去跑第一轮纠错译码，给整帧带来的额外干扰最多只有 $0.18\text{–}0.20\text{ dB}$，不仅不会把译码器卡死，反而省下找径名额、把多普勒误差减半；凡是重到会把第一轮译码卡死的大分裂双径，第 0 轮导频能量本来就强到一眼能拆开！** 等第一轮译码器把六七成数据认出来之后，探针能量暴涨、干扰骤降，拆径信噪比直接翻 **5 到 8.6 倍**，漏拆率从 53% 暴跌到 **0.4%**。这里只有一个极易踩坑的陷阱（借自冷冻电镜对称性渐进释放与误差变量统计）：第 1 轮拆径时绝不能喂检测器自己的后验输出（`raw_app`），因为检测器是在“假定只有一条径”的前提下硬凑数据，会把第二条径的残差吸进假数据里“自我证实”；必须只喂 LDPC 校验方程吐出的纯外信息（`raw_check_extrinsic`），才能无偏地把藏着的双径拆出来。

## 锚点（出处）
- **锚点 B（父卡 `I-20261121-l13` 与 `c06/c08` 的量化冲突）**：`c08` 证明已知分组时第 0 轮连续单径共享多普勒把 MAE 从 `.082/.090` 压到 `.031/.049` bin；`l13` 设下第 0 轮 `真单径合并率 >= 70%` 且 `L(H_2) >= 8% 坏双径误并率 <= 10%` 的双硬线，但其自身表内 $(0.65, 0.40)$ 在理想无背景干扰、等先验二选一下误判率已达 $9.3\%$，计入 4 实自由度未知方向与多径干扰后越过信息论极限。
- **锚点 D（冷冻电镜黄金标准渐进对称性分岔 + 误差变量消息传递的“双重蘸取”偏置 vs 无线叠加导频阶数自适应的脱节）**：单颗粒冷冻电镜（Scheres, *J. Mol. Biol.* 2012 RELION; Punjani et al., *Nat. Methods* 2017 cryoSPARC）在低信噪比起步时强制高对称合并类以压低姿态方差，待分辨率跨过分岔波数后再用独立半集外信息释放自由度；而 2026 年分数时延多普勒 AFDM 阶数自适应工作（`arXiv:2610.09970`、`arXiv:2607.18881`）要么只在导频段静态定阶，要么直接回送检测器全后验 `APP` 触发模型自证偏置。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：连续时延叠加导频接收机的两类现有路线两头受困——`c08/l13` 与 `arXiv:2610.09970` 试图在第 0 轮弱导频阶段一次性定死路径数（在 $\rho=0.15$ 时受数据自干扰压制，非中心参数仅 $D_{\text{R0}}=2.55$，坏双径漏拆率 $>50\%$）；而 `F0`（`native_twofft.py`）虽有多轮迭代，却从第 0 轮起锁死离散时延槽位，且把含自身似然的 `raw_app` 直接回灌信道重估（`native_twofft.py:26`），一旦第 0 轮粗合并就会自我锁死在单径子流形上。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：把连续时延多径估计从“第 0 轮静态定阶”改为**“第 0 轮宽容合并省名额保多普勒 → 第 1 轮凭 `raw_check_extrinsic` 触发局部单拆二渐进分岔”**：
   - **用本项目真实参数精确推导与复算**（$N=1024$，$\rho\in\{0.15, 0.25\}$，$\text{SNR}=4.5\text{ dB}\implies \sigma^2=0.3548$，局部双径簇占全帧平均两径功率 $P_{\text{loc}}=2/8=0.25$，坏双径结构损失门槛 $L(H_2)=0.08$，即全帧未建模算子能量 $\mathcal{E}_{\text{unmod}}=P_{\text{loc}}L(H_2)=0.020$）：
     - **最朴素做法 1（父卡 `l13` 第 0 轮纯导频判拆）**：在 4 个新增局部实参数自由度（相对位移与正交复分裂振幅）下，第 0 轮广义似然比非中心参数严格由 $\mathcal{E}_{\text{unmod}}$ 锁定：
       $$D_{\text{R0}}(\mathcal{E}_{\text{unmod}}) = \frac{N\rho}{(1-\rho)+\sigma^2}\,\mathcal{E}_{\text{unmod}}.$$
       代入 $\mathcal{E}_{\text{unmod}}=0.020$：在 $\rho=0.15$ 时 $D_{\text{R0}}=\mathbf{2.55}$，在保真单径合并率 $80\%$（$\chi^2_4$ 门限 $5.99$）下，**坏双径漏拆率高达 $52.9\%$**；即便升至 $\rho=0.25$，$D_{\text{R0}}=\mathbf{4.63}$，**漏拆率仍达 $35.3\%$**（是 `l13` 目标 $\le 10\%$ 的 $3.5\text{–}5.3$ 倍）。若强行压低门限保 $\le 10\%$ 漏拆，真单径会被大量误拆成双径，多普勒误差翻倍回 `.082–.090` bin 并耗尽 8 个槽位。
     - **最朴素做法 2（全程合并永不拆开，或第 1 轮直接用 `raw_app` 判拆）**：全程不拆在 $L(H_2)\in[0.12, 0.25]$ 的中等分裂帧上留下 $-13\text{ 至 }-10\text{ dB}$ 算子地板，卡住高信噪比尾部；而用 `raw_app = incoming_llr + raw_check_extrinsic` 判拆时，`incoming_llr` 正是由第 0 轮单径算子 $H_1$ 解出的匹配滤波输出 $z = d + H_1^\dagger \Delta H(p+d) + H_1^\dagger w$，$\mu_{\text{app}}$ 顺着 $H_1^\dagger \Delta H d$ 偏移，令残差 $y - H_1(p+\mu_{\text{app}})$ 中的分裂信号 $\Delta H d$ 被抵消衰减 $(1 - \gamma_{\text{det}})^2$ 倍。
     - **本卡方案收益**：第 0 轮临时合并 $\mathcal{E}_{\text{unmod}}=0.020$ 对首轮检测等效信干噪比的损失仅为
       $$\Delta\gamma_{\text{R0}} = 10\log_{10}\!\left(1 + \frac{(1-\rho)\mathcal{E}_{\text{unmod}}}{\sigma^2}\right) = \mathbf{0.20\text{ dB}}\;(\rho=0.15)\;\text{与}\;\mathbf{0.18\text{ dB}}\;(\rho=0.25),$$
       毫不阻碍首轮译码启动；当第 1 轮纯奇偶校验外信息消解 $65\%$ 数据方差（归一化剩余方差 $\bar v_{\text{chk}}=0.35$）时，分岔非中心参数跃升至
       $$D_{\text{R1}} = \frac{N\big[\rho + (1-\rho)(1-\bar v_{\text{chk}})\big]}{(1-\rho)\bar v_{\text{chk}}+\sigma^2}\,\mathcal{E}_{\text{unmod}} = \mathbf{22.06}\;(\rho=0.15)\;\text{与}\;\mathbf{24.47}\;(\rho=0.25),$$
       在同一 $80\%$ 真单径合并门限下，**坏双径漏拆率从 $52.9\% / 35.3\%$ 直接砸到 $0.44\% / 0.17\%$**！
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：两个结构缺口同时闭合——
   - **无死区同源对偶定理**：令 $\eta_0 = \frac{N\rho}{(1-\rho)+\sigma^2}$，则任意双径合并的“第 0 轮不可检区”（$D_{\text{R0}} < \tau_{\text{split}}\iff \mathcal{E}_{\text{unmod}} < \tau_{\text{split}}/\eta_0$）恰对应首轮相对噪声抬升 $\frac{(1-\rho)\mathcal{E}_{\text{unmod}}}{\sigma^2} < \frac{(1-\rho)[(1-\rho)+\sigma^2]}{N\rho\sigma^2}\tau_{\text{split}}$；在 $N=1024, \rho\ge 0.15, \text{SNR}\le 6\text{ dB}$ 全范围内，系数 $\frac{(1-\rho)[(1-\rho)+\sigma^2]}{N\rho\sigma^2} \le 0.024$，即任何第 0 轮看不清（$\tau_{\text{split}}\approx 6$）的近邻双径对首轮译码的 SINR 损伤恒 $< 0.6\text{ dB}$，“看不清”与“不伤首轮自举”在数学上严格蕴含。
   - **奇偶校验正交去自证（Extrinsic De-biasing）**：失配算子扰动 $H_1^\dagger \Delta H d$ 在 DAFT 域表现为非零时延–多普勒差驱动的跨符号相位旋转置换，与准随机 LDPC 校验图近似正交；只提取不含本符号观测似然的 `raw_check_extrinsic` 构造探针 $p + \mu_{\text{chk}}$，即可切断双线性估计中的误差变量“双重蘸取（double-dipping）”回路。

## 最接近的已有工作
1. **H. Wang et al.**, *"Model-Order-Adaptive Channel Estimation for AFDM Systems with Fractional Delay and Doppler,"* `arXiv:2610.09970` [eess.SP], Oct. 2026：在分数时延多普勒 AFDM 中通过残差能量门限自适应增删路径阶数，但依赖纯导频段（双导频/多符号导频）静态完成定阶，未揭示叠加导频下“第 0 轮不可检度与首轮译码损伤度同源对偶”，也未利用译码校验外信息做跨轮渐进分岔。
2. **S. Luo et al.**, *"Iterative Off-Grid Channel Estimation and Detection for Superimposed-Pilot AFDM,"* `arXiv:2607.18881` [eess.SP], Jul. 2026：在叠加导频 AFDM 中利用可靠译码符号迭代修正离网时延和多普勒，但路径槽位数在初始化后固定不变（无粗合并→细分裂拓扑分岔），且未区分 `APP` 回灌的自证衰减偏置与纯 `check_extrinsic` 探针。
3. **S. H. W. Scheres**, *"RELION: Implementation of a Bayesian approach to cryo-EM structure determination,"* *J. Struct. Biol.*, vol. 180, no. 3, pp. 519–530, Dec. 2012（及 A. Punjani et al., *Nat. Methods* 2017 cryoSPARC 多类从头分岔）：在低信噪比起步时合并高对称/单类模型压低姿态估计方差，随迭代信噪比提升再分岔细化，并用黄金标准独立半集防止过拟合自证；本卡将该渐进分岔与防自证思想迁移到编码叠加导频时变信道的连续近邻径拆并，并以 LDPC 奇偶校验外信息替代空间半集分割。
4. **N. Ueda, R. Nakano, Z. Ghahramani, and G. E. Hinton**, *"SMEM Algorithm for Mixture Models,"* *Neural Computation*, vol. 12, no. 9, pp. 2109–2128, Sep. 2000：提出混合模型的分裂–合并 EM（SMEM）准则跳出局部极值；但面向静态无编码观测的同分布混合模型，不含未知编码符号自干扰随译码相变消退带来的 $8.6\times$ Fisher 信息跃迁。
5. **Q. Denoyelle, V. Duval, G. Peyré, and E. Soubies**, *"The Sliding Frank-Wolfe Algorithm and its Application to Super-Resolution Microscopy,"* *Inverse Problems*, vol. 35, no. 12, 124001, Nov. 2019（`arXiv:1811.06416`）：在连续无网格稀疏恢复中交替加入新原子与连续滑动合并；面向已知测量算子，未涉及双线性盲/半盲编码通信中“先合并保译码启动、后借校验外信息拆径”的耦合动力学。
