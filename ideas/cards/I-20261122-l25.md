## 问题（一句话）

叠加导频在最优点（ρ* = .25）把四分之一的发射功率花在一条不带信息的已知序列上（数据功率损失 1.25 dB）；如果只留 ρ1 ≈ .08 的纯导频，把其余 ρ2 ≈ .17–.22 的功率换成叠加在全部 N 个符号上的一层低码率码字，接收机用粗信道先解这一层、解出后把它当作功率 ρ1 + ρ2 的导频再做后面的一切，这一层在同总能量、同帧长下能白带多少比特，折合能否正面超过 4.95 dB 基线 0.8 dB？

## 白话与类比

现在的导频像一段全场齐唱的固定旋律：接收机靠它对准，但它不带任何消息。这张卡把大半段固定旋律换成一句很慢、很好认的话：因为说得慢（码率低），接收机只凭最强的一两条回声就能听懂；听懂以后，这句话的每个音都已知，和固定旋律一样可以用来对准其余回声，而且检测器也能把它整段减掉。导频的总"已知功率"没有变，主数据看到的条件和 ρ = .25 的系统一模一样，多出来的是那句慢话本身带的一百来个比特。

与父卡 l03（不等保护虚拟导频）的差别：l03 把锚放在一部分符号位置上、只交给信道估计器，主码要为它升码率；这里锚是功率域叠加的一层，解出后对估计器和检测器都是已知量，它自己带信息，主码不用升码率。

## 锚点（出处）

- 锚点 D（两个社区各握一半）：信息论一侧，Li–Jin–Collins 的逐次译码（ISIT 2006 / IEEE TIT 2007）把 K 个不同码率的码字交织后依次译码，先译出的充当后面的导频，"以极少的导频代价逐步得到更好的信道估计"；Pastore–Koch–Fonollosa（IEEE TIT 2014，arXiv:1301.6120）在功率域把输入拆成多层逐层译码，收紧不完美信道信息下的可达速率下界。接收机一侧，SP-OTFS / SP-AFDM 文献（Mishra 等 TWC 2022；Kanazawa 等；Luo 等 2607.18881；"Superimposed Pilot-Based OTFS: Will it Work?" arXiv:2501.15935）都把导频当零码率的固定序列，优化的只是它的功率。两边互不引用（本次检索未见把逐次译码层当叠加导频用于时延–多普勒迭代接收机的工作；只查了摘要级，待第 6 步核实）。
- 本项目数字：ρ 扫描（res-20261119-06）最优 ρ = .25–.30，ρ < .25 崩塌；真第 0 轮 3.45 dB 对基线 4.95 dB（STAGEA2）；22-l15：不知道信道的信息税至多 0.84 dB。纯导频功率的数据损失 10·log10(1/(1 − .25)) = 1.25 dB。
- 推导：发射 x = √ρ1·p + √ρ2·c + √(1 − ρ1 − ρ2)·d，c 是低码率码字（QPSK），d 是主码字。第二层先译、把主层当噪声：每符号信干噪比 γ2 = ρ2·λ / ((1 − ρ1 − ρ2)·λ + σ²)（λ 为该处的信道功率增益），可达比特 K2 ≈ Σ log2(1 + γ2) − Q⁻¹(ε)·√(ΣV)（正态近似，V = (1 − (1 + γ2)⁻²)·log2²e）。译出后已知功率为 ρ1 + ρ2，主层的处境与 ρ = ρ1 + ρ2 的叠加导频系统逐项相同（上限由现有 ρ 扫描直接给出，不需要新仿真）。总载荷 1024 + K2 比特；折合到等载荷，主码率降 K2/2048，在 1 bit/符号附近每降 10% 码率约省 0.7–0.9 dB（数值积分核对的容量限，QPSK 每符号信噪比：码率 1/2 → .45 时高斯信道 0.19 → −0.49 dB，差 0.68 dB；遍历瑞利 1.83 → 0.93 dB，差 0.90 dB；本项目 8 径信道介于两者之间）。
- 探针（`~/.cache/idea-funnel/afdm-20261122-l4/probe_layer.py`，48 秒，频选玩具信道：8 径指数功率谱、只含时延、400 个信道；真信道臂是这张卡的白送真值上限）：ρ1 = .08、ρ2 = .17 时第二层容量 169 / 175 / 182 比特（4.0 / 4.5 / 5.0 dB），按 ε = 10⁻³ 的正态近似可载 105 / 110 / 116 比特（各信道的第 5 百分位 101 / 106 / 112）；ρ2 = .22（已知功率合计 .30）时 151 / 159 / 166 比特。只用"导频匹配滤波信干噪比 ≥ 12 dB 的径"做一次性粗估计时（ρ1 = .08 下平均只抓到 31% 的能量），可载量掉到 35–57 比特；ρ1 = .05 时粗估计一条径也抓不到。
- 代入：上限（第二层给真信道、理想短码）ρ2 = .17 多带约 105 比特 = 多 10.3% 载荷 ≈ 0.7–0.9 dB；ρ2 = .22 多带约 151 比特（14.7%）≈ 1.0–1.3 dB，扣掉主层功率从 .75 降到 .70 的 0.3 dB，净约 0.7–1.0 dB。一次性粗估计只有 0.25–0.5 dB。实际落在两者之间，取决于第二层译码与信道估计之间能迭代到哪一步，以及短低码率码离正态近似多远（码长 2048、100 比特左右的极化码加列表译码通常差 0.5–1 dB）。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：编码 SP-AFDM / SP-OTFS 接收机（本项目 F0 + CSTATE；Mishra 等 TWC 2022；Luo 等 2607.18881）在最优点要把 25–36% 的功率给零码率导频；本项目悬赏靶 #0 要在纯导频 ρ ≤ .12 下赢 4.95 dB 至少 0.8 dB。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：改的是发射端一处——导频层从"固定序列"变成"固定序列 + 一层低码率码"，帧长、总能量、主码都不动。最朴素的做法（现状：全部给固定导频）白丢这一层能带的比特：上限约 10–15% 载荷，折合 0.7–1.0 dB；按一次性粗估计的保守读数只有 0.25–0.5 dB。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：好码"全有或全无"，主码起步需要已知功率约 .25；但起步所需的已知功率不必是零码率的——低码率码在很差的信道估计下也能译（它的门槛低，只靠强径），译出后就是导频。这是逐次译码的链式法则：把"导频 → 主码"一步拆成"导频 → 低码率层 → 主码"两步，每一步的已知功率给下一步点火。难点在有限长：一帧只有 1024 个符号，第二层只有一百来个比特，短低码率码与粗信道下的损失决定它是 0.9 dB 还是 0.3 dB。

## 最接近的已有工作

1. T. Li, X. Jin, O. M. Collins, "Successive decoding for finite state Markov modelled flat fading channels", ISIT 2006，doi:10.1109/ISIT.2006.261588；T. Li, O. M. Collins, "A successive decoding strategy for channels with memory", IEEE TIT 53(2), 2007，doi:10.1109/TIT.2006.889013（读了两篇摘要）：K 个不同码率的码字按时间交织、逐次译码，先译出的给后面的做信道估计，少量码字就接近容量。原理与本卡相同。差别：它们是时间交织（占符号位置，类似 l03），针对平衰落或有限状态信道与长码；本卡是功率域叠加、单帧 1024 符号、稀疏时延–多普勒信道，译出的层对检测器也是已知量，上限可由现有 ρ 扫描直接读出。
2. A. Pastore, T. Koch, J. R. Fonollosa, "A rate-splitting approach to fading channels with imperfect channel-state information", IEEE TIT 2014，arXiv:1301.6120（读了摘要）：功率域分层逐层译码，用来收紧 Médard 下界；先译出的层只是从"信号相关噪声"里被拿掉，不回头改善信道估计，也没有接收机。本卡把译出的层回送给估计器。
3. H. Schoeneich, P. Hoeher, "Iterative pilot-layer aided channel estimation with emphasis on interleave-division multiple access systems", EURASIP JASP 2006，doi:10.1155/ASP/2006/81729（读了摘要与引言）：导频层与多个低码率数据层叠加、迭代半盲估计（IDMA）。与本卡同属"导频层 + 低码率层"，但各数据层码率相同、联合迭代，没有"专设一层先解并充当导频、主层保持高码率"的分工与比特账。
4. 父卡 I-20261121-l03（淘汰）：占位置的不等保护锚，白送 20% 已知符号只交给估计器，失败率降两成、主码升码率代价 0.60–0.65 dB，账为负。
5. I-20261121-l02（L3）：用度分布贴合检测器曲线的单一不规则码降低起步门槛。本卡是同一条面积原理的功率域两层实现，目标是导频功率税而不是码门槛；两者可能互相替代（若 l02 的匹配码让最优 ρ 自己降下来，本卡的奖池随之缩小）。

## 价值与代价

- 价值 2：只改发射端一个部件，针对悬赏靶 #0；原理（逐次译码）是已知的，新的部分是它在叠加导频时延–多普勒接收机上的两层实现与有限长比特账。上限 0.7–1.0 dB 正好跨在 0.8 dB 的线上，一次性粗估计的读数（0.25–0.5 dB）在线下——是否过线取决于迭代细化与短码，卡面不替它乐观。
- 适用范围：帧内径参数恒定；第二层译码前至少要抓到主要能量的径（ρ1 太小时粗估计失败，探针里 ρ1 = .05 抓不到任何径，所以 ρ1 有下限，约 .08）；结论按 ρ·N 缩放（见 22-l23）：帧越长，纯导频本来就越小，这张卡的奖池同比缩小。受影响的卡：01（悬赏靶）、l02、l03、`11-21-data-pilot-fer`（它改善的是第 0 轮捕获，可与本卡叠加：捕获越好，第二层越接近真信道上限）。
- 最便宜的致命检验（先查新，查新判 (1) 才做）：用现有管线在 ρ = .08 下的第 0 轮信道估计（把第二层与主层合起来当未知数据，统计上与现有 ρ = .08 系统相同），按真信道与估计信道逐帧算第二层的每符号信干噪比与正态近似可载比特，再加一轮"第二层软判决回送估计器"后重算。跑前判据：4.1 dB、ρ1 = .08、ρ2 = .17 下，可载比特的各帧第 5 百分位 ≥ 90（折合约 0.6–0.8 dB）记为通过；< 60（约 0.4–0.5 dB 以下）淘汰；之间停放。代价：约 1 核时 deinlab + 1 小时脚本（读数加算术，不改冻结接收机）。真码（极化码）检验与主层同帧误帧率是之后的事，超出 L2。
