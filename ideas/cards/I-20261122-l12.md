## 问题（一句话）
父卡 22-l08 测到：分组两端各放 256 点标记能把逐径多普勒估到 .014–.026 bin，但每端 128 点会因整周选错而失败（.10–.20）；现稿的叠加导频 ρ = .10 单独用也不够（.11–.14）。把这两种各自不够的导频合在一起——短标记负责精度，铺满整帧的低功率叠加导频负责解整周——能否用一半的标记开销达到目标线 .04 bin，并且所需的最小叠加导频比例有没有闭式？

## 白话与类比
量一个指针转得多快，可以在开头和结尾各拍一张照片：两张照片隔得越远，角度差量得越准，但指针中间多转了几整圈就看不出来。父卡的办法是把两张照片各换成一小段录像，录像够长（256 点）才看得出大概转速、从而定出圈数；录像太短（128 点）就会数错圈。现稿的做法相当于整段时间里一直有一盏很暗的灯照着指针：能连续看到它在转，不会数错圈，但太暗，量不准。

这张卡的做法是两样都用：暗灯（低功率叠加导频）只负责数圈，两端的短录像只负责量准。类比：游标卡尺的主尺刻度粗但不会读错整数，游标读小数但自己不知道整数；两者各自都不够，合起来才是一把尺。

实测（只到估计这一步，还没接译码）：每端 128 点标记单独用，误差 .14–.20 bin；ρ = .10 的叠加导频单独用，.11–.14；两者合用，.022–.030，过了 .04 的目标线。每端 64 点或 ρ = .05 合用则不过。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：突发通信的导频放置文献（Ying–Ghogho 2005；Rice 等 TCOM 2006）已知"参考符号越靠两端频率估得越准"，也已知代价是"工作范围缩小或门限信噪比升高"（即整周歧义）；水声分组用前后标记估共同伸缩（Li 等 JOE 2008）；叠加导频文献（Tugnait 等 2003；本项目）把导频均匀铺开。两边各用一种，没有人把均匀铺开的那一份当成两端那一份的解歧义工具来定量。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：分组里标记放多长、数据段叠加导频放多少。最朴素的两种做法各走一端：全靠标记要每端 256 点（标记占数据加前缀长度的 45%）；全靠叠加导频要 ρ = .30（数据功率少 1.55 dB），而且给了真时延也只到 .041–.046 bin。合用时每端 128 点（23%）加 ρ = .10（0.46 dB）得到 .022–.030。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：多普勒的局部精度正比于导频能量对时间的二阶矩（能量离中心越远越好），而不选错整周要求粗估误差小于歧义间隔的一半，粗估只能来自时间上连续的那部分导频。两端标记的二阶矩大、连续段短；均匀叠加导频连续、但每个采样的信干比被数据压得很低。两个要求可以分给两种导频，各自只做自己便宜的那件事。

推导与代入（本项目数字：N = 1024，4 dB 即 σ² = .398，平均径功率 p = 1/8，标记不留静默时两端中心距 D = L + 102 + 1024）：
- 两端标记的局部精度（父卡的式子）：σ_ν = N / (2π D √(L p γ))。L = 128、D = 1254：1024 / (2π × 1254 × √(128 × .125 × 2.51)) = .0205 bin，平均绝对误差 .016。
- 歧义间隔 N / D = .817 bin，半间隔 .41。只靠标记内部的相位斜率做粗估：单段 L 点的频率标准差 N√6 / (2π √(pγ) L^1.5)，两段合起来除以 √2。L = 128：.49 / √2 = .35 bin，与半间隔 .41 同量级，所以常选错；L = 256：.12，够用。这解释了父卡 128 点失败、256 点成功。
- 叠加导频做粗估：每个采样上这条径的导频信干比 s = ρ p / (σ² + 1 − ρ)，N 个采样均匀铺开，频率标准差 σ_SP = 1 / (2π √(s N / 6))。ρ = .10：s = .0125 / 1.298 = .00963，σ_SP = 1 / (2π × 1.282) = .124 bin，是半间隔的 1/3.3。
- 所以最小叠加导频比例的闭式：要求 σ_SP ≤ N / (2κD)（κ 取 3），即 s ≥ 6κ²D² / (π² N³) = .0080，ρ_min ≈ .0080 × (1 + σ²) / p。平均功率的径（p = 1/8）：ρ_min ≈ .09；与实测"ρ = .10 过、ρ = .05 不过"一致。弱径（p 小）需要更大的 ρ，它们会选错整周，但占功率少。
- 极端情形核对：ρ → 0 回到父卡的纯标记；L → 0 回到现稿的纯叠加导频；D 增大时精度变好而 ρ_min 按 D² 增长，所以存在最优的标记间距，不是越远越好。

## 最接近的已有工作
1. Y. Ying, M. Ghogho, "Optimal pilot placement for frequency offset estimation and data detection in burst transmission systems", IEEE Commun. Lett. 2005（读了摘要与正文开头）：平坦衰落下一半导频放头、一半放尾对频偏估计和检测都最优；单径、无叠加导频、没有处理整周门限。
2. M. Rice 等, "Carrier-phase and frequency-estimation bounds for transmissions with embedded reference symbols", IEEE TCOM 2006（doi 10.1109/tcomm.2005.863782，只读摘要）：前导 + 后导的频率下界低于中置导频，参考符号越靠两端越好；给的是下界，不含门限效应。
3. BYU 学位论文 "Real-time carrier frequency estimation using disjoint pilot symbol blocks"（scholarsarchive.byu.edu/etd/1780，读了检索到的段落）：导频块间距越大精度越高，"代价是工作范围缩小或门限信噪比升高"；提出的补救是多个块，不是叠加一层连续导频。
4. J. Tugnait 等, "Superimposed training for doubly selective channels", IEEE SSP 2003（doi 10.1109/ssp.2003.1289345，只读摘要）：周期叠加训练 + 多普勒估计 + 导频数据功率分配；全帧均匀，没有与两端标记配合。
5. 父卡引的 Zakharov 等 JOE 2019（叠加周期导频的多间隔自相关估速度与加速度）与 Li 等 JOE 2008（前后标记估共同伸缩）：分别是"连续导频"和"两端标记"在水声里的代表，各用一种。
以上五条里没有看到把连续低功率导频当作两端标记的解歧义层、并给出最小功率比例的；是否已有，需放行时再查（雷达里"粗测 + 精测"和 GNSS 的"码相位解载波整周"是同一思路的远亲）。

## 价值与代价
价值 2：改变一个系统的设计（水声分组的标记长度与数据段叠加导频比例怎样搭配），并给出一条可核对的闭式（ρ_min 与标记间距的关系）。与父卡合起来回答"叠加导频还剩什么用"：不再负责精度，只负责不数错圈，所以只要约 .10。
适用范围：N = 1024、8 条整数时延径、窄带频移、4–6 dB、时延已知（给的是真时延）；标记与数据等功率；U 和 G 两个场景结果相近。ρ_min 随最弱的"要紧的径"的功率反比变化，径数更多或功率更分散时要重算。标记间距若拉到下一包的前导（间隔数帧），ρ_min 按间距平方增长，这条规律预言那时叠加导频不够用，需要中间再有标记。对其他卡：父卡 22-l08 的标记开销减半；c14（前导给时延）是本卡的前提；l05 / l12 不受影响。
没有回答的：译码（误帧率）；时延也要从标记里估；能量与时长的总账——每端 128 点 + ρ = .10 的代价是时长多 23%、数据功率少 0.46 dB，全靠标记是时长多 45%，全靠叠加导频是数据功率少 1.55 dB，三者折算成同一口径后的净差要用误帧率定。
最便宜的致命检验（约 0.7 核时）：见 NEXT_COST。一刀否掉它的结果：以本卡估计作起点、ρ = .10 的 CD 错帧数明显多于父卡每端 256 点的结果（三个信噪比合并多出 10 帧以上），说明 .022–.030 的精度在译码上不够用。
