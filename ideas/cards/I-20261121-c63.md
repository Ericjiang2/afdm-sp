## 问题（一句话）
在场景 U 上，把 .25 网格从 [−2, 2]（17 点）删到 [−1, 2]（13 点），即只去掉一部分不可能的列，第 0 轮 FER 是否也显著下降。

## 白话与类比
c60 把不可能的格子全盖住有效；只盖一部分，效果是不是按比例来。

## 锚点（出处）
- D：c60（整数网格只留 {0,1,2} b − c = 33）、c56（.25 网格只留 [0, 2] b − c = 31）。

## 去壳三句
1. 谁真卡住了："列数 → 假原子"的机制解释需要剂量反应才站得住；跨模型审会问是不是"全有或全无"。
2. 解决了会改变什么：若部分删列也有比例收益，前端设计就是"能删多少删多少"，粗先验（如只知道符号范围的一部分）也值钱。
3. 难处的结构：删列的收益按 sqrt(2 ln K) 预测很小，需要大样本才分辨得出。

## 推导（项目数字）
- 列数 13 × 103 = 1339 vs 1751：sqrt(2 ln 1339) = 3.80 vs 3.87（−.16 dB），约为 c56（[0, 2]，927 列，−.39 dB）的 40%。预测：b − c 约为 c56 的 40%（≈ 12）。
- 实测（w13 vs g25，场景 U）：rho = .10 FER .325 [.281, .372] → .292 [.250, .339]（b 28, c 15）；rho = .15 .138 [.107, .175] → .122 [.094, .158]（b 15, c 9）；合并 b − c = 19，p = .027。F0 CPU .308 → .267 s。
- 报告（i4，整数 {−1, 0, 1, 2} vs base，412 vs 515 列，−.15 dB）：.370 → .318、.182 → .165，合并 b − c = 28，p = .0004；收益比预测大，说明 sqrt(2 ln K) 只给下限，列在多普勒 −2 处的假原子可能更"像"真径。

## 最接近的已有工作
- Chi et al., "Sensitivity to Basis Mismatch in Compressed Sensing"（IEEE TSP 2011，已打开）：失配损失。区别：本卡固定步长、只改列数。
- Wang, Kwon, Shim, "Generalized Orthogonal Matching Pursuit"（arXiv:1111.6664 / IEEE TSP 2012，已打开）：恢复条件随字典增大变难。区别：渐近条件；本卡给剂量反应的 FER 数字。
- Berger, Zhou, Preisig, Willett, "Sparse Channel Estimation for Multicarrier Underwater Acoustic Communication"（IEEE TSP 2010，doi 10.1109/TSP.2009.2038424，已打开摘要与方法节）：字典范围设置。区别：未测部分收窄的代价曲线。
