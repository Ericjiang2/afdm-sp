## 问题（一句话）
把生产前端第 0 轮字典的多普勒步长从 1 bin 细到 .25 bin（每时延 17 点，OMP 仍选 24 个原子，B0-p2，40 是容量上限），在独立帧上配对比较，F0+A1 后的 FER 是否显著下降。

## 白话与类比
c47 加了半格刻度，这里再加到四分之一格，看刻度细到 A1 返工所用的精度时，第一遍是否就少返工。

## 锚点（出处）
- A：生产 `pilot_front` 整数多普勒网格（`sp_afdm_frozen_reviewed_20260921/src/receiver.py`）；A1 的 `reopen_geometry` 用 .25 网格，说明这个精度在项目里已被认可但只用在补救步。
- D：c47 第一批 b − c = 1，本卡第一批 b − c = 5（p = .27），两者都需要独立确认。

## 去壳三句
1. 谁真卡住了：生产接收机第 0 轮；F0 失败率 rho=.10 时 83%，rho=.15 时 62%（确认批 base 臂），之后全靠 A1 兜底。
2. 解决了会改变什么：前端字典改成 .25 步长，F0+A1 后 FER rho=.10 下降 .07、rho=.15 下降 .04；代价是 F0 段 CPU 1.84 倍。最朴素替代（整数网格 + A1）就是本卡的对照臂。
3. 难处的结构：贪心 24 个原子在细网格上要和相邻高相关原子竞争；细网格把最坏失配能量损失从 3.9 dB 压到 .22 dB，同时 B0 的残差扣除也更干净，假原子少占名额。

## 推导（项目数字）
- 失配损失（同 c47 推导）：整数网格最坏 3.9 dB，.25 网格最坏 .22 dB；按均匀分布的失配平均，整数网格平均损失约 1.1 dB，.25 网格约 .07 dB。
- rho = .10 时导频 SNR 每降 1 dB，A3 的第 0 轮捕获率曲线在这一段的斜率约每 dB 几个百分点，所以预期 FER 降幅在 .03–.10 量级；实测 .07（rho=.10）、.04（rho=.15）落在这个范围。
- 成本：字典列数 103 个时延（`l_max_cap` = 102）× 5 = 515 → 103 × 17 = 1751（3.4 倍），OMP 每步相关 O(N·列数)，F0 段整体实测 1.84 倍（.151 → .278 s）。
