## 问题（一句话）

本项目与同类叠加导频论文都在一个固定帧长（N = 1024）上找最优导频功率份额 ρ*（这里 .25–.30），悬赏靶 #0 的奖池（真第 0 轮 3.45 dB 对扫描最优 4.95 dB）也是在这个 N 上量的；对"检测—译码—重估"自举接收机，第 0 轮的质量只取决于乘积 ρ·N，那么帧长加倍时 ρ* 是否减半、奖池是否随之缩小，N 的上限又由什么物理量决定？

## 白话与类比

导频在这类接收机里只干一件事：第 0 轮把径找出来、把多普勒估到够准，让后面的"译码结果回头当导频"接得上。找径和估多普勒靠的是把整帧导频能量攒起来，攒到的量是"导频功率份额 × 帧长"。帧长翻一倍，同样的第 0 轮质量只要一半的导频功率，省下的功率全给数据。这像点火：发动机转起来以后靠自己烧的油，点火用的那一点油不随油箱变大而变多，油箱越大，点火占的比例越小。

所以"低导频起不来"不是叠加导频固有的毛病，是帧短（时间带宽积小）的毛病。帧能加多长，由信道参数在一帧里能稳住多久决定：平台有加速度时，多普勒在帧内漂移，漂移量按帧长的平方涨。

## 锚点（出处）

- 锚点 C（多数论文的默认 + 实际情况的证据）：SP-OTFS / SP-AFDM 论文在固定帧上给最优导频功率（Mishra 等 TWC 2022，arXiv 2010.15066：按 SINR 下界求功率分配，约 .30–.36，只看了摘要与 res-20261008-01 的转述；本项目 res-20261119-06：ρ* = .25–.30，ρ < .25 崩塌）。没有一张卡或资产卡检验过 N（`grep` 全部卡片：无帧长缩放的卡）。FUNNEL.md「参数与适用范围」：N 是随手定的基础设定。
- 本项目数字：A4 读数（`experiments/data_pilot_fer_20261121/STAGEA4_READOUT.md`）里纯导频多普勒下界 ρ = .10 / .20 为 .085 / .058 bin，比值 1.47 ≈ √2，即误差 ∝ (ρ·N)^(−1/2)；A3：第 0 轮多普勒误差 ≤ 0.05 bin 时收益全保住，容忍度以 bin 计（与 N 无关）。
- 推导（单径、每样点导频对干扰加噪声之比 γ_p = ρ|h_p|² / ((1−ρ)P_tot + σ²)）：已知恒模序列的多普勒下界，以 bin 计的标准差 = √6 / (2π √(γ_p N)) = 0.39 / √(γ_p N)。代入 ρ = .10、|h_p|² = 1/8、σ² = 0.4（4 dB）：γ_p N = 9.85，标准差 0.124 bin，平均绝对值 0.099 bin（A4 的 pilot_white 功率加权值 .085，量级一致）。捕获的离群概率同样只经 γ_p N 进入。逐样点的量（数据检测 SINR、增益相对误差 1/(γ_p N)、以 bin 计的多普勒误差造成的载波间干扰）在 ρ·N 不变时都不变，而数据功率 1−ρ 变大。所以 (N, ρ) → (2N, ρ/2) 后第 0 轮与后续环路的起点相同，数据多得 10·log10((1−ρ/2)/(1−ρ))。
- 代入：(1024, .25) → (2048, .125) 多 0.67 dB；→ (4096, .0625) 多 0.97 dB；极限 1.25 dB（导频功率损失全部消失）。
- 探针（`~/.cache/idea-funnel/afdm-20261122-l4/probe_nscale.py`，时域玩具模型：8 径、指数功率谱、整数时延已知、每径 ±0.75 bin 内搜多普勒、4 dB；实际跑了 106 秒，超出 30 秒限，如实记录）：功率加权平均误差 / 误差 > 0.25 bin 的径占比——(1024, .25) .064 / 5.5%；(2048, .125) .064 / 4.1%；(4096, .0625) .063 / 4.6%；(1024, .125) .093 / 14.7%；(2048, .0625) .094 / 12.3%；(4096, .03125) .093 / 13.5%；(1024, .10) .106 / 17.6%（项目实测：阶段 A 的 .157 与 c23 的 11.9–16.1%，量级一致）。ρ·N 相同的三组读数相同。
- N 的上限：卡 11 的粗算（fc 12 kHz、fs 8 kHz）帧内多普勒漂移 ≈ 0.13·a bin（N = 1024，a 以 m/s² 计），按 N² 涨：N = 2048 时 0.52·a bin。以均方根失配 0.04–0.05 bin 为限，不补偿多普勒变化率时 a ≤ 约 1 m/s²（N = 1024）或 0.26 m/s²（N = 2048）。于是 N_max ∝ a^(−1/2)，最小导频份额 ρ_min ∝ √a。时延漂移（c12：v = 2 m/s 时 N = 1024 整帧漂 1.3 抽头）按 N 线性涨，公共重采样后只剩径间差。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：本项目的悬赏靶 #0 与 `11-21-data-pilot-fer` 都在 N = 1024 上追 ρ ≤ .12 的 0.8–1.2 dB；SP-OTFS / SP-AFDM 论文（Mishra 等 TWC 2022；Kanazawa 等）在一个固定帧上报最优导频功率，不报它随帧长怎么变。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：如果信道允许把相干处理的帧加长一倍（两个码字共用一帧的信道估计），朴素做法"加长帧、导频减半"就拿到约 0.67 dB，N = 4096 时约 1 dB，与悬赏靶要求的 0.8 dB 同量级，不需要任何新前端。决定的是：悬赏靶值不值得做，取决于 N 能不能加长；论文必须写明 N 的取值依据（加速度或径间伸缩差），否则审稿人一句"把帧加长"就消掉动机。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：自举接收机里导频只为过"起步门限"付费，门限由攒到的导频能量 ρ·N 决定；训练式（先估后检、不迭代）接收机的导频开销按相干长度的平方根律缩放，联合处理时只需每相干块约一个导频（Jindal–Lozano–Marzetta）。帧长被信道动态卡住：多普勒漂移 ∝ a·N²。不存在算法上的难处，这是一条设计边界。

## 最接近的已有工作

1. N. Jindal, A. Lozano, T. Marzetta, "What is the value of joint processing of pilots and data in block-fading channels?", ISIT 2009，arXiv:0905.0838（读了摘要与定理 1）：块衰落、插入导频、互信息下界；结论"联合处理时每个相干块至多一个导频符号"。与本卡同一条原理（联合处理下导频开销 ∝ 1/相干长度）。差别：它是块衰落的信息论界，没有叠加导频、稀疏时延–多普勒信道和第 0 轮门限；本卡不声称新原理。
2. N. Jindal, A. Lozano, "A unified treatment of optimum pilot overhead in multipath fading channels", IEEE Trans. Commun. 2010，doi:10.1109/TCOMM.2010.083110.090696（只读了摘要）：先估后检时最优导频开销与损失都按归一化多普勒的平方根缩放。这是训练式接收机的 N^(−1/2) 律，本卡的 N^(−1) 是自举接收机的对应物。
3. H. B. Mishra 等, "OTFS channel estimation and data detection designs with superimposed pilots", IEEE TWC 2022，arXiv:2010.15066（只读了摘要）：SP-OTFS 按 SINR 下界分配导频与数据功率，固定帧；没有给最优份额随帧长的缩放，也没有把迭代接收机的起步门限当约束。
4. 本项目 res-20261008-01、res-20261119-06：N = 1024 上的 ρ 扫描；卡 11（停放）：加速度门槛粗算，没有与帧长联系起来。

## 价值与代价

- 价值 1（前提检查，不是新算法也不是新原理）：原理是 Jindal–Lozano–Marzetta 的已知结论在本系统上的读数。它只给 Eric 一条论文边界建议和一条对悬赏靶的提醒。
- 适用范围：单帧内径参数恒定（时延、多普勒不漂）；改动的参数只有 N（与同步减小的 ρ）。对小时间带宽积的链路（水声、窄带卫星物联网，N 约 10³）成立；宽带链路（N ≥ 10⁴）里 ρ* 本来就只有百分之一量级，叠加导频的功率税可以忽略，悬赏靶在那里不存在。受影响的卡：01（悬赏靶）、`11-21-data-pilot-fer`、l02（匹配码的收益与 ρ 的关系）、11（加速度门槛）。
- 最便宜的致命检验：N = 2048、两个 n = 2048 码字共用一帧，ρ ∈ {.10, .125, .15} 对 N = 1024、ρ = .25 的 1% 误帧率穿越点（同总能量、同码、同信道参数的物理值）。跑前判据：N = 2048 的最优 ρ ≤ .15 且穿越点好 ≥ 0.4 dB 则成立；好不到 0.2 dB 则否定（说明环路里有随 N 变坏的环节）。代价：现有 L2 管线把 N = 1024 与码长绑定在冻结上下文里，要改帧映射和上下文，估半天编码 + 约 10 核时，超出 L2 上限。
