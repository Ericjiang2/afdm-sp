## 问题（一句话）
实测 `orig_front` 在 `10` 径信道上固定输出约 `24` 条径、假径率（FDR）高达 `57–73%` 且占据 `22–62%` 估计功率，把远域的复数 Benjamini-Hochberg FDR 支撑选择引入第 0 轮以压低假径率，能否改善低 `rho` 下的最终 `FER`？

## 白话与类比
渔网眼织得太密会捞上来六成杂草（假径），按统计学 FDR 把网眼放宽后杂草确实降到了 2%，但顺带把几条关键的小鱼（真实弱径）放跑了，结果整网收益反而崩盘——说明第 0 轮“宁可多捞杂草也不能漏掉弱鱼”。

## 锚点（出处）
- `D` 锚点：远域方法迁移（高维统计/DOA 复数 FDR 控制 `CT-Rex` → AFDM-SP 第 0 轮稀疏支撑检测），直接呼应项目“幻影接纳定律”。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：`orig_front` 在 `P=10` 真实信道上固定接纳约 `24.0` 条径，20 帧实测假径率 `FDR` 达 `73.3% (rho=50)`、`66.9% (rho=100)`、`64.0% (rho=150)`、`57.1% (rho=250)`，假径占据 `62.4% / 45.3% / 34.8% / 21.7%` 的估计功率。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：若用 BH-FDR（在原假设 `|g_hat_i|^2 ~ Exp(sigma_null^2)` 下按 `p_(k) <= q * k / m` 控假发现率 `q=0.25`）压缩假径能降 FER，则应把第 0 轮支撑检测改为自适应 FDR 门限；最朴素替代是保留过度接纳的 `orig_front`（`24` 条径）。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：支撑检测面临“漏真弱径（`miss_pw`）”与“接假径（`FDR`）”的不对称代价。实测揭示该代价高度不对称：多漏掉 `1.4%` 真实功率（`miss_pw: 0.010 -> 0.024`）带来的均衡失配，远比留着 `64%` 假径更致命。

- `doi:10.1109/TRS.2024.3467549`（Baydoun et al., IEEE TRS 2024, CFAR Compressed Detection in Heavy-Cluttered Indoor Environments Using IR-UWB Radar）：研究距离-多普勒域压缩检测与 CFAR 恒虚警门限。
- `arXiv:2011.10849`（Efficiently Estimating a Sparse Delay-Doppler Channel）：研究高维稀疏时延-多普勒信道的随机化支持集恢复，假设精确 `k`-稀疏而未考察迭代接收机对漏径功率的极端敏感性。

- 本机 CPU 代价：< 1 分钟（单核无 GPU）。

## 筛选记录
- 2026-11-21 L1 深想：方法：G12 远域方法迁移（复数统计 FDR 控制 → 信号模型/推断层第 0 轮支撑检测）。
- 2026-11-21 L2 真实 `stageA` 检验（20 帧，`U`，`snr=400`，单核 CPU < 1 分钟）：
  - `rho=100`：`base`（`24` 径）`FDR=0.669, miss_pw=0.020, FER=0.45`；`BH25`（`5.2` 径）把 `FDR` 压到 `0.133`，但 `miss_pw` 升至 `0.096`，`FER` **恶化到 `0.75`**；`top8`（`FDR=0.325, miss_pw=0.071`）`FER` 也恶化到 **`0.60`**。
  - `rho=150`：`base`（`24` 径）`FDR=0.640, miss_pw=0.010, FER=0.25`；`BH25`（`4.2` 径）把 `FDR` 压到 `0.021`，但 `miss_pw` 升至 `0.124`，`FER` **暴涨到 `1.00`**；即使 `top8` 仅把 `miss_pw` 从 `0.010` 提到 `0.024`，`FER` 仍恶化到 **`0.40`**！
- 2026-11-21 淘汰（`killed`）：一句话教训——第 0 轮支撑检测的损失高度不对称：多漏 `1–2%` 真实弱径功率比保留 `64%` 假径更毁 FER，因此 BH-FDR 硬控假径率在迭代 AFDM-SP 第 0 轮适得其反（过接纳是安全网，假径应留待第 1 轮数据辅助重估清洗）。
