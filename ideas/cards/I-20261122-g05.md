## 问题（一句话）

父卡 `I-20261121-c16` 仅把多水听器（`SIMO`, $M\ge 2$）用于第 0 轮导频匹配滤波非相干能量合并，因各阵元接收同一未知数据向量 $\mathbf{d}$ 而只能按 $1/\sqrt{M}$ 压低干扰涨落（$\rho=0.05\text{–}0.10$ 时 $M=4$ 仍达不到 `STAGEA3` 的 $0.040\text{ bin}$ 门槛）；若利用从 $M=1$（零维正交补）到 $M\ge 2$（$(M-1)N$ 维**精确无数据干扰正交补**）的维数相变，通过 $N\times N$ 带状 Woodbury 消数据半盲似然估计共享时延–多普勒，能否在仅 $\rho=0.02\text{–}0.05$（$2\%\text{–}5\%$ 导频功率）下把第 0 轮多普勒误差压到 $0.013\text{–}0.022\text{ bin}$（比 `c16` 准 $4.5\text{–}8.6$ 倍），彻底省掉 $25\%$ 叠加导频的 $1.1\text{ dB}$ 功率税？

## 白话与类比

单水听器接收叠加导频信号时，就像用一只麦克风听“微弱的约定暗号（导频）+ 震耳欲聋的陌生人说话声（未知数据）”：你有 1024 个采样方程，却刚好有 1024 个未知数据符号，未知数据把所有方向塞得满满当当，连半点干净缝隙都不留（所以 `STAGEA4` 测出单水听器半盲下界在 $\rho=0.10$ 时卡在 $0.040\text{ bin}$ 悬崖边上，再降导频就掉下去）。父卡 `c16` 想到真实水声 modem 本来就带 2 到 4 只水听器，但它只是把几只水听器的导频相关能量简单加起来——每个通道里那份“同一个陌生人的说话声”原封不动还在，4 只水听器在 $5\%$ 导频下误差仍有 $0.069\text{ bin}$，照样过不了关。

本卡指出的关键转折是：**从 1 只水听器变成 2 只水听器，不是“音量翻倍”的量变，而是方程数从 1024 变成 2048、未知数据却还是同一份 1024 个符号的“维数相变”**！多出来的整整 1024 个自由度构成了一个**完全不含未知数据干扰的干净子空间**——就像两只耳朵听同一个人经过不同墙壁反射的声音，把两边的回声规则交叉一对消，陌生人说的内容什么都不用猜就能被精确减掉，只留下纯粹的信道时间差和频移线索。精确计算表明，哪怕导频功率砍到只剩 **2%**（几乎全功率发有效数据），2 只水听器的理论半盲误差下界直接降到 **$0.022\text{ bin}$**（4 只降到 **$0.013\text{ bin}$**，追平单水听器“全知数据作弊上限” $0.015\text{ bin}$），比 `c16` 的导频合并准 **7 到 8.6 倍**。

## 锚点（出处）

- **锚点 B（本项目 `STAGEA3/A4` 冻结读数与父卡 `c16` 筛选批注的定量缺口）**：
  1. `experiments/data_pilot_fer_20261121/STAGEA4_READOUT.md`（冻结）：单水听器（$M=1$）在 $4\text{ dB}$、$\rho=0.10 / 0.15$ 下的第 0 轮多普勒功率加权平均绝对误差下界为 `pilot_white = 0.085 / 0.068 bin`、`semiblind = 0.040 / 0.037 bin`、`known = 0.015 bin`；`semiblind` 在 $\rho=0.10$ 刚好压在 `STAGEA3` 全额保收益线 $0.040\text{ bin}$ 上，留给估计器次优性的余量为零（实际估计器通常差 $1.6\text{–}1.9\times$）。
  2. 父卡 `I-20261121-c16` 第 4 次筛选记录指明：多水听器跨通道非相干导频合并因共享同一数据向量 $\mathbf{d}$，只能以平方根律降方差。
- **第一性原理严格推导与 $M=1,2,4$ 精确 Slepian–Bangs 数值代入**（本机 `/opt/anaconda3/bin/python` 核验，在 $M=1, \rho=0.10$ 处与 `STAGEA4` 对齐至 `0.041 vs 0.040`、`0.016 vs 0.015`）：
  1. **$(M-1)N$ 消数据零空间相变与带状 Woodbury 约化**：令 $M$ 阵元堆叠观测为 $\underline{\mathbf{y}} = \underline{\mathbf{H}}(\boldsymbol{\theta},\mathbf{G})(\sqrt{\rho}\mathbf{p} + \sqrt{1-\rho}\mathbf{d}) + \underline{\mathbf{w}}$，其中 $\underline{\mathbf{H}} = [\mathbf{H}_1^T,\dots,\mathbf{H}_M^T]^T \in \mathbb{C}^{MN\times N}$。未知数据协方差矩阵为 $\mathbf{C}_{\text{sb}} = (1-\rho)\underline{\mathbf{H}}\underline{\mathbf{H}}^H + \sigma^2\mathbf{I}_{MN}$：
     - **$M=1$ 时**：$\underline{\mathbf{H}}\in\mathbb{C}^{N\times N}$ 满秩无左零空间（$MN-N=0$），当 $\sigma^2\to 0$ 时 $\mathbf{C}_{\text{sb}}^{-1}$ 在全空间被 $(1-\rho)^{-1}$ 锁死，仅靠稀疏多径拍频交叉项提供有限二阶信息。
     - **$M\ge 2$ 时**：由 Woodbury 恒等式，全部 $MN\times MN$ 求逆精确坍缩为单一 $N\times N$ 公共输入 Gram 算子 $\mathbf{S} \triangleq \frac{\sigma^2}{1-\rho}\mathbf{I}_N + \sum_{m=1}^M \mathbf{H}_m^H\mathbf{H}_m$：
       $$\mathbf{C}_{\text{sb}}^{-1} = \frac{1}{\sigma^2}\Big(\mathbf{I}_{MN} - \underline{\mathbf{H}}\mathbf{S}^{-1}\underline{\mathbf{H}}^H\Big) \;\underset{\sigma^2\to 0}{\longrightarrow}\; \frac{1}{\sigma^2}\mathbf{P}_{\perp}(\underline{\mathbf{H}}), \qquad \dim\mathcal{R}\big(\mathbf{P}_{\perp}(\underline{\mathbf{H}})\big) = (M-1)N.$$
       在 $(M-1)N$ 维正交补上，**未知数据自干扰 $(1-\rho)\underline{\mathbf{H}}\mathbf{d}$ 被恒等清零**（对任意大双边多普勒与非对易时变算子均严格成立，无需经典 LTI 交叉关系 $\mathbf{H}_2\mathbf{H}_1=\mathbf{H}_1\mathbf{H}_2$ 的零多普勒对易假设——本机实测双边多普勒 `G` 下未补偿 Weyl 交换子 $[\mathbf{H}_2,\mathbf{H}_1]\mathbf{d}$ 残差高达 $-6.84\text{ dB}$，直接套 LTI 交叉关系会失败，而 Woodbury 正交投影精确为零！）。
  2. **含干扰增益边缘化的精确 Slepian–Bangs 下界表**（折算至 $N=1024, P=8$，对全部 $P$ 个多普勒与 $2MP$ 个未知复增益实虚部联合求逆，`SNR = 4.0 dB`）：
     | 导频比 $\rho$ | $M=1$ (`PW` / `SB` / `Kn`) | $M=2$ (`c16 PW` / **本文 `SB`** / `Kn`) | $M=4$ (`c16 PW` / **本文 `SB`** / `Kn`) |
     |---|---:|---:|---:|
     | **0.02（仅 2% 导频）** | `.209` / `.052` / `.016` | `.154` / **`.022`** / `.012` | `.112` / **`.013`** / `.008` |
     | **0.05（5% 导频）** | `.129` / `.050` / `.016` | `.094` / **`.021`** / `.011` | `.069` / **`.012`** / `.008` |
     | **0.10（10% 导频）** | `.091` / `.041` / `.016` | `.067` / **`.020`** / `.012` | `.049` / **`.012`** / `.009` |
     在 $\rho=0.02$ 时，`c16` 的纯导频模型在 $M=2 / 4$ 下仍有 `.154 / .112 bin` 误差（完全不可用），而多通道半盲下界直接压到 **`.022 / .013 bin`**，留出 **$2\text{–}3$ 倍**估计器效率裕量仍稳过 `STAGEA3` 的 `.040 bin` 全收益线！
  3. **低复杂度无偏实现关键点（防 Berkson 收缩陷阱）**：时域 $\mathbf{S}=\frac{\sigma^2}{1-\rho}\mathbf{I}_N + \sum_{m=1}^M \mathbf{H}_m^H\mathbf{H}_m$ 是对角占优稀疏带状阵（仅 $\le P(P-1)+1$ 条非零带，8 步共轭梯度 CG 即可达 $10^{-10}$ 精度，耗时 $<2\text{ ms}$）；用 EM 最大化精确边际对数似然时，M 步期望充分统计量必须同时保留后验数据均值 $\hat{\mathbf{d}}\hat{\mathbf{d}}^H$ **与后验协方差迹修正项 $\mathbf{S}^{-1}$**（本机预检已证实：若漏掉 $\mathbf{S}^{-1}$ 把 $\hat{\mathbf{d}}$ 当确定真值代回，$\rho=0.03$ 中位误差会退化至 `.129 bin`；保留精确 EM 后验二阶矩方可逼近 `.022 bin` 下界）。

## 去壳三句

1. 谁真卡住了（点名现在的做法或论文）：本项目 `11-21-data-pilot-fer`（`STAGEA4`）在单水听器下受困于半盲下界贴线（`.040 bin`）、低导频 $\rho\le 0.05$ 无法达标，而父卡 `c16` 及现有多通道水声叠加导频做法只对导频相关器做非相干合并（$\rho=0.05, M=4$ 误差仍达 `.069 bin`），白白浪费了水声 modem 标配多水听器提供的 $(M-1)N$ 维消数据子空间。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：直接改变水声/多天线叠加导频系统的导频预算与前端架构——在标配 $M=2\text{–}4$ 水听器下无需外加同步前导，即可将叠加导频功率占比从 $\rho=0.25\text{–}0.30$ 压低至 **$\rho=0.02\text{–}0.05$**（仅数据有效功率就净赚 **$1.05\text{–}1.35\text{ dB}$**，叠加 $M$ 通道合并再省多普勒重搜开销）；换成最朴素但不犯傻的 `c16` 跨阵元联合导频最小二乘（忽略跨通道公共数据协方差结构），在 $\rho=0.02\text{–}0.05$ 下多普勒误差大 **$4.5\text{–}8.6$ 倍**（`.094–.154` vs `.021–.022 bin`），被迫退回高导频比而白亏约 **$1.0\text{ dB}$** 净能量。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：现有办法要么忽略跨阵元噪声中的公共信号秩-$N$ 结构（`c16`），要么照搬静态 LTI 盲交叉关系 $\mathbf{H}_2\mathbf{y}_1-\mathbf{H}_1\mathbf{y}_2$ 却被双选多普勒算子的非对易 Weyl 交换子残差（实测 $-6.8\text{ dB}$）打穿，要么直接对 $MN\times MN$ 协方差求逆导致 $O(M^3N^3)$ 算不动；通过 Woodbury 将问题约化到单一 $N\times N$ 时域稀疏带状阵 $\mathbf{S}$，用共轭梯度 + 含 $\mathbf{S}^{-1}$ 迹修正的精确 EM（Hutchinson 随机迹或带状逆对角提取），既免疫双选非对易性又将复杂度压至 $O(MPN)$。
