## 问题（一句话）
在 N = 1024、c1 = 5/(2N)、ZC 根 r = 7 的叠加导频 AFDM 里，导频自己有一张"时延–多普勒模糊格"：时延差 Δℓ 与多普勒差 Δν 满足 Δν ≡ ±a·Δℓ (mod N)、a = 2N·c1 + r⁻¹ (mod 2N) 的两条径，对导频几乎是同一条径；这张格的最小间隔决定"第 0 轮单靠导频能无歧义分辨的最大时延扩展"，它能不能通过选 r 来设计，且在水声常见的"径间多普勒差很小"时能不能翻倍？

## 白话与类比
把导频想成一首只有一个音调在滑动的"滑音"。一条回声晚到 ℓ 个采样，又带了 ν 的频移，在滑音上听起来像是"换了一个起点"：滑音的特点是晚到和频移可以互相抵消。所以总有一些（晚到多少，频移多少）的组合，听起来和"没晚到、没频移"几乎一样。这些组合排成一张规则的网格。网格的疏密由 ZC 序列的根号 r 决定。r 选得好，第一个"听起来一样"的组合出现在 256 个采样（16 ms）之外；选得差，4 个采样就撞上。项目用的 r = 7 正好是好的一类，所以此前换导频序列的实验（c10）看不出差别，那是因为时延被限制在 102 以内、没碰到网格。一旦水声的时延扩展超过 7 ms，这张网格就会出现。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：用 ZC 叠加导频做第 0 轮找径的 SP-AFDM/SP-OTFS 接收机（2404.10232 一类）和本项目 F0 前端。它们默认导频序列"够好"，项目在 ℓ ≤ 102 内验证过（c10），没有人写出导频能分辨的最大时延扩展是多少、怎么靠根号调。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：改变两个决定：叠加导频的 ZC 根号怎么选（现在默认随便挑一个互质的数；r ≡ 3 (mod 8) 的根号时延间隔上限 ≤ 128，r = 51 时只有 4 个抽头），以及水声时延扩展超过 7 ms 时"导频一侧"的可用上限是多少。最朴素做法是沿用 r = 7：它已经属于最优类（r ≡ 7 mod 8，上限恰为 256 个抽头），所以对当前主线损失是 0。收益只出现在两处：避免别人选到坏根号；在径间多普勒差 ≤ 1 个格点（共同多普勒已去掉，见 c25、c29 的路线）时改用 r ≡ 1 (mod 4)，上限从 256 翻到 512 个抽头。损失上界：按下面的估算，在 RMS 时延扩展约 10 ms 的信道里，这 256 个抽头处的撞车只影响约 4% 的帧。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：导频的时域形式是 chirp，s_p[n] ∝ exp(jπ a n²/N)，a = 2N·c1 + r⁻¹ (mod 2N)。延迟 ℓ 加多普勒 ν 的原子与参照原子的相关是一个 Dirichlet 核，峰值在 ν + aℓ ≡ 0 (mod N)，即模糊点集是格 Λ = {(ℓ,ν): ν ≡ ∓aℓ (mod N)}，行列式 N。Minkowski 定理给出任何 r 都躲不开的界：矩形 [−L,L]×[−B,B] 只要 L·B ≥ N 就含非零格点，所以"时延扩展 × 多普勒差"在格意义上不能超过 N，这和空间扩展面积 ≤ 1 的可辨识性界（Heckel–Bölcskei）同形。数论部分：2N·c1 = 5 为奇、r⁻¹ 为奇，故 a 恒为偶；纯时延模糊（Δν = 0）出现在 ℓ0 = N/gcd(a, N)。r ≡ 1 (mod 4) 时 a ≡ 2 (mod 4)，ℓ0 = N/2 = 512；r ≡ 7 (mod 8) 时 a ≡ 4 (mod 8)，ℓ0 = N/4 = 256；r ≡ 3 (mod 8) 时 8 | a，ℓ0 ≤ N/8 = 128，r = 51 时 a 被 256 整除，ℓ0 = 4。ν 方向的近似模糊来自 ‖aℓ/N‖，是联立丢番图逼近问题。设计规则因此是：按径间多普勒差的范围 B 选 r。B ≤ 1 选 r ≡ 1 (mod 4)，B ≥ 2 选 r ≡ 7 (mod 8)。

## 最接近的已有工作
- **3GPP PRACH ZC 根号与限制集**（本次搜索的专利转述，未打开标准原文）：同一机制：多普勒让 ZC 相关峰偏移 d_u，办法是限制循环移位。差别：那里是一维 ZC 加频偏，没有 AFDM 的 c1 项，也没有"根号决定可分辨的时延上限"这个设计问题；本卡给出 a = c1 项 + r⁻¹ 的闭式。
- **arXiv 2502.14203**（AFDM-ISAC 导频与模糊函数）：搜索摘要说它为感知优化模糊函数，并说 c1 控制各径在 DAFT 域的分离、c2 控制相位。我没有打开全文，故不确定它是否写了根号规则。差别：它面向感知与导频间隔，不针对叠加导频的数据干扰，也没有按根号的算术给出时延上限。
- **Zheng 等，arXiv 2404.10232**（AFDM 叠加导频）：DAFT 域稀疏叠加导频及迭代估计与检测。差别：不涉及 ZC 的根号，导频是稀疏位置而非全带。
- **Bemani 等，arXiv 2104.11331**（AFDM 满分集）：给出非重叠条件 c1 = (2k_max+1)/(2N)，这是数据检测器一侧的混叠线（本项目的 205 个抽头界）。差别：本卡的格是导频一侧的，数值上位置不同。
- **Heckel & Bölcskei，arXiv 1209.5187**（稀疏线性算子的辨识）：给出一般算子面积 ≤ 1/2、几乎所有算子面积 ≤ 1 的可辨识条件。差别：它是信息论意义上的界；本卡是一个具体导频的格，Minkowski 论证只给出同形的必要条件，实际可达上限（256）低于它（512）。

## 价值与代价
- 价值 1：对当前主线损失为 0（r = 7 已在最优类），也不改论文结论。它的作用是给"过扩展水声（ℓmax 超过 7 ms）下导频一侧的可用上限"一个闭式，并在 l12 的"打包界"之外补上第二个独立上限；若 r ≡ 1 (mod 4) 在小径间多普勒差时确实翻倍，可写成一条设计规则。
- 量级估算（项目数字）：N = 1024、r = 7 时 a = 5 + 1463 = 1468，a mod 1024 = 444；444 × 113 ≡ −4、444 × 256 ≡ 0 (mod 1024)，与数值表一致。P = 8 条径、指数时延谱均值 τ0 = 160 个抽头（约 10 ms，实测水声量级）、两径 |Δℓ − 256| ≤ 1 且 |Δν| < .5 的概率约 e^{−256/160}/(2·160) × 3 × 0.5 ≈ 1.5e-3，28 对约 4% 的帧；撞上时相干 .84，联合估计两径的方差放大 1/(1−.84²) = 3.4（5.3 dB）。r ≡ 1 (mod 4) 把撞点推到 512：e^{−512/160}/320 × 3 × 0.5 ≈ 1.5e-4，28 对约 0.4%。所以真实收益上界约 4 个百分点的帧，实际可能 1–2 pp，数据迭代还会再吃掉一部分。
- 适用参数范围：N = 1024（N 为 2 的幂）、K = 2N·c1 = 5、r 为奇数；径间多普勒差范围 B（B ≤ 1 与 B ≥ 2 两档）；时延扩展 ℓmax ∈ [102, 512]。当前主线默认 ℓ ≤ 102、r = 7，不在受影响范围内，不需要改默认参数。其他 N 和 K 只有格公式是一般的，具体的 mod 8 / mod 4 分类只在 N = 1024、K = 5 上数值验证过。
