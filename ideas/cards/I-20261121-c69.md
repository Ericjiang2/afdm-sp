## 问题（一句话）
同一帧上 base（整数网格）与 g25 两个前端各跑 F0，取 F0 校验子权重较小者再跑 A1，FER 是否低于单用 g25。

## 白话与类比
两把尺子各量一次，留读数更自洽的那个。

## 锚点（出处）
- D：c48（g25 vs base 同帧 b/c 仍有 c > 0，base 有时更好）。

## 去壳三句
1. 谁真卡住了：g25 仍有约 4% 的帧 base 能救而 g25 救不了（循环 6 c = 64/1600）。
2. 解决了会改变什么：若择一有效，前端可以用两个便宜前端代替一个更贵的。
3. 难处的结构：F0 校验子是否能预测 A1 后谁成功。

## 推导（项目数字）
- 上限：g25 失败而 base 成功的帧 c = 64/1600（4.0%），这是择一能收回的上限；g25 成功而 base 失败 211 帧是择错的风险。
- 实测（sel vs g25）：U .10 .318 → .295（b 16, c 7）；U .15 .115 → .107（7, 4）；G .10 .323 → .338（8, 14）；G .15 .117 → .115（7, 6）。合并 b − c = 7，p = .47；选 base 的比例 31%。F0 CPU .39 → .58 s。
