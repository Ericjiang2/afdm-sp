## 问题（一句话）
g25 与 g25off 两个前端都跑完 F0 + A1，任一 A1 后校验子为 0 就取它，2 倍算力能买到多少 FER？

## 白话与类比
两个人独立答题，只要有一人的答案通过验算就交卷；验算（LDPC 校验子）几乎不会放过错答案。

## 锚点（出处）
D：c73 预注册要求先核对可观测性——本批 11200 个臂·帧里 a1_syn = 0 而 a1_err > 0 的漏检为 0（Wilson 上界约 3.4e−4），所以"校验通过"可作为选择信号。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：当前接收机单前端，A1 失败即丢帧；c69/c72 只用 F0 校验子选，信息弱。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：或分集按构造 c = 0（只在 g25 失败而另一臂通过时替换）；朴素做法是单前端，损失是全部 b 帧（本批 63/1600）。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：难处是 2 倍算力；可行的关键是 LDPC 校验子为 0 几乎等价于译对（0 漏检）。
