## 问题（一句话）
父卡 l12 测到：时延上限从 102 抽头放到 400 抽头，完整接收机多付 1–2 dB，而给真信道时没有损失。这份损失是"字典变大"造成的，还是现用 ZC 导频在时延–多普勒平面上有近乎完全相同的"孪生位置"造成的？如果是后者，只把叠加导频换成随机相位序列，损失能否降到 0.5 dB 左右，使"单块 AFDM 的时延不能超过无混叠上限（本检验管线里 2N·c1 = 5，约 203 抽头、12.7 ms）"不再是一堵墙？

## 白话与类比
现在的导频在时间上是一段匀速滑动的哨音。哨音有个毛病：晚到一会儿再把音调挪一点，听起来和原来几乎一样。按项目自己的变换算，晚到 151 个采样、音调低 2 格的回声，与原回声的相似度是 0.84（晚到 210 个采样、音调高 4 格的是 0.98）；时延不超过 102 个采样的窗口里没有这样的"孪生位置"（最大相似度 0.38），所以现在的仿真里看不出问题。窗口一放大到 240 或 400，孪生位置进了搜索范围，接收机就会把一条回声认到它的孪生位置上：导频对得上，数据却按错的时延和频移去解，于是译不出来。

类比：用一把只有一种齿纹的钥匙去试一排锁，齿纹每隔一段就重复，开得了第 3 把也大致开得了第 154 把，你分不清手里这把是哪扇门的。换成齿纹不重复的钥匙（随机相位导频），每扇门只有一把对得上。代价是钥匙不再有规律，不能靠规律快速试；但本项目的接收机本来就是逐个位置试的。

这个 idea 说的是：时延放大后多付的那一两个 dB 属于钥匙的齿纹，不属于门。还没有验证；要看换钥匙之后误帧数是否真的回到接近原来的水平。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：AFDM 的参数设计规则（Bemani 等 TWC 2023 §III-E：各径在变换域的位置互不重叠，即 (2k_max + 1)(l_max + 1) ≤ N）被当成波形本身的限制；本项目 l12 据此得出"实测尺度的时延下单块 AFDM 的可行窗口很窄"，并建议收窄论文适用域。做感知的人知道 chirp 导频有模糊格（Ni 等 arXiv 2507.08293 的"无模糊平行四边形"），做叠加导频接收机的人（Zheng 等 2404.10232、本项目）仍默认用 ZC。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：长时延信道下叠加导频用什么序列。若换成随机相位导频就能把 2 dB 拿回大半，l12 的结论要从"论文适用域收窄到 7 ms 以内"改成"时延超过 7 ms 时换导频序列，剩下的代价是前缀开销"。最朴素的做法是保留 ZC、只把搜索窗放大：父卡已测，场景 G 在 400 抽头时多付约 2 dB。另一个朴素做法是把帧拉长：受相干时间限制（l12 的三难）。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：chirp 导频在时域是恒定斜率的调频，延迟 Δl 再频移 Δν 后，与原信号的相关是一个 Dirichlet 核，峰在 Δν ≡ a·Δl (mod N) 上，形成一张行列式为 N 的格；任何单斜率导频在"时延范围 × 多普勒范围 ≥ N"的窗口里必有孪生点（l15 的 Minkowski 论证）。数据不是 chirp，没有这张格，所以给真信道时检测不受影响。随机相位序列的模糊函数是图钉形：没有孪生点，代价是处处约 1/√N = .03 的底噪，而数据干扰本来就在这个量级。稀疏信道在图钉形探测信号下可辨识、不受"扩展面积 ≤ 1"限制，是压缩感知雷达和稀疏算子辨识的已知结论；这里要验证的是它在"有数据干扰的叠加导频 + 编码迭代接收机"里是否足以把损失拿回来。

推导与估算（本项目数字）：
- 孪生点对接收机意味着什么。第 0 轮在字典里选相关最大的原子。真径 (l, ν) 与孪生原子 (l + 151, ν − 2) 的导频响应相关 .84；对 400 条随机分数多普勒（|ν| ≤ 1.6）的径直接算，字典里最好的孪生整数原子的匹配输出是真时延处最好原子的 0.845 倍（中位数，99.8% 的径在 0.8 以上）。两个高度相关的候选要分开，有效信干比要乘 1 − .84² = .29：ρ = .30 时平均功率的径匹配信干比约 N·ρ·(1/8) / ((1 − ρ) + σ²) ≈ 38（15.8 dB），乘 .29 后还有 11，不易选错；功率只有平均六分之一的弱径是 6（8 dB），乘 .29 后只有 1.8，选错的机会约三成。选错后这条径的数据分量按错的时延和多普勒重建，数据没有孪生结构，这条径的功率变成干扰，还白占一个找径名额。
- 所以预期的图像是：强径不受影响，弱径成批认错；损失大小取决于弱径占多少功率，这一步没有闭式，要靠检验。
- 多少条径有孪生原子在字典里。字典多普勒为整数 −2…2。(151, −2) 要求真多普勒 ν ≥ 0 且 l + 151 ≤ l_cap，反向 (−151, +2) 要求 ν ≤ 0 且 l ≥ 151；(361, +2) 要求 ν ≤ 0 且 l + 361 ≤ l_cap；(210, +4)、(302, −4) 要求多普勒差 4 格，只有 |ν| 接近 1.6 的径够得着。l_cap = 102 时字典里没有孪生原子；l_cap = 240 时 l ≤ 89 且 ν ≥ 0 的径有；l_cap = 400 时 l ≤ 249 的大部分径都有。场景 U 的多普勒全为正（0.4–1.5 bin），只有 (151, −2) 这一支有效；场景 G 正负都有，两支都有效。这与父卡"G 约 2 dB、U 约 1 dB、240 比 400 轻"的次序一致，但次序一致不是证据。
- 换随机导频后剩多少。字典从 515 列变 2005 列，纯噪声下最大值的门槛按 ln(M / P_fa) 增长：ln(2005 / .01) / ln(515 / .01) = 12.21 / 10.85 = 1.125，即 0.51 dB。所以预测：随机导频在 l_cap = 400 的损失约 0.5 dB，而不是 2 dB。
- 极端情形核对：l_cap = 102 时两种导频应无差别（卡 10 的 L2 在 60 帧上已测到无差别）；给真信道时导频序列不应有任何影响。

## 最接近的已有工作
1. A. Bemani, N. Ksairi, M. Kountouris, "Affine Frequency Division Multiplexing for Next Generation Wireless Communications", IEEE TWC 2023（arXiv 2204.12798，§III-E 已读）：给出"各径位置互不重叠"的 c1 条件，目的是满分集和嵌入导频估计；没有讨论叠加导频下这个条件是否仍是必要的。
2. R. Cao 等, "AFDM Channel Estimation in Multi-Scale Multi-Lag Channels", arXiv 2405.02660（读了正文相关段）：定义两径在变换域重叠的概率（COP）并用 c1 控制它，是"稀疏信道按碰撞概率而不是最坏情形设计"的先例；讨论的是数据侧矩阵的重叠，导频仍是嵌入式，没有涉及叠加导频的模糊格。
3. Y. Ni 等, "Ambiguity Function Analysis of AFDM Signals for Integrated Sensing and Communications", arXiv 2507.08293（读了 §III-C）：给出 AFDM chirp 子载波的周期性模糊函数和"目标须落在无模糊平行四边形内"的条件；面向感知，没有连到通信接收机的误帧率，也没有提出用非 chirp 叠加导频绕开。
4. F. Zhang 等, "AFDM-Enabled Integrated Sensing and Communication: Theoretical Framework and Pilot Design", arXiv 2502.14203（只读摘要）：推导导频辅助 AFDM 的模糊函数，提出新的导频设计以"克服由导频间隔带来的感知与信道估计范围限制"；是嵌入式多导频的设计，需读全文确认它是否已经覆盖叠加导频与过扩展时延。
5. M. Herman, T. Strohmer, "High-Resolution Radar via Compressed Sensing", IEEE TSP 2009（arXiv 0803.2257，只读摘要）与 R. Heckel, H. Bölcskei, "Identification of Sparse Linear Operators", IEEE TIT 2013（arXiv 1209.5187，只读摘要）：非相干探测信号下稀疏时延–多普勒目标在 N × N 网格上可恢复；稀疏算子在支撑面积 ≤ 1/2 时可辨识且不限制总扩展范围。这是原理来源；它们没有数据干扰、没有编码反馈。
6. 卡 `I-20261122-l02`（同父卡的子卡）：保留 ZC，只翻转前缀末端 113 个采样的导频相位来拆开孪生点；它的数字是按 2N·c1 = 9 推的，要重算；我用项目变换按实际参数算了翻转 113 个采样后的孪生相关：(151, −2) 从 .84 降到 .64，(361, +2) 从 .85 降到 .65，(210, +4) 从 .98 降到 .78，而随机导频处处 ≤ .10。本卡的检验同时回答它的前提（损失是否来自孪生点）。

## 价值与代价
价值 2：改变一个系统的设计（长时延下叠加导频序列的选法），并把 l12 的前提问题变成一个有解的问题；若成立，同样的话适用于任何用单斜率 chirp 或周期序列做叠加导频的时延–多普勒波形。它不改变现稿默认参数下的任何结论（l_cap = 102 内两种导频等价）。
适用范围：N = 1024、2N·c1 = 9、8 条整数时延径、理想长前缀、窄带频移；时延上限 102–400 抽头（6.4–25 ms）；多普勒 ±1.6 bin 内。结论依赖"径数远小于 N"（稀疏）；径很多或成簇时图钉形底噪会累加，要另测。前缀开销（400 抽头时 28%）不因换导频而消失。对其他卡：若成立，l12 的"估计层 2 dB"大半归于导频序列，22-l02 的前缀翻转被更简单的做法支配，l15 的"选根号"只是在格里挪位置；c06 / c08（分数时延）不受影响。
最便宜的致命检验（需 deinlab，约 0.7 核时，只用已有代码）：复用 `ideas/l2/l2_r2_batch1.py` 的扩窗管线和 `ideas/l2/l2_20261121.py::swap_pilot`，新帧，场景 G，ρ = .30，5 / 6 / 7 dB，时延上限 102 / 240 / 400，导频 ZC 对随机相位，同帧同数据同噪声配对，读真信道、F0、`CODELAY` 三臂的错帧数和第 0 轮找到的真时延个数。一刀否掉它的结果：l_cap = 400 时随机导频的 `CODELAY` 错帧数与 ZC 相差不到四分之一（说明损失来自字典变大，不是孪生点）。
