## 问题（一句话）
当信道是 P 条稀疏径加一个能量占比 κ、覆盖 M_t 个时延–多普勒分辨单元的弥散尾时，叠加导频（SP）AFDM 接收机该不该为尾建模（HSD 式）？“值得建模”的判据，是不是每个尾单元分到的导频信噪比 s_t = Nρκ / (M_t σ_c²) 是否过 1，从而在 SP 的可行 ρ 范围内这个窗口基本是空的？

## 白话与类比
两派文献说的是相反的话。一派说：只要稀疏径抓对，尾可以当噪声。另一派说：连尾一起建模，BER 更好。其实两派用的导频量不同。

打个比方：要在一片雾里分辨一盏灯的光晕形状，得有足够的光子打到每一小块上。训练序列占满全部符号时，每一块都有很多光子，建模有用。叠加导频只拿出 10–30% 的功率，雾又被切成上百块，每块分到的光子比噪声还少，建模只是在拟合噪声。

所以预言是：在 SP 里，尾要么弱到可以当白噪声（损失不到 0.15 dB），要么强到损失明显（约 1 dB）但仍估不出来。想把“建模尾”的收益提到 0.3 dB 以上，要同时满足 κ ≥ −10 dB 和 ρ ≥ 0.25。这个区间很窄。

## 锚点（出处）
- 类型 D：HSD（hybrid sparse/diffuse）信道估计文献与 SP-OTFS/AFDM 文献互不引用。前者是 Michelusi、Mitra、Molisch、Zorzi 等的 HSD 模型，在 SPACE08 实测上报告“HSD 估计器优于纯稀疏和 LS”。后者是 SP 的一整串工作（Mishra TWC'22、Wei 等 off-grid SBL TWC'22，以及 Kanazawa 等 arXiv 2501.15935 的编码 SP-OTFS，v3 2026-02）。后一类里我没有搜到谁处理弥散尾。
- 类型 A：Lyu、Ferreira Da Costa、Mitra, *Atomic Hybrid Sparse/Diffuse Channel Estimation and Cramér-Rao Bounds Analysis*（arXiv 2605.01825，2026）。该 CRB 分析在 OFDM 训练设定里做；SP 下数据自干扰会抬高有效噪声，是它没有覆盖的设定（我只读了检索摘要，未读全文，这一点待核）。
- 同一议题的另一侧：arXiv 2611.13699（残差闭环 SAGE-Brent 估计）的检索摘要写道，尾能量对路径检测可忽略，对均衡有害，对频域求逆又有利。三种说法互相矛盾，正是需要“统一条件”的地方。

## 去壳三句
1. 谁真卡住了：想把 HSD 搬进 SP-AFDM 的人。现有 SP 接收机（本项目的 F0、CODELAY 等）只估 P 条稀疏径，把尾和 σ² 一并当白噪声。HSD 文献没有回答“导频只占 10–30% 时，建模尾是否还有收益”。
2. 解决后改变的设计决定：要不要在 SP 接收机里加尾模型（对角协方差、原子范数或岭项）。最朴素做法是“只估稀疏径，尾并入 σ²”。代入本项目数字，这样做在 κ = −15 dB 时至多亏 0.15 dB，在 −10 dB、ρ = .25 时至多亏约 0.4 dB（下一节推导）。结论是不建尾模型，省一层复杂度。这是一个窄的工程取舍，不是原理。
3. 难处的结构：SP 的“尾单元的有效观测”被三件事压低：数据自干扰（第 0 轮）、尾自身的噪声化、导频只有 ρ 份功率。判据 s_t 是 Fisher 信息比。窗口为空是靠“每单元导频能量”这个量，不靠任何接收机机制。

## 最接近的已有工作
1. Michelusi、Mitra、Molisch、Zorzi 等，HSD 信道模型与 UWA 估计（OCEANS'11 与后续；SPACE08 实测）：在训练序列占满符号的设定里，HSD 优于纯稀疏。差别：训练设定的 ρ = 1 等效，每单元信息量大（s_t ≈ 1.5，见下），本卡问的是 ρ ≤ 0.3 的叠加设定。
2. Lyu、Ferreira Da Costa、Mitra，arXiv 2605.01825（2026，原子 HSD 加 CRB）：给出 HSD 的估计下界。差别：它在 OFDM 导频设定下，没有“数据叠加在导频上”的有效噪声项（只读检索摘要，未读全文）。
3. Wei、Yuan、Li、Yuan、Ng，off-grid SBL for OTFS（TWC 2022）：把分数时延和多普勒当超参数，动机是“分数偏移破坏稀疏性”。差别：它处理的是点径偏离网格，不是连续弥散尾。
4. Berger、Zhou、Preisig、Willett 与 Berger 等，UWA 压缩感知（arXiv 1002.2677）：稀疏估计的实务说明（检索摘要）。差别：没有把尾当作与导频比例相关的可辨识度问题。
5. arXiv 2611.13699：尾“对检测可忽略、对均衡有害、对频域求逆有利”的混合叙述（检索摘要）。差别：它没有给出“何时有利”的定量判据。本卡给的 s_t 是候选判据，尚未检验。

## 价值与代价
**推导（待实测核对；假设：N = 1024、P = 8、σ² = 0.316 对应 5 dB、尾为 M_t 个独立复高斯单元、总信道功率归一为 1；所有 σ_c² 取收敛后——数据已译码消除——这对 HSD 最有利，符合教训 16 的口径）：**

- 收敛后有效噪声：σ_c² = σ² + κ(1−ρ)。
- 每个尾单元的导频估计信噪比：s_t = Nρ·(κ/M_t) / σ_c²。MMSE 能去掉的尾方差比例：s_t/(1+s_t)。
- 代入 κ = 0.03（−15 dB）、ρ = .15、M_t = 64：s_t = 1024×.15×.03/64 / (0.316+0.026) = 0.072/0.342 ≈ 0.21，去除比例约 17%。
- 代入 κ = 0.1（−10 dB）、ρ = .25：s_t = 1024×.25×.1/64 / (0.316+0.075) = 0.40/0.391 ≈ 1.0（取 M_t = 64 时的数值，σ_c² 以 0.391 代入）。
- 训练设定（ρ = 1，无数据自干扰）：s_t = 1024×.03/64 / 0.316 ≈ 1.5，已过 1，与 HSD 文献的“建模有益”一致，这是本卡对两派文献的调和。
- 窗口边界：ρ*(κ) = M_t σ_c² / (Nκ)。κ = 0.03 时 ρ* ≈ 0.7（超出 SP 可行范围）；κ = 0.1 时 ρ* ≈ 0.25（正好落在最优 ρ 附近）。
- 建模的上限收益（相对“尾并入白噪声”）：全知尾时 10·log10(1 + κ(1−ρ)/σ²) = 0.33 dB（κ = .03）、1.03 dB（κ = .1）。MMSE 去除后，κ = .1、ρ = .25 时约 0.4 dB（残余方差 0.316 + 0.0375，对基线 0.391，比值 1.106），κ = .03 时约 0.05–0.1 dB。

**默认了什么（教训 15）：** 尾单元独立同分布高斯、M_t 已知、导频相关器对准。尾若在强径周围成簇（真实气泡散射常如此），有效 M_t 变小，s_t 变大，窗口会向低 ρ 移动。M_t 在 16–256 内变，ρ*(κ = .1) 在 0.06–1 间变化，所以结论对 M_t 敏感，这是该卡最弱的一环（教训 5：窄参数角）。

**价值判断：** 1。理由：结论是“不要加模块”，且只在中等 κ 的窄角里可能翻；一般情况下就是白噪声。它能独立成文的部分只有“两派文献的调和判据 s_t”，作为 Trans 论文的一节勉强，不足以单独成篇。

**代价与最便宜检验：** 本机几秒钟的 Monte Carlo 核对 s_t 公式和去除比例；deinlab 约 3 核时配对 FER：8 径加尾对总方差相同的白噪声，κ ∈ {−20, −15, −10} dB，M_t ∈ {16, 64, 256}，各 800 帧。判据写在跑前：若尾对白噪声差超过 0.3 dB，则“尾 ≈ 噪声”被否，卡转为“尾的结构为什么有害”的新问题；若差在 ±0.15 dB 内，则只留作论文一句话。
