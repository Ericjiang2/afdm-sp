## 问题（一句话）

在叠加导频双色散编码接收机面对未知谱宽与跨数量级功率的簇信道（从离散单径到 3GPP TDL 连续 Jakes 簇）时，能否将现有“点原子找径 + 固定维平坦基拟合”的设计准则替换为**跨抽头共享多普勒核的克罗内克子空间边缘似然准则**（同时管辖多轮子空间支撑重捕获与逐模态 Wiener 收缩，并配合每轮 3 个标量的轻量物理展开校准），在不改发射端与 `(3,6)` LDPC 码的前提下，同时消除离散径上的宽基自由度税与 3GPP TDL 上的盲捕获崩塌？

## 白话与类比

把无线或水声信道里的每一次墙壁、海面反射（一个时延抽头）想成夜空里的一团星云：只有平滑镜面反射时它是一个亮斑（离散单径，只需 1 个数描述），而在真实城市、高速移动或起伏海面下（如 3GPP TDL 标准信道），每个时延抽头都是一小片散开的光斑（连续多普勒簇，需要 5 到 8 个正交形状拼出来）。现在的叠加导频接收机在“怎么认光斑、怎么分配观察预算”上卡在了一个三难死胡同里：
- **按亮斑找（现行主线 `B` 与盲基展开 `SPcb` 的第 0 轮前端）**：拿一根极细的针孔去扫星云，光斑的能量被摊薄在五六个方向上，弱星云直接漏掉一半，强星云的边缘还被误当成七八颗假星星；`SPcb` 随后在每个选中的位置硬塞进 8 个自由参数且第 2 轮不再重找，结果在 3GPP `TDL_B`（8 dB、导频占 20%）下，哪怕给真时延误帧率只有 `15.9%`（给真信道为 `0.0%`），自己盲找却崩到 **`89.7%`**（升到 11 dB 仍错 `58.1%`）。
- **全按大光斑留足 8 个名额（全宽平坦基展开 `SPg_flat` / `WIDE`）**：遇到真正的单径或低速信道时，7 个空方向全在吸进噪声，在离散径场景 `P1` 上白白倒亏约 **1 dB**；遇到有 18 个强弱悬殊抽头的 TDL 时，十几个微弱尾抽头也平摊大方差，撑爆首轮自由度预算。
- **先按窄光斑算、译不出再加宽（`UNIFIED`），或直接减噪声方差定能量（`SPg_slep`）**：窄光斑起步漏掉的 25%–40% 星云边缘在第一轮就变成强干扰，把译码软信息彻底带歪，事后怎么加宽都救不回来（`J4` 上误帧率高达 `61.3%`）；而直接减掉平均噪声方差则会把将近一半刚好贴着噪声线的真抽头直接清零（`C1` 上 `SPg_slep` 误帧率反升至 `91.2%`）。

别的领域（脑磁图源定位、多任务高斯过程与雷达匹配子空间检测）处理这种“每个分量是一小片子空间”时，不拿针孔找点，也不给每个位置硬配固定维数，而是算**整片子空间的边缘证据（Marginal Evidence，即“信号落在这片子空间里的总把握减去子空间维数税”）**，并且利用一个物理不变量：**同一帧里所有反射抽头经历的是同一个移动终端的速度，因此它们共享同一张多普勒能量形状表，只差各自的总强弱**。先汇总最强几个抽头估出这张 $8\times 8$ 共享多普勒核（高速时自动张开 5 维，低速/单径时自动缩回 1–2 维），再用它给所有候选时延做核匹配子空间打分与正部软收缩，并在第 1 轮译码消去大半数据干扰后重跑一次子空间增删，就用一个准则同时打通了离散径和 3GPP 簇信道。

## 锚点（出处）

- **B1（簇信道崩塌与两难，项目实测）**：[res-20261008-02](research-assets/res-20261008-02.md)、`experiments/headroom_ladder_20261008/out/m2_test/M2_TABLE.md` 与 `afdm_sp_joint_unrolled/outputs_dpss_paired_screen_20261111_v2/summary.json`。四抽头 Jakes 簇（`J4`）给 AFDM 最高真信道分集斜率（`6.6` 对离散径 `3.3`），但参数化接收机 `B` 误帧率崩至 **`.873`**（真信道 **`.002`**）；全宽 DPSS-BEM（`M_adapt` / `WIDE`）四项预注册门全败，在 $\rho=0.3$ 离散径 `P1`（`U`/`G`）上输给 `B` **`0.87 / 1.07 dB`**；而先窄后宽的 `UNIFIED` 在 `J4`（8.5 dB）上崩至 **`61.3%`**（`WIDE` 仅 `2.5%`）。
- **B2（C1 自举悬崖、消数据失败与 3GPP TDL 盲捕获鸿沟，项目实测）**：[res-20261009-01](research-assets/res-20261009-01.md)、[res-20261010-01](research-assets/res-20261010-01.md)、[res-20261014-02](research-assets/res-20261014-02.md)、`experiments/headroom_ladder_20261008/out/c1_boot/analysis/C1_TABLE.md` 与 `out/c1_tdl/test_analysis/TDL_REPORT.md`。发射端消数据 `DDST` 因干扰子空间秩 $r_{90}\approx 0.33\text{–}0.66N$ 损伤码字而使悬崖倒退（`0.81–0.84x`）；逐抽头去偏估计能量的 `SPg_slep` 在 `C1`（$L=24, 8\text{ dB}, \rho=.2$）因弱抽头清零崩至 **`.912`**（平坦先验 `.450`）；在 3GPP TR 38.901 `TDL-A/B/C`（`d60`, $8\text{ dB}, \rho=.2$, 1000 帧）上形成三级反差：真信道 `A3` 误帧率 **`.003 / .000 / .000`** $\rightarrow$ 白送真时延平坦 DPSS `SPg_flat` **`.308 / .159 / .162`** $\rightarrow$ 无真值 `SPcb` **`.781 / .897 / .551`**（`B` 为 **`.992 / 1.000 / 1.000`**；即使升至 $11\text{ dB}, \rho=.2$，`TDL_B_d60` 上 `SPg_flat` 已达 **`.004`** 而 `SPcb` 仍卡在 **`.581`**）。

## 去壳三句

1. 谁真卡住了（点名现在的做法或论文）：叠加导频 AFDM/OTFS 接收机——无论是按离散点径设计的 `F0+CSTATE`（本项目现主线及 Zheng TVT 2025），还是点原子找径加固定维基展开的 `SPcb` / `M_adapt`（本项目 `dpss_rx.py`、Huang 等 `arXiv:2309.08177`）及先窄后宽的 `UNIFIED`——只要不事先知道每个时延是离散径还是宽多普勒簇，就在 3GPP TDL 上误帧率超 `55%–100%`，或在离散径上倒亏 `0.9–1.1 dB`。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：把接收机支撑获取、重搜与正则化的基本单元从“一维频移点原子或固定 $D=8$ 平坦块”统一改为**共享多普勒谱核下的克罗内克子空间边缘证据原子**（收发波形与纠错码不动）；最朴素但不犯傻的替代做法是用无权重的全宽 $D=8$ 块正交匹配追踪（`BOMP`）配平坦岭回归：只读探针显示，在低速/近离散 `TDL_A`（$\nu_{\max}=0.25\text{ bin}, 6.5\text{ dB}, \rho=0.3$）上朴素 `BOMP` 首轮有效信干噪比仍比核匹配子空间证据低 **`1.18 dB`**（`SPcb` 低 **`1.92 dB`**），且在高速 `TDL_B`（$\nu_{\max}=2.0, 8\text{ dB}, \rho=0.2$）仅靠第 0 轮导频块捕获仍漏掉 **`25.2%`** 弱抽头能量，必须在译码反馈后做软残差子空间重捕获才能跨过 `58% -> 0.4%` 的盲捕获鸿沟。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：难处在“单抽头能量低、无法各自定阶”与“点相关分裂簇能量、宽块撑爆自由度”同时耦合——在第 0 轮强数据干扰下，单靠一个抽头的 $D$ 维含噪投影做硬截断或无偏减噪必然误杀弱抽头，而固定窄基又把簇边缘变成自干扰毒化软符号；靠**物理层 WSSUS 克罗内克分解 $\boldsymbol{\Sigma}=\operatorname{diag}(\mathbf{e})\otimes\mathbf{C}_{\text{Dop}}$** 让全帧活跃抽头汇集估计同一个 $D\times D$ 多普勒核 $\mathbf{C}_{\text{Dop}}$，再在正交化后的 $D$ 个谱坐标上用闭式子空间边缘似然同时完成多轮支撑增删与连续谱收缩（辅以每轮 3 个标量的轻量展开校准软残差温度），难处随之消失。

2. **Z. Zhang and B. D. Rao, "Sparse Signal Recovery With Temporally Correlated Source Vectors Using Sparse Bayesian Learning," *IEEE Trans. ## 价值与代价

### 1. 关键数学推导与白送真值上限分解（G12）

在去前缀时域（酉 IDAFT 后），令候选时延 $\ell\in\{0,\dots,\ell_{\max}\}$ 的归一化 Slepian 基为 $\mathbf{E}=[\mathbf{v}_1,\dots,\mathbf{v}_D]\in\mathbb{R}^{N\times D}$（$\mathbf{E}^H\mathbf{E}=\mathbf{I}_D$，取全宽窗 $W_{\max}=2.5\text{ bins}, D=8$），第 $r$ 外轮软均值信号为 $\hat{\mathbf{x}}^{(r)}=\mathbf{p}+\boldsymbol{\mu}^{(r)}$（平均功率 $E_x^{(r)}=\rho+(1-\rho-\bar{v}^{(r)})$，残差等效方差 $s_r^2=\sigma^2+\alpha_r \bar{v}^{(r)}(1-\rho)$，每基模态归一化噪声方差 $\nu_{\text{eff}}^{(r)}=s_r^2/(N E_x^{(r)})$）。

对多径抽头矩阵 $\mathbf{H}_{\text{BEM}}=[\mathbf{h}_0,\dots,\mathbf{h}_{\ell_{\max}}]^T\in\mathbb{C}^{( \ell_{\max}+1)\times D}$ 施加物理 WSSUS 克罗内克先验 $\mathbf{h}_\ell \sim \mathcal{CN}(\mathbf{0}, e_\ell \mathbf{C}_{\text{Dop}})$（$\operatorname{tr}(\mathbf{C}_{\text{Dop}})=1$，谱分解 $\mathbf{C}_{\text{Dop}}=\mathbf{U}_D\operatorname{diag}(\mu_1,\dots,\mu_D)\mathbf{U}_D^H$）：
1. **跨抽头谱核汇集估计（免 $\nu_{\max}$ 先验）**：取前 $J$ 个强候选块（第 0 轮 $J\approx 6$，后续轮取已激活集）的匹配投影 $\mathbf{z}_\ell^{(r)}=\frac{1}{\sqrt{N E_x^{(r)}}}\mathbf{B}_\ell(\hat{\mathbf{x}}^{(r)})^H \mathbf{y}_{\text{res}}$，去噪样本协方差特征值正部截断：
   $$\widehat{\mathbf{C}}_{\text{Dop}}^{(r)} \propto \left(\frac{1}{J}\sum_{\ell\in\mathcal{S}_{\text{top}}} \mathbf{z}_\ell^{(r)}\mathbf{z}_\ell^{(r)H} - \nu_{\text{eff}}^{(r)}\mathbf{I}_D\right)_+, \qquad \hat{\mu}_d \leftarrow \max(\hat{\mu}_d, \eta_r),\;\sum_{d=1}^D \hat{\mu}_d=1.$$
   在 $N=1024, W_{\max}=2.5, D=8$ 下，真实 Jakes 核 $J_0(2\pi\nu_{\max}\Delta n/N)$ 在 $\mathbf{E}$ 上的精确特征值谱随 $\nu_{\max}$ 剧烈收缩：
   - $\nu_{\max}=2.0\text{ bins}$：`[0.275, 0.259, 0.174, 0.165, 0.107, 0.018, 0.001, 0.000]`（98.1% 能量集中于前 5 维，后 3 维为空模态）；
   - $\nu_{\max}=1.0\text{ bin}$：`[0.420, 0.381, 0.179, 0.019, 0.001, 0, 0, 0]`（98.0% 集中于前 3 维）；
   - $\nu_{\max}=0.25\text{ bin}$（慢速/准离散）：`[0.905, 0.094, 0.001, 0, ...]`（99.9% 集中于前 2 维）。
2. **闭式子空间边缘对数似然与核匹配选径准则**：旋转至谱特征基 $\tilde{\mathbf{z}}_\ell^{(r)}=\mathbf{U}_D^H \mathbf{z}_\ell^{(r)}$，单块关于抽头功率 $e_\ell \ge 0$ 的精确对数边缘似然（积分消去 $D$ 维基系数 $\mathbf{h}_\ell$，自带奥卡姆维数惩罚）为
   $$\ell(e_\ell) = -\sum_{d=1}^D \left[\ln\!\big(\nu_{\text{eff}}^{(r)} + e_\ell \hat{\mu}_d\big) + \frac{|\tilde{z}_{\ell,d}^{(r)}|^2}{\nu_{\text{eff}}^{(r)} + e_\ell \hat{\mu}_d}\right].$$
   其在 $e_\ell=0^+$ 处的导数给出无手调自由度歧义的**核匹配子空间激活统计量**：
   $$\left.\frac{\partial \ell}{\partial e_\ell}\right|_{0^+} > 0 \iff T_{\text{KMS}}^{(r)}(\ell) \triangleq \sum_{d=1}^D \hat{\mu}_d \frac{|\tilde{z}_{\ell,d}^{(r)}|^2}{\nu_{\text{eff}}^{(r)}} > 1.$$
   在空假设 $\mathcal{H}_0$ 下 $\mathbb{E}[T_{\text{KMS}}]=1$、$\operatorname{Var}(T_{\text{KMS}})=\sum_{d=1}^D \hat{\mu}_d^2 \triangleq 1/D_{\text{eff}}$，统一门限 $1 + \tau_r \sqrt{\sum_d \hat{\mu}_d^2}$ 自动随有效维数 $D_{\text{eff}}\in[1,8]$ 缩放；激活抽头在一维对数网格/2 步牛顿法最大化 $\ell(e_\ell)$ 得 $\hat{e}_\ell > 0$（彻底避免 `SPg_slep` 减噪清零奇点），联合先验 $\boldsymbol{\tau}_{\ell,d}=\hat{e}_\ell \hat{\mu}_d$ 送入多抽头 LMMSE 与 `scalar_joint_cols`。
3. **软残差跨轮重捕获与轻量物理展开**：第 0 轮 $\bar{v}^{(0)}=1$ 时弱抽头受限于 $\nu_{\text{eff}}^{(0)}\approx\frac{\sigma^2+1-\rho}{N\rho}$；第 $r\ge 1$ 外轮利用译码软符号重算残差后 $\nu_{\text{eff}}^{(r)}$ 下降 $4\text{–}8\times$，重跑子空间证据贪婪增删即可补回第 0 轮被自干扰掩盖的弱 TDL 抽头并剪除假时延。为补偿有限步非高斯软符号与残差的相关偏置，仅将每外轮 3 个物理标量 $(\alpha_r, \tau_r, \eta_r)$（噪声温度系数、证据门限倍数、谱核底噪，3 轮共 9 个可解释标量）在独立合成帧上展开校准。
