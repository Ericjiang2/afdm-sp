## 去壳三句
1. 谁真卡住了：c48 的 CPU 代价。
2. 解决了会改变什么：若成立，以约 1.1 倍 CPU 得到细网格收益。朴素替代：c48 全字典。
3. 难处的结构：局部细化只能改进已选原子的多普勒，无法补回整数网格漏掉的真径，也继承了其中的假原子。

## 推导（项目数字）
- 列数 ≤ 120（.07 倍 g25），CPU 预期接近 base。若 c48 收益来自失配回收，loc 应拿回大部分；若来自假原子减少（c54/c60），loc 继承 24 个原子中约 20 个假原子，应无收益。
- 实测：loc vs base：rho = .10 .357 → .367；rho = .15 .142 → .158；合并 b − c = −10。loc vs g25：合并 b − c = −34，p = .0001。F0 CPU .172 s。
