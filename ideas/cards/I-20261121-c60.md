## 问题（一句话）
不加密网格，只把生产整数网格的多普勒候选从 {−2, …, 2} 删到 {0, 1, 2}（列数 515 → 309），第 0 轮 FER 是否显著下降；即"去掉不可能的列"本身是否就是收益来源。

## 白话与类比
不换尺子，只把明显不会有东西的格子盖住。

## 锚点（出处）
- D：c54（失配分层不支持"失配回收"解释）、c56/c57（缩窗大幅降 FER，窗口位置不必准）。

## 去壳三句
1. 谁真卡住了：c48 的机制解释；跨模型审会追问"是网格细还是列少"。
2. 解决了会改变什么：若列数本身是主因，前端设计的方向是"压缩候选集"（先验、粗估、跟踪），而不是"加密网格"；对论文的论证也不同。朴素替代：生产网格（对照）。
3. 难处的结构：步长相同时失配损失完全不变（平均约 1.1 dB），只有噪声列数变化。

## 推导（项目数字）
- 列数 103 × 3 = 309 vs 515；噪声最大相关按 sqrt(2 ln K)：sqrt(2 ln 309) = 3.39 vs sqrt(2 ln 515) = 3.53（−.36 dB），与 g25 → 半窗的降幅（−.37 dB）几乎相同。若主因是列数，预期 pos1 对 base 的收益与 pos25 对 g25 的收益同量级（b − c 约 30）。
- 实测（pos1 vs base）：rho = .10 FER .357 [.312, .406] → .310 [.267, .357]（b 38, c 19）；rho = .15 .142 [.112, .180] → .107 [.081, .142]（b 24, c 10）；合并 b − c = 33，p = .0007。与 pos25 vs g25（同批 b − c = 38）同量级，符合预测。F0 CPU .156 → .183 s。

## 最接近的已有工作
- Chi et al., "Sensitivity to Basis Mismatch in Compressed Sensing"（IEEE TSP 2011，已打开）：失配损失。区别：本卡固定失配，只改列数，量化的是噪声列的代价。
- Wang, Kwon, Shim, "Generalized Orthogonal Matching Pursuit"（arXiv:1111.6664 / IEEE TSP 2012，已打开）：RIP / 相干性条件随字典增大而变难。区别：渐近恢复条件；本卡给迭代接收机 FER 数字。
- Berger, Zhou, Preisig, Willett, "Sparse Channel Estimation for Multicarrier Underwater Acoustic Communication"（IEEE TSP 2010，doi 10.1109/TSP.2009.2038424，已打开摘要与方法节）：过完备字典的范围设定。区别：未测范围过宽的代价。

## 价值与代价
- 价值：3（重解释 c48：一半以上收益与网格密度无关，主因是噪声列数；配合 c57 指向"压缩候选集"的设计方向）。
- 最便宜决定性检验：`cycle4.py` pos1 臂对 base 同帧配对。
