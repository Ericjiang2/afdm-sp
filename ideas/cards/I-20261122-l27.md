## 问题（一句话）
在无额外前后导、总发射能量与现用 `(3,6)` 规则 LDPC 码均不变的前提下，能否利用未知数据在 DAFT 域服从离散 QPSK 星座而非圆对称高斯分布的结构优势（$4\text{ dB}$ 下信道 Fisher 信息为高斯二阶半盲的 $3.0\times$），通过“Stein 散度解耦的软方差 M-step + 免矩阵带状时域 CG-VAMP + 支撑/多普勒联动的轻量物理驱动深度展开”在第 0 轮内打通低导频自举环，从而在 $\rho\le 0.12$ 下正面击败现行扫描最优基线（$\rho=0.25$ 处 $4.95\text{ dB}$）至少 $0.8\text{ dB}$？

## 白话与类比
现有叠加导频 AFDM 接收机在导频压到 10% 以下时直接卡死，像在嘈杂房间里只凭 10% 音量的暗号去听清 8 条墙壁回声，剩下 90% 的陌生人讲话声（未知数据）全被当成白噪声。正在推进的“数据二阶统计当导频”进了一步，把讲话声当成有回声结构的“随机高斯杂音”，但这样仍丢掉了讲话内容最关键的物理规律——每个符号在 DAFT 域里不是乱飘的圆团，而是死死钉在四个正方形顶点上的 QPSK 离散点。把 2D 精确信息量算出来：在 $4\text{ dB}$、10% 导频下，圆团（高斯）完全看不出相位旋转（相位信息量 $=0$），而四个顶点（QPSK）哪怕完全不靠纠错码，也自带 **3 倍**于高斯杂音的信道信息量，能把理论多普勒误差压到高斯半盲的一半以下（$0.018\text{ bin}$ 对 $0.040\text{ bin}$）。

可为什么把未编码 QPSK 软判决直接塞回现有接收机的信道估计器（`time_refine`）里还是起不来？因为这里藏着一堵类似射电天文自校准里“自己回声骗自己”的墙：
- 现有 `time_refine` 给所有软符号不确定度加了权重 $\beta=1$ 的整块惩罚 $\boldsymbol{\Gamma}(\mathbf{v})$，结果把信道增益一路往里缩（第 0 轮缩到真实幅度的 $0.12$ 倍，哪怕站在真信道上迭代也会缩到 $0.84$ 倍），在贪婪找径时连强径都减不干净，弱径被强径残差盖死；
- 如果图省事直接把惩罚 $\boldsymbol{\Gamma}(\mathbf{v})$ 删掉（$\beta=0$），因为软判决是从带噪观测里算出来的，它和噪声之间存在 Stein 相关性，每次回代都会把噪声当成真信号放大，信道幅度直接炸到 $1.60\text{–}1.85$ 倍，整帧 100% 崩盘；
- 只有按 Stein 引理把 $\boldsymbol{\Gamma}(\mathbf{v})$ 的职责拆开——**找径和多普勒寻优用完整 $\boldsymbol{\Gamma}(\mathbf{v})$ 防幻影，增益更新用 Stein 校准权重 $\beta_t\approx\sigma^2/v_r^{(t)}$ 保无偏（$|g|\approx 1.00$）**——再把只认标量通道增益的 `scalar_joint` 换成利用时域 $P=8$ 稀疏带状结构的免矩阵 CG-VAMP，最后把每一层的阻尼、噪声温度、Stein 权重和支撑重搜阈值展开成只有几十个物理参数的轻量深度展开网络来端到端校准，就能在不加一比特前导、不换纠错码的前提下，让 10% 导频自己爬出悬崖。

  2. `experiments/data_pilot_fer_20261121/STAGEA3_READOUT.md` 与 `STAGEA4_READOUT.md`：保住全部 $1.50\text{ dB}$ 收益需要第 0 轮功率加权多普勒 MAE $\le 0.040\text{ bin}$；在 $\rho=0.10, 4\text{ dB}$ 下，`pilot_white` 下界为 $0.085\text{ bin}$、最优纯导频为 $0.074\text{ bin}$、高斯二阶半盲 `semiblind` 为 **$0.040\text{ bin}$**（刚好压线、零次优裕量，且在 $\rho=0.05$ 退化至 $0.050\text{ bin} > 0.040$），全知数据 `known` 为 $0.015\text{ bin}$。`STAGEA4_PROTOCOL.md` 第 18 行明注：“QPSK 的有限字母表信息介于 semiblind 和 known 之间，这里没有单独计算。”

     |---|---:|---:|---:|---:|---:|

     | $5.0\text{ dB}$ | $2.85$ | $.385$ / $.000$ ($.192$) | **$.948$ / $.475$ ($.712$)** | **$3.70\times$** | $.136$ vs $.260$ |
     由此在 $\rho=0.10, 4.0\text{ dB}$ 下，未编码 QPSK 半盲局部多普勒下界约为 $\text{CRB}_{\text{known}}/\sqrt{0.639}\approx 0.015/0.80 \approx \mathbf{0.019\text{ bin}}$（不到高斯半盲 $0.040\text{ bin}$ 的一半，且不依赖多径拍频，单径同样成立）。
  2. **软符号 M-step 的 Stein 收缩–爆炸精确偏置律**：对软均值 $\boldsymbol{\mu}=\eta_{\text{QPSK}}(\mathbf{r}_x; v_r)$ 与方差 $\bar{v}=(1-\rho)-\overline{|\mu|^2}$，当 M-step 解 $(\mathbf{B}^H\mathbf{B}+\beta\boldsymbol{\Gamma}(\mathbf{v}))\hat{\mathbf{h}}=\mathbf{B}^H\mathbf{Y}$ 时，由 MMSE 正交性 $\mathbb{E}[\boldsymbol{\mu}^H\mathbf{d}]=\|\boldsymbol{\mu}\|^2$ 与 Stein 引理 $\frac{1}{N}\mathbb{E}[\boldsymbol{\mu}^H\mathbf{H}^H\mathbf{w}]=\alpha_{\text{Stein}}\bar{v}\mathbf{h}$（其中 $\alpha_{\text{Stein}}=\sigma^2/v_r$），得到逐径增益期望偏置比：
     $$\frac{\mathbb{E}[\hat{\mathbf{h}}(\beta)]}{\mathbf{h}_{\text{true}}} = \frac{\rho + (1-\rho-\bar{v}) + \alpha_{\text{Stein}}\bar{v}}{\rho + (1-\rho-\bar{v}) + \beta\bar{v}} = \frac{1 - (1-\alpha_{\text{Stein}})\bar{v}}{1 - (1-\beta)\bar{v}}.$$
     **20 帧探针（$\rho=.10, 4.0\text{ dB}$，真实 `time_refine` + `scalar_joint`）精确印证三个极端与解耦点**：
     - 导频初值 $\boldsymbol{\mu}=0, \beta=1$：理论 $|g|=\rho=0.10$，实测 $|g|=0.11\text{–}0.13$；
     - 未编码 QPSK 真信道不动点 `TrueFP`：$\beta=1.0$（现行 `mode='soft'`）实测 $|g|=\mathbf{0.84}$、$\text{MAE}=0.019\text{ bin}$、中位 $\text{MI}=0.593$（$12/20\ge 0.58$）；$\beta=0.0$（`mode='mean'`）发生 Stein 正反馈爆炸，实测 $|g|=\mathbf{1.60}$（盲初始化更炸至 $|g|=\mathbf{1.85}$，0/20 通过）；改用 **Stein 校准 $\beta=\sigma^2/v_r$** 或解耦 $\beta_{\text{obj}}=1, \beta_{\text{gain}}=0.65$ 后，`TrueFP` 恢复无偏 $|g|=\mathbf{0.97\text{–}1.04}$、$\text{MAE}=\mathbf{0.018\text{ bin}}$、中位 $\text{MI}=\mathbf{0.606}$（距真信道 $0.614$ 仅差 $0.008$，$15/20\ge 0.58$）。
  3. **真实 `e1_ldpc` 编码误帧率多工况探针**（含随机瑞利多径与固定指数 PDP，跨 $\rho\in\{0.05, 0.10, 0.25\}$、$\text{SNR}\in\{3.0, 3.5, 4.0, 4.25, 4.5, 5.0\}\text{ dB}$；免矩阵时域 CG-VAMP 仅用 `TimePathOps` 做 $O(PN)$ 共轭梯度，零稠密求逆）：
     - **固定指数 PDP（$n=20\text{–}30$ 帧）**：在 $\rho=0.25$ 下现行 `BaseF0` 于 $4.50 / 5.00\text{ dB}$ 的 FER 为 `0.767 / 0.333`；在 $\rho=0.10$ 下 `BaseF0` 于 $4.00 / 4.50\text{ dB}$ 的 FER 为 `1.000 / 0.850`；仅加入未编码离散 QPSK 预自举（`QPSK-Pre`）在 $\rho=0.10$ 的 $4.00 / 4.25\text{ dB}$ 即降至 `0.200 / 0.067`（$28/30$ 译对），已领先 `BaseF0`（$\rho=.25$）逾 $1.0\text{ dB}$。
     - **随机瑞利多径（$n=20\text{–}30$ 帧，真实多径衰落起伏）**：
       - **$\rho=0.10$**：在 $3.0 / 3.5 / 4.0\text{ dB}$ 下，单轮 `TrueH_AMP` FER 为 `0.95 / 0.45 / 0.10`，`TrueH_VAMP` 为 `0.90 / 0.45 / 0.10`；6 轮盲 `Blind_AMP`（`scalar_joint` + 软支撑重搜 + Stein $\beta_g=0.75$）为 `0.95 / 0.80 / 0.30`，而**同循环仅换为时域带状 CG-VAMP 的 `Blind_VAMP` 达到 `0.80 / 0.45 / 0.35`**——在 $3.5\text{ dB}$ 瀑布核心区追平真信道（`0.45` 对 `0.45`，领先 `Blind_AMP` **35 个百分点**），$3.0\text{ dB}$ 反超单轮真信道（`0.80` 对 `0.90`）。另在 $n=30$ 帧 8 轮对比中，`Turbo50`（同前端 + 支撑重搜）在 $3.5 / 4.0\text{ dB}$ 达 `0.300 / 0.067`（对比 `TrueH` `0.400 / 0.033`）。
       - **适用边界实测（诚实暴露失败区）**：在 **$\rho=0.05$** 下，`TrueH_VAMP` 在 $3.5 / 4.0\text{ dB}$ 已低至 `0.05 / 0.00`，但未训练的手工调度 `Blind_AMP`（`1.00 / 0.95`）与 `Blind_VAMP`（`0.95 / 0.85`）均未过关——说明 $\rho=0.05$ 的初始导频吸引域过窄，恰是轻量深度展开（结合第 0 轮二阶粗支撑提名与逐层学习温度/Stein 权重/支撑门控）需要重点验证的边界，而在 $\rho\in[0.10, 0.12]$ 上手写物理原型已展现出逼近 $3.45\text{ dB}$ 上限的巨大余量。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：叠加导频 AFDM/OTFS 编码接收机（Zheng TVT'25 `arXiv:2404.10232`、Kanazawa `arXiv:2501.15935` 与本项目现行 `F0 + CODELAY`）在 $\rho\le 0.12$ 下因第 0 轮纯导频估计误差（$0.157\text{ bin}$）和漏径卡死在自举悬崖，只能退回 $\rho=0.25$ 多付 $1.25\text{ dB}$ 导频功率税（最优 $4.95\text{ dB}$）；同时仅用数据二阶协方差的半盲路线（本项目 `STAGEA4`）因把数据当圆高斯（$\eta_\phi=0$），下界卡死在 $0.040\text{ bin}$ 悬崖边缘，容不下估计器次优性。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：会把 SP-AFDM 的系统工作点从“高导频 $\rho=0.25\text{–}0.30$ 保第 0 轮捕获”直接下移到“极低导频 $\rho\approx 0.10$ + 离散星座/码字联合双线性展开前端”，无需额外前导、不改发射端与 `(3,6)` LDPC 码；最朴素但不犯傻的做法有两条：(i) 维持现行接收机并离线扫最优 $\rho=0.25$（$4.95\text{ dB}$），相对 $\rho=0.10$ 真信道上限（$3.45\text{ dB}$）白亏 $1.50\text{ dB}$；(ii) 不做 Stein 解耦与带状 VAMP、只跑朴素未编码 `QPSK-Pre` 或 `scalar_joint` 盲迭代，在瑞利多径 $\rho=0.10, 3.5\text{–}4.0\text{ dB}$ 下仍因增益收缩与标量信道失配比 `Blind_VAMP` 多出 15–35 pp 误帧（或陷入 10%–20% 尾部地板，1% FER 穿越点仍难压过 $4.15\text{ dB}$）。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：难处有三层耦合——(a) 导频过弱时数据自干扰淹没弱径，高斯二阶统计虽不受数据判决错传播影响却缺失全部相位信息（$\eta_\phi=0$）；(b) 启用离散 QPSK 软符号后，传统 EM 耦合了“防假径惩罚”与“无偏增益更新”，在 $\beta=1$（系统性收缩 $|g|\to 0.84$ 掩盖弱径）与 $\beta=0$（Stein 噪声回声爆炸 $|g|\to 1.60$）之间两难；(c) 低 $\rho$ 下早期支撑/多普勒残差与多径频率选择性使标量 AMP 退化并引发尾部错误平台。新方案靠**三项紧耦合的物理结构**消解难处：用离散 QPSK 非高斯因子把局部多普勒信息抬升 $3\times$（$0.040\to 0.018\text{ bin}$），用 **Stein 散度解耦**把目标函数 $\boldsymbol{\Gamma}(\mathbf{v})$（$\beta_{\text{obj}}=1$）与增益/残差校准权重 $\beta_t\approx \sigma^2/v_r^{(t)}$ 分离，再用**免矩阵时域带状 CG-VAMP**与**轻量深度展开**（仅学习每层约 6–8 个物理标量：温度 $\tau_t$、Stein 权重 $\beta_t$、VAMP/BP 阻尼 $\lambda_t,\gamma_t$ 及轻量 1D 模糊图残差打分核，总参量 $<200$，跨帧/跨信道泛化）在有限层数内打通低导频捕获吸引域。
