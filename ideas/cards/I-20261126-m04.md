## 问题（一句话）
在已建立块边界与频率基准、但**无已知直射波（LoS）/回波锚点**、零导频（`0%`）、零空子载波（`0%`）、未知目标数 $P$、未知噪声方差 $\sigma_w^2$、允许任意逐帧公共本振随机相位 $\phi_m \sim \mathcal{U}[0,2\pi)$ 且目标经历帧间独立瑞利快衰落（Swerling-II）的整数时延双弥散被动双基地 `AFDM-ISAC` 系统中：已发表最强盲双基地协方差法（`Ranasinghe et al., arXiv:2407.05328v2`）因均匀功率 $\mathbf{R}_x=\mathbf{I}_N$ 令所有自径退化为无信息常数阵 $\mathbf{\Gamma}_p\mathbf{I}_N\mathbf{\Gamma}_p^H=\mathbf{I}_N$（无 LoS 单径严格退化、无锚多径存在精确公共整数时移歧义 `1.4e-16`、Swerling-II 下平均交叉项消失）；在普通 `OFDM (c_1=0, c_2 固定)` 上施加相同对角功率掩码 $\mathbf{D}$ 则因循环阵 $\mathbf{F}_N^H\mathbf{D}\mathbf{F}_N$ 与整数循环时移 $\mathbf{\Pi}^\ell$ 对易，使整块二阶协方差对整数时延严格不可辨识（差 `1.1e-15`）；即使利用 AFDM 啁啾剪切（$c_1=Q/(2N)\neq 0$，偶数 $Q\ge 2\nu_{\max}+1$）与对角 DAFT $m$-序列功率掩码 $\mathbf{R}_x=\mathbf{D}$ 激活自径信息，若仅用对角功率 `lag-0` 则受整数多普勒偶对称零导数奇点拖累，若撤掉异方差 `1/\mu_k^2` 加权（单因素 `Abl_HomoBanded` 消融）或用同帧去啁啾非绕回时域协方差谱估计（`R_z[r]/C_d[r]`）则在强目标掩蔽弱目标时损失显著动态范围；能否以**零导频、时域恒功率、精确等净载荷匹配比特加载的 DAFT 域 $m$-序列功率掩码**（`127` 个 `16-QAM @ 5/3` + `127` 个 `QPSK @ 1/3` + `1` 个 `8-QAM @ 1.0`，精确 `765 bits/block = 3.000000 bpcu`，对称无偏 LMMSE 下等速率格雷码 BER 过非劣门），配对**标度不变的去啁啾带状（`lag-0 + lag-1`）异方差复合矩（Quasi-ML）接收机**，在同名义纯噪声虚警校准（并独立报告 `H1` 残差虚警）下，于强弱目标共存的 Swerling-II 盲双基场景中显著超越 `Ranasinghe` / 同载荷无掩码、母方法 `OFDM (c_1=0)`、同数据仅主对角线消融（`DiagOnly`）、同带状同方差消融（`HomoBanded`）以及同帧去啁啾时域协方差谱估计（`TDCov-NOMP`）？

## 白话与类比
被动双基地感知站想借旁边通信基站发出的下行信号测周围目标的距离和速度，但既不知道基站发的数据（`0%` 导频、`0%` 空子载波），又没有已知的直射波（LoS）当参考坐标，目标回波每帧还在独立快衰落（Swerling-II），收发两端的公共本振相位也允许每帧随机跳动。

三类基线分别卡在不同的物理结构上：
1. **均匀功率盲协方差（`Ranasinghe 2407.05328`）**：所有子载波功率一样大，单径自相关永远变成常数阵 $\gamma_p\mathbf{I}_N$，没有已知直射波参考或进入 Swerling-II 快衰落时二阶平均协方差直接退化；
2. **OFDM 频域对角掩码（$c_1=0$，固定 $c_2$）**：在频域给子载波刻功率纹理后，整数循环时延只改频域相位、不改频域功率也不改任何副对角协方差（`F^H D F` 是循环阵，与时移矩阵严格对易），整块 $N\times N$ 协方差对整数时延完全失明（差 `1.1e-15`）；
3. **同一 AFDM 掩码下的两种不完整接收机**：
   - **仅看主对角功率 `lag-0`（`Abl_DiagOnly`）**：Dirichlet 功率核 $|K_{\mathrm{Dir}}(k-u)|^2$ 在每个整数多普勒 $u=m$ 处偶对称（一阶导数为 0，$m\pm\epsilon$ 差异仅 $O(\epsilon^3)$），形成镜像伪峰，拖垮弱目标检出并放大多目标残差虚警（`13.3%`）；
   - **同帧去啁啾时域协方差谱估计（`Rival_TDCov`, `R_z[r]/C_d[r]`）**：虽然代数上能无偏恢复复指数频率 $u_p = \nu_p - Q\ell_p$，但在时域做等权自相关相当于对高功率（`5/3`）和低功率（`1/3`）DAFT 子载波等权平均——在强目标（`0 dB`）掩蔽弱目标（`-11.5..-13.5 dB`）时，低功率格的 Gamma 方差比高功率格安静近 `22×`，等权时域谱估计浪费了这层 `+3..5 dB` 的异方差 Fisher 信息！

本卡通过**收发协同的两步结构耦合**同时解除上述障碍：
1. **发射端（DAFT 域 $m$-序列非平稳功率掩码 + 精确 765 比特等净载荷格雷加载）**：AFDM 偶数啁啾参数 $Q=2Nc_1=12$（使 $\mathbf{\Phi}_\ell \equiv \mathbf{I}_N$ 精确成立，且各整数时延对应的多普勒区间互不重叠）将 $(\ell_p, \nu_p)$ 唯一编码进 DAFT 域移位 $u_p = (\nu_p - Q\ell_p)\bmod N$；二进制 $m$-序列掩码（`127` 个 `5/3` + `127` 个 `1/3` + `1` 个 `1.0`，均值精确为 `1.000000000000`）保持时域平均功率在全部 $N$ 采样点精确恒平 `1.000000000000`，并分别加载格雷码 `16-QAM / QPSK / 8-QAM`（精确 `765 bits/block = 3.000000 bpcu` 与均匀 `8-QAM / 8-PSK` 逐比特相等，全部 255 子载波最小欧氏距离平方均为 $2/3$，对称无偏 LMMSE 开发集读数显示 `16/20 dB` BER 显著非劣）；
2. **接收端（标度不变的去啁啾 `lag-0 + lag-1` 异方差复合矩估计器）**：主对角线采用异方差 Gamma/Itakura–Saito 准则（单因素 `Abl_HomoBanded` 消融在开发集直接验证异方差加权带来 `+47.5 pp` / `+27.5 pp` 净收益）；叠加仅占 $O(N)$ 存储、经已知 $c_2$ 去啁啾的第一副对角线 `lag-1`（以线性奇对称 $O(\epsilon)$ 打破 `lag-0` 在整数多普勒处的偶对称镜像奇点，将多目标 `H1` 残差虚警压至 `0.0%`）；全接收机先做输入 RMS 归一化与无量纲 Rao 粗搜评分（严格标度不变 `0.00e+00`），配固定公开 `P_max = 5` 与合法搜索域硬边界约束。

## 去壳三句
1. **谁真卡住了（点名现在的做法或论文）**：在无已知 LoS 锚点、零导频、未知目标数与噪声功率的 Swerling-II 盲双基 `AFDM-ISAC` 中，`Ranasinghe 2407.05328`（均匀功率）因自径退化与无锚平移歧义无法定位弱目标（`WT-Pd = 0.0%`）；母方法 `OFDM (c_1=0)` 在对角掩码下整数时延二阶不可辨识（`WT-Pd ~ 5.9%`）；即使保留 AFDM 啁啾与 DAFT 掩码，仅用主对角线 `Abl_DiagOnly` 因整数多普勒镜像奇点在强弱目标场景跌至 `56.7%–66.7%` 且 `H1` 残差虚警飙升至 `11.7%–31.7%`，而同帧去啁啾时域协方差谱归约 `Rival_TDCov` 因等权平均高/低功率子载波浪费异方差增益，在强目标掩蔽弱目标（`-13.5 dB`）下跌至 `60.0%`。

     - **主场景 `Reg1`（`P=2`, `0 dB` 强路径 + `-13.5 dB` 弱目标, Swerling-II，高异方差对比度）**：`Ours_Banded` **`WT-Pd = 88.8%` (`anyFA = 0.0%`)**，相对同数据仅关异方差加权消融 `Abl_HomoBanded`（`41.2%`）领先 **`+47.5 pp`**、相对同帧精确 `nnls` 时域谱归约 `Rival_TDCov`（`56.2%`）领先 **`+32.5 pp`**、相对仅主对角消融 `Abl_DiagOnly`（`53.8%`, `anyFA 23.8%`）领先 **`+35.0 pp`**（双向占比 `60.6% < 80%`）、相对 `OFDM c_1=0`（`0.0%`）与同载荷无掩码 `Abl_NoMask`（`0.0%`）领先 **`+88.8 pp`**；

3. **难处的结构是什么（为什么现有办法过不去；靠什么解除）**：
   - 均匀功率的酉不变性与 `c_1=0` 频域对角掩码的循环时移对易性封锁了二阶时延辨识；仅用主对角 `lag-0` 在整数多普勒处存在 $O(\epsilon^3)$ 偶对称奇点；时域非绕回自相关谱归约则是等权同方差投影，丢失了功率掩码在强目标背景上自然制造的 `22×` 子载波方差对比度；
   - 以 AFDM 偶数啁啾 $Q=2Nc_1$ 配对 DAFT $m$-序列掩码（打破平移对易性并保时域恒功率与等速率 BER 非劣），再以异方差 `1/\mu_k^2` Gamma 主对角准则联合去啁啾奇对称 `lag-1` 副对角复合矩接收机，同时兑现异方差动态范围收益与整数多普勒镜像消歧。
