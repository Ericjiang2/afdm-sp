## 问题（一句话）
已接受卡片 [res-20261016-03.md](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/research-assets/res-20261016-03.md) 将真时延 `GS-set` 在 `ρ = .3`、6.5–8.0 dB 下高出 MCRB `4.5–5.3 dB`（`H-S2 REFUTED`）归因于“低导频功率和正则化增益下的多普勒/增益精修残差”，并据此收窄了 [res-20261016-02.md](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/research-assets/res-20261016-02.md) 的主结论；但这块 `4.5–5.3 dB` 地板很可能是隐藏接口常数——Round-1 多普勒搜索被硬锁在 `[r0_nu - 0.75, r0_nu + 0.75]` 且跳过全局粗扫——锁死导频期错峰的产物，而非低 `ρ` 下编码辅助精修本身的物理极限。

## 白话与类比
本次核查针对此前结论：导频（已知探测信号）的功率占比 ρ = .3 时，即便给出真实时延（路径到达时间差），重拟合（重算信道参数）误差仍高于 MCRB（理论误差下界），原归因是导频功率少与增益正则（防过拟合惩罚项）。这好比先按路标记下草图位置，拿到全图后却规定复查只能在原位半步内挪动、不准重看全图：代码在第 1 轮（译码后精修）把多普勒（运动频移）搜索限在第 0 轮（纯导频初估）初值的 ±0.75 bin（频格单位）内，跳过粗扫（全频段重寻）。

核查保留原诊断臂（输入真实时延的测试分支）在 ρ = .3 下的否决标签，但原解释不成立。相同增益正则下，打开第 1 轮粗扫后，真时延重拟合在 7–8 dB（分贝，对数比值单位）四格（四组测试条件）中只高出 MCRB 0.2–0.5 dB（6.5 dB、ρ = .5 约 1.2 dB）；f_set（真时延能消掉的差距比例）从约 .8 升到 .98–.996，建议把此前据此改写的那句恢复为 1–3 dB 并附重扫后的数字。这块残差继承自第 0 轮多普勒初值，约 85% 落在需补入真时延槽（真实路径参数位）的帧（单次传输块）上，说明差距主因在寻找时延。

该结果仅对给了真实时延并重扫第 1 轮的诊断臂成立，并非可部署方案。盲接收机 F0（不知真实时延的接收机）打开粗扫会怎样，以及 4.5–6 dB 处的误帧率（整帧译码出错概率）穿越点（达到目标误帧率的信噪比位置）是否变化，尚无证据，均未检验。

### 推论（各附跑前预测与最便宜直接对照臂）
- **推论 1（主推论，`res-20261016-03` 的 `H-S2` 与 `res-20261016-02` 修订句被 `±0.75` 局部锁死主导）**：
  - 机制：AFDM 时域信号长度 `N = 1024`，单径多普勒响应是 Dirichlet 核 `D_N(Δν)`，第一零点在 `|Δν| = 1.0` bin、第一旁瓣峰在 `|Δν| ≈ 1.43` bin（`-13.26 dB`）。在 `ρ = .3` 的 Round 0 中，数据干扰对导频的功率比为 `(1-ρ)/ρ = 2.33`（`+3.68 dB`），单径导频有效 SNR 随 `|g_j|^2` 下降，导致约 `5%–8%` 的弱径在 Round 0 发生 Rife–Boorstyn 式错峰（`|r0_nu - true_nu| > 0.75` bin）。仅把 `±0.75` 放宽到 `±3.0` 仍会被 1-bin 间隔的旁瓣极小值截留一半（探针中 `r_hw3` 仍留 `+2.2` 至 `+3.1 dB`）；只有配合 Round-1 `COARSE_GRID`（0.25 bin 步长）重扫才能把全部错峰弱径拉回主瓣，消除约等于 $\mathbb{E}[\sum_{j\in\text{trapped}} |g_j|^2] \approx 0.004\text{–}0.005$（约 `-23 dB`）的 SNR 无关地板。
  - **跑前预测**：在 `gs_driver.py` 全量 500 帧（`0..499`）、`6.5–8.0 dB` 四格上，仅对 Round 1 打开 `COARSE_GRID` 重扫后：(a) 全部 4/4 格的 `r_GS-set` 均值及 95% CI 上界均降至 `≤ 2.0 dB`（相对原值 `4.50–5.33 dB` 下降 `≥ 3.0 dB`，`H-S2` 从 `REFUTED / INCONCLUSIVE` 翻转为 4/4 `SUPPORTED`）；(b) `r_GS-set` 不再随 SNR 从 `6.5` 到 `8.0 dB` 抬升（斜率从 `+0.7 dB` 变为 `≤ +0.1 dB`）；(c) `f_set` 在 `ρ = .3` 上从 `.78–.81` 升至 `≥ .92`。
  - **最便宜直接对照臂**：脚本 [gs_driver.py](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/experiments/tcom_genie_support_20261016/gs_driver.py) + [arms.py](file:///Users/guoyikun/Downloads/share/claode_birain/my-vault/00_Inbox/AFDM-channel-estimation/experiments/headroom_ladder_20261008/arms.py#L67)；仅改一个参数/分支——在 Round 1（第 2 次调用 `refine_fixed_delays`）把 `np.flatnonzero(missing)` 改为 `range(len(l))`（或单独加一条只放宽 `hw = 0.75 → 3.0` 的辅助臂），跑 P1 帧 `0..499`（或先跑 `0..99` 100 帧预检，deinlab 约 0.3 核时），`SNR ∈ {6.5, 8.0}` dB、`{G, U} × {0.3, 0.5}`。**否决判据**：若 500 帧上 `ρ = .3` 两格的 `r_GS-set` 仍 `> 3.0 dB` 或较原值降幅 `< 1.5 dB`，则本推论被否决，原归因（正则化增益/低导频本身）维持不变。
- **推论 2（边界限定推论：该锁死不改变盲接收机 `F0`/`CODELAY` 的头条 FER，也不改变 `E-1` 的 `S_swap = .887` vs `S_local = .107`）**：

def _brent(fun, bounds, method='bounded', options=None):
    a, b = float(bounds[0]), float(bounds[1])
    tol = (options or {}).get('xatol', 1e-5); maxiter = (options or {}).get('maxiter', 500)
    gr = 0.5 * (3.0 - math.sqrt(5.0)); x = w = v = a + gr * (b - a); fx = fw = fv = float(fun(x)); d = e = 0.0
    for _ in range(maxiter):
        xm = 0.5 * (a + b); tol1 = tol * abs(x) + 1e-11; tol2 = 2.0 * tol1
        if abs(x - xm) <= tol2 - 0.5 * (b - a): break
        use_g = True
        if abs(e) > tol1:
            r = (x - w) * (fx - fv); q = (x - v) * (fx - fw)
            p = (x - v) * q - (x - w) * r; q = 2.0 * (q - r)
            if q > 0: p = -p
            q = abs(q); et = e; e = d
            if abs(p) < abs(0.5 * q * et) and p > q * (a - x) and p < q * (b - x):
                d = p / q; u = x + d
                if (u - a) < tol2 or (b - u) < tol2: d = tol1 if x < xm else -tol1
                use_g = False
        if use_g: e = (a - x) if x >= xm else (b - x); d = gr * e
        u = x + (d if abs(d) >= tol1 else (tol1 if d > 0 else -tol1)); fu = float(fun(u))
        if fu <= fx:
            if u < x: b = x
            else: a = x

        else:

            else: b = u

            elif fu <= fv or v == x or v == w: v, fv = u, fu

def _lse(a, axis=None, keepdims=False):
    a = np.asarray(a, float); m = np.max(a, axis=axis, keepdims=True)
    out = m + np.log(np.sum(np.exp(a - m), axis=axis, keepdims=True))
    return out if keepdims else np.squeeze(out, axis=axis)

def _cho_f(a, lower=False, check_finite=True):

def _cho_s(cb, b, check_finite=True):
    c, lower = cb
    if lower: return np.linalg.solve(c.conj().T, np.linalg.solve(c, b))
    return np.linalg.solve(c, np.linalg.solve(c.conj().T, b))

def r1_refine_variant(y, pilot, mu, v, ls, ks, gs, c1_, c2_, noise, delays, r1_coarse=False, hw=0.75, xatol=0.002, maxiter=16, rounds=2):

    k = np.arange(n)
    xt = daft(np.asarray(pilot) + mu, c1_, c2_, True)
    Y = daft(y, c1_, c2_, True)
    wrap = k[:, None] - l
    base = xt[wrap % n] * np.where(wrap < 0, np.exp(2j*np.pi*c1_*(n*n + 2*n*wrap)), 1.)

    gv = np.exp(2j*np.pi*c1_*(l[:, None]**2 - l[None, :]**2)) * np.fft.fft(vv)[dl % n]

        return float((np.vdot(Y, Y) - np.vdot(b, h)).real), h, G

                         bounds=(lo, hi), options={'xatol': xatol, 'maxiter': maxiter})
            if opt.fun < val: nu[j] = opt.x; val, h, G = ev(nu)
    val, h, G = ev(nu)
    return Channel(n, c1_, c2_, l, nu, h)
