## 问题（一句话）
既然 A1 的收益主要来自重选支撑（c51），第 0 轮 OMP 只选 24 个原子是不是瓶颈：改成 40 个原子（B0-p3）后 FER 是否下降。

## 白话与类比
如果第一遍漏了径，多给几个名额也许就能装进来。

## 锚点（出处）
- D：c51 停放结论；`supplement_baselines.PARAMETERS['B0'] = (8, 16, 24, 40)`，生产用 24。

## 去壳三句
1. 谁真卡住了：第 0 轮贪心前端的名额设置。
2. 解决了会改变什么：若 40 更好，生产前端直接换 B0-p3；朴素替代就是保持 24（对照臂）。
3. 难处的结构：名额多能装下漏径，也会装入噪声拟合的假原子，假原子占增益能量、污染 F0 的初始信道。

## 推导（项目数字）
- 本批 800 帧里功率 ≥ .5σ² 的相关径平均 3.26 条（1–7 条）。24 个名额已是相关径的约 7 倍，"名额不够"不可能是主因。
- 多出来的 16 个原子基本都是噪声原子；每个吸收约 σ²·(1/N_pilot) 量级噪声能量并带走部分真径能量，c39/c40 已显示第 0 轮假径能量是 FER 的主要毒源，因此预期 40 原子更差。
- 实测：n40 vs base：rho = .10 .470 → .460（b 16, c 14），rho = .15 .160 → .200（b 6, c 14）；合并 b − c = −6。g25n40 vs g25：rho = .10 .395 → .475（b 11, c 27），rho = .15 .115 → .195（b 4, c 20）；合并 b − c = −32，p = .0001。
