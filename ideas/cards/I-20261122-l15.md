## 问题（一句话）
叠加导频接收机为"不知道信道"付的代价（导频功率加上捕获和估计的损失）里，有多少是信息论上非付不可的、有多少是现在的做法多付的；按支撑、多普勒、增益三项拆开，哪一项多付得最多？

## 白话与类比
收一封信之前不知道信封的样子，要先花一点功夫认信封，这点功夫省不掉；但可以算出最少要花多少。这里"信封"是信道：8 条回声各自晚到多少（支撑）、各自转多快（多普勒）、各自多强（增益）。把接收机要弄清的这些东西折成比特数，一帧大约 132 比特，而一帧载 1024 比特的信息，所以最少要多付约 13% 的"邮资"，折合 0.84 dB。

现在的接收机实际付了 1.62 dB：光是把四分之一的功率拿去发导频就是 1.25 dB，已经超过整个信息账。三项里，"哪 8 个位置有回声"在信息上最便宜（约 38 比特，0.24 dB），可现在的接收机在低导频时恰恰为它付得最多（导频比例 .10 时，告诉它位置与不告诉相差 1.6 dB 以上）。

类比：找 8 个朋友在 103 个座位里坐哪儿，答案本身只有 38 比特；用一盏很暗的灯（低功率导频）一眼扫过去认不出来，不等于这件事本身难——让后面"读信"的过程（译码器）来回帮着认，理论上只要多付 0.24 dB。

## 去壳三句
1. 谁真卡住了（点名现在的做法或论文）：本项目和叠加导频 OTFS / AFDM 的接收机论文都拿"已知信道"当参照线，报告自己离它多远（这里是 1.62 dB），但已知信道不是可达的目标；没有一条线说明"不知道信道时最好能做到哪"。于是每个改进捕获、减导频、配码的想法（本漏斗里的 c14、l02、01 等）都不知道自己在争多大的奖池。
2. 解决了会改变什么设计决定；换成最朴素但不犯傻的做法，损失多大：给出一条可以画进误帧率图的参照线和一张三项价目表。现接收机 1.62 dB 对信息账 0.84 dB：所有这类想法合起来至少还能争 0.78 dB，至多 1.62 dB；导频功率一项（1.25 dB）就超过整个信息账，所以该往低导频走；支撑一项只值 0.24 dB，所以"译码失败后重搜支撑"在信息上是便宜的方向，值得把搜索做强，而不是把导频加大。最朴素的做法就是现在的：把导频加到捕获稳为止（ρ = .25）。
3. 难处的结构是什么（为什么现有办法过不去；有思路的话，靠什么让难处消失）：链式法则给出 I(X;Y) = I(X;Y|θ) − I(X;θ|Y) ≥ I(X;Y|θ) − I(θ;Y|X)，后一项是"数据全知时观测带了多少关于信道的信息"，可以逐项算。难处不在算，而在第 0 轮：导频一眼认支撑是个低信噪比检测问题，每条径只拿到 ρ·N·p / (1 − ρ + σ²) 的匹配信噪比，和信息账上的 38 比特不是一回事；差距要靠译码器反馈来回迭代或重搜来补。

推导与代入（N = 1024，8 条径，功率从大到小平均为 .41 / .22 / .14 / .09 / .06 / .04 / .02 / .01，场景 G 多普勒范围 3.24 bin；γ 是不含导频的每采样信噪比）：
- 增益：Σ_i log2(1 + N·p_i·γ)，同功率下高斯先验给出上界。3 dB 时 55.9 比特。
- 多普勒：数据全知时逐径下界 σ_i² = 6 / ((2π)²·N·p_i·γ)（bin²）；Σ_i ½·log2(1 + R² / (12·σ_i²))。3 dB 时 37.9 比特。
- 支撑：log2 C(103, 8) = 37.8 比特。
- 合计 131.7 比特 / 帧 = 0.129 比特 / 符号。QPSK 互信息在 3 dB 处每 dB 增加 0.153 比特 / 符号，所以代价至多 0.84 dB（增益 .36、多普勒 .24、支撑 .24）。2 dB 处 0.79，4 dB 处 0.95。
- 尺度律（同样的径，3 dB）：N = 256 / 512 / 1024 / 2048 / 4096 时为 2.77 / 1.53 / 0.84 / 0.46 / 0.25 dB，大致与 P·(每径约 16.5 比特) / N 成正比。帧长 256 时光是信息账就 2.8 dB，短帧不适合这类"让接收机自己认 8 条径"的设计；帧长 4096 时只有 0.25 dB。
- 导频功率 ρ 的直接代价是 10·log10(1 / (1 − ρ))：ρ = .25 为 1.25 dB，ρ = .10 为 0.46 dB。令它等于信息账 0.84 dB 得 ρ ≈ .18：导频比例高于 .18 的方案，在估计误差为零时也已经比信息账贵。

## 最接近的已有工作
1. A. Pachai Kannu, P. Schniter, "On communication over unknown sparse frequency-selective block-fading channels", IEEE Trans. IT 2011（arXiv 1006.1548，读了定理 1 与证明开头）：稀疏块衰落信道的非相干容量预对数是 1 − S/N，支撑知不知道不影响；用的就是同一条链式法则。给的是高信噪比的斜率，没有有限信噪比下逐项的比特数，也没有与实际接收机对照。
2. V. Raghavan, G. Hariharan, A. Sayeed, "Capacity of sparse multipath channels in the ultra-wideband regime", IEEE JSTSP 2007（arXiv 0705.2847，读了摘要与引言）：稀疏时延–多普勒信道在宽带低信噪比区相干与非相干的差距、训练的作用；渐近分析。
3. "A simple capacity lower bound for communication with superimposed pilots"（arXiv 1804.07114，读了摘要与模型；作者未核对，不写）：平衰落下叠加导频的互信息下界和最优导频功率比例（低信噪比趋于 1/2）；单抽头、快衰落，结论是导频比例要大，与稀疏参数信道的情形相反。
4. 本项目 `I-20261121-l02`（L3）：从实测的检测器 EXIT 曲线下面积（.586 > .5）出发，说明悬崖不是原理上的，并预测配码可得 1.1–1.45 dB。本卡不依赖任何接收机的实测曲线，给的是同一件事的闭式上界和逐项价目，可以与 l02 的预测互相核对（l02 的预测落在本卡的奖池 0.78–1.62 dB 之内）。
5. 短包下"导频辅助还是非相干"的有限码长比较（Östman、Durisi 等，TCOM 2019 前后；凭记忆列出，本次没有检索到原文，放行时请核对）：块衰落、短包；没有稀疏参数信道。
查新（两次检索）：理论是现成的；没见到把它按支撑、多普勒、增益逐项折成 dB，并与叠加导频接收机的捕获损失并排的。属于已知理论的应用，新意在"尺子"和"三项里谁多付"的对照。

## 价值与代价
价值 2：不改接收机，只多一条参照线和一张价目表，但它决定几条 L3 线的优先级——减导频与强化重搜（现稿主线、c14、l02）在争 0.78–1.62 dB；把导频加大或换导频序列这一类则没有奖池。也给现稿一句可以写进引言的话：导频功率的直接代价已经超过信息账。
适用范围：N ≥ 512、径数 4–16、3–6 dB、QPSK 码率 1/2；价目按 P / N 缩放，径数加倍或帧长减半代价约翻倍。它是上界（往大里估的），所以"至少还能争 0.78 dB"是保守的。
它默认的东西（LESSONS 规则 15）：互信息是遍历意义下的，每帧一个码字时按互信息斜率折成 dB，默认码离容量的差距不随信噪比变；三项相加默认各径回归量近似正交；T0 用的是"真信道起步的现接收机"，它比 l09 那套已知信道迭代接收机差约 0.4 dB（场景 U：3.43 对 3.06），若用更好的已知信道基准，实际代价和奖池都再大 0.4 dB。它不告诉你怎样做到，只告诉你上限在哪。
对其他卡：l02、c14、01 的收益上限由本卡给出；与 c35（第 0 轮的全局 Ziv–Zakai 界）互补——那张卡量的是"只用导频一眼认"的极限，本卡量的是"用上全部数据"的极限，两者之差就是迭代和重搜该补的部分。
最便宜的致命检验已做（第 15 批）：若信息账不比实际代价小 0.2 dB 以上，这把尺子量不出东西，淘汰；结果 0.84 对 1.62，通过。
