## 问题（一句话）
已知（或已捕获）时延后，第 0 轮多普勒误差的大头是门限离群值（c23：11.9–16.1% 有效径误差 > .25 bin）；把"数据当导频"的滞后积 $r^*[k]\,r[k+l_i-l_a]$ 以最强径为锚做 FFT，得到 $\nu_i-\nu_a$ 的全功率（$1-\rho$）谱，与导频匹配滤波谱融合，能否在 ρ ≤ .10 把离群压掉、把第 0 轮多普勒推近 A4 的半盲下界？

## 白话与类比
认 8 个人各自走多快：手电（导频）很暗，弱者常认错；但每个人都和最显眼的那个人"踩着同一段数据"，看两人脚步的相对节奏（数据滞后积）就能读出相对速度，再加上显眼者的绝对速度。

## 锚点（出处）
A（近期论文的局限）：Globecom 2025 "Joint Channel Estimation and Data Detection for AFDM With Superimposed Pilots"（doi 10.1109/globecom59602.2025.11432016）自述只在"低数据功率"（导频功率高）时胜过嵌入导频——叠加导频接收机在低导频下靠迭代判决补救，第 0 轮仍只用导频。本项目 A4 读数：半盲下界 .040/.037 vs 纯导频 .074/.060（ρ = .10/.15），信息主要来自数据协方差；A3：误差 ≤ .04–.05 bin 保住真信道收益（真信道 3.45 dB vs 基线 4.95 dB）。

## 去壳三句
1. 谁真卡住了：F0 第 0 轮与 A4 的"半盲估计器"步骤——现有估计器的差距来自离群值（c23），局部精修（Fisher scoring/VarPro）从离群初值出发继承离群，半盲下界是局部界，到不了。
2. 改变什么设计决定：若锚相对数据滞后谱把离群压到 ≤ 1% 功率、再经半盲局部精修达到 ≤ .05 bin，则 ρ = .10 可用（A2/A3：最多 1.5 dB 奖池）；朴素做法（只导频、全局网格 + 局部精修）在 ρ = .10 留下 2.8% 离群功率、平均误差 .22 bin。
3. 难处结构：多普勒差只给相对量，锚的绝对误差会整体平移所有径；其他同差分时延的径对造成交叉项；数据滞后积的噪声是四阶量（但只做单一二维谱，不估累积量）。
