# 实现方案：OAMP-Net 检测器 (Phase 3)

**项目**: AFDM水声通信系统深度学习接收机
**阶段**: 第三阶段 - OAMP-Net 检测器替换 LMMSE
**日期**: 2026-03-08
**状态**: 📋 计划制定中，还没开始改代码

---

## 一、目标

替换 DiffLMMSELayer，用 OAMP-Net 检测器。利用 OAMP 的正交化解耦，将有色自干扰白化，打破第二阶段遇到的自干扰地板。

---

## 二、核心思想

**LMMSE 是"睁眼瞎"**

- 把含有极强结构相关性的自干扰当成高斯白噪声处理
- 导致 25dB 时 Error Floor

**OAMP 的魔法：解耦（Decoupling）**

- 将带色干扰重新白化
- 恢复高信噪比下解调数据的能力

---

## 三、网络架构

### 3.1 单层 OAMP-Block

每次迭代包含两个模块：

1. **线性估算器 (LE)**：LMMSE 矩阵求逆 + 正交化
2. **非线性估算器 (NLE)**：QPSK 后验概率推断

### 3.2 OAMP-Net 结构

```
Input: y, H, σ²
   ↓
Layer 1: LE → NLE → (μ_x¹, v_x¹, LLR¹)
   ↓
Layer 2: LE → NLE → (μ_x², v_x², LLR²)
   ↓
Layer 3: LE → NLE → (μ_x³, v_x³, LLR³)
   ↓
Layer 4: LE → NLE → (μ_x⁴, v_x⁴, LLR⁴)
   ↓
Output: μ_x, v_x, LLR
```

### 3.3 可学习参数

| 参数 | 作用 |
|------|------|
| γ (gamma) | 去相关步长 |
| θ (theta) | 噪声方差调节 |

## 四、关键决策

### 4.1 矩阵求逆方式 ✅ 选 A

| 方案 | 描述 | 用户选择 |
|------|------|----------|
| **A. 严格 OAMP** | 每层显式求逆 | ✓ 已选 |
| B. OAMP-Net + CG | CG近似求逆 | - |
| C. 混合 | 第一层精确，后续CG | - |

**理由**: 用户选择精确方案，训练稳定但计算量增加4倍

### 4.2 与 CE 网络关系 ✅ 选 C

| 方案 | 描述 | 用户选择 |
|------|------|----------|
| A. 冻结 CE | 只训练 OAMP-Net | - |
| B. 联合训练 | CE + OAMP-Net 端到端 | - |
| **C. 两阶段** | 先冻结OAMP，再解冻CE | ✓ 已选 |

**理由**:
- 第一阶段：冻结 CE，训练 OAMP-Net（20 epochs）
- 第二阶段：解冻 CE，联合微调

## 六、训练策略

### 阶段一：冻结 CE，训练 OAMP-Net
- 冻结 `ce_backbone_1`
- Loss: BCE(LLR) 或 KL 散度（如有 Teacher 标签）
- Epochs: 20

### 阶段二：解冻 CE，联合微调
- 解冻所有参数
- Loss: BCE + MSE(H)
- Epochs: 10

## 十、训练结果 (2026-03-08)

### 10.1 模型配置

| 参数 | 值 |
|------|-----|
| 模型参数 | total=1,530,556, CE=1,530,547, OAMP=9 (T=4) |
| OAMP 层数 | 4 |

### 10.2 BER 对比结果

| SNR (dB) | LMMSE_BER | OAMP_BER | 改善 | 状态 |
|----------|-----------|----------|------|------|
| 5 | 0.2037 | 0.1985 | -2.6% | ✓ better |
| 10 | 0.1393 | 0.1148 | -17.6% | ✓ better |
| 15 | 0.1157 | 0.0790 | -31.7% | ✓ better |
| 20 | 0.1042 | 0.0625 | -40.0% | ✓ better |
| 25 | 0.1006 | 0.0532 | -47.1% | ✓ better |

**关键改善**: 25dB BER 从 10% 降到 5.3%，改善约 47%

### 10.3 v_x 对比结果

| SNR (dB) | LMMSE_vx | OAMP_vx | 改善 |
|----------|----------|---------|------|
| 5 | 0.4543 | 0.2724 | - |
| 10 | 0.2993 | 0.2159 | - |
| 15 | 0.1606 | 0.1921 | ↑ |
| 20 | 0.0894 | 0.1776 | ↑ |
| 25 | 0.0603 | 0.1701 | ↑ |

**关键改善**: 高 SNR 下 v_x 不再归零，网络保持理性不确定性

### 10.4 验收结果

| 验收标准 | 目标 | 实际 | 状态 |
|----------|------|------|------|
| BER @ 25dB | < 5% | 5.32% | ❌ 差一点点 |
| v_x @ 25dB | > 0.05 | 0.170 | ✅ 达标 |

**结论**: 部分通过，BER 尚未突破 5% 阈值

### 10.5 物理意义

**v_x 达标的物理意义**:
- OAMP-Net 不再"过度自信"
- 网络知道当前还存在 SP 干扰
- 高 SNR 下仍保持理性不确定性 (v_x = 0.17)

**BER 改善的物理意义**:
- OAMP 的正交化确实起作用了
- 有色自干扰被部分白化
- Error Floor 有所降低，但未完全消除

## 十一、原因分析与后续方向

### 11.1 为什么 BER 没突破 5%

可能原因：
1. Phase B (解冻 CE 微调) epoch 数不够
2. CE 网络的自干扰误差仍在影响 OAMP
3. 4 层 OAMP 可能不够深

### 11.2 后续方向

- 增加 Phase B epoch 数
- 尝试更深的 OAMP-Net (6-8 层)
- 或引入更复杂的解耦策略
