## 二、大模型的四个核心洞察

### 2.1 网络拓扑：螺旋上升

**问题**：之前是"一次CE → 一次检测"的单向流程

**正确做法**：Turbo 拓扑，相互扶持的螺旋上升

```
Init_CE → OAMP检测器 ↔ 信道精炼器 ↔ ... 重复 T 次
              ↓              ↓
         (μ_x, v_x, LLR)  (更准的 Ĥ)
```

### 2.2 Layer-wise Supervision

**问题**：只在最后一层算 Loss，前几层变成无法解释的"黑盒"

**正确做法**：每次迭代吐出的信道和 LLR 都要准

```
Loss = Σ_{t=1}^{T} w_t * (Loss_CE_t + Loss_Det_t)
```

### 2.3 观测一致性

**问题**：只算信道估得准不准

**正确做法**：还要算"用估出来的信道重构的 y 是否接近真实 y"

```
L_obs = ||y - Ĥ(x_p + μ_x)||² / σ²
```

### 2.4 知识蒸馏

**问题**：没有利用传统强基线

**正确做法**：用 Joint OMP+MP 作为 Teacher，蒸馏 LLR 和信道 support

## 三、多任务 Loss 函数

### 3.1 Loss 组成

```python
Loss = λ_bce * BCE(LLR, bits)           # 检测 Loss
     + λ_mse * MSE(H_hat, H_true)       # 信道估计 Loss
     + λ_obs * 观测一致性               # 物理约束
     + λ_kd  * 蒸馏Loss                 # 知识蒸馏
```

### 3.2 建议权重

| 参数 | 建议值 | 说明 |
|------|--------|------|
| λ_bce | 1.0 | 检测 Loss |
| λ_mse | 10.0 | 信道估计 Loss（前期大一点）|
| λ_obs | 0.5 | 观测一致性 |
| λ_kd | 0.5 | 知识蒸馏 |

### 3.3 Layer-wise 权重

```python
weight_t = (t + 1) / T  # 后面的层权重更大
```

## 四、网络架构

### 4.1 Deep Turbo 结构

```
┌─ 初始化 ─────────────────────────────┐
│  Init CE → Ĥ₀                        │
└──────────────────────────────────────┘
              ↓
┌─ 迭代 t=1...T ──────────────────────┐
│  ┌─ OAMP 检测器 ─────────────────┐  │
│  │  Ĥ_t → (μ_x_t, v_x_t, LLR_t)  │  │
│  └────────────────────────────────┘  │
│              ↓                        │
│  ┌─ 信道精炼器 ─────────────────┐    │
│  │  软信息 → ΔH → Ĥ_{t+1}       │    │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

### 4.2 输出历史

每次迭代需要保存：
- `history_H_hat[t]` - 信道估计
- `history_LLR[t]` - LLR
- `history_mu_x[t]` - 软符号均值
