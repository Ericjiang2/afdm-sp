# 截断可以制造可辨识性：AFDM 双径模型的数学边界

2026-10-06。本轮得到可用于论文模型分析的具体结论：**固定 Fourier 侧带截断能让原本无法从功率识别的共同多普勒中心变得可识别。因此，近似模型里的识别能力不能直接解释为完整物理信道的信息。** 独立数学审查、实际生成器接口和四项冻结 SSH 验证均已完成；尚未建立新接收机的性能或成本优势。

这不等于“截断一定有害”。若测量系统真实实施了额外投影，应重新写出那个测量模型；本报告针对的是把完整信道响应替换成截断响应的建模操作。`diag(PH)US` 也不能未经推导等同于对真实观测实施 `P diag(H)US`。

## 两条可保留的结论

**一、完整同零 delay 信道存在精确的功率不可辨识轨道。** 两条 Doppler 同时平移 a，只给完整响应乘单位对角矩阵：`H′=D_a H`。匹配完整响应的 Gram 归一化保持这一性质。固定 H、相同源分布和跨快照独立、与全部源独立的 proper circular 对角 Gaussian 噪声下，可耦合 `n′=D_a n` 得到 `Y′=D_a Y`。所以任意有限快照数的整块原始坐标功率数组 `|Y|²` 同分布；任意阶功率矩、非线性功率特征和仅使用该数组的学习器都不能区分这些中心。

**二、冻结 G0 五分量模型打破该对称性，并有显式二阶逆。** 对 N≥9、共同零 delay、合法正 Doppler 内点、每条路径的 −2…2 五行全部保留且有效复增益非共线，三个去相位 Fourier 虚部 I₂、I₃、I₄ 的比值给出一个严格单调的一元方程，恢复无序节点；不需要噪声方差、信号尺度或 gain 真值。给定节点后，功率设计全分支秩为 5。N≥9 是无混叠的充分条件，未证明必要或最小；N5 的实际模型仅保留三分量，存在开放的等功率、不同节点反例。

两条结论合在一起构成模型有效性结果。完整证明与可移入技术稿的表述见 [TECHNICAL_NOTE.md](TECHNICAL_NOTE.md)，展开代数见 [POWER_IDENTIFIABILITY.md](../../.trellis/tasks/10-05-method-advantage/research/20261006-usable/POWER_IDENTIFIABILITY.md)。

完整补全使用冻结 `alpha(m+ν)` 与正号 Fourier 合成，精确对应反转时间索引 `r_n=(-n) mod N`，不是未经说明的正时序 G1。最大独立合成误差 6.31×10⁻¹³。现有 `g1` 标签沿用 G0 Gram；本轮以未知 τ 的合法补偿消除该公共尺度，不能把它当成固定 τ 的匹配完整归一化模型。四阶 gap 未除 N；每坐标约 .00145–.00146，不能据总 gap 随 N 增长声称统计收益按 N 增长。

其余三项验证为：

- **代数：** N9/16/64/1024、两个间距、两类 raw gain、三个 τ 与三个噪声方差，共 144 个总体节点逆全部通过；最大节点绝对误差 4.89×10⁻¹⁰，矩公式误差 5.28×10⁻¹⁶。N5 两组合法不同节点的功率差 1.25×10⁻¹⁴，直接原生成器与 DAFT 重建也吻合。
- **敏感性：** 32 个基线中 24 个可反演，8 个有效共线点按预期拒绝；48 个解析 Jacobian 与差分检查通过。576 个固定扰动中 172 个返回合法节点，404 个拒绝，其中 weak-I₄ / 非法比值 / 负判别式 / 越界 / 无分支根分别 96 / 112 / 84 / 72 / 40。它们是人工矩扰动，不是随机信道失败率。
- **四阶对比：** N5 全部 1024 个 QPSK 符号向量、两个共同正幅度向量、四个固定候选相位、三个解析积分噪声方差，共 24 个评分案例。总体与枚举评分最大差 1.43×10⁻¹⁴，固定样本梯度差 4.36×10⁻⁹。不同节点等功率对具有正总体 gap，循环 character 对比保持逐样本不变。

**增益重建单独看，不能被 `all_passed` 掩盖。** 144 个设计的数值秩均为 5；109 个通过预设秩一残差检查、35 个未通过；11 个给出负噪声估计，均在真实噪声零的边界，最低 −5.79×10⁻¹²。秩一残差最大 8.70×10⁻⁸。两类标志同时通过的为 98 个，但没有据此做完整 PSD/H/τ/σ² 数值认证。未裁剪这些估计、未放宽阈值、未重跑以消除不利结果。满秩的精确定理与浮点求解稳定性是不同命题。

## 科研直觉：先找“不变的东西”

1. **先问观测是否变化，再问算法能否估计。** 如果参数变化可以被一个观测不变的对称变换吸收，更多数据或更强网络也无法从该统计中辨别它。这里不是协方差碰巧相等，而是整个功率数据的分布相等。
2. **一个很准的近似也可能改变逆问题。** 拟合误差衡量响应有多接近；可辨识性衡量不同参数是否精确相撞。这两件事不连续地关联。固定投影与调制不交换：`E=[P,D_a]H`，截断前后的功率差正由 `2 Re(conj(D_a PH) E)+|E|²` 产生。该恒等式针对未作逐列归一化的投影，实际 G0 归一化另行处理。
3. **消去 nuisance 不代表保留了强信号。** 三个虚部共同含一个很小的 gain/间距因子，取比在代数上消去它，同时会放大经验误差。矩逆的 oracle-local delta-method 外推 T 为 2.71×10⁸–1.10×10²⁰（目标两节点平均 RMSE=.01）；这是局部渐近病态诊断，不是所需样本数的上下界，也不是所有二阶方法的限制。
4. **重要的是相位信息，而不只是统计阶数。** 任意高阶原始坐标功率统计仍受上述障碍。先做非对角相干混合再取模，则保留了原坐标间的相位关系。共同固定幅度下的 FFT 四阶对比有严格总体 gap；它沿非整数共同平移轨道消除连续歧义，但还不能证明所有物理参数全局恢复或优化全局收敛。

## 论文中怎么使用

可用作“近似信道模型的可辨识性有效性”小节及证明附录：先给完整模型的功率分布不变性，再给冻结 G0 的显式反演作为严格对照，最后说明相位敏感四阶对比如何观察功率看不到的方向。该结果会改变研究决策：完整信道中心估计应验证实际相位信息，不能把 G0 的截断功率模式当成物理依据。

这是一个有解析证书和实际源码证据的具体模型结论，不意味着仅凭本结果就足以独立发表 Transactions 论文。谱因子分解、CMA/ICA、对称性导致不可识别等基本机制均为经典。Quadeer–Al-Naffouri 2010 已采用谱因子与候选选择；Shalvi–Weinstein 1990 已使用二/四阶盲反卷积。本轮的具体贡献候选是冻结 Dirichlet 五行族的单调逆与完整模型调制对称性的严格反差，不能声称一般机制首创。
