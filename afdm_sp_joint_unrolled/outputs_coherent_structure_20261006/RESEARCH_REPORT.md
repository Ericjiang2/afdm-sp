# 相干观测与保留分量数改变碰撞问题的边界

本轮目标是找到足以改变研究判断的重要结构结论。以下数学结论已由独立代理复核，并完成正式 SSH 几何、统计和原始数据复算；结果与裁决见后文。研究使用项目冻结的 **G0 截断 Dirichlet、同零整数 delay、双径条件模型**，不是对所有传播模型或生产接收机的结论。

## 1. 重复观测是否共享信道，决定一阶碰撞信息能否被利用

令两径 Doppler 为 μ−δ、μ+δ，δ 是半间距。固定复增益 g₋、g₊，且 a=g₋+g₊≠0。实际 Gram 归一化后的时间响应为

\[
H_\delta=\sqrt{\tau N}\,
\frac{w(\mu-\delta)g_-+w(\mu+\delta)g_+}
{\|w(\mu-\delta)g_-+w(\mu+\delta)g_+\|}.
\]

记 ζ=Im[(g₊−g₋)/(g₊+g₋)]。消去未知复尺度与实中心后，泛型增益 ζ≠0 仍保留 O(δ) 法向项。N=4 时，不需要知道符号或增益，单用观测的功率差

\[
d(Y)=(|Y_0|^2-|Y_1|^2,\ |Y_2|^2-|Y_3|^2)
\]

就能见到这一项。设 x=tan(πμ/4)、K=1+2x²+5x⁴，则

\[
E[d(Y)\mid H_\delta]
=\delta\frac{2\pi\tau(1+x^2)}{K}\,\zeta
\begin{pmatrix}1+3x^2\\-(1-x^2)\end{pmatrix}+O(\delta^2).
\]

单径零假设下，该均值对未知 μ、功率和噪声均为零。同一未知信道内重复 T 个独立符号，均值噪声为 O(T⁻¹ᐟ²)，所以泛型固定增益下具有 **T⁻¹ᐟ² 的条件局部检测尺度**。使用 Q=T·d̄ᵀS⁻¹d̄，S 是 ddof=1 的样本协方差；检验只接收 Y。

此前逐观测重新抽信道会平均掉带符号的一阶方向。因此，旧独立重生模型的 R⁻¹ᐟ⁴/√log R 边界不能直接用来否定相干块内的检测。这是**观测依赖结构改变**带来的差异，不是同一数据模型下某算法击败另一算法。

限制：ζ=0 时一阶项消失；在一般非退化同相 raw 增益情形，已知符号 oracle 的首项是二阶。单个增益为零属于精确单径。a→0、ζ→0 附近没有统一常数保证；检测到双径不等于准确估出 δ。固定 T 的先验边缘展开不能未经证明外推到 T、块数 B 同时增长。

## 2. 三个公共分量有精确多解，第四个公共分量改变唯一性边界

在固定截断分支，已知完整无噪声复信道 H，仍可能无法唯一估计两径位置。把三个公共整数分量 m=−1,0,1 的已知行相位去掉，经过一个可逆实线性变换，可写为

\[
M_j=\lambda_1 y_1^j+\lambda_2 y_2^j,\quad j=0,1,2,
\qquad y_i=\tan(\pi/N)\cot(\pi\nu_i/N).
\]

如果 D=Im(M₁M̄₀)≠0，可由 S=Im(M₂M̄₀)/D、P=Im(M₂M̄₁)/D 得到节点方程 y²−Sy+P=0。因此三个分量**泛型可辨识**。但有效增益 λ₁、λ₂ 共线时，存在连续精确歧义；这里的有效增益相位条件与上一节 raw 增益的 ζ=0 不可混同。

已构造实际正 PDP 支撑内的两组参数：(μ,δ) 约为 (0.2951672353,0.0167492862) 与 (0.3011750031,0.0184115434)。适当非零增益使它们具有完全相同的归一化 H。有理数构造使两组三个矩均精确等于 (2,17/2,145/4)。增加 SNR 或重复次数不能消除这种同 H 歧义。

这并不意味着无法检测双径：M₀M₂−M₁²=λ₁λ₂(y₁−y₂)²≠0，仍可排除单径。**路径数检测与间距估计是不同任务。**

如果共同保留至少四个互不混叠的整数分量，Dirichlet 列经非零行列缩放成为 Cauchy 矩阵，任意四个不同合法 Doppler 列线性独立。于是同一固定合法分支内，两个不同 Doppler 的双径分解对所有非零增益唯一，除去标签交换；重合路径先合并为一个有效分量。单纯增加 N 而仍只保留三个分量不能获得这一保证。

限制：这是完整 H 的精确代数唯一性；不保证近碰撞时数值条件良好，不保证盲观测可以恢复 H，也不是 FER 或部署性能结论。跨不同 mask、整数奇点或 alias 的全局情形不在本定理范围内。

## 3. 研究判断与经典理论关系

本轮把原来的单一问题拆成两个可操作的结构问题：块内相干性是否被观察模型保留，以及保留的分量数是否足以排除精确歧义。它们决定了“需要更强估计器”之前是否还有可用信息、是否存在唯一答案。

实节点 Prony 反演、Cauchy 满 spark、均值二次型检验及交叉样本 U 统计都是经典工具。本轮新增的是它们在**实际 G0 归一化与截断分支中**的明确连接、条件、反例及可观察见证。尚未完成针对这些特定结论的近期文献逐篇新颖性比对，不声称首次提出或直接达到论文录用标准。

数学来源：本任务 `research/20261006-important/coherence/THEORY_CANDIDATES.md` 与 `algebra/ALGEBRA_CANDIDATES.md`；独立审计：本轮 Mission 的 `reviews/PROOF_AUDIT.md`、`PROOF_SKELETON.md`。原研究结论保持有效，本轮补充其观察模型和可辨识性适用边界，没有替换旧实验数字。
