# 创新候选：可执行机制蓝图

2026-10-01；MAP-01 初始优化。承接 [concept-review](concept-review.md)，所有预期均为待检验假设，非新实验结果。实施、协议与唯一 CSV 由 root 维护。

## 主路线 D-FULL：从闭合缺陷到实际 TF

**问题。** CSTATE 已在几何评分中计算 Γ，但后续 TF 在每步增益反作用中使用 $sI$，旧 CGR 使用 $sR$。非均匀 AF 方差的跨延迟项尚未由两者覆盖。

**来源支持。** 已冻结代码映射和 `VERIFIED_THEOREM.md`；NOMP/VALSE/JCCD 并不提供当前 TF 的闭合保证。**优化推论。** 匹配真实工作方差的反作用可能改变增益/译码轨迹；方向大小与效果不必正相关。

**机制。** 保持同一物理路径、标量方差、阻尼、先验和迭代预算，只在增益 pseudo-observation 内将 $s\bar h$ 换为 $\Gamma(V)\bar h$。这是隔离反作用的候选，不是精确 Bayes、完整 full-covariance AMP 或对其他更新正确性的证明。

共同状态、

\[
q^{-1}=\max\{\alpha\|\bar x\|^2,10^{-12}\},\qquad
\tau=1/P
\]

时应逐步核对：

\[
h_{\Gamma}^{+}-h_I^{+}
=-\frac{\alpha}{P+q^{-1}}[\Gamma(V)-sI]\bar h,
\quad s=\operatorname{tr}V.
\]

这沿用现有 TF Gaussian denoiser 的仿射结构；两条实际运行轨迹分叉后不能再把它当同轨迹恒等式。若实现中的噪声尺度、先验或 damping 不同，先按真实代码重新导出。

**最小执行包。**

1. 固定共同 checkpoint，保存每步 $v,\bar h,\alpha,q$ 以及 $(\Gamma-sI)\bar h$；数值对照上述一步差异；Γ 必须作用于 AF 数据坐标的工作方差。
2. 在预定旧观测上跑 scalar / $sR$ / full Γ 完整 TF+LDPC，同样停止规则、相同物理前端、共同输入与初值。记录逐帧输赢、错误字、syndrome、完整耗时和任何非有限量；包括未触发群体分母。
3. 判别：full Γ 与 $sR$ 差异对应跨延迟项；均优于 scalar 才支持该类反作用的重要性；只改变信道误差、无最终/截止期收益则降级为机制观察。

**强对照与去重。** 保留已有 CSTATE、相同额外预算的 scalar continuation。仅对弱前端改善、被强前端吸收的结果应写作条件性。D-01–04 仍适用。

**失败后的最小修复。** 若一步公式不符，先修实现。若强反作用造成数值不稳定，可预注册混合 $sI+\beta(\Gamma-sI)$，$\beta\in[0,1]$；不能见结果后挑最好 β 当确认，也不能据此称新理论。若稳定且方向对译码无关，停止该配置，转向真实轨迹中互补状态的获取；不反复调权。

**相邻修复的保留边界。** full Γ 的这一项仍不处理所有非圆/块协方差消息。旧 BLOCK 的 observation/response 坐标错误属于实现失败；旧 Γ crossfit 的 proper-complex 工作模型有约 0.972 的伪协方差/协方差比，且只作离线候选比较。这两项均不能否定合法 block/augmented-real 更新。若 D-FULL 无收益而真实工作状态显示强非圆性或块依赖，应先追加可观测工作分布诊断；有清楚机制与预算后再重推完整局部更新，禁止只替换一个矩阵却称完整协方差接收机。

## 条件备选 C-PAIR：可辨识簇坐标的内部求解

**问题。** 同延迟近碰撞两径使单独参数估计病态。接收目标是预测物理响应，不要求每条径参数都精确。

**来源支持。** NOMP 的循环 Newton、近碰撞超分辨率界、D-GESBL 的 Taylor/动态网格均已存在。**优化推论。** 中心/差分坐标或成对信赖域更新可能在当前局部算法中减少病态方向的无效计算。

**边界。** 精确可逆换基且先验正确时，精确求解的物理结果必须相同。两模式没有自动压缩；任何改进应来自数值稳定、非凸几何步，或显式截断后的成本/风险取舍。

**合法最小版本。** 先对现有 same-delay 双径构造精确和/差分坐标（避免直接把有限 Taylor 当精确物理模型），同步变换 Gaussian prior；在内部进行等价正则求解，再恢复同一物理双径传 TF。其作用仅为数值等价性/条件性控制。δ=0 合并同一算子，合并增益先验方差为两者之和。

**有算法差异的下一版本。** 用中心与间隔参数做联合几何更新，梯度与真实 fractional response 相容；每步重新拟合增益、保留变换先验与原目标下降检查。对照逐径 Newton/现有 LOCAL 及固定预算的直接二参数优化。算法差异是有限预算下的更新策略，不能写成新 Taylor 理论。近碰撞模式若被截断，要预注册误差界和何时恢复第二模式。

**判别证据。** 全群体中近碰撞覆盖率；真实响应 Gram/加权时间方差；精确换基物理解误差；相同训练预算下 full-chain 配对输赢。若所有 CSTATE 失败均无近碰撞，此路线在当前群体不能解释主要剩余错误，但可作为压力场景结论。C-01–04 的假设未满足时禁止宣称改善。

## V-DEADLINE：把路由目标改为可实现的收益

**问题。** 当前 STOP/LOCAL/CSTATE 的最终正确集合嵌套。最终 FER 已被 CSTATE 上界约束，而同一截止期的输出集合可能不嵌套。

**机制。** 行动前观测状态 $z$；合法动作集合 $\mathcal A$；固定外生成本参数 λ 或截止期 T：

\[
Q_a(z)=P(\text{correct after }a\mid z)-\lambda E[C_a\mid z],
\]

或直接预测“截止期内正确”的概率。此式是经典计算价值形式，不申请通用理论新颖性。

**先做上界。** 逐帧哈希匹配现有动作输出，计算最终以及固定截止期 oracle；历史不同 campaign 的耗时不能拼接成单个反事实样本。oracle 只决定是否有值得学习的余地，不能进入运行决策。

**再做可部署版本。** 最多一个简洁规则/小模型，输入仅为 action 前已付费计算得到的 syndrome、LLR 统计、stagnation、预计算几何量。同帧 action 后分数不作为免费输入。与固定 GLOBAL、原生 syndrome trigger、固定额外 iteration 比较，费用含特征/路由计算。

**停止/修复。** 若同预算 oracle 无实质 headroom，停止旧动作学习；若 oracle 有余地但观测规则无泛化，明确“oracle 不可达”。只有 D-FULL/C-PAIR/M-CACHE 提供新互补动作后才重开最终 FER 路由。V-01–03 保持稳定 IDs。

## M-CACHE：从已付费轨迹获取小型联合状态

**问题。** 旧大码字银行的主要限制是缺有效候选，昂贵精确评分不能补回缺失。生产级便宜模式获取仍未闭合。

**来源支持。** JCCD-VALSE 已有软外信息闭环；项目旧实验已有 OSD、branch、coreset、联合交叉矩。**优化推论。** 复用实际 TF/LDPC 各次迭代已生成的不同合法码字及其物理通道状态，可能以较低边际成本产生互补输出。

**最小版本。** 从已经付费的 checkpoint 收集有限去重码字；0 syndrome 仅表明码约束满足，不是真值。固定同一几何与 exogenous gain prior，比较完整字条件化的 marginal/profile 物理分数；候选生成、变换、refit、评分和反馈均计时。若条件几何不同，必须报告该差异并防止用不同先验/自由度制造评分优势。

**真正新增的实验。** 若存量候选只包含一个模式，缓存路线已经没有提议 headroom；允许一次预注册的局部 branch/restart，改变有限观测侧弱可靠位/初值，与同成本普通 continuation、OSD 及单路径扰动对照。分支初值变化不能被冒充额外独立证据。

**消费者。** 首先测试终端选择；若其存在互补收益，再测试 branch-conditioned 下一轮。保留 $E[H(g)d]$ 所需联合量，不把后验均值当独立先验再次重复计数。避免以仅信道 NMSE 或漂亮 joint-moment 恒等式替代完整链。

**停止/修复。** 缺真字/缺互补时修提议；同银行排名失败时修合法评分；有好候选但反馈损害时审消费者。若修复成本超过普通 continuation 或被其收益吸收，停止该获取器，不能据此否定所有多模态推断。

## 反馈顺序与本轮饱和条件

先 D-FULL 的实际接口与全链试验，平行完成四族人口诊断；再按明确机制证据选择 C-PAIR 或 M-CACHE，VALUE 复用实际动作成本评估。初版优先级不是结果承诺，新增修复由 root 先写 CSV。

每族必须留下：最近邻差异、关键数学/接口条件、真实群体覆盖、至少一种最小救援的处理结果。可接近饱和的是这套接收机和预算内的候选邻域。仍有可执行且高价值的具体修复，就继续；仅“还能想更多”不构成无限扩张，也不得以环境失败、小样本无显著或代数验证代替真实接收机结论。
