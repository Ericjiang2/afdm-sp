## Design (frozen)
- Stage 3 pipeline and grid (U/G × ρ .3/.5 × 5–11 dB, 34 keys per frame), fresh frames 9400–9799 (13,600 keys); F0 captured once,
  geometry arms run on the same state when triggered.
- Arms change only the geometry-stage inputs:
  - CD = `CODELAY` (reference);
  - Z = same route with the variance vector set to zero (Γ = 0);
  - H = hard-decision dictionary, v = 0;
  - S = scalar A2 (anchor);
  - Z-sel = Z's exact support with CD-Γ gain refit (secondary).
- P-A (Z, H): first accepted global edit is a phantom when the new atom shares a delay with a surviving slot. SUPPORTED if the 95%
  upper bound ≤ 10%, REFUTED if the lower bound ≥ 30%. Anchors: S lower ≥ 80%, CD upper ≤ 5%, calibrated on archived E-1
  (A2 93.59%, A1 1.61%).
- P-B: paired rescue Z − CD on triggered keys, EQUIVALENT if the 95% interval lies within ±3 pp. Frame-cluster bootstrap, 20,000 draws.

## Interpretation (untested beyond what is stated)
1. **H** — On P1, the split-phantom pathology of the scalar exchange comes from adding diagonal uncertainty that does not collapse when
   atoms coincide. It does not come from omitting the co-delay coupling. Dictionaries without that diagonal (Γ = 0, hard decisions,
   exact co-delay Γ) do not produce near-duplicate phantoms: 0–1 within 0.25 bin, against 1,733 for the scalar arm.
2. **M** — In this exchange, the exact co-delay block buys no measurable rescue over deleting Γ altogether (the margin excludes
   differences beyond about ±0.7 pp). The two arms take different first edits on 39% of keys but end with the same delay multiset on
   86.5%: the joint detector and the second edit absorb most geometry differences (H-mask, secondary readout only).
3. **M** — Z-sel beats Z by 0.51 pp with 10:0 discordance. Refitting the initial gains with CD's Γ helps the joint detector slightly.
   This leans against a pure "Γ over-shrinks posterior-mean gains" (Berkson) reading for the exchange, but the size is small.
4. **L** — Whether the same holds off P1 (true co-delay pairs, clustered channels) or in the SBL stage is untested. SBL is a different
   regime: there the difference direction needs a floor (res-20261119-03).

## Limits
- One channel family (P1, eight distinct true delays), one grid, pooled triggered-key rescue; ±3 pp is a practical margin, not
  per-cell equivalence.
- Z accepts more edits than CD (no-edit 270 vs 341), so equal outcomes do not mean equal search paths.
