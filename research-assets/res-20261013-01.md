## Observation
- Seal (CAL): C1 non-operable; sealed P* (action value Delta = q20 - q_e) == B4 (generic risk-triggered promotion) in C2/C3,
  P ~ B* in C4 -> frozen primary gate unreachable before TEST (A3).
- TEST screening: pooled C2-C4 vs the five-arm clock hull B0: receiver time -10.48% [8.94, 12.04], inner updates -12.39%
  [10.72, 14.07] (95% CI). C3 FER 1.6 points above B0 (reliability not certified). P vs B4: 0; P vs B5 (direct rescue):
  0.87% [0.51, 1.21] (< 5% bar). P/B*: C2/C3 R = 1, C4 R = .985 (bootstrap upper 1.008).
- G4: load/budget-aware state model beats the generic model in 4/4 leave-one-cell-out cells (Brier gain >= .005); Delta
  ranks net rescue strongly (top vs bottom quintile difference .50, one-sided 95% bound .48).
- Timing: quiet vs main ratio gap <= .015 (< .03); TEST and QUIET rows identical in all deterministic fields.

## Interpretation (scoped)
Per-frame risk-controlled scheduling is a real but modest engineering gain (~10% at near-equal FER) that a generic failure-risk
controller already captures; the action-value (rescue - harm) controller adds no decision value, so the "new controller"
headline is killed (prior art: Lee & Yang 2010, Ylioinas 2013, Strodthoff 2019, Akyildiz-Mahdavifar 2026, EP4364367).
The load- and budget-aware state does carry transferable predictive information about rescue (G4) -> support for A as a
predictive object (5(c) candidate), not for a new scheduler.

## Limits
Screening (n = 1000 test frames per cell; no non-inferiority certification); C1 non-operable; one rho, two SNRs, genie delays,
one code; receiver = scalar-approximate DPSS kernel (codex-kernel-review-20261013.md M1); cost under 64-shard contention
(validated against the quiet subset). G4 is model-level evidence; it does not show a decision or compute benefit.
