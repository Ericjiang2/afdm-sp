## Observation
- Code threshold universal in MI: P(round-1 decode) = .5 at decoder-input MI .576-.578 for SP, true-H and AWGN inputs
  (I* = .577, code only). The old first-pass SINR threshold 1.37 was a coordinate artefact.
- Frozen 1-D scalar error closure (T2) failed: round-1 channel error 1.55-3x above prediction; kill rule applied.
- Interventions (6.5 dB, rho .3, 400 frames): round budget moves the cliff (L20 FER R1-R4 .99/.75/.51/.42); an exact
  channel start is forgotten; freezing the channel fails (FER .965-1).
- Measured return map Phi_K (genie consistent-Gaussian decoder beliefs, disjoint frames) with a staircase rule frozen
  before the grid ran: Kc predicted/observed 77.7/75.7, 136.4/134, 158.5/159.2, 180.3/168.1 (6.5 dB R1-R4),
  138.8/141, 203.5/201 (8 dB R1-R2); |ln| <= .07, 6/6 pass. Fold (tangency) near K 224 at 6.5 dB rho .3.
- Round-1 loop law (derived): refit e_ind(v) = Ks/(1+Ks); link q = eta a (1-e)/(n+e); coherent self-absorption
  e* = e_ind/(1-c)^2, c = kappa beta d, d = q v (Stein). Parameter-free bracket kappa in [0,1] contains the observed
  eps_det1 in 56/56 stored cells. Post-hoc kappa = data share w: I_1 within .036 bit on 12 points, Kc_R1 within |ln| .21
  in 7 groups (retrodiction only).
- A4 fold run (6.5 dB, rho .3; 300 fresh frames, dense injection grid; 10-round runs): mean map below the diagonal
  with CI at K 224/256/288; bistable by the frozen rule, CI-robust at 224 and 256 (no escape below I* at 288). Pilot-start
  runs stall: FER after 10 rounds .61/.85/.95 at K 192/224/256, end states bimodal (~.41 vs ~.78). Mean-map staircase
  correct for Kc up to 6 rounds; it overstates long-run success near the fold (K 192: predicted decode, 61% stall).
- A5 (10-round runs at L16/20 and on the EXIT frames; per-frame maps): Kc_R10 = 180.1 [176.2, 184.8], saturating after
  round 5. Frames whose own map is closed below I* never decode from the pilot start (0/459); open frames decode .29-.50
  (pre-registered >= .8 failed; the Gaussian-belief map is optimistic for real trajectories). For 176/251 (L28) and
  180/288 (L32) stalled frames an injected start below I* decodes within 2 rounds; class-C frames 1/150.

## Interpretation (scoped)
The SP receiver's state is the decoder belief; the code threshold is fixed in MI; the cliff is where the round-1 information
I_1(K) and the return-map staircase fail to reach I* within the round budget. The round-1 loop is monostable in the stored
regime; its information loss is smooth in K/N and is roughly doubled by coherent self-absorption of the channel error.

## Limits
Return map is component-calibrated (measured on the SP receiver), not zero-SP. R1 row near-tautological given the MI
threshold. Start dependence of the outcome shown only under genie consistent-Gaussian starts (2-round horizon); stability
of the stalled state and reachability by real receiver states not shown. The 10-round cliff (finite rounds) is set by per-frame heterogeneity, not by the mean map; per-frame genie maps
are a necessary-condition test only. kappa = w is post hoc. V3 (blind, 20 cells): I_1 within .042, bracket 20/20, e* biased high
(median ln +.21), Kc_R1 within ln .25 with no margin at 6.5 dB rho .2. V1 failed: the LMMSE link is not reliably better
than the T2 link (round-1 output not LMMSE-orthogonal). V2 (loop-gain probe) rejected the self-absorption mechanism
(probe gain .51-.67 vs realised effective gain .07-.22); kappa is an effective constant (~.7 w), not derived. Joint-FP
round 1: soft-symbol noise absorption explains the magnitude of the gap; the fixed-point premise fails (J run). J12: the
excess is mainly the structure of the receiver's own symbol errors; the 20-update round-1 output is mid-transient.
All Kc values above are for the default 20 inner updates per round. 40 updates move R1-R4 by +10-23% at 6.5 dB rho .3
(IB run; one condition, not yet replicated). K/N scaling untested (frozen receiver accepts N = 1024 only). One delay/PDP law, genie delays, QPSK,
LDPC (3,6) n 2048. EXIT and LMMSE are classic tools; novelty not claimed before a literature pass.
