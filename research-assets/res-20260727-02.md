## Verification

- 文件内配对完整性 `torch_ref_errs == classical_errs`：
  - SNR15 **逐位相等**：主跑 27259 = 27259，地板跑 136718 = 136718（各 1,638,400 bits，翻转率 **0**）✅
  - SNR20 **不相等**：主跑 110 vs 111（1 bit，6.1e-7）、地板跑 135638 vs 135647（9 bits，5.5e-6）⚠️
    **成因是 SNR 区间依赖，不是错误数依赖**——地板跑 SNR20 有 135,638 个错误仍翻 9 bit，而 SNR15 有 136,718 个错误翻 0 bit。
    高 SNR 下 LS 增益估计/BP 消息更接近判决门限，NumPy 与 torch 的浮点归约顺序差异才会翻出比特。
    如实记录：NumPy↔torch 锚的逐位等价性在 SNR15 成立、在 SNR20 不成立。
    **对 C1 的直接后果**：bit-exact 判据只在 SNR15 well-posed，SNR20 退化（1 bit 翻转就能让判据失败而无科学含义）→
    审计 v3 §6.3 建议的 `gateA_s15firm` 回放 shard 由此获得实测依据，而不只是方便。
- 两跑均无 `_partial`，每点满 800 帧

## Supported conclusion

1. **「线性/EP 家族结构不可行」三腿论证的第三腿成立**：LMMSE-SP 在两个 SNR 上都到 0.44–0.45（近随机），
   NMSE 仅 −2 dB。按审计判读只进表 + 正文一句，不入 waterfall 主图（会压扁纵轴）。
2. **Cao re-OMP 在我方基底上劣 3.0×（SNR15）**——外部基线对照成立，但公平性需附录（配置对齐表 + dual-protocol 第二列）背书。
3. **串行地板确立**：n_outer=1 → 7.6–7.9e-2，与迭代版差 5.0×，为「部署壳主导」归因提供直接测量。
4. **部署臂 SNR15 −37.04% 复现**（单 seed 800 帧，CI 分离），与 3-seed firm 的 −35.7% 一致 → out-of-sample 复现命中。
5. **PCSI 梯子四级完整定价**（审计 v3 §3.1 的箭头代数，全部同帧同 harness）：
   serial (n_outer=1) 8.345e-2 → classical (n_outer=10) 1.664e-2 → F2P+ach 1.048e-2 → PCSI 3.961e-3。
   以 serial→PCSI 的对数总差（3.048 nat）为分母：**联合迭代单独回收 52.9%，迭代 + F2P 打分交换共回收 68.1%**，
   剩余 31.9% 住在信道估计侧。v3 只能从 classical 起算（得 32.2%），因为它当时还没有 serial 端点。
6. **v3 interim → 终值零漂移**（800f 对 500/800 快照）：classical 1.670e-2 → 1.66376e-2（−0.37%）；
   Cao 3.02× → 2.987×；LMMSE-SP 0.444 → 0.4449；PCSI 4.04e-3 → 3.961e-3；PCSI gap 4.13× → 4.201×，
   ach→PCSI 2.6× → 2.645×。**v3 的「n↑ 只收紧不移动」预言全部命中**。

## Does not establish

- **SNR20 的 −28.9% firm headline 在本跑既未复现也未被推翻**：本跑给 −10.0% 但 p=0.104，
  错误数（110 vs 99）不足以判决。方向一致、量级更小。需要 E3（SNR20 功效化，≥5k 帧或多 seed 池）才能判。
  在此之前，论文引用 SNR20 数字须用 [[res-20260610-01]] 的 3-seed 池，不得用本跑。
- SNR20 的 torch-ref 与 classical 非 bit-exact（差 1 bit）；bit-exact 等价性只在 SNR15 被证。
- 单 seed（20260601），单配置；`ours-reOMP` 在 SNR20 反超部署臂（3.66e-5 vs 6.04e-5）
  这一现象未被解释，也未做多 seed 复验——不可作为结论，登记为待查。
- DRCE / PB-iGaBP 两臂本跑未开（`with_drce=false`, `with_pbigabp=false`），基线覆盖不完整。
- 全部 CPU 跑，与历史 GPU firm 数据不构成 bit-exact 可比。
