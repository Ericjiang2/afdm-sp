## Interpretation
1. **The mechanism replicates outside CSTATE.** In an independent estimator, the scalar data-uncertainty model places many
   extra co-delay atoms on true delays, and the full projected covariance removes them. This is not an iteration-budget
   artefact. Luo's hard-decision version shows almost no excess.
2. **The consequence reverses.** In on-grid SBL the extra co-delay atoms of the scalar model go with better NMSE (.6 dB) and
   better FER, with up to 2.3 dB earlier 1e-2 crossings at ρ .3. The difference is ≈ 0 at ρ .5. The full covariance is no
   better than Luo's hard decisions.
3. **Post hoc candidate explanation, untested.** The fixed .25-step grid has no off-grid refinement, so a fractional-Doppler
   path needs several adjacent co-delay atoms to be represented. The scalar model's ℓ2-type penalty Σv·Σ|μ_k|² rewards
   spreading a path's gain over adjacent atoms; on a grid, that acts as useful interpolation and shrinkage under uncertain data.
   CSTATE instead refines Doppler continuously and has a fixed 8-slot budget, so there the same reward produces pure phantoms
   that displace true paths. A test: give the SBL continuous or off-grid Doppler refinement (as Luo's Taylor step does) and
   check whether the scalar advantage disappears.
4. **What the project can now claim.** "Scalar data models create co-delay atoms; the full covariance removes them" is
   supported in two estimator families. "This is a defect, and the full covariance is the right fix" is supported only for
   off-grid search with a fixed path budget (E-1/E-2). It is not supported for on-grid SBL, where the opposite holds.

## Limits
- One external estimator: on-grid EM-SBL with a screen, which is a simplification of Luo's off-grid D-GESBL. The detector and
  LDPC are the project's own, not Luo's.
- The P1 generator has no true co-delay paths. N = 1024, QPSK, one code.
- The genie gap is large (FER .014 against .11–.15), so this data-aided SBL is far from its own data-genie bound.
- The explanation in item 3 is post hoc and untested.
