§0 · Latent Question — 你没问、但先于一切的问题

Asked（表面问题） 「根据现有证据，这篇论文还站得住的 claim / innovation / contribution 是什么？怎么在尽量复用已有成果的前提下推到顶刊？」
Unasked（决定性问题） Under a byte-identical downstream and a fixed F2-P deployment, which single realizable object is CI-verified to move BER — and is its effect size (−2.0 % relative at the default ρ=0.5) large enough to be the paper's headline, or must the headline be the mechanism law and the deployment, with the scorer as the theory's constructive witness?
为什么它先于表面问题 因为贡献列表是因果归因的下游产物。数据显示 −35.7% headline 里 96.6% 来自「部署壳 + 几何先验」这一层，3.4% 来自协方差感知打分（achievable-Λ），≈0% 来自学习。三层的量级差了一个数量级以上——不先钉死这一分解，任何「贡献怎么写」的回答都会把不同层的功劳互相挪用（旧叙事正是这么死的）。

对 latent question 的直接回答：BER 的可实现移动对象是 achievable-Λ（用 OMP-once 估计 Ĥ⁰ 构造插件协方差 C=(1−ρ)Ĥ⁰Ĥ⁰ᴴ+σ²I 的白化贝叶斯候选打分），在固定部署下 CI-分离地压低 BER，且优势随 (1−ρ) 单调放大（ρ=0.75→0.25：0.7%→1.0%→2.0%→4.5%→4.6%），并在 integer-Doppler 对照下不消失——即它的价值机制是 SP 数据干扰协方差，不是分数多普勒泄漏。但在默认工作点 ρ=0.5 它只有 2.0%：它撑得起「机制定律 + 理论构造性见证」的角色，撑不起「性能 headline」的角色。性能 headline（−36~−37% vs OMP-only support）属于部署层（scored support exchange），且部署层增益已被证明不需要学习（手调几何先验完全复现 head）。所以表面问题的答案被 latent question 直接改写：这是一篇 theory + mechanism + systems 论文，学习是一等公民的 negative/verification 结果——不是学习论文，也不是单纯性能论文。

Executive Verdict — 不悬念，先给判决

一句机制句（先于一切）：The BER-moving object is covariance-aware support scoring inside a fixed scored-support-exchange deployment — not learning — because with the downstream receiver byte-identical, swapping the learned head for the hand-set geometric prior leaves errors unchanged (17 496 vs 17 510 / 1.64 M bits, ratio 0.9992 [0.991,1.008]), while swapping the geometric prior for the plug-in-whitened achievable-Λ removes a further 347 errors (ratio 0.980 [0.968,0.992]), a gap that grows monotonically as pilot power falls (4.5 % at ρ=0.375) and survives the integer-Doppler control (0.977 [0.970,0.984]).

当下唯一诚实的 thesis statement（EN，可直接进 §I）：
"Under superimposed pilots, the pilot-domain residual is corrupted by channel-colored data interference with exact second moment Cd=(1−ρ)σx²HeffHeffᴴ; the OMP selection statistic is therefore a mismatched white-noise GLRT. We derive the in-class Bayes candidate score log Λ = geometric prior + whitened evidence, instantiate it with a realizable plug-in covariance from the one-shot OMP estimate at ≈1.6 % of receiver runtime, and embed it in an OMP-once joint receiver with a scored support-exchange step. Controlled, paired experiments show (i) the deployment delivers −36 % BER at fixed downstream, (ii) the whitened score adds a further CI-separated margin that scales with the SP interference power (1−ρ) and persists under integer Doppler, (iii) the plug-in covariance already attains the genie ceiling, and (iv) a trained scorer — including one given the whitened sufficient statistics — matches but never exceeds the closed form, and has no runtime case, so we report learning as tested-and-null."

什么明确不是贡献：① 学习 head 的 BER 价值（HERO 叙事，死于 Gate A）；② self-suppression（死于 9 200 帧 pool，方向反转）；③ 「泄漏制造先验价值」（死于 integer-Doppler 对照）；④ −80.6%/−88.6% 旧 headline（死于小误差计数 + 复现危机 + F2-P/head 混淆）；⑤ 任何 "near-optimal / first / complexity-optimal" 措辞。

论文类型判定：theory + mechanism + systems 论文（C1 检测理论 + achievable-Λ 构造 + 机制对照实验 + OMP-once 接收机与复杂度账），negative results 一等公民（学习三级 null、self-suppression null、integer-Doppler 双重证伪）。不是学习论文。目标 venue：TCOM（首选）/ TWC；TSP 需把理论份额再抬高一档；TMLCN 作为主投已不成立。

1.1 系统（从 decision_harvest.py::_make_config_a / harvest_frame 逐行确认）

N=1024（DAFT 大小），P=8 物理径，UWA 参数化（vmean=2 m/s，τspread=10 ms，fs=4B 过采样约定，fc=12 kHz 级），fractional Doppler 开启（Dirichlet 泄漏，接收机 cluster-expand kleak=2）。SP 帧：xsp=√ρ·zc+√(1−ρ)·xd，ZC 导频（单位模），QPSK 数据（σx²=1），每样本总功率恒为 1，σ²=10−SNR/10；数据域有效 SNR=(1−ρ)/σ²。每帧 1024 数据符号 = 2048 bits（SP 满速率，无 EP 保护间隔牺牲——这是 SE 卖点的物理来源）。字典 Φ∈ℂN×Q，Q=(2kmax+1)(lmax+1)，本工作点 kmax=2、lmax=102 ⇒ Q=515=O(N)（固定物理 τspread、vmax 下 lmax∝N、kmax∝N）。

1.2 SP 观测与数据干扰协方差（重导）

y = Heff(√ρ·p + √(1−ρ)·xd) + w,   w∼𝒞𝒩(0,σ²I).
OMP-once：ŝ=OMP(y,Φ,P)，gLS=ΦŜ+y，残差 r = y − ΦŜgLS = Φmisshmiss + √(1−ρ)·Heffxd + w − (LS 投影项).
数据干扰二阶矩（xd i.i.d.、E[xdxdᴴ]=σx²I）：Cd = (1−ρ)σx² HeffHeffᴴ，  C = Cd + σ²I.

三个协方差变体即三条 scorer 臂（与 decision_harvest.py L195-210 逐行一致）：genie C=(1−ρ)HHᴴ+σ²I（真 H，oracle 上界）；achievable C=(1−ρ)Ĥ⁰Ĥ⁰ᴴ+σ²I，其中 Ĥ⁰=gen_h_daft(gLS, lomp, komp) 仅由 OMP-once 输出构造（可实现，无 genie 身份）；white C=σ²I（失配）。ρ 已知（发端设计参数），σ² 由接收机估计（recipe: update_sigma2=True）。

1.3 逐候选 Bayes/GLRT 分数 Λ（从零重导，与 decision_bound.py::assemble_lambda_percand 严格一致）

候选原子 φi 的 on/off 假设：H₀: r∼𝒞𝒩(0,C)；H₁: r=hφi+n，h∼𝒞𝒩(0,σh,i²)，n∼𝒞𝒩(0,C) ⇒ r|H₁∼𝒞𝒩(0, C+σh,i²φiφiᴴ)。Sherman–Morrison + 行列式引理：

(C+σh²φφᴴ)⁻¹ = C⁻¹ − σh²C⁻¹φφᴴC⁻¹ / (1+σh²q),   det 比 = 1+σh²q,   q≜φᴴC⁻¹φ.
⇒ log LR = σh²|φᴴC⁻¹r|²/(1+σh²q) − log(1+σh²q) = (b/(1+b))·T − log(1+b),  b≜σh²q,  T≜|φᴴC⁻¹r|²/q.
log Λi = log(πi/(1−πi)) + (bi/(1+bi))Ti − log(1+bi)  （先验 log-odds + 白化证据）。

推导结果与代码实现逐符号相同；(T,q) 经 Cholesky 求解（不显式求逆），decision_harvest.py::_self_test 已含 Prop.1 数值验证 + 显式逆交叉核对（我复核了断言逻辑本身正确）。先验 (πi, σh,i²) 由几何 lookup(dlnn, dknn, gnn) 在独立 calib 流（seed_base+1000+snr，n_calib=400 帧）上分层估计（fine cell ≥30 样本，否则回退 coarse/global）——held-out 红线在代码中成立。

1.4 Proposition（OMP = 白噪声 GLRT 的失配陈述，精确化）

C=σ²I ⇒ Ti = |φiᴴr|² / (σ²‖φi‖²)，与白匹配滤波 |φiᴴr|²/‖φi‖² 排序等价（自测断言 argsort 相等）。

精确措辞义务：完整 Λ 排序 ≡ OMP 排序还需 bi 跨候选近常数（等范数列 + 共同 σh²）或先验平坦；论文里 Prop.1 必须写成「evidence 项在 C=σ²I 下与 OMP 选择量排序等价」，而不是「Λ 退化为 OMP」。失配论断的可检验推论：SP 下白化证据用错 C 会有害——数据证实（§2：white-Λ 4 408 > 纯先验 geom 4 213，geom/white=0.956 [0.932,0.982]，即失配证据比不用证据更差）。

1.5 部署层定义：F2-P = scored support exchange（从 classical_joint_unrolled.py::apply_f2p_refinement L1166-1285 重读）

每轮（共 2 轮）：当前支撑 S 上 LS → 取导频-MF top-M=96 离支撑候选 → scorer 打分 → top-kadd≤4 加入（topk 模式 τ=−∞）；defer_prune=True 轮间不剪；末端在增广支撑上整体 LS，按 |gain| 剪回 |S|≤P，但 logit 最高的 protect_added=2 个新增原子豁免剪枝。即：这是一个带分数保护的 add-then-prune 支撑交换步（CoSaMP/SP 家族的 merge-prune 变体 + score-protected swap），scorer 只影响「换入谁、保护谁」；下游 joint_omp_mp_iterative（n_outer=10 轮 DA-LS 增益重拟合 + MP-BP 检测，pic_iter=20，kleak=2 cluster expand）对所有臂逐字节相同。（注：接收机内核 afdm_baselines.py 不在包内；其旋钮由 recipe 元数据与 f2p_firm _argv 指纹确认，标注为「包外但指纹可查」。）

1.6 复杂度（结构重导 + 实测）

  • 结构：Ĥ⁰ 由 P 个整数 (l,k) 原子构成，每原子在 DAFT 域是一条相位调制的循环对角线（偏移 loc=(α+2Nc₁l) mod N）⇒ Ĥ⁰ 恰有 ≤P 条 populated 对角线；Ĥ⁰Ĥ⁰ᴴ 的偏移 ∈ {loci−locj} ⇒ ≤P²=64 条、成簇（实测 ≤26 @P=8）。C 的 matvec 成本 O(NP)；cond(C)≈60–90（σ²I 正则）。
  • 实测（receiver 级，primary：complexity/runtime_table.*）：N=1024 classical-torch 416.0 ms vs learned（F2-P+head）402.3 ms（差在噪声内）；N=2048：802.7 vs 834.1 ms（+3.9%）；classical-numpy N=2048 1855 ms；外部 qing 基线原生 N=512 268 ms（regime 不匹配，见 §6）。
  • Λ scorer 成本（脚本在包内 decision_complexity_bench.py，原始输出不在包内）：二手报告数值 dense Cholesky 8.7 ms @N=1024 = receiver(532 ms) 的 1.6%（512: 1.2%，2048: 3.4%），maxTrel~1e-11 数值等价。结构上完全可信（上一条 O(NP) matvec + 小常数 N³），但按证据优先级标为 YELLOW：需重跑 dump 原始 JSON 才能进 camera-ready。
  • 推论（复杂度判决）：Λ 便宜 ⇒ 「学 head 摊运 Λ」没有 runtime 理由；OMP-once（O(PNQ)=O(PN²)）避免每轮 re-OMP 的 ~5× 常数与 dense LMMSE 的 O(N³)（后者在 Q=515 已被旧数据证明数值上灾难，见 §9/C5）。措辞恒为 "complexity-preserving"，禁 "complexity-optimal"。
1.7 数学诚实性 caveats（必须写进论文，否则被审稿人先说）： ① 残差 r 经过 LS 投影，其精确协方差是 (I−PŜ)C(I−PŜ)ᴴ + missed-atom 项；代码用未投影 C——一个显式近似（低秩投影、P≪N 下影响小，但要声明）。 ② id 是离散星座的有限高斯混合；Cd 精确、高斯化是 CLT 近似（N=1024 求和使其紧；这同时是 §13 学习复活空间的上界论证）。 ③ C 依赖待估 H ⇒ 精确 Λ 是 genie 边界；achievable 是插件版——而数据显示插件版已贴住 genie（§2），这是论文能白捡的一条正结果。 ④ σh,i²、πi 是 population prior（held-out 校准），不是逐帧量——红线在代码成立，写作时保持。

0. 未被问出的决定性问题（一句）：在字节同构下游 + 固定部署下，唯一被 CI 证实移动 BER 的可实现对象是插件白化 achievable-Λ（默认点 2%、机制上 ∝(1−ρ)），而部署占 headline 的 ~97%、学习占 0——论文必须按这三层分层写。

1. 现在的一句话贡献：We characterize SP-induced data interference as a colored-detection problem in on-grid sparse channel estimation, give a realizable plug-in-whitened Bayes candidate score that CI-beats the geometric prior with a (1−ρ)-monotone, leakage-independent mechanism at ~1.6 % receiver cost inside an OMP-once exchange receiver, and show learning matches but never exceeds it.

2. 这不是什么：不是学习论文；不是 “first SP-AFDM”；不是 near-optimal 性能论文；不是 UWA validated 系统论文（目前）。

3. 三条最硬证据（各带机制）：① 同壳换分器 geom→ach：C⁻¹ 改 (T,q) → 364/800 帧支撑改 → −347 errs，0.980 [0.968,0.992]，且 ρ 律 4/5 格复制；② 同壳 head→geom：排序不变性 → Δ=14 errs，0.9992 [0.991,1.008]（学习 null 的正面机制证明）；③ intDopp 双读：无泄漏 ⇒ 无修复对象 ⇒ 部署 ×3.6 自伤，而 scorer 优势仍 0.977 [0.970,0.984] ⇒ 部署与 scorer 是两个不同机制层。

4. 旧叙事中最危险的残留 overclaim：“the learned head yields −35.7 % (…−85.7 %) BER reduction”——它同时犯归因错误与不可复现引用，任何场合再出现一次都足以让审稿人否掉全文的统计可信度。

5. 现在写、还是先跑哪一个实验：先跑 E1（LDPC）——它是唯一能证伪主 claim 的实验；E1 期间并行写 §II–§V（不依赖它）。E1+E2 落地即投。

6. 若只许保留一个 innovation：achievable-Λ——SP 干扰协方差的可实现白化候选打分及其机制定律（C1+C2 的交点）。

7. 一处刻意不再加结构的地方：部署壳内部（refine/protect/defer 的相对功劳）只给了「壳 ≥87%、entangled」的两层陈述就停——因为对照数据到此为止；在 E5 之前任何更深的分解都是讲故事，不是机制。
