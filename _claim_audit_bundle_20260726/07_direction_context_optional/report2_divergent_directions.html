01延迟-多普勒调制（OTFS / AFDM）→ LEO 卫星 / 高动态（V2X、无人机）核心

是什么把你的 AFDM/OTFS 直接搬到“极端多普勒”的场景：低轨卫星、车联网、无人机。用 AI 做信道预测（LSTM 预测多普勒/时延）、信道估计（CNN/物理引导元学习）、以及贝叶斯/SBL 联合估计与检测。

为什么是你几乎零摩擦地延伸你现在的 AFDM 工作；LEO 是 6G 明确热点；直接对接刘雨莎（她做 LEO＋估计）和 Southampton（Hanzo 组的 OTFS-LEO 是经典工作）——这是你联培的天然桥。

02模型驱动深度学习 / 深度展开（你的“签名方法”，不是某个题）核心

是什么把迭代算法展开成可训练网络（OAMP-Net2 一类），注入领域知识——参数少、要数据少、可解释，同时打败纯模型法和纯数据法。它不是一个方向，是你带着走的方法：检测、信道估计、波束成形、译码、感知，处处能用。

为什么是你这是你最强的那张牌（你已经做过 MP-BP、深度展开、OMP）。立足点足、几乎不吃硬推导，且是“模型＋ML 双语”者的专属地盘——纯 ML 出身的人做不好。把它当作你贴在所有课题上的底色。

03水声通信 ＋ 深度学习（你的本科毕设老本行）蓝海备选

是什么水声信道是典型的双弥散（强多径＋多普勒）——你的 AFDM/OTFS 与稀疏估计技能原样迁移。模型驱动的信道估计（OMP/展开）与检测正是主线。

为什么是你你本科就做过（SP-AFDM、OMP、MP-BP）；刘雨莎也有一篇水声 OMP 的论文，组里有抓手。海洋/国防是国家需求，而且明显更蓝海、不拥挤——一条“用同样的牌、却少很多人挤”的赛道。前景偏 niche，但作为主线之一或副线都稳。

04低空经济 / 无人机 通感（ISAC 的应用垂直）可加挂

是什么ISAC 的具体落地场景，3GPP Rel-20 单站感知的首攻用例就是无人机。在中国“低空经济”是明确的国家级战略风口。

05可移动 / 流体天线（MA / FAS）可加挂

是什么2024–2026 最热的新方向之一：天线位置/形态可重构，带来电磁域的新自由度。和 ISAC 交叉（MA 增强 ISAC），也大量用 AI（学习式“波束＋天线位置”联合设计）。

为什么是你（部分）UESTC 有人在做（梅卫东、赵宜哲一线），热度高、还算新。但它偏阵列/优化，离你的“波形＋估计”稍远，优化味也重一些。适合作为加挂或合作，不必硬当主线。

06面向任务 / 语义通信（应用侧 DeepJSCC，非纯理论）看情况

07近场通信 / 超大规模 MIMO（XL-MIMO）了解即可

是什么6G 热点：超大孔径阵列把工作区推到近场，球面波建模带来新的信道估计/波束成形问题。

为什么不当核心能用上你的估计技能，但阵列信号处理与优化偏重、数学更硬，且已相当拥挤。知道、能合作，但不是你优势最大化的地方。

08无线大模型 / 生成式 AI for 信道（LWM 等）了解即可

是什么最前沿：用大模型/基础模型做通用无线表征、用生成模型造信道与回波数据。天花板很高。

最终排序其实不是 8 选 1——最好的几个会合成一个

发散调研最容易给人“选项太多”的焦虑。但把你的牌摊开看，排名最高的三条不是互相竞争，而是能拼成同一个研究身份。

把 No.1 ＋ No.2 ＋（其一里的 ISAC）合起来
面向高动态 / LEO / 通感场景的
“模型驱动 AI × 延迟-多普勒（AFDM/OTFS）传输与感知”

这一个身份，用上了你的每一张牌：AFDM 波形优势、深度展开方法、刘光辉的 AFDM-ISAC-AI 线、刘雨莎的 LEO＋估计＋Southampton 桥、6G 的国家需求与耐久度。它窄到可防御、又宽到能发很多文、还能加挂“低空/无人机”这层国家需求外衣。

第二梯队（同样复用你的牌，作为对冲或副线）：

  • 水声通信＋DL——如果你想要一条更蓝海、少人挤的路，它用同一套技能、还连着国家海洋/国防需求，是很好的“安静赛道”备选或副线。
  • 低空 / 无人机通感、可移动天线——作为主线的加挂，提升立项与就业，不必单独立身。

建议别当核心的（不哄你）：

  • 纯语义信息论——硬推导密集、空白造地基，正踩你两个软肋。
  • 无线大模型 / 近场理论——要么是 ML 原住民主场、要么数学更硬，你的优势在这里被稀释。了解、合作即可。
