国内博士论文全文多在知网/万方付费墙后，无法逐篇通读。本报告按“有策略地读”——以标题、摘要、创新点、关键词、可见的章节结构为单位，覆盖 6 个聚类、20+ 篇代表性工作（含可确认的万方/校库学位论文、以及结构与博士论文章节高度同构的顶刊综述与代表作）。对“反推合理 scope”这个目的，这个粒度恰好够用且准确——因为博士论文的“骨架”就写在摘要与目录里。文末按聚类列出全部语料并标注类型。

物理层博士论文从来不是一个“窄点”，

主线（一种波形 / 一个场景 / 一个方法范式）
　＋ 信道估计 → 信号检测·接收机 → 均衡·同步·波形优化 → 一个延伸（ISAC / 场景 / 反馈）

几乎每一篇延迟-多普勒、ISAC、深度学习物理层的博士论文都是这个骨架。所以你纠结的“方向是不是太窄”是个伪问题——正确的规划单位不是一个点，而是“主线＋章节束”。你要做的，是选一条能把你已有的每块积累都变成一章的主线。

01 / 调研六个聚类，各自的“主线＋章节束”长什么样

每个聚类给出：典型主线、反复出现的章节束（这是关键证据）、代表语料、以及对你的契合评级。注意各聚类的章节束高度相似——这正是“可迁移的博士骨架”。

A延迟-多普勒波形（OTFS / AFDM）主线契合 ★★★★★

章节束

波形原理·分集分析 → 信道估计（压缩感知 / SBL / 非均匀网格）→ 信号检测·低复杂度接收机（MP / 迭代 / BEM）→ 同步·均衡·分数多普勒 → 场景（车联网 / 卫星 / 海洋）或 ISAC 扩展

为什么是你这正是你现在做的事，章节束里每一格你都有存量（AFDM 波形、OMP/SBL 估计、MP-BP 检测）。是你“摩擦最小”的主线。

语料廖勇等《6G 时延多普勒范式 OTFS》(JEIT 综述，给出了同步/估计/检测×车联网/无人机/卫星/海洋的标准骨架)、OTFS 压缩感知信道估计、OTFS 分数多普勒加窗估计、低复杂度 OTFS 接收机(SBL+d-LSMR/BEM)、SJTU《SBL OTFS 信道估计》等。

B通信感知一体化（ISAC）主线契合 ★★★★

章节束

一体化波形设计 → 性能折中分析·CRB → 参数估计·感知算法 → 双功能接收机 → 资源分配·场景（车联网 / 低空）

为什么是你是 A 的天然延伸章（你“其一”报告里 AFDM-ISAC 的位置）。国家需求对齐、好立项；偏“折中分析”的章会用到一点 CRB，但仍以算法/仿真为主。

语料AFDM-ISAC 理论框架与导频设计(JSAC)、c₂ 数据驱动 AFDM-ISAC 波形、基于 OTFS 的车联网通感一体化(USTB)、通感一体化硬件设计综述(JEIT 2025)。

C模型驱动深度学习 / 深度展开（方法范式主线）契合 ★★★★★

章节束

数据驱动 vs 模型驱动综述 → 信道估计（LDAMP / 展开网络）→ 信号检测（OAMP-Net 类）→ 联合估计-检测 → CSI 反馈 / 端到端

为什么是你这是你最强的牌（MP-BP、深度展开、OMP）。它是贴在 A/B 每一章上的方法底色——把传统迭代算法展开成可训练网络，参数少、要数据少、可解释、同时打败纯模型与纯数据。几乎不吃硬推导。

语料《基于模型驱动深度学习的 OTFS 信道估计》(LDAMP 深度展开，JEIT 2024)、Model-Driven DL for MIMO Detection (OAMP-Net2, TSP)、《模型驱动的物理层通信深度学习》综述、Deep Unfolding 综述(arXiv 2502.05952)。

DAI-native 空口 / 神经接收机主线（前沿）契合 ★★★★

章节束

神经接收机（估计＋均衡＋解映射合一）→ 学习星座·无导频传输 → 收发端到端联合优化 → site-specific / 协议学习

为什么是你（有条件）这是“通信＋AI”推到极致的版本，势头与标准支持都最猛。但纯黑盒端到端是 ML 原住民的主场，对你有风险；适合你的是模型驱动版的神经接收机＋你的波形——见下一节专门分析。

语料Hoydis 等《Toward a 6G AI-Native Air Interface》(神经接收机/无导频/协议学习)、《5G-Advanced Towards 6G》AI-native 章、Samsung Research 6G PHY AI/ML、DeepSig OmniPHY × NVIDIA AI Aerial、含语义压缩的原生 AI 空口(arXiv 2508.15277)。

E大规模 / 毫米波 MIMO ＋ 深度学习主线契合 ★★★

章节束

信道估计 → CSI 反馈 → 波束训练·跟踪 → 信号检测 / 预编码

为什么部分能用上你的估计/检测技能，章节束清晰、学位论文样本最多（下列均为可确认博士论文）；但阵列/优化偏重、较拥挤，离你的“波形”优势稍远。可借鉴其骨架，不必当主线。

语料（学位论文）《基于深度学习的毫米波大规模 MIMO 信道估计》(万方)、《…波束训练与波束跟踪》(万方)、《基于深度学习的 MIMO 信道估计与 CSI 反馈研究》(西南交大)；另：稀疏连接网络大规模 MIMO 检测(JEIT)、Massive MIMO CSI 反馈综述(Mashhadi & Gündüz)。

F水声 / 探测通信一体化主线（蓝海）契合 ★★★★

章节束

双弥散水声信道建模 → 稀疏信道估计（OMP / 展开）→ 一体化波形 → 检测 → 声呐 / 海洋应用

为什么是你你本科毕设老本行；水声信道也是双弥散，AFDM/OTFS 与稀疏估计技能原样迁移；刘雨莎也有水声 OMP 论文；海洋/国防国家需求、且明显更蓝海少人挤。是极佳的副线或差异化主线。

语料《探测通信一体化波形研究进展与声呐应用展望》(信号处理学报 2025)、刘雨莎组水声 OMP 高精度信道估计(WCL 2026)。

02 / 专题AI-native 物理层：它是个“方向”，更是你的“总命名”

你新看到的 AI-native 物理层（AI-native 空口）值得单列。它不是又一个并列选项，而是“通信＋AI”推到尽头的形态，且很可能是你整套身份最合适的高层命名。它有一个清晰的三级阶梯：

  • 第一级 · 替换单个模块：用 NN 做信道估计 / 解调 / 译码中的某一块。
  • 第二级 · 神经接收机：把信道估计＋均衡＋解映射合并成一个训练好的模型——这一级正好命中你的估计＋检测存量。
  • 第三级 · 端到端 / 无导频：收发联合训练、学习星座、去掉导频（DeepRx、DeepSig OmniPHY 实测吞吐增益约 15–20%）。

势头是真的：Hoydis 团队的“6G AI-native 空口”、Samsung/Nokia 的神经接收机、DeepSig×NVIDIA 的实机演示、以及 3GPP Rel-18/19 已把 AI/ML 写进空口框架（CSI、波束、定位）。

对你的判断

别去做“纯黑盒端到端”那一版——那是 ML 原住民主场，你的模型素养被稀释。要做“模型驱动的 AI-native”——把神经接收机做成可解释的深度展开，并叠上你的延迟-多普勒波形，得到一个别人抄不走的角度：“AI-native 延迟-多普勒空口”。这样，AI-native 就从一个竞争对手，变成了你整套研究的总命名（umbrella）。

05 / 为什么这是“智慧”而不只是“热”五个约束同时满足

  • 导师契合：刘光辉主页明写“AFDM-ISAC-AI 波形＋接收检测”，刘雨莎做“AI＋估计＋LEO＋水声”——这份蓝图的每一章都落在两位老师的射程内。
  • 认知契合：六章全是“有立足点、把已有方法做更好”的类型，避开了你不擅长的“空白造地基＋长篇硬推导”。
  • 目标契合：应用/整合型、稳定出文、对齐国家需求——正是双一流/一本/985 分校教职最想要的画像；不行也有移动研究院/电科/华为做地板。
  • 可立项：6G、AI-native、ISAC、低空、海洋——条条对齐国自然与国家战略。
  • 耐久：主线是“波形＋估计＋检测”这种慢变核心，套上 AI-native 的快变外壳——内核不贬值，外壳追前沿，跑道到 2030+。

不哄你 · 三个别当主线：

  • 纯黑盒端到端 AI-native（ML 原住民主场，稀释你的优势）。
  • 纯语义信息论 / 近场重数学方向（硬推导密集，踩你软肋）。
  • 无线大模型（算力＋ML 工程为王，离你的波形太远）。
