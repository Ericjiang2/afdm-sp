# Fixed-channel OAMP/LDPC replay

Development comparison on the archived 6.5 dB population, with no new frames or channel estimation. Include every frame whose saved TF prefix finished with a nonzero LDPC syndrome. Both continuations use the saved round-1 delays, Dopplers, final gain means, and clipped LDPC check extrinsic. The deployment policy keeps the native decision on every non-triggered frame.

Both arms run two fresh LDPC calls (50 sweeps maximum per call, input clipping at ±20), with check extrinsic replacing the previous code prior. TF uses 20 fixed-gain scalar iterations per call. OAMP uses a trace-normalized scalar LMMSE stage with the decoder as its nonlinear stage. Project the check prior to QPSK moments and use their average variance for the linear solve. For this fixed channel, precompute one eigendecomposition of the time-domain Gram matrix per frame, then reuse it across the two calls. Use the existing CPP/DAFT operator, bit order, decoder, and frozen code. This is an untrained OAMP detector/decoder loop, following the scalar Gaussian message construction of Luo et al., arXiv:2312.11302 §IV-C, with the repository's check-extrinsic convention.

Preserve the source/observation/checkpoint hashes and both decisions per arm before opening truth. Verify the archived TF and CSTATE decisions against the original counts. Report both rounds, the number of CSTATE-only rescues recovered, paired rescue/harm counts, and serial single-thread timing including OAMP setup, detector, and decoder. CSTATE is an archived one-call reference. Timing against archived CSTATE is descriptive.

Advance to formal baseline design only if OAMP recovers at least half of the archived CSTATE-only rescues and its median continuation time is at most twice the matched fixed-TF time. Prediction before the run: probability of passing both criteria 0.25. A failure to pass applies only to this fixed-H implementation and budget. This is a reused-cohort screen.

Qualification: compare the eigensolver update against a direct LMMSE solve on a dense nonorthogonal fixture, check that a scaled identity channel cancels the incoming code prior exactly, and compare the archived physical channel matrix against its independent AF-domain apply path on each triggered frame. Fail on any hash, allocation, finite-value, or identity error. One CPU thread. Remote launch cap 15 minutes.
