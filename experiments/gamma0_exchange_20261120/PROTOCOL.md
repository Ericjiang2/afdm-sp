## 2. 主判定（冻结后不重标）
**P-A：自洽类是否不生幻影**（Z 与 H 各自判定）
- 幻影率 = 触发键中，最终支撑含至少一对同时延原子的比例。P1 的真实路径时延互不相同，所以任何同延对都是虚假的；G3 须核实新帧满足这一点。
- 锚点（有效性前提）：S 的幻影率下界 ≥ 80%，且 CD 的幻影率上界 ≤ 5%；不满足则记 ANCHOR_FAIL，不下定律判定。
- **SUPPORTED**：该臂幻影率的 95% 上界 ≤ 10%。
- **REFUTED**：95% 下界 ≥ 30%。
- 其余为 INCONCLUSIVE。

**P-B：交换中能否删掉 Γ**（Z 对 CD 为主判定；H 对 CD 只报告）
- 救回 = 触发键上该臂译码后信息位零错。Δ_Z = rescue(Z) − rescue(CD)，配对，按帧簇 bootstrap 的 95% 区间。
- **EQUIVALENT**：区间整体落在 [−3, +3] pp 内。
- **CD_BETTER**：区间上界 < −3 pp。
- **Z_BETTER**：区间下界 > +3 pp。
- 其余为 INCONCLUSIVE，并报告方向。
- 3 pp 裕量的理由：stage 3 中触发键的 `CODELAY` 救回率约 33%（1,976 个触发中失败 1,318 个），3 pp 约为相对 9%；它也是 Fable 预注册的"相差 3 pp 以内"。

**组合读法**（只是映射，不另立判据）：
- P-A SUPPORTED 且 P-B EQUIVALENT → Fable 定律的完整版；
- P-A SUPPORTED 且 P-B CD_BETTER → 一半：几何自洽足以防幻影，Γ 对增益或排序另有价值；
- P-A REFUTED → 定律错。

**7.2 更正 §0、§4、§5 中的机制陈述（REQUIRED）**
- "Gram 是真向量的 Gram"本身既不保证同延内积等于 N·D_N，也不保证没有幻影：软列的实际内积还取决于波形的时域功率剖面，有限间隔时差模方向会去拟合残余的数据干扰。
- 恰好重合、总增益 H 固定时，Z 与 CD 省下的罚都是 λ|H|²/2。按 Prop 2，孤立母原子（列能量 E）的拆分奖励占其得分下降的比例为 λ/[2(E + a) + λ]，Z 取 a = 0，CD 取 a = u。
- 有限间隔时，Z 对差模方向只付 λ，CD 另付 u(1 − |D_N|)。这给 H-overfit 一个具体机制；§5 中"拆分奖励只剩岭项"只对恰好重合成立。
- H-shrink 与 H-Berkson 不能靠救回差的方向区分，只能靠 §3 的机制读数和 7.5 的 Z-sel 臂，二者仍为次要。res-20261018-02 本身记录过一次失败的同支撑增益预测。
