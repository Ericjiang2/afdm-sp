## 规则外的探索性检查：ρ = .05 为什么给了全真信道也到不了
full 臂在 ρ = .05 时，第 0 轮译码在所有 SNR 下约 100% 失败（12 dB 时 99.9%）。20 个键（U，12 dB）的对照：
- 检测器默认的联合增益重估（`gain_mode='joint'`）：即使从真增益出发，估出的增益也偏到随机相位（例如 87°、−77°、153°），幅度比 0.2–6.9 倍，第 0 轮失败 20/20。
- 增益固定（`gain_mode='fixed'`）：失败 0/20。
- ρ = .10 时联合重估能锁住相位（偏差 ≤ 1°），但幅度系统性偏大 6–21%，失败 0/20。

所以 ρ = .05 那一列测到的是检测器的问题（导频太弱时，增益和数据之间的相位歧义锁不住），不是信道信息不够。冻结判读只用 ρ ≤ .20 的最小值（落在 ρ = .10），不受影响。

## 未检验的解释
- 时延找对以后，第 0 轮的**多普勒精度**还值约 0.95 dB；增益精度几乎不值钱（ldop ≈ full）（H）。这和阶段 A 中"时延全对仍失败的帧，约一半多普勒偏 0.1 bin 以上"一致。
- 这是全真参数的上限，任何可实现的估计器都达不到。可实现的部分取决于第 0 轮多普勒要准到什么程度：需要一条"多普勒误差—穿越点"的容忍度曲线，再和导频单独、导频加数据两种下界去对照（M）。
- ρ = .05 是第二道墙：检测器的联合增益更新本身在极低导频下失稳。它和 STATE 研究第 1 项里"检测器增益接口（固定 vs 联合重估）"可能是同一类问题，未核对（L）。
