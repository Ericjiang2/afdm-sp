## 第二层：预注册冻结判定（不改标）

- **主估计量**：$E = \min_{\rho \in \{0.10, 0.15\}} \overline{M}_{\mathrm{SB}}(\rho, 4\text{ dB}) = \mathbf{0.0430\text{ bin}}$（取于 $\rho = 0.15$），95% 物理帧聚类自助区间 **`[0.0408, 0.0455] bin`**。
- **冻结规则**：CI 上界 $\le 0.08 \Rightarrow$ **`PASS`**；下界 $> 0.08 \Rightarrow$ `FAIL`；其余 $\Rightarrow$ `BORDERLINE`。
- **结论**：**`PASS`**（上界 `0.0455` 远低于 `0.08` bin；即使单独看 $\rho = 0.10$，`SB` 亦为 `0.0527 [0.0495, 0.0559] bin`，上界同样远低于 `0.08`）。

## 第三层：未经验证的解释、边界条件与后续含义（附置信度）

1. **为什么精确梯度联合 `L-BFGS-B` 能紧贴 `SB-CRB`（`1.09×–1.32×`），而冻结前固定增益坐标搜索却在 12 dB 卡在 `1.84×`？**（*未经端到端验证，但有 G3 隔离诊断支撑*，置信度 **H**）
   - 在未中心化的时间索引 $k \in [0, N-1]$ 下，单径多普勒 $\nu_p$ 与复增益相位 $\angle g_p$ 存在强线性耦合（$\rho \approx \sqrt{3}/2 \approx 0.866$），且协方差项 $\log\det C + e^H C^{-1} e$ 携带了关于增益幅度与相对相位的关键信息。固定增益做一维多普勒扫描并用仅导频 GLS 更新增益会沿窄谷停滞；联合优化全部 $3P$ 实参数 $(\nu, \operatorname{Re} g, \operatorname{Im} g)$ 直接释放了半盲似然的全部信息，使得实测效率在 4 dB 下即达到 `1.32×`（$\rho=.10$）和 `1.17×`（$\rho=.15$），与渐近 `SB-CRB` 非常接近。
2. **从 Stage A 实测误差（`.157/.108/.082`）到 `SB`（`.053/.043/.038`），收益由两部分叠加**（*描述性分解，置信度* **M–H**）：
   - 在已知真时延前提下，仅把第 0 轮导频估计换成连续变量投影最小二乘（`PW`）就将 4 dB 误差压到了 `.093/.073/.061`（接近 `PW-CRB` `.085/.068/.058`）；
   - 在此基础上，半盲高斯协方差项（`SB`）再把误差整体压低 **38%–43%**，在 $\rho = 0.15$ 下几乎触达 Stage A3 中"保住全部收益"的 `0.04` bin 线（`0.0430`）。
3. **本代理检验未验证的关键缺口（不可直接外推为端到端 FER 结论）**（置信度 **H**）：
   - **未知时延**：A5 给定了真时延 $l_i$。在 $\rho = 0.10\text{–}0.15$、4 dB 下，真实第 0 轮导频检测可能漏检弱径或引入假时延；未知时延下 `SB` 能否保持 $\le 0.08$ bin 仍需专门检验。
   - **弱径离群尾与 FER 映射**：尽管功率加权 MAE 很低（`0.0430` bin），但未加权的逐径离群率（$|\hat{\nu}_i - \nu_i| > 0.25$ bin）在 $\rho = 0.10/0.15$ 下仍达 `23.25% / 18.62%`（主要落在弱径，对照 `KD` 仅 `5.12%`）。Stage A3 的 `s050/s100` 是对全部路径施加均匀高斯抖动，弱径大误差对真实 LDPC/检测器 FER 的影响需端到端验证。
   - **计算开销**：当前直接对 $1024 \times 1024$ 稠密矩阵做 Cholesky + `zpotri` 单键耗时约 `10.6 s`（约为 `CD2` 单次触发 `189 ms` 的 ~55×）。工程落地前需低复杂度结构化/子空间近似。

### 下一步建议
按协议 `PASS` 分支：在进入端到端 FER 之前，先做**未知时延下的低导频第 0 轮联合/两步半盲估计检验**（明确时延漏检与计算开销是否构成新瓶颈），并同步评估是否需要低复杂度半盲近似以匹配 `CD2` 的延迟量级。
