# 阶段 0b：多锚叠加打分——冻结规则（FROZEN 2026-11-21，计算前提交）

来源：Eric 转来的建议（11-21）。阶段 0 的召回是 .653，但精度只有 .192，原因是"不经过锚的径对"和"强径与强径"的峰也被当成了候选。建议的改法：一条真弱径会和**每一条**已找到的强径各产生一个峰，所以对每个绝对位置的假设，把它相对所有已知径的峰值加起来打分。前后歧义也随之消失，因为假设的就是绝对位置。脚本 `stage0b.py`，复用 `stage0.py`，键与阶段 0 完全相同（1,200 个）。

## 打分（只用观测量）
- 已知径 = F0 第 0 轮保留的 8 条（`r0_delays`、`r0_dopplers`；可能含假原子，不做筛选）。
- 假设 (ℓ, ν)：ℓ ∈ 0..102 且不在已知径里；ν 取 −2.5 到 2.5、步长 0.25。
- 分数 = Σ_j（自相关图在 (|ℓ − ℓ_j|, 折叠后的 ν − ν_j) 处 ±0.5 bin 内的最大值），j 遍历已知径，同时延的跳过。每个 ℓ 取 ν 上的最大分数。
- 新候选 = 分数最高的 8 个时延。"强径与强径"的峰不需要单独剔除：它们只在一个已知径对上出现，叠加不起来。

## 打分方式与阶段 0 相同
召回 = F0 第 0 轮漏掉的有效径中进入新候选的比例；精度 = 新候选中真时延的比例。另报前 2 个候选的精度。

## 预写判读（不改标签）
合并精度 ≥ .50 **且** 召回 ≥ .60 → **ADOPT**（阶段 B 用多锚打分产生候选）；否则 → **FALLBACK**（阶段 B 退回"只放 1–2 个候选"，在阶段 0 选择器和本打分中取前 2 精度更高的一个）。
