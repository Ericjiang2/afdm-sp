# 阶段 A4：第 0 轮多普勒的四种下界——冻结协议（FROZEN 2026-11-21，运行前提交）

任务 `.trellis/tasks/11-21-data-pilot-fer`。接阶段 A3：判读 MIDDLE，规则是先算导频单独和导频加数据的多普勒下界，再决定做不做估计器。Eric 11-21："算下界"。脚本 `stageA4.py`。

## 问题
第 0 轮给定真时延时，只用导频（以及在不同程度上利用数据）估多普勒，理论上最多能估多准？能不能达到 A3 测出的"收益全部保住"的精度，即功率加权平均绝对误差约 0.04 bin（σ = 0.05）？

## 模型（原始单位，门槛 G1 已核到 6e-16）
y = F T F^H (p + d) + w，F 是 DAFT（酉矩阵），T = Σ_i g_i diag(c_i) P_{l_i}，与 `physical.regressors` 一致。未知量是每条径的多普勒 ν_i 和复增益 g_i（增益作为干扰参数一起算进 Fisher 矩阵），时延已知。数据是 QPSK，每个子载波功率 v_d = 1 − ρ；导频功率 ρ；噪声 σ² = 10^(−SNR/10)。

| 下界 | 含义 |
|---|---|
| pilot_white | 只用导频，把数据当白噪声（现有接收机第 0 轮的做法） |
| pilot | 只用导频，但知道数据干扰的真实协方差 C = v_d T T^H + σ² I（最好的"只看导频"估计器） |
| semiblind | 导频，加上数据的二阶统计（把数据当高斯，Slepian–Bangs）：数据协方差里携带的信道信息 |
| known | 全部数据已知（任何用数据的方法的天花板，第 0 轮实际达不到） |

CRB 是局部下界：它不覆盖门限区（大误差、离群值），估计器在低 SNR 下可能离它很远。QPSK 的有限字母表信息介于 semiblind 和 known 之间，这里没有单独计算。

## 设定
- 帧 41000–41099，场景 U/G，共 200 个信道；ρ ∈ {.10, .15, .20}；SNR ∈ {3, 4, 5} dB。同一帧的信道在各 ρ、SNR 之间相同（运行中断言）。
- 指标与 A3 相同：Σ|g_i|²·min(√(2/π)·√CRB_i, 0.375) / Σ|g_i|²。0.375 是 ±0.75 bin 搜索窗内均匀误差的平均绝对值，用来避免个别不可辨识的径把平均值撑爆。对 200 个信道求平均，并报告中位数和按信道自助 2,000 次（种子 20261121）的 95% 区间。

## 门槛（运行前已通过，`out/stageA4_gate.json`）

## 读数（冻结，不改标签）
在 SNR = 4 dB，对每个下界取 ρ ∈ {.10, .15} 中较小的平均值，按顺序判：
1. pilot ≤ 0.04 → **PILOT-ENOUGH**：信息已经在导频里，现有误差（ρ = .10 时约 0.157）是估计器的损失。下一步做更好的纯导频第 0 轮估计器，不需要数据。
2. 否则 semiblind ≤ 0.04 → **SB-REACHABLE**：数据的二阶统计足以补上。下一步做半盲第 0 轮多普勒估计器，用 A3 的代理指标检验。
3. 否则 known ≤ 0.04 → **ALPHABET-ONLY**：只有判决类（用到符号字母表）的信息才够，第 0 轮没有判决，这条线难。
4. 否则 → **CLOSED**。
- 如果决定标签的那个下界在对应 ρ 上的 95% 区间包含 0.04，标签后加"(borderline)"。
- 描述：四个下界在每个 ρ、SNR 上的平均值、中位数和区间；与 0.08（σ = 0.1，保住约六成）的比较；ρ = .10/.15/.20 时导频的实际第 0 轮误差（阶段 A，.157/.108/.082）与 pilot_white 下界之比（估计器效率）。

## 竞争假设与预测
| 假设 | 预言 |
|---|---|
| H-pilot：导频信息已经够，现有误差主要来自估计器（门限、离群值） | pilot ≤ 0.04（PILOT-ENOUGH），实际误差 / pilot_white ≫ 1 |
| H-cov：导频不够，但数据协方差带的信息能补上 | pilot > 0.04 ≥ semiblind（SB-REACHABLE） |
| H-alpha：协方差也不够，只有知道符号才行 | semiblind > 0.04 ≥ known（ALPHABET-ONLY） |

- Claude（粗算：ρ = .10、4 dB 时 pilot_white 约 0.1，known 约 0.02）：PILOT-ENOUGH .10 / SB-REACHABLE .40 / ALPHABET-ONLY .45 / CLOSED .05。

## Premortem
最可能误导的地方：CRB 是局部下界。如果 semiblind ≤ 0.04，也只说明"信息上不排除"，低 SNR 下估计器能否接近这个下界要另测。另外 A3 的 0.04 来自高斯注入，而 A3 的锚点显示真实误差的伤害比同样平均值的高斯误差小，所以 0.04 可能偏严。
