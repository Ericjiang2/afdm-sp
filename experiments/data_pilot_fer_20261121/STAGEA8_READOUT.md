- **结论**：**`GO`（值得继续）**。95% 配对区间下界 **`+0.8063 dB`** 大幅超过 `+0.50 dB` 门槛；给定真时延下的第 0 轮多普勒线总空间（`CD2 − ldop = +0.9638 dB`）中 **`98.5%`（`+0.9492 dB`）被无真值全局半盲估计器 `SBGdop` 完整回收**，最优导频比例同步下移至 $\rho = 0.10$（`3.4664 dB`）。*(注：对 Stage A6 [STAGEA6_READOUT.md](STAGEA6_READOUT.md) 第三层中“半盲第 0 轮多普勒无法领先 CD2”的旧判断作显式更正——A6 的失败纯属 `PW` 单起点局部搜索陷阱，不改高斯半盲似然即可通过全局初始化与逃逸扫描消除。)*

## 第三层：未经验证的解释、方法学边界与下一步含义（附置信度）

1. **为什么消除旁瓣后 $\rho = 0.10$ 反超 $\rho = 0.15$ 达 `0.48 dB`（`3.4664 vs 3.9437 dB`）？**（*与 `ldop`/`s050` 趋势一致，但未单独拆解检测器与估计器贡献*，置信度 **H**）
   - 一旦 `SBG` 消除了 $\rho = 0.10$ 下的强径旁瓣错锁，$\rho = 0.10$ 将 `90%`（对比 $\rho=0.15$ 的 `85%`）功率分配给编码数据符号，既提升了终端检测器/LDPC 的有效数据信噪比（约 `+0.25 dB`），又增强了协方差项 $v_d T T^H$ 的信干噪比；剩余 `8%–9%` 的离群径全部局限于功率最低的极弱径，对 1% info-FER 几乎无损。
2. **`3.0–4.0 dB` 网格间距与 `1e-4` 截底插值的刻度风险（需 `3.50 / 3.75 dB` 加密复核）**（*方法学事实*，置信度 **H**）：
   - 与冻结的 `stageA2`（`ldop = 3.4518 dB`）和 `stageA3`（`s050 = 3.4559 dB`）完全相同，`SBGdop` 在 $(\rho=0.10, 4.0\text{ dB})$ 实测终态错误为 `0/800`（F0 错误 `26/800 = 3.25%`，高于 `ldop` 的 `4/800 = 0.50%`），`stageA2.crossing` 按历史定义将 `0/400` 截底为 `10^{-4}` 后在 `3.0 dB`（`56.12%`）与 `4.0 dB`（`0.00%`）间对数插值得到 `3.4664 dB` 及极窄 CI `[3.4619, 3.4703] dB`，且 `SBGdop − ldop = +0.0145 dB` 完全由 `3.0 dB` 错帧比与 `10^{-4}` 截底代数决定（`0/400` 与 `1/400` 之间存在 `+0.28 dB` 插值跳变）。*（审阅更正：若完全不用 `(3.0, 4.0) dB` 内插而仅取 `4.0000 dB` 作保守上界，则 `4.4156 − 4.0000 = +0.4156 dB`、配对 95% 下界约 `+0.27 dB < 0.50 dB`，不足以单独跨过 `+0.50 dB` 门槛；故在 Stage A8b [STAGEA8B_PROTOCOL.md](STAGEA8B_PROTOCOL.md) 中对 $\rho=0.10$ 补测 `3.50 dB` 与 `3.75 dB` 直接消除该插值盲区。）*
3. **下一步真正的关键瓶颈（未知时延放开）**（置信度 **H**）：
   - 本轮（与 A5/A6 一致）给定了真时延 $l_i$。既然在已知时延下第 0 轮多普勒的 `~0.95 dB` 空间已证明可由纯高斯半盲全局搜索完整回收，且单键耗时已压至 `2.94 s`，下一步唯一决定工程闭环的问题是：**放开未知时延**（例如结合 `data_autocorr_acq_20261121` 的数据自相关时延捕获或候选时延集上的分块快速半盲评分），检验未知时延下能否保住这 `+0.95 dB` 中的主体（$\ge 0.5\text{ dB}$）并进一步压缩单触发延迟。
