## 第二层：预注册冻结判定（不改标）

1. **主对比冻结裁决**：**`STOP`**（不满足自动推进门槛，按任务书第 4–5 条提交完整增益–成本曲线由 Eric 决策）。
   - **依据**：主对比两侧最小穿越点均满足 $\le 0.50\text{ dB}$ 严格括号（实际均为 `0.25 dB` 步长双侧非零错帧括号），无真值双束接收机 `SBJ`（$\rho=0.10$ 处 `3.9166 dB`）相对完全无真值的 `CD2`（$\rho=0.20$ 处 `4.4296 dB`）取得点估计 **`+0.5130 dB`** 的正向增益，且 95% 物理帧配对自助法置信区间 **`[+0.3843, +0.6740] dB`** 严格大于零；但 **95% 置信下界为 `+0.3843 dB < +0.50 dB`**（距预注册硬门槛 `+0.50 dB` 差 `0.1157 dB`；Haldane `0.5/320` 敏感性下界为 `+0.3736 dB`），故按冻结规则唯一判为 **`STOP`**。
2. **单因子对照结论**：仅在 `CD2` 自身第 0 轮时延支撑上替换全局半盲 `SBG` 多普勒（`Ctrl`），在 $\rho=0.10$ 下仅从 `7.7877 dB` 微移至 `7.5244 dB`（仍崩溃），在最优 $\rho=0.20$ 下相对 `CD2` 增益仅为 **`+0.0405 dB` `[-0.0516, +0.1261] dB`**；而在同一 $\rho=0.10$ 下将时延搜索一并纳入半盲似然的 `SBJ` 比 `Ctrl` 提升 **`+3.6078 dB` `[+2.6383, +∞) dB`**。这在无混杂单因子意义下确认：**未知时延条件下低导频半盲增益能否存活，决定性瓶颈不在固定时延上的多普勒估计，而在利用 90% 数据能量恢复未知时延支撑本身。**
3. **成本靶标对照**：主方案双束 `SBJ` 每触发 CPU 为 `903–1013 ms`（`1.29x HG`，超出 `HG` 靶标约 `29%`）；而同算法族的单束伴随档 **`SBJ_lite`**（`603–647 ms`，**`0.82x–0.86x HG` 均值、`0.78x–0.83x HG` p95**，点估计增益 **`+0.4798 dB`**）与 **`SBJ_ultra`**（`496–527 ms`，**`0.67x–0.71x HG` 均值、`0.64x–0.69x HG` p95**，点估计增益 **`+0.3964 dB` `[+0.1248, +0.6665]`**）均严格低于实测 `HG` 的 `mean` 与 `p95` CPU 开销。

## 第三层：未经验证的解释与研究含义（附置信度）

1. **为什么放开未知时延后，第 0 轮半盲增益保留了约 `73%`（`+0.5130 dB` vs 真时延 `SBGdop` 的 `+0.7045 dB`），但损失了约 `0.20 dB` 使 95% 下界落在 `+0.384 dB`？**（*有 `596` 个触发键时延命中率 `6.56/8` 与 Stage A8b 基准对比支撑，但未在 `41500–41819` 同帧上重跑真时延 `SBGdop` 做逐键配对分解*，置信度 **H**）
   - 在 $\rho=0.10, 3.75–4.00\text{ dB}$ 穿越区，8 条瑞利衰落路径中最弱的 1–2 条路径功率往往低于总信道能量的 `2%–4%`。即使联合利用 90% 未知数据协方差与 10% 导频能量，`SBJ` 前向贪心生长 + 弱径单轮交换平均恢复 `6.56 / 8` 条真时延（漏掉约 `1.4` 条最弱径或将其吸附到邻近幻影抽头），使等效残余干扰底比给定全部 8 条精确真时延的 `SBGdop`（Stage A8b `3.7111 dB`）抬高约 **`0.205 dB`**（至 `3.9166 dB`）。由于真时延天花板相对 `CD2` 本身仅有 `+0.7045 dB` 净余量，扣除 `~0.20 dB` 未知弱径支撑损失后，真实总体均值恰好落在 `+0.51 dB` 附近，有限样本 `320` 帧抽样波动（半宽约 `±0.14 dB`）自然令 95% 置信下界落在 `+0.38 dB`。
2. **为什么 `SBJ_lite` 点估计（`3.9498 dB`，`+0.48 dB`）几乎追平双束 `SBJ`（`3.9166 dB`），但自助法下尾（`-0.05 dB`）明显宽于 `SBJ`（`+0.38 dB`）与 `SBJ_ultra`（`+0.12 dB`）？**（*直接由原始错帧计数表可观测，但未在 `4.25 dB` 补测单束 `SBJ_lite` 验证*，置信度 **M**）
   - 两个因素叠加：(i) 网格分辨率效应：`SBJ` 在 `4.25 dB` 有实测点（`0/640`），而 `SBJ_lite` 在 `[4.00, 4.50] dB` 步长为 `0.50 dB`；(ii) 极少数单束主锚点误锁尾事件：`SBJ_lite` 在 `U` 场景 `4.00 / 4.50 / 5.00 dB` 存在 `3 / 2 / 1` 个单束种子陷入次优时延对的长尾帧（双束 `SBJ` 通过不交第 2 束在 `4.25–4.75 dB` 将其清零为 `0/640`），当自助法重抽样恰好重复抽中这 3 个 `4.00 dB` 错帧（`>= 4/320 = 1.25% > 1%`）时，`U` 穿越点即从 `[3.50, 4.00]` 跳变至 `[4.00, 4.50]`。这也定量展示了第 2 条不交束的价值不在中位帧，而在消除高 SNR 长尾错锁。
3. **留给 Eric 的决策切面**（置信度 **H**）：
   - 无真值半盲联合恢复在完全未知时延下**确实打通了 $\rho=0.10$ 低导频工作区**（将 $\rho=0.10$ 处 1% FER 从 `CD2` 的 `7.79 dB` / `Ctrl` 的 `7.52 dB` 压至 `3.92–4.03 dB`），并在跨 $\rho$ 最优无真值公平对比下稳定击败 `CD2` 约 **`+0.40 ~ +0.51 dB`**（其中 `SBJ_ultra` / `SBJ_lite` 在成本严格低于 `HG` 的前提下给出 `+0.40 / +0.48 dB`）；
   - 但若论文主张要求无真值接收机相对最优 $\rho$ `CD2` 具备 **稳健超过 `+0.50 dB`（95% 下界 $\ge 0.50\text{ dB}$）** 的端到端净收益，当前 `+0.5130 dB [+0.3843, +0.6740]` 表明单靠第 0 轮高斯半盲联合搜索已被给定真时延天花板（`+0.70 dB`）减未知弱径损失（`~0.20 dB`）基本封顶，不宜在同一方向继续盲目堆算力，应由 Eric 决定就此收官定稿还是转向其他机制。
