## 预注册判读
**MIDDLE**：R(0.1) 的 95% 下界 0.33 < 0.5，R(0.05) 的上界 1.00 ≥ 0.5。按冻结规则，下一步是先算两种多普勒下界（导频单独、导频加数据），看在 ρ = .10–.15 能否做到 σ ≈ 0.05，再决定做不做估计器。

## 未检验的解释
- 第 0 轮多普勒有一个容忍门槛，大约在平均误差 0.05–0.1 bin 之间（σ 0.05–0.1）。导频在 ρ = .10 的误差（约 0.16）在门槛外面，要把误差降到约三分之一到一半，才拿得到 A2 收益的大部分（M）。
- 锚点不符说明"平均误差"不是完整的刻度。导频估出的多普勒和它配套的 LS 增益是一起拟合出来的，误差的方向可能被增益部分吸收；随机加的误差没有这种配套。另一种可能是导频的误差集中在少数径上、分布比高斯窄。哪一种都意味着用高斯 σ 换算导频要达到的目标会偏严（L–M，未检验）。最便宜的分辨办法：从阶段 A 的行里取导频第 0 轮的误差分布（每条径），和高斯比较；或者把导频的真实误差打乱到别的帧上再注入。
- 预测里写的 H-tail 方向（σ = 0.2 明显好于 delay）是反的；实际是高斯误差更坏。
