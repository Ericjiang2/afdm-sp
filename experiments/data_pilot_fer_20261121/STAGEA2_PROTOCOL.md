# 阶段 A2：第 0 轮给全真信道的上限——冻结协议（FROZEN 2026-11-21，运行前提交）

任务 `.trellis/tasks/11-21-data-pilot-fer`。来源：Eric 转来的外部模型建议（半盲下界："译码前的信道信息多数在数据协方差里"，建议先测上限再谈估计器）。Claude 改了两处：先测全真参数、不加下界大小的误差（任何第 0 轮估计器的天花板，不依赖外部的 CRB 程序）；注入点从 `pilot_front` 改到第 0 轮的 `time_refine`，因为后者会用导频在 ±0.75 bin 内重估多普勒并重解增益，只改 `pilot_front` 时注入的精度会被覆盖（`sp_afdm_native_joint_20260921/src/twofft.py:82`）。Eric 11-21："先跑上限检验"。脚本 `stageA2.py`。

## 问题
第 0 轮如果连多普勒和增益也是真值（不只是真时延），低导频（ρ ≤ .20）的最好穿越点能不能比阶段 A 的真时延上限（4.40 dB，ρ = .20）再好 0.15 dB 以上？

## 设定
- 与阶段 A 同一条管线、同样的帧（41000–41399）、同样的观测（G1 已核对）。ρ ∈ {.05, .10, .15, .20}；SNR 在阶段 A 网格前加 2、2.5 dB（防止穿越点落到网格以下）。
- 两个臂，同一个观测：
  - **full**：第 0 轮信道 = 真 (l_i, k_real, g_i)，跳过第 0 轮的 `time_refine` 搜索；第 1 轮（用译码数据重估）和 `CODELAY` 交换都不变。
  - **ldop**：第 0 轮 = 真 (l_i, k_real)，增益为 `time_refine` 在这些值上的导频 LS 解（不搜索）。只作描述，用来区分多普勒和增益。
- base、delay 两臂直接用阶段 A 的行（远程 `out/stageA/`，md5 见 `out/stageA/REMOTE_ROWS_MD5.txt`）。

## 门槛（运行前已通过，`out/stageA2_gate.json`）
- G1：8 个键上，base 臂复现阶段 A 行的校验子、F0 错误数和最终错误数；用恒等包装替换 `time_refine` 时，第 0、1 轮支撑和译码比特逐位不变：8/8。
- G2：full 臂第 0 轮的时延、多普勒和 CE 增益正好等于真值：8/8。
- G3：增益约定。无噪声、真数据已知时，在真 (l, ν) 上的 LS 增益与真 g_i 的余弦 ≥ .999：4/4（.99998–.99999）。门槛第一版是"ρ = .30、12 dB、未知数据"，余弦 ≥ .99，结果 .989–.996 没过；30 dB 下几乎不变，说明这个上限来自把数据当干扰，与约定无关。所以运行前改成现在这版，两版结果都写在这里。
- 成本：每键（两臂）0.46 CPU 秒，外推加 30% 余量为 8.0 核时；32 进程。

## 读数（冻结，不改标签）
- 穿越点：与阶段 A 相同（信息位 FER = 1%，log10 插值，U/G 平均；各臂用自己的 SNR 网格）。
- **余量** = 阶段 A delay 臂在 ρ ≤ .20 上的最优 − full 臂在 ρ ≤ .20 上的最优。按 400 帧配对自助 2,000 次（种子 20261121），两个阶段的行按帧一起重抽。
  - 95% 下界 > 0.15 dB → **CONTINUE**（下一步：按我们自己算的下界加误差，看可实现精度下还剩多少）；
  - 95% 上界 < 0.15 dB → **STOP**（时延给对之后，第 0 轮估多准都不重要；半盲下界换不来性能，这条估计器线停）；
  - 其余 → **INCONCLUSIVE**。
- 描述：full 相对 base 最优的余量；ldop 的穿越点；full 臂失败键的分类（最终漏径 / 支撑对但多普勒误差 > 0.1 bin / 其余），以及其中第 0 轮译码就失败的比例。

## 竞争假设与预测
| 假设 | 预言 |
|---|---|
| H-prec：低导频下第 0 轮的多普勒或增益精度是瓶颈 | full 明显好于 delay（CONTINUE）；ldop 接近 full 说明是多普勒，接近 delay 说明是增益 |
| H-loop：时延对了以后，第 1 轮用译码数据就能补回精度 | full ≈ delay（STOP） |
| H-exch：剩余失败主要来自交换步骤把对的径换掉 | full 失败里"最终漏径"占多数，余量小 |

- Claude：CONTINUE .45 / INCONCLUSIVE .25 / STOP .30；full 最优导频比 ≤ .10 的概率 .45。
- 外部模型（针对"真参数加下界大小误差"，比本检验弱）：最优穿越点 ≤ 4.3 dB 的概率 .5；最优导频比 ≤ .10 的概率 .55。

## Premortem
最可能与预期相反的情况：full 不比 delay 好多少，原因是 H-exch。阶段 A 的 delay 臂失败里有 26% 是交换步骤把对的时延换掉了，第 0 轮再准也挡不住这一步。失败分类表就是为了把这一种和 H-loop 分开。
