# 阶段 A3：第 0 轮多普勒误差的容忍度曲线——冻结协议（FROZEN 2026-11-21，运行前提交）

任务 `.trellis/tasks/11-21-data-pilot-fer`。接阶段 A2（CONTINUE：第 0 轮给真时延 + 真多普勒，比真时延上限再好 0.95 dB；增益几乎不值钱）。Eric 11-21："跑容忍度曲线"。脚本 `stageA3.py`。

## 问题
第 0 轮给真时延，多普勒给"真值 + 高斯误差"，增益由导频 LS 估。误差要小到多少，才能保住 A2 那 0.95 dB 的一半？换句话说，要把第 0 轮多普勒估到多准，"用数据帮第 0 轮估多普勒"这条估计器线才有意义。

## 运行前的参照（已有数据，`out/stageA` 的 delay 臂）
真时延下，导频自己估的第 0 轮多普勒误差（按功率加权的平均绝对误差，SNR 4–5 dB）：ρ = .10 约 0.15–0.16 bin，ρ = .15 约 0.10–0.11，ρ = .20 约 0.08。从 4 到 5 dB 几乎不变，说明它主要受数据干扰限制，不是噪声。高斯误差的平均绝对值约 0.8σ，所以 σ = 0.2 大致对应导频在 ρ = .10 的水平，σ = 0.1 对应导频在 ρ = .20 的水平。

## 设定
- 同一条管线、同样的帧（41000–41399）、同样的观测；ρ ∈ {.10, .15, .20}（ρ = .05 是检测器那道墙，见 A2 读数）；SNR 网格同 A2（2–12 dB，15 点）。
- 4 个臂，σ ∈ {0.025, 0.05, 0.1, 0.2} bin。第 0 轮 = 真 l_i，加上 k_real + σ·z_i；增益为 `time_refine` 在这些值上的导频 LS 解（不搜索）。第 1 轮和 `CODELAY` 交换不变。
- z_i ~ N(0,1)，每条径一个，由 (20261121, frame, scenario) 定种子。同一帧的 z 在 σ、ρ、SNR 之间共用（嵌套：σ 只改变大小）。
- 参照臂直接用已有行：delay（阶段 A）、ldop = σ 0（阶段 A2）。

## 门槛（运行前已通过，`out/stageA3_gate.json`）
- G1：σ = 0 时，在 8 个键上复现 A2 ldop 行的校验子、F0 错误数和最终错误数：8/8。
- G2：σ = 0.05 时，第 0 轮支撑正好是真时延，多普勒正好是 k_real + 0.05 z：8/8。
- 成本：每键（4 臂）0.95 CPU 秒，外推加 30% 余量为 12.3 核时；32 进程。

## 读数（冻结，不改标签）
- 穿越点：与 A2 相同（信息位 FER = 1%，log10 插值，U/G 平均）。
- 每个 σ 的**最优** = 在 ρ ∈ {.10, .15, .20} 上的最小穿越点。
- **保留比例** R(σ) = (delay 最优 − σ 最优) / (delay 最优 − ldop 最优)。delay、ldop 最优同样只在这三个 ρ 上取（分别为 4.40、3.45）。按 400 帧配对自助 2,000 次（种子 20261121），三个阶段的行按帧一起重抽。
  - R(0.1) 的 95% 下界 ≥ 0.5 → **EASY**：误差和导频在 ρ = .20 时差不多（用在 ρ = .10–.15 上），就能保住一半以上。下一步直接做半盲多普勒估计器的小试。
  - R(0.05) 的 95% 上界 < 0.5 → **HARD**：要比导频在 ρ = .10 时准 3 倍以上才保得住一半。估计器线停，A2 只作诊断结论。
  - 其余 → **MIDDLE**：下一步先算导频单独和导频加数据两种多普勒下界，看 σ ≈ 0.05 在 ρ = .10–.15 能不能达到，再决定做不做估计器。
- 描述：各臂各 ρ 的穿越点；各臂第 0 轮实际的多普勒误差（同一度量，SNR 4–5 dB），与 delay 臂的参照值并列。

## 竞争假设与预测
| 假设 | 预言 |
|---|---|
| H-soft：小的多普勒误差会被第 1 轮用译码数据修掉，容忍度宽 | R(0.1) ≥ .5（EASY） |
| H-sharp：低导频下第 0 轮译码对多普勒误差很敏感，一点误差就起不来 | R(0.05) < .5（HARD） |
| H-tail：导频的真实误差不是高斯的，主要坏在少数大误差径上 | σ = 0.2 在 ρ = .10 的穿越点明显好于 delay 臂（6.36），高斯曲线高估了导频的问题 |

- Claude：EASY .35 / MIDDLE .45 / HARD .20；σ = 0.2 臂在 ρ = .10 的穿越点落在 delay 臂 6.36 dB ± 0.5 dB 以内的概率 .45。

## Premortem
最可能与预期相反的情况：σ = 0.2 在 ρ = .10 远好于 delay 臂（H-tail）。如果是这样，"导频误差约 0.15 bin"这个刻度就不能直接当作估计器要达到的目标，因为真实误差的形状更重要。第 0 轮实际误差的描述表和锚点比较就是为了看清这一点。统计单位是帧：同一帧的 z、噪声和数据在各 ρ、SNR 之间共用，所以按帧重抽。
