## 混杂（读数前已查明）
同一帧在不同 SNR、不同 ρ、U 与 G 之间，用的是**同一份噪声向量**（相关系数 1.0，只是缩放），数据比特和信道种子也相同。所以预言 2 的"子集"关系在"尾巴由信道决定"和"尾巴由这份噪声决定"两种假设下都会成立，**判不了真假**。照算照报，但标为非判别性。要分开这两种假设，必须对尾巴帧换噪声重跑（不在本检验内）。

## 预言与判读（不改标签）
- **T1**（外部模型 .70）：阶段 A base 臂，ρ = .10、12 dB 的信息位误帧率在 [1%, 10%] 之间。U、G 各自报；U/G 平均落在区间内 → PASS，否则 FAIL。
- **T2**（外部模型 .75，非判别性）：base 臂，ρ ∈ {.15, .20}，H = 8 dB 仍失败的帧，L = 4.5 dB 失败的帧；|H ∩ L| / |H| 合并 U/G 和两个 ρ > .80 → PASS。
- 描述：base 臂 ρ ≤ .20、SNR ≥ 7 dB 仍失败的键（尾巴键）中，(a) 第 0 轮漏了有效径的比例，(b) 同一观测下 delay 臂（第 0 轮给真时延）解对的比例。用来看尾巴是不是主要来自第 0 轮漏径。
