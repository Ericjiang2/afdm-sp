## Closed form and qualification

For integer delay l and real Doppler nu, set Gamma[i,j] = sum(v) * dkernel(nu[j] - nu[i], N) if l[i] == l[j], and zero otherwise. Use the frozen positive-Doppler complex kernel and Hermitianize square blocks. Keep the data Gram and noise ridge intact. In the rectangular bank evaluate dkernel only on co-delay entries. Use this path without a variance FFT through compact, direct and direct fallback, each small-system refit, and finalization. DAFT and frequency-domain field transforms still run where required.

Compare to FULL at a constant v = mean(v), holding the true soft mean unchanged. Qualify both grid strategies, accepted actions and paths, gains, objectives, local and final refits. Exercise the direct fallback with a forced compact numerical failure in a synthetic gate. Compare objective values at 1e-10 relative plus 1e-11 times the observation energy. The bounded scalar minimizer can move by several micro-bins when its objective ties at floating precision. For refinement parity use a 2e-5 absolute Doppler bound and require the same integer delays, direct objective agreement and end-to-end decoded hash. Compare decoded hashes in a real archived P1 state gate. Instrument the synthetic gate to reject variance-vector FFTs or use of FULL projected_variance in CODELAY. For FULL require equality with the original archived A1 on the P1 trigger gate. Record runtime and source hashes.

## Estimands and decision

For per-key FER differences, directional discordance and the exact two-sided McNemar statistic, use the intersecting (scenario, rho, SNR, frame) keys. Disclose per-cell sample counts. For SNR at FER .01, use the same physical frame cohort for both curves but allow each curve its own measured grid. With L-hard/L-diag use frames 4000–4399. With diag-off use 4000–4199. Use first downward bracket, interpolate linearly in log10 FER, and replace zero FER with 0.5/n in interpolation. Also show the common-grid result, including any censoring bound. Define SBL margin as SNR(SBL) - SNR(CODELAY), positive favouring CODELAY. A delta from a censored crossing is reported as a bound when its endpoints allow one.

Joint physical-frame cluster bootstrap, 20,000 draws, seed 20261118. Draw frame IDs with replacement and retain all their available SNR, scenario, rho and arm rows. Compute 95% percentile endpoints as order statistics (inverted empirical CDF). For a left-censored crossing use (-infinity, minimum grid SNR] and for a right-censored crossing use (maximum grid SNR, infinity). Propagate these bounds through each draw without dropping censored draws. Report censor counts and unbounded endpoints explicitly. Compute the four cellwise margins pointwise as specified.

The CODELAY screening gate passes only if (1) the whole-grid upper 95% bound of paired FER(CODELAY) - FER(FULL) is <= 0.002 and (2) each of the four upper 95% bounds of SNR_1e-2(CODELAY) - SNR_1e-2(FULL) is <= 0.05 dB. Outcomes with an unbounded upper limit are inconclusive for that condition. Report counts of changed decoded hashes and FER discordances separately. A zero-width interval from zero discordance is explicitly identified as a degenerate empirical bootstrap, with a one-sided 95% exact upper bound on the rate of frame clusters having any discordance. State whether empirical gates pass and keep statistical precision and production promotion distinct.
