# DRAFT v2 — 受控扫描：强制漏检 + 逐单元闭式转折点（Claude，2026-11-19，未冻结）

> 授权：Eric 2026-11-19 授权全自动推进，由 Claude 代为冻结，不再逐项审核。过程记录在[过夜日志](../../09-22-tf-production-gap-audit/research/autonomous-run-20261119.md)。

## 0. 为什么改：第一阶段校准的两个事实
1. **低 R 端为空**：在自然漏检条件下，R=2/4/8 的可判单元，ρ=.3 只有 0/5/40，ρ=.5 只有 0/0/3（每格 200 帧）。
2. **可判单元多数已经译码成功**：例如 ρ=.3、R=64 时，u 的中位数为 0.11，95 分位数为 88。u≈0 时 Γ≈0，标量和 `CODELAY` 没有差别，机制只在译码失败的尾部起作用。

所以 v1 的样本主要由"两臂本来就一样"的单元构成，转折又落在网格之外。另外，Gemini 双模型（[外部批评](external-critique-gemini-20261119.md)）独立指出了同样的问题，以及高 R 端不可检测、单一 R₅₀ 掩盖跨帧差异两个缺陷。

## 1. 设计
- **强制漏检单元**：
  - F0 的全部选径步骤都把指定弱径的整个时延（所有 Doppler 原子）排除在可选集之外。第一轮译码就用这个支撑，所以 F0 状态与译码结果是自洽的。
  - 第一次交换时解除屏蔽，A2 与 `CODELAY` 从同一个保存的 F0 状态出发。
  - 每个物理帧 × R 都是一个单元，不再按"F0 是否自然漏检"筛选。
- **信道**：沿用 Sol 的 P1 构造（强径、弱径的选取规则与 RNG 方案都不变），只改三处：
  - 背景 6 径 = P1 原始功率 / 强径原始功率，截断到 **[.1, .4]**，保证强径是唯一的幻影来源；
  - 弱径 = 1/R，不再要求它是最弱的一条；
  - **R 网格 = {1.5, 2, 3, 4, 6, 8, 12, 16, 24, 32, 64, 128}**。

  强径功率 1、其余都 ≤ .67，因此强径恒为唯一最大。
- **帧块**（在同一命名空间内取新 ID，G3 核验新鲜性）：
  - 校准块 v2：帧 54000–54199，每格 200 帧，只跑 F0；
  - 主块 v2：帧 55000–55999，每格 1000 帧。
- **逐单元闭式转折点**：只依赖 F0 的退出状态 r1，不依赖真值和交换结果。
  - E、u、λ 的定义与 Sol 第一阶段相同。z = |D| 取强径锚点与最近合法同时延候选之间的值，定义同第一阶段的几何量；没有锚点或没有合法候选的单元记为"窗口未定义"。
  - 定义 T = E+u+λ，然后：
    - `R_A2* = (T² − z²E²) / (z²(u+λ)²)`：标量的幻影/弱径翻转点；
    - `R_C* = (T² − z²(E+u)²) / (z²λ²)`：`CODELAY` 的翻转点（若分母 ≤ 0，记为 +∞）。
  - 横轴用 ξ = R / R_A2*。这是 Astra 规则中的有限间隔窗口（式 13）的直接推论，在 z=1 时退化为 1 + 2E/(u+λ)。
- **SNR 规则**（在校准块 v2 上计算，只用 F0 与上述闭式量，不看任何交换结果）：每个 ρ 从 {4.5, 5.5, 6.5, 7.5, 8.5} dB 中，选"所有 R 合计、窗口有定义且 ξ ∈ [1/4, 4] 的单元数"最多的 SNR，并列时取较低的一个。这样选出的是转折附近杠杆最大的工作点。
- **理论预测曲线**（Sol 在校准块 v2 上计算，主跑前提交）：每个 (ρ, R) 格中 ξ > 1 的单元比例，记为 P̂_A2；`R > R_C*` 的比例，记为 P̂_C。
- **记录**：
  - 主块中每个单元记录首步编辑的五类（无编辑、幻影、补回弱径、补回其他漏检真时延、其他），以及 E、u、λ、z、R_A2*、R_C*、ξ。
  - 有非零 syndrome 的单元照常跑完整续接，得到次要的救回与 FER。

## 2. 判定（冻结后不重标）
物理帧簇 bootstrap，20,000 次，seed 20261119，同一物理帧在所有 R、ρ 下一起重采样。主分析单元为窗口有定义的强制漏检单元，两个 ρ 合并报告，同时分 ρ 报告。

- **S1（标量的转折存在）**：A2 幻影首步占比，ξ ≥ 2 的单元减去 ξ ≤ 1/2 的单元，差值的区间下界 > .50。
- **S2（位置）**：只用"幻影"与"补回弱径"两类，对 log ξ 做 logistic 回归，求 50% 点 ξ₅₀。
  - 区间完全落在 [1/2, 2] 内 → SUPPORTED（位置误差在 2 倍以内）；
  - 区间完全落在 [1/2, 2] 外 → REFUTED；
  - 其余为 INCONCLUSIVE。
- **S3（`CODELAY` 不翻转）**：在 1 < ξ 且 R < R_C* 的单元上（即 Astra 窗口 W 之内），同时满足
  - `CODELAY` 幻影首步占比的区间上界 ≤ .10；
  - `CODELAY` 补回弱径减去 A2 补回弱径，区间下界 > 0。
- **S4（人群曲线的预测）**：主块各 (ρ, R) 格实测的 A2 幻影占比，与校准块预测的 P̂_A2 相比，最大绝对偏差 ≤ .15 → SUPPORTED；有格偏差 > .30 → REFUTED；其余 INCONCLUSIVE。只算单元数 ≥ 30 的格。
- **次要**：
  - 五类首步构成随 R 的变化，用来看高 R 端的可检测性极限；
  - 触发单元上两臂的 FER 差随 R 的形状，预期为倒 U 形：低 R 两臂无差，中段 `CODELAY` 更好，高 R 又无差；
  - 窗口未定义的单元占比；
  - 按间隔分层的结果。

## 3. 竞争假设
- **H1（窗口理论成立）**：A2 在 ξ≈1 处陡变；`CODELAY` 在 W 内不翻转；S1–S3 成立。
- **H2（下界错位）**：A2 在 ξ < 1 时仍选幻影，即弱径的实际奖励低于模型，例如弱径离网或其他候选竞争。ξ₅₀ 会明显小于 1。接纳定律中窗口外仍有 78% 的幻影，这是 H2 的旁证。本实验首次直接填满窗口下界以下的一侧，正好能把 H1 和 H2 分开。
- **H3（竞争主导）**：首步多为"其他"或"无编辑"，两类的样本稀少，S2 无法评估。

## 4. 预测（Claude，本稿提交时写定）
- S1 成立：.80
- S2 SUPPORTED：.45；REFUTED：.25
- S3 成立：.75
- S4 SUPPORTED：.40

## 5. 事前验尸
- **若 ξ < 1 时 A2 仍多选幻影**，可能的原因有三：
  - 屏蔽弱径时延后，F0 的状态变差，其他背景径也被漏掉，O 类竞争变强。查五类构成即可分辨。
  - z 的定义取错了配对。G1 的历史一致性检查覆盖了几何量的代码路径。
  - 窗口本身的下界有偏，这就是 H2，属于真正的发现，不是缺陷。
- **成本**：主块 24,000 个单元，约为第一阶段 16,000 键估计的 1.5 倍，再加上强制漏检提高了触发率。草稿上限为 10 核时。

## 6. 冻结前修订（按 [Astra 设计评审](../../09-22-tf-production-gap-audit/research/astra-design-review-20261119.md)，2026-11-19；本节优先于 §2）
Astra 已核对代数：R_A2* < R < R_C* 正好是窗口 W 取倒数；z = 1 时化为原式；物理区域内不会反转；u = 0 时窗口为空。

1. **标注**：
   - z 的配对用了强径的真实时延和 Doppler，属于 oracle 几何，在交换之前即已确定；
   - 总体是强制漏检单元，不是自然漏检单元；
   - ξ = 1 是条件于 F0 状态的翻转点，不是某个物理帧固定的阈值。
2. **主检验改为指定配对的直接打分**：在每个单元、每一臂的第一次交换中，记录两个指定候选在同一个预定删除槽下的实际交换前 Schur 增益：
   - 幻影 = 强径锚点最近的合法同时延候选；
   - 弱径 = 弱径时延上增益最大的候选；
   - 删除槽 = 除强径锚点外拟合 |h̃|² 最小的槽。

   指示量 Q_a = 1{G_a(幻影) > G_a(弱径)}。这正是窗口理论本身的主张（成对偏好），不受全局其他候选竞争的影响。五类全局首步编辑降为次要报告。
3. **判定（取代 §2；主分析单元为窗口有定义的强制漏检单元）**：
   - **P1（成对翻转存在，A2）**：Q_A2 的均值，ξ ≥ 2 的单元减去 ξ ≤ 1/2 的单元，差值的区间下界 > .50。两侧各需 ≥ 30 个独立物理帧，否则记为 UNEVALUABLE。
   - **P2（位置，A2）**：对 log ξ 拟合 Q_A2 的 logistic 回归。要求斜率为正，且 ξ = 1 两侧各有 ≥ 30 个帧。
     - 完全分离时，用分离区间 [最大的 Q=0 ξ, 最小的 Q=1 ξ] 代替区间估计。
     - ξ₅₀ 的区间完全落在 [1/2, 2] 内 → SUPPORTED。这里的 2 倍容差是事先定的实用精度目标，不是由式 (13) 推出的。
     - 区间完全落在外 → REFUTED。
     - 斜率不为正 → REFUTED。
     - 其余为 INCONCLUSIVE。
   - **P3（`CODELAY` 不翻转）**：在窗口内的单元上（R_A2* < R < R_C*），Q_C 的均值区间上界 ≤ .10。至少需要 30 个帧，否则记为 UNEVALUABLE。
   - **P4（理论曲线可迁移）**：比较同一种量。
     - 预测：校准块 v2 上 share(ξ > 1)；
     - 实测：主块上 Q_A2 的均值；
     - 分母：两块都用窗口有定义的单元。
     - 只计两块都有 ≥ 30 个单元的格；不确定度由两块各自独立做帧簇 bootstrap 合成。
     - 各格偏差的区间上界都 ≤ .15 → SUPPORTED；
     - 任一格的偏差区间下界 > .30 → REFUTED；
     - 其余 INCONCLUSIVE；没有可计算的格 → UNEVALUABLE。
   - **次要**：
     - 原 S1/S3 的全局首步版本（五类构成，分母包括"无编辑"和"其他"）；
     - 触发单元上的 FER 差；
     - "另一锚点的幻影获胜"或"第三个候选获胜"的比例。
4. **预测改写**（冻结前写定）：
   - P1 成立：.85；
   - P2 SUPPORTED：.50，REFUTED：.20；
   - P3 成立：.80；
   - P4 SUPPORTED：.40。

   理由：成对打分去掉了全局竞争，所以 P1 与 P3 的把握比全局版本高；P2 仍然取决于弱径一侧的模型是否准确，这正是 H2 要检验的。
