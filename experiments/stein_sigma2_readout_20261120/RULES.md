## 被检验的两个估计量（照抄外部公式）
- 闭环：σ̂² = [r + sqrt(max(0, r² + 4ν(r − ν)))] / 2。
- 开环：σ̂² = (r − ν) / (1 − 2ν/(s0 + ν))；分母 ≤ 0 的行记为无效并计数。

## 人群
- 主：DD 触发行，即 `arms.DD.B.f0.syndrome` ≠ 0 且 `residual_power` 存在；全部 SNR 合并。
- 次：同上但只取 4.5–6.0 dB（与 READOUTS R-F 的 2,413 行同口径），及逐 SNR。

## 判据（外部公式自己给的，照用）
主人群 σ̂²/σ² 的中位数：
- 落在 [0.90, 1.10] → **成立**；
- 落在 [0.75, 1.25] 之外 → **否定**（"LDPC 非线性散度不能用单符号 Tweedie 闭合"）；
- 其余 → **不确定**。
闭环为主判读，开环只报告。另报 sqrt 被截断（参数 < 0）的比例。

## 计算前已注意到的一点（不改判据）
外部公式的模型给出 r/σ² = (1 + t²)/(1 + t)，t = ν/σ²。它的最小值是 0.828（在 t = √2 − 1 = 0.414 处取得；原文把取最小值的位置写成了 0.828）。READOUTS R-F 的触发帧 r/σ² 中位数为 0.807，低于这个下限。所以过半的触发帧落在模型达不到的区域，这是一个不利信号。
