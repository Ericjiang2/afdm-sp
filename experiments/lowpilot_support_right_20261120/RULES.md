# 低导频"支撑已对、仍然失败"帧：零仿真判读规则（2026-11-20，计算前提交）

起因：Eric 11-20 指出，低导频下"支撑已对、仍然失败"的帧是一个还没解释的现象，而且已有数据里能看到。
上一条线（[低导频漏径，已归档](../../.trellis/tasks/archive/2026-11/11-20-low-pilot-missed-path/research/step1-readout-20261120.md)）只研究了缺径的帧，这批帧没有单独看过。
本判读只读已存的行，不跑接收机、检测器或译码器。

## 已知的参照
- ρ = .30、5 dB，F0 失败帧（[R-D](../readout_batch_20261119/READOUTS.md)）：给出真时延集合（GS-set）能救回 85%；给出真信道（A3）能救回 99.8–100%。
  也就是说，在 .30 下，支撑对了还有约 15% 的帧失败，而这部分失败不是噪声造成的。
  低导频下没有 GS-set 或 A3 的数据。
- 在 A3 下，导频已知、可以整体减掉，所以 ρ 只通过数据功率起作用。
  数据 SNR = SNR + 10·log10(1−ρ)。
  A3 在 ρ = .30、5 dB（数据 SNR 3.45 dB）下几乎不失败（失败率 ≤ 1.1%）。

## 计算前已经看到的数（如实登记）
- 合并所有 SNR 后，SR 失败率（定义见下）：
  - 编辑预算实验：ρ = .15 / .20 / .30 分别为 187/1331、238/1217、485/1737；
  - ρ 扫描实验：ρ 越大，失败率越高。
  这些数没按 SNR 分层，混有数据 SNR 和触发选择两个因素，不作判读。
- 上一条线的 R1：ρ = .15、6–8 dB 下，CD4 失败帧中有 11 个时延全对。

## 人群
- **SR 键**：F0 失败而触发交换，CD4 最终状态的时延集合等于真时延集合。
  数据里每帧都有 8 条真径、时延互不相同，状态也是 8 个槽位，所以 SR 等价于没有幻影、没有漏径；Doppler 是连续估计，不要求相等。
- 主数据：`edit_budget_lowrho_20261119/out/main_20261119`，用 CD4 臂；帧 6400–6799，场景 U/G；ρ = .15/.20/.30 共用同一批帧和 SNR。
- 复核数据：`rho_sweep_20261119/out/main_20261119`，用 CD 臂；帧 5400–5799，ρ 有 .15/.20/.25/.30/.40/.50。
- **干净区**：数据 SNR ≥ 3.45 dB，也就是 A3 在 .30 几乎不失败的那一点及以上。
  在网格上对应：ρ = .15 时 SNR ≥ 4.5 dB；ρ = .20 时 ≥ 4.5 dB；ρ = .30 时 ≥ 5 dB。

## 对立解释
| 记号 | 解释 | 预言 |
|---|---|---|
| H_N | 噪声/数据功率不够：给真信道也会失败 | 干净区的 SR 失败率 ≈ A3 水平（≤ 2%）；同一数据 SNR 下与 ρ 无关 |
| H_C | 支撑对了，但增益估计受导频能量限制（叠加导频下数据还会干扰导频估计） | 同一数据 SNR 下，ρ 越低越容易失败；高 SNR 下可能有失败率地板 |
| H_D | 时延对了，但 Doppler 估偏 | SR 帧中，按功率加权的 Doppler 误差在同格内能区分失败与成功 |
| H_X | 其他：检测器、软符号沿用 F0 第一轮的 μ、v 等 | 上面三条都不成立时留给它；零仿真无法与 H_C 分开 |

H_C 与 H_X 在已存行里无法区分（行里没存估计增益），本判读不尝试区分。

## 判读（冻结）
- **R1 是否超出噪声**：合并 ρ = .15 和 .20 的干净区 SR 键，计算失败率及 Wilson 95% 区间。
  - 下界 > 2%：H_N 不足以解释，现象成立；
  - 上界 ≤ 2%：H_N 能解释；
  - 其他情况：不确定。
  - 另外按 (ρ, SNR) 列出计数表，作描述用。
- **R2 导频功率依赖**：在三个 ρ 的干净区 SR 键上拟合 logistic：fail ~ 场景 + 数据 SNR(dB) + log2(ρ)。
  报告 ρ 每减半时的优势比（OR），用按 (场景, 帧) 聚类的 bootstrap，2000 次，种子 20261120。
  - OR 的 95% 下界 > 1：H_C 得到支持；
  - 上界 < 1：没有证据支持 H_C；
  - 其他情况：不确定。
  - 偏差方向：低 ρ 下 F0 本身更容易失败，触发集合里会混进更"容易"的帧，这会把 OR 往 < 1 推。
    因此 OR > 1 的结论是稳的；OR < 1 不能当作 H_N 的证据。
- **R3 Doppler**：在 ρ ≤ .20 的干净区 SR 键上，在同一 (场景, ρ, SNR) 格内算 AUC，用帧聚类 bootstrap 给区间。
  - 主指标 e_w = Σ|g_k|²·|ν̂_k − ν_k| / Σ|g_k|²，按时延配对，权重用真功率；
  - 辅指标：最强真径上的 |Δν|。
  - 主指标 AUC ≥ .70 且下界 > .60：Doppler 误差承载失败；
  - 上界 < .60：不承载；
  - 其他情况：不确定。
- **R4 地板**（描述）：ρ = .15 在 8 dB 和 10 dB 的 SR 失败率。
- **R5 一致性审计**（描述）：ρ = .30、5 dB 的 SR 失败率，与 R-D 的 GS-set 失败率 ~15% 对照。
  两者人群不同：CD4 是自己找到全部时延的帧，GS-set 是直接给出真时延。若相差很大，先查原因，再解释其他结果。
- 复核数据集上重复 R1–R3（ρ 扫描的 CD 臂），只作复核，不改主判读。
