# 主推断因果诊断与候选结论

本轮验证了五个问题和两个推导约束，并执行了一次针对余项失效的最优仿射修订。**未得到可推荐为论文主创新的新接收机或同预算性能提升。** 得到的是可复现的数学缺口、对若干根因猜想的降级，以及一个有证据的候选不准入结论。它不表示整个方向创新空间已耗尽。

| 原问题 | 实际证据与反馈 |
|---|---|
| 1. 是否同一统计模型？ | 已知数据极限 CE 正则为 σ²I，joint 为 Pσ²I；18 个源码条件调用与推导吻合。但 CE 本来是初始化，不是已证实 bug。256 帧固定接口、1024 次匹配调用中，20 步后的初始增益差中位仅保留1.064%，故不能把先验差异称主要根因。 |
| 2. 标量不确定性是否丢信息？ | 精确条件协方差的方向性一般无法由标量表达，数学反例成立。实际256帧的方向差异与失败关联区间跨零，且6个失败与末级分支完全混杂；未建立 FER 因果关系。 |
| 3. 耦合遗漏是否导致过度自信？ | 48个小模型条件的精确后验对照反驳“普遍过度自信”。有导频、pilot-ridge初始化下 joint 概率MSE .006657，point .042395；前者平均略不够尖锐。精确边缘乘积虽丢交叉矩，却保持LLR，故缺矩本身不构成因果证明。 |
| 4. 新推导是否修复缺陷？ | 完整 Schur 均值/协方差、零方差支撑、cavity 和局部Jacobian经数学检验。但单一全局仿射忽略余项的候选未通过模型准入：切线及最佳仿射修订均仅1/24有导频条件满足预设余项门。 |
| 5. 是否有同预算实际价值？ | 当前候选未准入，因此按原任务书的no-go分支关闭主检测原型及后续FER比较。没有新主检测、完整成本优势或独立性能确认，不能用小模型算力/误差代替。 |

## 有数学意义的修订

令z包含信道和数据的全部实、虚部，f(z)为无噪声接收信号。任意有限二阶矩下，最佳仿射投影为

K=Cov(f,z) Cov(z)^†，f_aff=E[f]+K(z-E[z])。

其残差与z正交，且对任意仿射斜率A，误差能量为最佳残差能量加tr((A-K)Cov(z)(A-K)^T)。这是把“互干扰正交化”落实为精确可检验对象的自然方式。

但正交不等于独立，也不代表余项可以忽略。本次所有48个后验的实协方差均保留全部正模态；有导频时最佳残差/噪声能量均值仍为.339428，只有1/24低于预先固定的.1门。该门是工程准入约定，不是所有有效算法的数学必要条件，更不是FER下界。最佳系数还依赖精确后验，只能作诊断，不能当可部署算法。

## 文献与论文落点

原文核对表明 P-BiG-AMP、AFDM PBiGaBP、EP/EC/VAMP 已包含相邻的双线性方差、cavity和矩匹配原理。当前 twofft 也已有P·vh·vx，不能再包装成“补上遗漏二阶项”。Schur、外信息减法、最佳线性投影本身均是标准工具。

本轮适合保留为机制诊断、方法选择依据和可复用的精确oracle工具。新方法主贡献、生产FER收益及首创性均不受本轮支持。非线性因子推断、显式余项建模及模式条件化仍是未验证空间，不能据此称其有效或无效。

## 证据与限制

- 数学与实现测试：36项通过（experiments内10项，根tests内26项）；实际单线程检查通过。
- 诊断包括18个已知输入条件案例、256个旧完整状态、1024次固定接口scalar调用、48个小模型精确后验和192次小模型scalar调用；这些都不是新增完整级联FER实验。
- 小模型只有6个独立外生随机簇，48是条件数；不作总体显著性结论。旧256帧已揭盲，相关性分析只是探索。
- 独立复核检查214项来源/原始hash，复算96条oracle记录及48个条件的余项/最优仿射投影，最大数值误差3.22e-15；另核对256帧状态和干预摘要。没有重新生成观测或运行接收机。
- 独立result-to-claim对“新实用机制与同预算收益”判定为no。原始证据在本任务execution/，研究公式/文献在Trellis任务research/；主线和旧结果未修改。
