# 候选一第 0 步：首轮导频捕获计算——冻结规则（2026-11-20，计算前提交）

候选一：有译码反馈时，导频只需让"对译码有影响的每条径"在首轮被检测到；崩塌点 ρ* 由检测门限决定，ρ*·N 近似不变（随 ln M 缓增）。
Eric 2026-11-20 要求先做第 0 步，由 AI 计算；查新暂缓。本计算**不跑接收机、不跑译码**，只用已存真值和系统参数算首轮导频匹配滤波。

## 输入
- ρ 扫描已存行（deinlab `experiments/rho_sweep_20261119/out/main_20261119/rows_shard*.jsonl`，62,400 行，帧 5400–5799，U/G，ρ ∈ {.15,.20,.25,.30,.40,.50}，13 个 SNR）：真值 `delays`、`dopplers`（分数）、`gains`、`sigma2`，以及 F0/CD 的 `errors`。
- 系统参数取自 `tcom_reference_frame_20261015/p1_driver.load_context()`：N = 1024，c1、c2、ZC 导频 `system._zc_seq`，字典 l ∈ 0..102 × k ∈ {−2..2}（515 列，与 F0 前端 `pilot_front` 相同）。
- 生成律（`gen_fixed.make_frame`）：y = H(√ρ·zc + √(1−ρ)·qpsk) + σ w，‖H‖²_F/N = 1。

## 模型（首轮只有导频，数据当噪声，与 F0 第 0 轮 μ = 0 一致）
1. 单位范数字典列 u_c = r(l_c, k_c)/‖r‖，r 为 `physical.regressors(zc, l, k, c1, c2)`。
2. 导频响应 z_c = u_cᴴ Σ_j h_j √ρ r(l_j, ν_j)（真分数多普勒，精确计算，含强径旁瓣）。
3. 背景 B = (1−ρ) + σ²；统计量 s_c = |z_c|²/B。
4. 离径列集 O：时延不等于任何真时延的列；M = |O|；T = ln M + 0.5772（M 个单位指数变量最大值的期望）。
5. 帧门限 Θ = max_{c∈O} s_c + T（离径列上的导频旁瓣峰 + 噪声最大值）。
6. 径 j 被捕获 ⇔ 列 (l_j, clip(round(ν_j), −2, 2)) 的 s ≥ Θ。
7. 漏掉的有效功率 m = Σ_{j 未捕获} g_j。**捕获失败 ⇔ m ≥ τσ²**，τ = 0.2（主）；τ ∈ {0.1, 0.4} 只作敏感性。

## 预写判读（不改标签）
- **R1 崩塌位置**：P_fail(ρ) = 捕获失败帧比例，在 5.0 dB、U/G 平均。ρ*_pred = 网格上使 P_fail ≤ 1% 的最小 ρ。
  - 通过：ρ*_pred ∈ {.20, .25, .30}（观测到的崩塌在 .15–.30 之间）。
  - 失败（太容易）：ρ*_pred ≤ .15，捕获不足以解释崩塌。
  - 失败（太难）：ρ*_pred ≥ .40，预言了没观测到的崩塌。
- **R2 与真实失败的关联（事后）**：ρ ∈ {.15, .20}、全部 SNR，按（场景 × ρ × SNR）分层，CD 帧失败率在捕获失败行对捕获成功行的风险比（Mantel–Haenszel），帧聚类自助 2,000 次。通过：95% 下界 > 2。另报 ρ = .30 的 P_fail（预期 ≤ 2%）。
- **R3 导频形状（旁瓣）是否主导**：在未捕获的有效径上，统计 max_{c∈O} s_c > T 的比例（旁瓣峰大于噪声峰）。> 50% 记为"旁瓣主导：1/N 律不应成立"；否则记为"数据干扰/噪声主导"。
- **R4 N 标度（推导，只写预言）**：若 R3 非旁瓣主导，且信道按网格单位固定（M 不变），则 s 与 ρN 成正比，ρ*(2048) ≈ ρ*(1024)/2。R3 旁瓣主导时不写此预言。

## 事先预测（Claude）
R1 通过 .45；R2 通过 .55；R3 旁瓣主导 .25。

## 局限（事先写明）
确定性门限是粗模型：不模拟 F0 的 40 候选贪婪选择和第 0 轮 time_refine 的细化；分数多普勒只取最近整数列；B 用期望值。结论只能写成"首轮匹配滤波捕获是否足以定位崩塌"，不能写成 F0 的真实捕获率。
