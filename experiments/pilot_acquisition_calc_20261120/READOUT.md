## 观察
- 首轮单次匹配滤波下，5 dB、τ = 0.2 时的捕获失败帧比例：ρ = .15 / .20 / .25 / .30 / .40 / .50 为 98.9 / 95.9 / 92.8 / 89.9 / 80.1 / 70.8%。τ = 0.1、0.4 同样没有任何 ρ 降到 1%。
- 失败比例随 SNR **升高**（ρ = .30：3 dB 82% → 12 dB 98%）：有效径门限 τσ² 随 SNR 下降，而压住弱径的东西不随 SNR 变。

- ρ ∈ {.15, .20} 上，CD 失败对"捕获失败"的分层风险比 1.16 [1.03, 1.32]。

## 事后变体（看到冻结结果后才定，只作诊断，不改上面的标签）
把离径列改为"DAFT 位置离任何真径都超过 2 格"的列，排除相邻时延列对同一条径的重复计数。结果几乎不变（ρ = .30 仍 89.9%，旁瓣主导 80%）。所以压住弱径的不是相邻格的泄漏，而是远处的旁瓣。

## 解释（未检验，置信度 M）
- ZC 叠加导频在 AFDM 里与强径相关后，在远离真径的位置留下高旁瓣（可能是 chirp 导频与 chirp 调制叠加形成的模糊脊）。单次匹配滤波看不见弱径，是**导频形状**决定的，不是"导频能量对数据干扰加噪声"不够。
- 真实 F0 在 ρ ≥ .25 能工作，最可能是因为它逐个拟合、扣掉强径（贪婪最小二乘），把旁瓣一起扣掉。若如此，弱径能否被捕获取决于强径估得多准，估计精度又回到了捕获里，这与候选一"导频只管捕获、估计事后再补"的划分相冲突。
- 最便宜的检验：在已存帧上只跑 F0 第 0 轮（不译码），记录有效径是否被选中，看它是否在 ρ < .25 处崩塌。即使通过，得到的也是只对 ZC 导频成立的规律，普适性弱。
