# 碰撞、KL 与独立重复规模

统一对象是 `THEORY.md` 的有限 QPSK/Gaussian 增益精确边缘族。状态：**控制模型 COHERENT AS STATED；实际归一化先验必须分支裁决**。

在固定有限 N、tau>0、sigma2>0 的局部邻域，THEORY 的解析密度与多项式支配也允许三次 log-density 导数积分。令局部 nuisance 路径 `eta(q)=eta0+q lambda+O(q²)`。归一化恒等式消去 KL 一阶项，得到

`D_KL(p_(0,eta0) || p_(q,eta(q))) = (q²/2) E_0[(s_q+lambda^T s_eta)²]+o(q²)`。

对固定 nuisance，系数为 `I_qq/2`。对一阶最有利 nuisance 路径 `lambda=-I_etaeta^+ I_etaq`，系数为 `I_eff/2>0`。这里的“最有利”是线性局部切空间的系数最小化，不是对任意远处 nuisance 或其他路径数模型的全局最小 KL。

因 `q=delta²`，该局部 KL 是 `Theta(delta⁴)`。R 个**独立生成的整帧**形成 product experiment，KL 精确相加为 R 倍。于是：

- `R delta⁴ -> 0` 时 total variation 由 Pinsker 趋于零，不能一致区分碰撞与该局部备择。
- `delta=c R^(-1/4)` 是非平凡局部检出尺度，通常只得到有限局部功效，不是零误差分辨保证。
- 控制模型中，T 的均值差约 kappa delta²、方差有限。固定紧 nuisance 域使 tau、sigma2 远离零，且校准方差可得时，样本均值检验在 `sqrt(R)delta² -> infinity` 的小间距区间可一致区分。这给出该尺度的可达检出含义。

以上不等于 delta 的常规无偏 CRLB，也不等于某估计器的均方误差上界，更不保证标签/周期别名意义下的全局唯一性。边界 q>=0 的约束仍存在。

注册数值计算采用 `E_0[exp(u)-1-u]` 核对 reverse KL，其中 `u=log p_q-log p_0`。因为 `E_0[exp(u)-1]=0`，该积分精确等于 `D(p_0||p_q)`，且逐点补偿去除了小 q 的一阶 Monte Carlo 噪声。样本估计仍只是 Monte Carlo，保留独立批次标准误。投影系数用前 4096 帧，KL/投影外推核验用后 4096 帧；固定 nuisance KL 与投影路径分开报告。

**R 不等于 N，也不等于 lag 数。** 一帧里所有时刻共享 h1,h2；时间变换后的 QPSK 也不是独立变量，其交叉功率恰为 `1-1/N`。不同 T 共享 r0 和其他时刻，必须使用联合协方差。例如 `T_13=T_12+T_23`，三个特征只有两个代数自由度。共享同一底层信道、数据和标准噪声的多个 SNR 是同一外生簇，不能增加独立 R。

N 变化还要明确时间单位。Doppler 以 bin 为单位，物理频率 `nu_Hz=nu_bin/(N Ts)`；半间距同理。对于

`kappa_ab=(1-1/N)tau² (2pi/N)²(b²-a²)`：

- 固定整数索引 a,b，固定 bin 半间距，kappa 为 `Theta(N^-2)`。这表示实际归一化 lag 缩短；不能同时称作固定物理频差。单个 T 的信息下界是该 kappa² 除以其 N 相关的真实方差，不能据此推出全帧信息必为 N^-4。
- 固定归一化索引 `a/N -> alpha, b/N -> beta`，`alpha²!=beta²`，kappa 收敛到非零常数。不同 N 的 T 分布和联合协方差仍需重新计算；常数级单特征灵敏度不等于 N 个独立重复。
- 若固定物理频差、固定 Ts，则 bin 半间距随 N 增长，必须将 `delta_bin=N Ts delta_Hz` 一起代入；“小 delta”邻域和可用时间孔径随实验设计变化。

实际归一化先验没有统一的 R^(-1/4) 结论。PRIOR 线已定位冻结 G0 的 rank-one 剪枝平台：两条同 delay、整数中心附近的路径被映射到同一虚拟原子，G0 归一化输出分布不随半间距变化，故该平台内 KL 精确为零、任何 R 都不能从该 G0 分布分辨间距。G1 若复用这些潜在增益而未消去相应零空间，可出现不具有有限二阶矩的输出；控制模型的矩和 L2 推导不再可用。对保持支持不变且 R 正定的光滑分支，可以在固定基变量推前、正噪声和所需导数可积条件下另作局部展开，但不自动保证其碰撞坐标为 q、KL 阶数为 delta⁴。具体半间距范围、Gram 谱及矩存在判据以 PRIOR 的正式证明和注册证据为准；不把尚未证明的 q log q 行为写成结论。
