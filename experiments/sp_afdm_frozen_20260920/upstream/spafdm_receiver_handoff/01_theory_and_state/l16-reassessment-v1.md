# I1 轻量诊断后的推导与研究重估

## Target

解释码反馈、信道二阶统计、整数支撑和有限步检测为何相互影响，并用本批实际结果决定哪些方向仍值得研究。目标不是证明新增模块必然改善译码，而是区分可复算恒等式、接收机近似和有待确认的算法收益。本文吸收本批所有主要轮次；连续多普勒估计与连续几何优化按用户要求排除。

## Status

**COHERENT AFTER REFRAMING / EXTRA ASSUMPTION**。冻结分布下的 CE 恒等式、整数域特例、局部非圆度量和投影分解成立；从这些局部结果推到完整接收机 FER 下降的链条仍未成立。新鲜开发中最小候选仅有方向性信号，不能据此宣布新算法、学习贡献或论文突破。

## Invariant Object

统一目标是信息报文错误风险与完整计算成本：

\[
R(\mathcal A)=\Pr\{\widehat b_{\mathcal A}\ne b\},
\qquad \mathbb E[C(\mathcal A)]\le B.
\]

这里 \(b\) 是信息比特，\(\mathcal A\) 是包含初始化、检测、CE、消息传递和译码的完整接收机，\(C\) 是完整计算量或按指定设备实测的时间，\(B\) 是预算。NMSE、残差、局部 KL 和软比特 NLL 都是诊断量。没有证明其中任一个的单调改善会使 \(R\) 单调下降。

## Assumptions

1. 当前数值范围为 G0、N=1024、8 条物理路径、rho=0.5、固定 LDPC 和 7/8 dB；真实展开仍含分数多普勒产生的截断整数簇。排除连续估计不等于把原生成器改成整数多普勒。
2. 发射向量为 \(s=p_\rho+d\)，两个分量已含功率。数据星座是 \(\{\pm0.5\pm0.5j\}\)，不再对其方差乘 rho 或 1-rho。
3. CE 推导固定工作分布 \(q(d)\)、活动支撑、旧增益及正则强度；不假设 q 是真实联合码后验。把 q 换成有限步检测/译码输出是近似步骤。
4. 整数原子写作 \([U_i x]_n=d_i[n]x_{n-s_i}\)，相位模长为 1。标量 Gamma 特例还要求支撑有效位移模 N 不碰撞，以及对角符号协方差。
5. 局部非圆高斯要求 \(v>|c|\)。圆热噪声保证观测因子的正定性；退化单符号分布不能直接代入非退化高斯密度。
6. 旧 64 块反复用于机制选择。新鲜 16 块在候选冻结后生成，仍属于开发复现；7/8 dB 共享外生块。所有区间均为描述性，未做选择后确认。
7. 新完整链使用通过重复性门的 CPU-gels。旧 CUDA 与新 CPU 完整基线没有证明逐块等价，不能合并其效应量。

|\(\mu,V,P\)|q 的均值、协方差、伪协方差；\(V=E[(d-\mu)(d-\mu)^H]\)，\(P=E[(d-\mu)(d-\mu)^T]\)|
|\(v_j,c_j\)|第 j 个符号的复方差与伪方差|
|\(\mathcal S,K,g,U_i\)|整数活动支撑、原子数、增益和单位增益算子|
|\(A_m\)|第 i 列为 \(U_i(p_\rho+\mu)\) 的 CE 字典|
|\(\Gamma,\lambda,g_o\)|符号不确定性惩罚、旧 proximal 正则及其中心|
|\(T,\beta\)|边星座投影温度、已经截断的终端 LLR 的缩放；两者均不是物理噪声定义|

## Derivation Strategy

报文风险 → 精确统计恒等式 → 当前接收机采用的近似 → 实际消费者 → 同条件干预 → 新鲜开发 → 研究止损。保持最终目标不变，不把较易优化的 CE 目标偷换为整条接收机的目标。

## Derivation Map

1. 标量 QPSK 似然固定单位，排除二倍功率误读。
2. 展开冻结 q 下的平方残差，得到 Gamma 的零中心位置。
3. 整数位移代数给出对角 V 特例和一般相关统计的差集表达。
4. 正交投影拆开表示与系数误差；再用终端译码验证其决策意义。
5. 伪方差进入二维检测度量，码外信息进入明确的消息消费者。
6. 用闭环、时机对照和新鲜开发约束解释，保留没有通过的科学门。

## Main Derivation

### 1. 单位正确不等于推断置信度最佳

**[恒等式]** 对 \(z=x+n\)、\(E|n|^2=\sigma_n^2\)、\(x\in\{\pm a\pm ja\}\)，均匀先验时

\[
L_I=4a\operatorname{Re}z/\sigma_n^2,\qquad
L_Q=4a\operatorname{Im}z/\sigma_n^2.
\]

在独立 I/Q 比特工作近似下，令 \(t_I=\tanh(L_I/2)\)、\(t_Q=\tanh(L_Q/2)\)：

\[
\mu=a(t_I+jt_Q),\quad v=a^2(2-t_I^2-t_Q^2),\quad
c=a^2(t_Q^2-t_I^2).
\]

**[实测与解释]** a=0.5 与数据能量 0.5 相符。BASE 另含历史固定 0.5 乘子；终端/热噪声比 0.430703/0.511490，去乘子后为 0.861405/1.022979。没有证据支持把“约一半”直接认作实/复单位错误。

**[条件性恒等式]** 已知 H、准确后验均值下，残差 \(r=E[n\mid y]\)，于是

\[
N\sigma_n^2=E\|r\|^2+E\operatorname{tr}\{H\operatorname{Cov}(d\mid y)H^H\}.
\]

未知 H、近似后验和同观测拟合不能直接继承无偏性。真实数组核对了残差分解的交叉项；更换软矩来源会改变修正后的噪声量。这解释了为什么“补回二阶项”需要明确输入来源。

**[反证]** 7 dB 真 H + 热噪声 + T2 仍有 25/64 错块；终端 beta 网格最多改善至 19/64。改为 T1 则为 2/64。只把原 BASE 的 T2 改 T1 又恶化到 60/64。内部投影和末端尺度存在交互，标量 beta 不能解释全部差别。正 beta 保留原始硬判，却能通过 clip 和有限 LDPC 改变报文输出；全局精确 MAP 的公共温度论证不能直接套到某条边的投影。

### 2. Gamma 是正确的冻结 q 二阶项，不是增大旧增益惯性

**[恒等式]** 写 \(d=\mu+e\)、\(E_qe=0\)，则

\[
E_q\|y-H(g)(p_\rho+d)\|^2
=\|y-A_mg\|^2+g^H\Gamma g,
\quad \Gamma_{ij}=\operatorname{tr}(U_i^HU_jV).
\]

加上 \(\lambda\|g-g_o\|^2\) 并对共轭增益求导，得到

\[
(A_m^HA_m+\Gamma+\lambda I)g=A_m^Hy+\lambda g_o.
\]

**[边界]** Gamma 只加左侧。固定 zero-ridge 加 \(\eta\|A_m\|_F^2/K\,I\) 也是零中心；增加 proximal 则同时改变左侧和右侧。三者目标不同。普通复平方残差只涉及 V，不额外涉及 P；不能无推导地把伪方差塞进这个 Gamma。

**[条件性命题]** 对单位模整数原子、无位移碰撞、\(V=\operatorname{diag}(v)\)，异原子乘积没有对角项，故

\[
\Gamma=\Big(\sum_jv_j\Big)I_K.
\]

本项目 515 整数域及实际支撑满足此条件。若只通过该接口消费方差，逐符号网络最终也只改变总和，不能凭输出维数宣称获得更多 CE 自由度。碰撞、一般相关 V 或不同原子模型需要重导。

**[实测]** 324 个固定 A/均值/方差/旧增益状态，六种 solve 共 1,944 次，后经原始审核与独立增广最小二乘复算。7 dB 第 1/2 轮 Gamma 的未掩码 NMSE 变差，第 5/9 轮改善。完整链延至第 3/5 轮启用后，旧 16 块上与 ridge 同为 7 错，未超过 ridge。新鲜块上 START3 为 6 错、ridge 为 7 错；样本不足以证明动态方差优越。

**[解释条件]** q 方差并非真实符号 MSE；支撑遗漏、错误均值、相关性、有限消息和变化中的 proximal 中心均阻止把上述更新叫作完整接收机 EM 单调改进。早期收缩不利、后期有利是当前工作点的证据，不是通用轮次定律。

### 3. 相关统计压缩的对象明确，可信估计仍然缺失

**[恒等式]** 一般 V 下

\[
\Gamma_{ij}=\sum_n d_i[n]^*d_j[n]V_{n-s_j,n-s_i}.
\]

因此 CE 只消费支撑偏移差集上经相位加权的相关统计。输出为 K×K，并不意味着获得输入统计也只花 K² 工作。实际 K=24 时有约 372/368 个不同 lag；保存所有相关 lag 约占 N² 的 36%。也可流式累加 Gamma，但仍需计相关样本/估计的成本。

**[实测限制]** 32 个合法邻近码字的受限后验给出 ESS 约 1。压缩式与完整受限分布的 Gram 一致，只验证代数；退化的局部集合不能代表完整码后验，也不能证明真实码后相关可忽略。

**[可证伪研究问题]** 后续若能用有混合/覆盖证据的合法采样或解析近似获得 Gamma 的遗漏部分，再比较对角模型、低秩近似和同成本少样本估计。若估计噪声或成本超过收益，停止。当前没有可信监督目标，不能直接训练一个“相关性网络”再以低误差拟合自己的偏置标签。

### 4. 表示与系数都有限制，固定 q 的支撑目标仍可能选错动作

**[条件性恒等式]** 当 \(\widehat H\in\operatorname{span}(U_i:i\in\mathcal S)\)，Frobenius 正交投影给出

\[
\|H_t-\widehat H\|_F^2
=\|H_t-H^*_{\mathcal S}\|_F^2+
\|H^*_{\mathcal S}-\widehat H\|_F^2.
\]

实测 7 dB 平均 NMSE 0.047160=0.018189+0.028971。当前支撑最佳投影使 35→22 错，同容量真值 topK 使 35→3，真 H 为 2。真数据 LS 在当前支撑为 18 错，优于 Frobenius 最佳投影，直接排除了“投影是 FER 上界”的解读。

**[实际方法]** 新离散提名使用 \(U_i(p_\rho+\mu)\)，与 pilot-only 提名分开。每次动作保留 24 个原子；8 个 inactive 提名 × 24 个 drop，全部重拟合并比较

\[
J(U,g)=\|y-A_Ug\|^2+\Big(\sum_jv_j\Big)\|g\|^2
+\lambda\|\operatorname{embed}_U(g)-\operatorname{embed}_{\mathcal S}(g_o)\|^2.
\]

被删除旧原子的正则常数保留；比较基点先在当前 S 重拟合；接受后清除旧 H 中被删除原子的阻尼记忆。共 195 个额外小 solve/动作，不能按一次 cheap add 计费。候选不读 truth。

**[负结果及止损]** 第 2 轮交换在 32 块上相对 JSOFT 新增错误，尽管 J 下降；第 5 轮码条件化交换在 16 块上与 JSOFT 的错误向量完全相同，pilot-only 在 8 dB 新增 1 错。过早更新能解释一部分损失，却没有获得净收益。停止该时机/交换网格，不晋级；这只否定当前候选池、目标和动作，不否定全部离散模型选择。

所有真值整数原子都在当前 G0 域内。当前失败不能归因于未生成的完整 G1 尾项。\(10^{-3}\)–\(10^{-2}\) 平方 NMSE 对应 0.1%–1%，不是 1%–3%；改变能量缩放不能恢复被丢弃的相位与耦合。

### 5. 非圆统计有明确消费者，局部 KL 不等于全图收益

**[恒等式/近似边界]** 在忽略跨符号相关的因子近似下，干扰复方差和伪方差分别为 \(v=\sigma^2+\sum|h_k|^2v_k\)、\(c=\sum h_k^2c_k\)，排除目标符号自身项。均衡后 c 除以 h²，而非 |h|²。

\[
\Sigma_\mathbb R=\tfrac12\begin{bmatrix}v+\Re c&\Im c\\\Im c&v-\Re c\end{bmatrix},\qquad
\ell(e)=-\frac{v|e|^2-\Re(c^*e^2)}{v^2-|c|^2}.
\]

有限星座权重需要包含相应 prior 后归一化，再逐比特求 APP；有 I/Q 耦合时只能减去自身 bit prior，不能把另一比特的 prior 一并删掉。

**[条件性恒等式]** 非圆高斯相对同总方差圆高斯的 KL 为 \(-\tfrac12\log(1-\zeta^2)\)，\(\zeta=|c|/v\)。它只比较两个局部高斯分布。

**[实测与修正]** 旧终态代理曾估计 BASE 约 38% 边满足 zeta>0.2；真实最后空腔只有 2.791%/3.297%。NOISE/T1 为 15.041%/20.500%。7 dB 圆/非圆 BASE 为 35/33 错，NOISE/T1 为 32/31 错，8 dB 都为 2 错。区间含零。原型保留旧“只阻尼均值”规则，v/c 围绕未阻尼投影均值，不能声称全矩一致。

已完成必要终端原型，不加入最小候选。全内部非圆算法还需一致阻尼、合法消息和完整成本合同；小幅终端信号不支持立即叠加。

### 6. 合法刷新有价值迹象，剩余迭代并非空转

**[算法内等式]** LDPC 的 raw APP 减该次输入得到 check 外信息；新一次解码替换旧 prior，不累加 APP。记录了实际输入、输出、hash 和 CE/检测消费者。这消除显式自信息重复，不保证 loopy 消息统计独立。

**[实测]** 第 4 轮额外刷新在旧 16 块为 8/0 错（MEAN 9/1），新鲜 16 块为 4/1（MEAN 7/1）。该对照每 F 使用 3 次 LDPC，原 I1 为 2 次。它应成为未来强经典参考，但不能事后改名为本轮预选候选。

OUTER6 旧 7 dB 总错数相同但逐块不同，新鲜块新增一错；OUTER3 与减少 CE 的控制也有损失。“没有再译码”不等于没有新的检测软信息；删除 CE 求解后 H 阻尼、掩码和噪声仍变化。停止盲扫截断与刷新时刻。

## Remarks and Interpretation

|轮次结果|证据允许的解释|下一步/停止条件|
|---|---|---|
|标量与 LLR 交叉控制|物理方差、有限边投影、末端尺度不同|保留固定尺度及 GMI/分阶段低参数规则作参考，不继续追网格最小值|
|支撑分账|系数与离散支撑都有诊断余量|已做观测驱动完整交换；当前方法无净收益，停止|
|Gamma 及同均值时机|早期 q 与收缩可能不匹配|完成 START3/5 与 ridge，完成冻结后的新鲜复现，不扩样调参|
|非圆真实空腔|存在局部非圆性，但代理会夸大|有限原型已完成；全内部算法属于条件后续|
|刷新与删步|新似然可带来有用码反馈，短迭代可能丢信息|REFRESH4 必须成为强经典参考；不能宣称无损降本|
|新鲜开发|START3 7→6、REFRESH4 7→4，8 dB 1→1|配对区间含零，保持 I1，正式确认另行设计|

最近邻原文见 [五篇核实记录](l16-neighbor-audit-v1.md)。软均值/方差联合估计、GMI 标度、非圆 PDA、AFDM 数据辅助 SBL、LDPC 约束联合展开均已有直接先例。1303.4452 的式 10 和 1311.1712 的式 29 是 conjecture；前者 I-curve 的二阶导非正，应称凹，不能照抄为 convex。没有核实额外 AFDM PBiGaBP 或 CC-NOMP 原文，不把用户提供的算法名称算作本次文献核查。

学习只保留三个有条件的对象：经验证有必要的 Gamma 遗漏相关统计；合法反馈与离散自由度的低成本控制；与状态有关的有限步推断校准。各自必须先胜过对角/低秩/少样本、固定周期/可靠度阈值、固定尺度/GMI/分阶段规则，并在相同合法输入和完整成本下比较。当前证据不支持大网络输出 H，不支持恢复旧 scorer，也不支持“展开即创新”。

## Boundaries and Non-Claims

本批完成了指定轻量判别，未完成新算法正式确认、全内部非圆、可信完整码后相关估计、完整 G1、跨路径/导频比例/码配置泛化或新的正式 COST。没有更改旧确认、D_test 或已接受论文主张。真 H 的 33 次救回是终端干预余量，不能当作可部署可达增益。

本次主会话完成实现与自审，未独立复核。已有单元测试、实际 CPU 工程/开发和原始审核是不同层级的证据，不互相替代。

## Open Risks

主要风险是 q 的条件统计不可信、同观测反复使用的相关性、局部目标与报文风险失配，以及开发选择偏差。下一步优先建立强经典参考下的预登记独立比较及成本合同；在此之前，停止组合模块、扩大时机网格和以极少错误判定研究路线。具体缺失证据、报价条件和硬件条件见 [后续登记](l07-remaining-work-v1.md)。
