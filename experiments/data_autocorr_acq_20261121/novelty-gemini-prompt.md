## 要查的想法（按逻辑描述）

设定：AFDM，N = 1024；ZC 导频叠加在数据上，导频功率比 ρ；LDPC 编码 QPSK；稀疏双色散信道，8 条径，整数时延 0–102，分数多普勒。现有接收机在第 0 轮把数据当噪声、只靠导频找径；ρ < .25 时崩塌，最好的工作点是 ρ = .30。

**核心一行**：数据白，所以接收信号的延迟乘积 E[r_n r*_{n−d}] 里只留下时延差恰好为 d 的径对，表现为频率 ν_i − ν_j、幅度 h_i h_j* 的单频。所以接收信号自己的"延迟–多普勒自相关"就带着信道的配对结构，未知数据本身就起了导频的作用。

**主张**：以最强径为锚，自相关能在第 0 轮找出导频漏掉的弱径。于是导频只需要定参考（绝对时延、绝对多普勒、整体相位、前后镜像），不需要负责找径，可用的导频比例因此可以降下来。

**我们已有的证据**（只到"看得见"这一层，见 `experiments/data_autocorr_acq_20261121/READOUT.md`）：真实设定下，ρ = .15 时自相关在公共虚警预算下捕获 94.8% 的有效弱径，补回导频匹配滤波漏掉的 91.9%；改成每条径带独立数据的对照只剩 4.2%。误帧率会不会改善还没有检验。
