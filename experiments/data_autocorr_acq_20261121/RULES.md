# 数据当导频：真实设定下的自相关捕获检验——判读规则（FROZEN 2026-11-21，Astra 审后、计算前）

来源：外部 AI 的候选（Eric 11-21 转来）。核心一行：数据白，所以 E[r_n r*_{n−d}] 只留下时延差为 d 的径对，是频率为 ν_i − ν_j 的单频，幅度 h_i h_j*。由此推出两个预言：检测信噪比约为 N g_s g_w/(1+σ²)²，与 ρ 无关；与导频通道的交叉点在 ρ ≈ .15–.2。
它的玩具结果是：ρ = .15 时自相关捕获 87.8%，导频匹配滤波 89.8%。但我们 11-20 在真实设定上的计算显示，导频匹配滤波受 ZC 旁瓣限制，和玩具里的结果矛盾。所以先在真实设定上复核。Eric 11-21 批准检验。

## 设定
- 真实 P1 生成器：`p1_driver.generate`，U 和 G 两个场景，TCRF 种子；帧 30000–30399，不跑接收机，只算统计量。5 dB；ρ ∈ {.02, .05, .10, .15, .20, .30, .50}。
- 时域：r = DAFT⁻¹(y)。这组 c1 下 2Nc1 和 c1N² 都是整数，chirp 周期前缀的相位为 1，所以按循环处理。
- 自相关臂：q_d[n] = r_n r*_{n−d}（循环），d = 1..102；对 n 做 4 倍补零 FFT，得到 |Q_d(f)|²，f 的步长为 1/4 bin，范围 |f| ≤ 6。
  - 以最强径 s 为参照。弱径 w 的"峰"取格 (|ℓ_w − ℓ_s|, ±(ν_w − ν_s)) 在 ±0.5 bin 内的最大值（d < 0 按镜像折到 d > 0）。
  - "无关格"指不在任何真径对 (i ≠ j, ℓ_i ≠ ℓ_j) 的 ±1 bin 内的格。
  - 判为捕获：峰 > 无关格的最大值。与最强径同时延的弱径记为未捕获（d = 0 不用）。
- 导频匹配滤波臂（同一个 y、同一判据）：用与 F0 前端相同的 515 列整数字典（单位范数）求 |u_cᴴ y|²。弱径的格为 (ℓ_w, round(ν_w))；无关格为时延不等于任何真时延的列；判为捕获：格值 > 无关格的最大值。
- 有效弱径：最强径以外、g_w ≥ 0.2 σ²_internal 的径。这个口径与 11-20 两次读数一致。

## Astra 审查后的改动（[astra-review.md](astra-review.md)，2026-11-21）
- 推导更正：数据对项的幅度按 (1 − ρ) 缩放，ZC 导频自身的延迟乘积在任意延迟都留下确定峰，循环截断让分数多普勒出现相位跳变。所以"检测信噪比与 ρ 无关"和交叉点的数值，在不建模导频项时都推不出来；本检验不检验它们。
- 改动 1（机制对照）：ρ = .15 时增加对照臂。导频、信道、噪声和每条径的数据功率都不变，但每条径各带一个独立的数据波形，于是跨径的数据单频在期望里消失，导频脊保留。
- 改动 2（公共虚警预算）：仍以真最强径为锚。不经过锚的真径对一律算作竞争者（相对于锚读，它们就是假候选）；每个分辨出的峰最多给一条径记功。两臂都按"高过它的不同竞争峰少于 8 个"（预算 = 8 = max_paths）判为捕获；竞争峰为局部极大，自相关臂的邻域为 ±1 延迟 × ±1 bin，导频臂为 ±1 时延 × ±1 多普勒列。原来"高过所有无关格"的严格判据只作描述。
- R1 判为 FAIL 时，R2 只描述、不判读。

## 预写判读（不改标签）
- **R1（玩具在真实设定下是否成立）**：ρ = .15 时，U、G 合并后自相关臂对有效弱径的捕获率 ≥ 70% → PASS；< 50% → FAIL（停）；其余 → INCONCLUSIVE。
- 以下 R1、R2 都用改动 2 的预算判据；区间为按 400 个帧号聚类的自助法（2,000 次）。
- **R2（是否补导频的短板）**：ρ = .15 时，在导频匹配滤波漏掉的有效弱径里，自相关臂能捕获的比例 ≥ 50% → COMPLEMENT；< 25% → NO；其余 → INCONCLUSIVE。
- **R3（是否归因于共享数据）**：自相关 − 对照 ≥ .30 且对照 < .30 → ATTRIBUTED；差 < .10 → NOT_ATTRIBUTED；其余 → INCONCLUSIVE。
- 只描述、不判读：两臂及"任一"随 ρ 的曲线；与最强径同时延的比例。
