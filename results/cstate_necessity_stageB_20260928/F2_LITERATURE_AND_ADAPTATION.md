# F2 primary-source reconciliation and adaptation gate

**Gate: published literal formulas fail; a faithful corrected specialization remains pending.** This is not a negative performance result or a proof that specialization is impossible. The located primary release is Luo et al., [arXiv:2607.18881v1](https://arxiv.org/abs/2607.18881), [HTML](https://arxiv.org/html/2607.18881) (2026-07-21). Its archived PDF has SHA-256 `8568724710e2a34ac41e18017b4f18f2d55626dbd20b25b1268bd77ada508e2c`; its LaTeX source tar has SHA-256 `f8b72ceac25eef234602d5ae985fbbec3f0959739af19ca1ef12637bc52986c4`. `main.tex` contains the algorithms and equations; the release contains no implementation or supplementary algorithm file. These are primary-source findings, not an inferred reconstruction.

Algorithm 1 (§III-A, `main.tex` 274–293) initializes unknown data to zero, estimates geometry from the pilot, forms an effective channel, performs **LMMSE data detection**, hard demodulation/remodulation, and feeds those symbols back until a relative-decision-change condition or `Tmax`. No LDPC APP or syndrome is part of this published loop. Algorithm 2 (§IV, 608–623) is full D-GESBL: exact complex-Gaussian posterior mean/covariance via an inverse, EM updates for row variance `δ` and equivalent-noise precision `β`, off-grid delay/Doppler updates, then grid shifts. Algorithm 3 (§V, 625–651) replaces the inverse with scalar GAMP mean/variance messages, while claiming the same EM/grid updates. Original experiments are **SIMO/MMV, N=256, 8 receive antennas**, fractional delay and Doppler, and sensing NMSE/BER; they are not the project's coded SISO N=1024 FER evidence (`main.tex` 711–747).

The project specialization would use `y = Φ(x)h+w` in the existing DAFT observation domain, with each physical column `Φ_j(x)=Channel.regressors(x)` for one integer delay and continuous Doppler. The `Channel` CPP phase and sign must be retained. SIMO/AoA collapse to one receive vector; the published fractional-delay component `ι` must be **removed explicitly** under the project integer-delay channel law, while fractional Doppler `κ` remains continuous. Distinct Doppler slots at one delay must remain separate through both TF rounds; `time_refine`'s unique-delay regrouping is forbidden. The published outer hard-data/LMMSE work, or any explicitly substituted TF/decoder feedback, would be charged before the final TF/LDPC backend. Early F2 cannot consume decoder APP before its scheduled creation; triggered F2 can consume only the saved native state then available. F2-EARLY, F2-TRIGGERED, F2E+LOCAL, and F2E+CSTATE are **proposed project policies**, not policies measured in the paper.

The literal practical algorithm contains reproducible algebraic inconsistencies, detailed in [the equation map](F2_EQUATION_TO_SOURCE_MAP.md): `δ` is defined as a variance but the printed GAMP input denoiser uses it as a precision; the complex input adjoint omits conjugation; and its output-variance expression is negative for the stated Gaussian output function. The Gaussian prior/likelihood and `Φᴴ` forward model determine corrections to those three without outcome tuning. Algorithm 3 **explicitly** takes a diagonal covariance approximation; substituting it into the published grid expressions is not an undefined missing step. The Taylor derivative labels for `κ` and `ι` are interchanged relative to their definitions, also resolvable by the declared coordinates. The remaining scientific choices are numerical `b,d,e,θ_s,θ_h,ε_g,ε_q,Imax,Qmax,Tmax`, initial `δ,β`, the complex support threshold/norm and a faithful support-to-TF interface (the current eight-slot interface must not silently replace the paper's support rule), and an explicit data-feedback/stop convention. These must be frozen from paper/source and observed-only engineering rationale **before** any real receiver comparison. No user-outcome tuning, silent correction, or real receiver run is justified before that freeze.

Full D-GESBL remains a mathematical reference for small synthetic validation. A corrected GAMP implementation must explicitly disclose the few algebraic repairs and its diagonal-covariance approximation, and then pass that reference check. The present gate authorizes only algebraic synthetic checks; no F2 receiver, decoder, acquisition replay, or new observation was executed by this work.
