## Architecture verdict

**A, but only for the retained channel actually entering each original native TF call.** The observed-only `pilot_front` initializer constructs a 515-column dictionary with five Dopplers per delay and may select multiple entries sharing a delay ([receiver.py](../../experiments/sp_afdm_frozen_20260920/src/receiver.py), lines 122–129). That *raw initializer* is not a distinct-delay model. In both native rounds, however, `native_twofft.receive` calls `time_refine` **before** `scalar_joint` (lines 18–24); `time_refine` forms `np.unique(ls)` and selects one strongest-gain Doppler center per delay (twofft.py, lines 82–89), then varies only those Dopplers (lines 100–109). Therefore the retained `Channel` passed into original TF has unique integer delays, so its physical operator Gram is exactly `R=I` under the source's AFDM/CPP operator convention (twofft.py, line 20). This proof does not cover pilot candidates, alternative receiver routes, or arbitrary `Channel` objects.

CSTATE starts from those native `r1` slots (run_observed.py, lines 188–199), keeps the slot count (lines 205–207), and scores replacements from a full delay×Doppler bank (geometry_validation.py, lines 101–108, 310–347). Its validity rule rejects only *same delay with Doppler separation below* `1e-6`, not all same-delay pairs (lines 90–98, 111–117, 182–185, 334–345); direct fallback uses the same bank/rule (lines 388–427). Local Doppler refinement likewise rejects only near-duplicate paths (lines 450–473). Thus CSTATE can create same-delay, different-Doppler retained channels with `R≠I`, but this is a possibility, not a claim that every reopened channel does so. **Even when pre-CSTATE `R=I`, nonuniform AF-domain marginal variances can leave cross-delay entries of the exact `Γ(V)` nonzero; `R=I` alone does not imply full `Γ(V)=Nv_x I`.**
