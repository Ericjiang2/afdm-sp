# F2: D-GAMP-GESBL adaptation notes

**Identity.** The exact method is Luo, Guan, Ge, Jiang, Meng, and González, “Data-aided Channel Estimation and Sensing With Sparse Bayesian Learning for AFDM-ISAC System,” arXiv:2607.18881v1 (2026-07-21), [author paper](https://arxiv.org/abs/2607.18881). D-GAMP-GESBL is the paper’s GAMP implementation of its **data-aided grid-evolution sparse Bayesian learning (D-GESBL)** receiver; it replaces expensive matrix-inverse posterior calculations with iterative GAMP messages while retaining grid evolution (Abstract; §§I, V). The local literature lookup found no exact D-GAMP-GESBL reference, so this identity is resolved from the primary paper, not inferred from the acronym.

**Published inputs and loop.** Algorithm 1 takes the received DAF-domain matrix `Y`, maximum normalized delay and Doppler, outer-iteration cap `Tmax`, and convergence tolerance. System construction also supplies the superimposed known pilot, AFDM operator/parameterization, and modulation. Algorithm 3 adds SBL/noise hyperparameters and inner/outer GAMP tolerances and caps (`b,d,e, εg, εq, Imax, Qmax`). The paper models effective noise as thermal noise plus residual data-decision error, with a learned equivalent variance. It initializes unknown data to zero: the first channel pass uses the pilot alone; subsequent passes use the pilot plus the previous pass’s **hard modulation decisions**, then remodulate/demodulate and repeat until decision-change tolerance or `Tmax` (paper §§II–III, Algorithms 1 and 3). It does not specify LDPC decoding or code APP feedback; substituting decoder APP is a project extension, not a faithful detail of the published loop.

**Geometry and model order.** The publication is an uplink AFDM-ISAC **SIMO** model: one-antenna UE, BS receive ULA, angle-of-arrival and a common row-sparse MMV channel. Its physical delay and Doppler both have integer and fractional components; it evolves nonuniform virtual delay-Doppler grids from off-grid estimates. Row-wise SBL variance hyperparameters `δ` induce sparsity; target extraction uses an amplitude threshold. The paper gives a theoretical active-component bound `R̄ = floor(N/log(Lτ Kν))` for its off-grid update, not a project-matched fixed eight-slot policy (§§II, III-B, IV-B; Algorithms 2–3). It is therefore not already the project’s integer-delay/fractional-Doppler SISO coded estimator.

**Required project adaptation (design only).** Use the frozen physical AFDM/CPP operator and sign convention; restrict delay to the project’s admissible integer values and retain continuous fractional Doppler within its registered bounds. Collapse the receive-array/MMV and AoA dimensions to SISO. Permit multiple distinct Dopplers at one delay if the physical slot budget allows; do not turn grid evolution into one center per delay. For a fair necessity comparator, cap active paths at the same `≤8` physical slots as the existing front end, with an observed-only sparsity/threshold rule fixed before comparison. Preserve posterior uncertainty and use an explicitly documented equivalent-noise update; do not import the paper’s dimensions or `R̄` as if it were the project cap.

**Information boundary and trigger policy.** A project adaptation may consume only the current observed `y`, registered pilot, known `σ²`, frozen operator/configuration, and decoder APP only on iterations where the protocol explicitly schedules and authorizes it. Never use truth or future observations. The paper’s **always-on** policy runs a pilot-only first pass and then repeatedly feeds back its current hard symbol estimates. A **syndrome-triggered** substitute would run only after the scheduled native decoder reports failure, would use only then-authorized APP (if any), and would retain the native result as fallback; trigger frequency and complete added latency must be counted separately. This trigger is a proposed project comparator, not a policy evaluated in the paper.
