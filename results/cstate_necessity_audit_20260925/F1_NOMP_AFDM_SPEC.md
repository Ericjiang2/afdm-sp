Status: **mathematical/interface specification frozen; implementation and runtime qualification remain pending, and Stage A is not ready to run.** Source anchor is project HEAD `cd0be005484e1c21fd148f686e08acfc30d567b7` on 2026-09-25. This is a hostile classical comparator, not a proposed method contribution. It consumes only the same observed `y`, AF-domain known `pilot`, and `sigma2` as F0. No initial decoder messages, truth, CSTATE score, or previous arm outcome may enter acquisition. The [original NOMP paper](https://arxiv.org/abs/1509.01942) motivates greedy continuum refinement; its sinusoid and CFAR formulas are **not** imported as AFDM equations or a justified stopping law here.

## Frozen physical response and search

Let `N=1024`, `t=0,...,N−1`, `z=IDAFT(y)`, and `a=IDAFT(pilot)` with the frozen `c1,c2` and `physical.daft(..., inverse=True)`. For delay `l` and continuous Doppler `ν`, the one-path **time-observation** response is

\[
b_{l,\nu}[t]=a[(t-l)\bmod N]C_l[t]e^{+j2\pi t\nu/N},\quad
C_l[t]=\begin{cases}e^{+j2\pi c_1(N^2+2N(t-l))},&t<l,\\1,&t\ge l.\end{cases}
\]

This is `TimePathOps.responses_time` / `physical.Channel.apply` under the source's positive-Doppler CPP convention; no independent time-domain QPSK prior is invented. The response norm `E=||b||²=||pilot||²` is independent of `l,ν` because shift, CPP, modulation, and DAFT are unitary. For a residual `r` and `λ=sigma2`, rank candidates by the normalized ridge-coordinate reduction

\[
U_l(\nu;r)=\frac{|b_{l,\nu}^{H}r|^2}{\sigma^2(E+\lambda)}.
\]

The factors `sigma2` and `E+λ` are common for the frozen pilot, so this has the same order as normalized matched-filter power. It is an **observed-pilot** score, not the later APP-conditioned CSTATE score. At each insertion choose the maximum valid bank item, with exact tie order `(delay, Doppler)` ascending. The bank is `l=0,...,102` and `ν=-3+j/4, j=0,...,24`: **103×25=2,575** points. The delay extent equals F0; the Doppler extent and quarter spacing equal the already registered CSTATE physical search, not F0's five integer atoms. F0's initial centers are `−2,...,2`, with first local windows reaching at most `[-2.75,2.75]`; F1's `[-3,3]` is explicitly broader. This breadth is a comparator advantage and must be reported, not called like-for-like search. Quarter spacing has an a priori isolated same-delay response guarantee: nearest grid error `|δ|≤1/8` gives normalized correlation squared at least `cos²(π(N−1)/(8N))≈0.854` for any nonnegative pilot-energy weights. That bound does not guarantee multipath detection or Newton convergence.

## Insertion, refinement, gains, and model order

Start at `r=z`, no paths. At each insertion, reject a candidate only if its delay matches a retained slot and `|ν−ν_slot|<1e−6` (the existing CSTATE exact-duplicate rule). Distinct same-delay Dopplers remain legal. Let the winning finite bank score imply `Δ=|bᴴr|²/(E+λ)`. If `Δ≤1e−12·max(1,||z||²)`, stop as a **numerical** no-improvement condition; no 2,575-way joint-refit sweep or second-best fallback is hidden in selection. Initialize the new gain by `bᴴr/(E+λ)`, then jointly minimize `||z−B h||²+λ||h||²` over **all** selected gains using a checked complex-Hermitian solve; `λ=sigma2` matches the original physical refit's ridge, while F0's earlier integer OMP gain LS remains a documented difference. Every bank score must be finite or the arm records numerical failure. Require `cond(BᴴB+λI)≤1e12`, finite gain/objective, and a relative linear-solve residual `≤1e−10`; failures are charged numerical failures, never silent ridge changes, path deletion, or success-path stops.

For each new path, optimize Doppler in the fixed bracket `[max(−3,ν_grid−0.75), min(3,ν_grid+0.75)]`, anchored to that path's original bank center. With other paths' latest gains held fixed, form `r_j=z−Σ_{k≠j}h_k b_k`; optimize `U_j(ν;r_j)` with its gain analytically eliminated. Use **four** safeguarded Newton steps: propose `−U′/U″` only for finite `U″<0`, clip to the bracket, and try step multipliers `1,1/2,1/4,1/8` in that order. Evaluate each bracket endpoint **once per coordinate visit**. Every Newton/backtrack/endpoint proposal that would make `|ν−ν_other|<1e−6` at the same delay is invalid, including proposals after cyclic moves; no hidden slot merging is allowed. Accept the highest valid proposal only if it improves `U` by more than `1e−12·max(1,U_old)`; otherwise retain the old coordinate. Its analytic one-coordinate gain is `g(ν)=b(ν)ᴴr_j/(E+λ)` before the joint refit. After every accepted coordinate, jointly refit gains and require the full regularized objective to be nonincreasing within `1e−10·max(1,old objective)`; failure is numerical, not an arm-specific fallback. After each insertion, make **two cyclic passes** over all retained paths in insertion order with the same coordinate rule and gain refit. No learned step size, truth-guided tolerance, or outcome-driven bank revision is permitted.

The structural budget is **at most eight physical slots**, matching the current receiver's maximum. F1 attempts eight insertions; it stops early only when the selected maximum valid `Δ` fails the declared numerical threshold or no valid bank item remains. A failed checked solve is a recorded numerical failure, **not** a successful stop. There is no statistical/CFAR stopping threshold: the unmodeled superimposed data make a thermal-noise-only null unjustified. Record actual `P_F0` and `P_F1`; F1 can use more slots than F0's delay grouping, so a C-versus-A gain cannot be attributed solely to preserving same-delay multiplicity. The low-level TF gain prior remains `CN(0,I/P_actual)`, with `P_actual` recorded per arm.

## Comparator-only TF handoff

Do **not** pass F1 through `twofft.time_refine` or `physical.fit`: both call `np.unique(ls)`, select one strongest Doppler per delay, and would silently erase F1's central distinction. A separate comparator-only `time_refine_keep_slots` must retain the ordered `≤8` `(delay,ν,gain)` slots in **both coded rounds**. At each call its slot brackets are anchored to the **current incoming Dopplers**, as in frozen `time_refine`, not to the initial F1 coarse bank centers. It must otherwise use the frozen `time_refine` working objective `BᴴB+Γ(v)+sigma2 I`, the same `mu,v`, and the same two bounded local passes (`±0.75`, `xatol=.002`, max 16 evaluations per slot). Its every local proposal must obey the same-delay `1e−6` separation rule or retain the old slot; no merge is allowed. `Γ(v)` must retain every same-delay and cross-path term; the same finite/conditioning checks above are required. This adapter must be separately qualified against the original `time_refine` on all-distinct-delay synthetic states and against direct physical responses on duplicate-delay states. Its cost is charged to F1.

Then call the **unchanged** `twofft.scalar_joint` (`20` iterations, damping `.3`, joint gain mode), unchanged LDPC messages (`±20` clip, maxiter `50`), and the same second-round APP/check update timing as `native_twofft.receive`. The F1 variant uses the same frozen scalar gain reaction even when same-delay paths make `R≠I`; it does not sneak in CGR or an exact block metric. For the D arm, the original CSTATE continuation may use the F1 second-round entering state only after a nonzero final syndrome; its structural valid rule already allows distinct same-delay Dopplers. Preserve the A/B frozen F0+TF/CSTATE code and observed inputs byte-for-byte. All adapter differences, source hashes, slot counts, numerical failures and complete times belong in the future registration.
