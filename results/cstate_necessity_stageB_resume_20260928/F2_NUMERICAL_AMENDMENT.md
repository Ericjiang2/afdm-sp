The original producer is retained byte-for-byte as `experiments/cstate_necessity_stageB_resume_20260928/f2_estimator_unscaled_v1.py` (SHA-256 `f86321834db43dc860e39f63143cdecd66c17c2af37f8bee1413daf40124a432`, original producer commit `110a5fd7f6e486a3f79aecbe444ed32f858b173e`). For the frozen real grid objective `f(κ)=κᵀQκ−2αᵀκ`, define `D_i=sqrt(Q_ii)>0` and `z=Dκ`. The solver sees `Q_z=D⁻¹QD⁻¹`, `α_z=D⁻¹α`, and each mapped box `[D_i lo_i,D_i hi_i]`; returned physical offsets are `κ=D⁻¹z`. This preserves the objective and feasible physical Doppler shifts. A nonpositive/nonfinite diagonal fails explicitly. L-BFGS-B remains `maxiter=100`, `ftol=1e−12`, `gtol=1e−8`; Rbar, Q/I/T limits, priors, grid selection, support, data feedback, and TF/LDPC stay fixed. This is a variable-norm change: `gtol` is applied to the transformed coordinates. Each successful grid step reports both original-coordinate and transformed-coordinate projected KKT residuals plus the actual solver termination message; `success` by relative objective reduction does not assert that either coordinate's `gtol` was met.

The single offline comparison on the captured QP, with the same objective/box and fixed solver options, reduced the quadratic condition number to 8.465 and returned `success` in 16 iterations, with original-coordinate projected-gradient infinity norm `1.14e−6`. The original run stopped at 100 iterations with norm `6.19e−4`. This isolated comparison supports the repair but does not qualify a complete receiver.
