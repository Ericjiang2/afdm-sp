# F2 project specialization and information boundary

**Status:** method constants frozen by [F2_METHOD_CONTRACT.md](F2_METHOD_CONTRACT.md) and [F2_NUMERICAL_AMENDMENT.md](F2_NUMERICAL_AMENDMENT.md); v2 one-frame probe is operational evidence only. Full-population reliability remains unmeasured. This is corrected Luo-style D-GAMP-GESBL for coded SISO SP-AFDM, not the author's SIMO sensing experiment or an exact implementation of unavailable code.

| Contract | Fixed project choice and boundary |
| --- | --- |
| Observation/physics | N1024, one antenna, same sealed `y,pilot,sigma2`, CPP `c1,c2`, `Channel.regressors`; integer delay 0…102 and continuous Doppler −3…3. No new observation, true path, coded truth, or decoder output in pilot acquisition. |
| Grid/model order | 103 delays × seven integer Doppler centers = 721 initial columns. Duplicate delay with distinct Doppler is legal. Evolution changes Doppler only, box ±.5 per update intersect physical range. Rank positive δ; stable grid-index tie; top `floor(1024/log(721))=155` for grid/communications output. No F0 regrouping, F1 8-slot cap or fractional-delay rounding. |
| Hyperparameters | `δ0=max(1e−12,N max(||y||²/N−σ²,σ²)/(M||p||²))`; `b=1e−6/δ0`, `d=1`, `e=1e−6σ²`, `β0=1/σ²`, `δfloor=max(1e−15,1e−12δ0)`. Posterior/EM, not truth, updates δ and β. These scales are autonomous choices absent from the paper. |
| Schedule | Qmax100 GAMP, Imax20 EM/grid, Tmax4 pilot/data; squared relative tolerances all 1e−6, first comparison after ≥2 passes, denominator floor 1e−30; damping on s/μ both .5. Each EM and final reconciliation resets inner `(μ,V,s)` to `(0,δ,0)` on its then-current Φ. Carry grid, δ, β across hard-data passes; report cap hits and actual iterations. |
| Grid numerics | Real expected-loss QP, L-BFGS-B 100 iterations, ftol1e−12/gtol1e−8 in diagonally transformed coordinates; transformed and original projected KKT both recorded. Failure is explicit, never a silent fallback. This does not retune Rbar, iteration caps or data feedback. |
| Data feedback | F2E first pass pilot-only, then charge full physical dense `H_eff`, LMMSE ridge `2σ²`, hard QPSK feedback up to three further passes. F2T only on original F0+TF nonzero syndrome: take **already charged** native APP hard symbols as first feedback, carry native check into **one** legal TF20/LDPC50 continuation; subsequent F2 data feedback is newly charged. No early APP is smuggled into F2E. |
| Downstream | Direct 155-path Channel, unchanged scalar TF20 and LDPC50. F2E has two coded rounds and its own trigger for optional matched LOCAL/CSTATE; F2T branch is one additional round after paid native work. Applying LOCAL/CSTATE to P155 requires separate interface qualification and must preserve geometry representation; the one-frame F2E probe did **not** qualify those branches. |
| Evidence/cost | All estimator matrix/posterior/grid/dense-H/LMMSE, TF, decoder, branch, checkpoints and serialization belong in the wrapper clock. A failed numerical step stops and is charged. Saved sealed observation identity and source hashes are mandatory. The 6.5-dB 1024 population is developmental, not fresh confirmation. |

The paper's support threshold for sensing is not used as a communications path cap. The selected 155 paths are a deliberate project interface; any subsequent overflow must fail qualification instead of truncating them. The existing [v2 f0000 probe](F2_PROBE_V2_OUTCOME.json) confirms only one F2E front end plus its two coded rounds at P155, with three EM caps and a data-pass cap reported; it neither validates F2T/LOCAL/CSTATE nor proves a population risk–cost ranking.
