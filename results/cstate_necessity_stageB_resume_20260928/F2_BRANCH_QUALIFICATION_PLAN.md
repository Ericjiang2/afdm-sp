Calls run in table order. The three caps sum to 1920 s; no retry, new observation, source edit, extra posterior/TF/decoder pass, truth access or fallback on I/O/schema error. A single preflight verifies both source inventories, observed population seal, prefix raw SHA/semantic input identity, code cache and exact source hashes. Before each continuation it fsyncs an attempt record. Each completed call saves its durable checkpoint, complete raw containing the final decision, and a ledger row with wall cost, syndrome (not truth) and file SHA. Failure evidence records the attempted index, elapsed cost and any ready checkpoints; return-path inventory can add MD5 without altering the qualification. On failure stop. If only the last, optional CSTATE call fails numerically or times out, the first two completed qualifications remain admissible in an explicitly sealed `partial_qualified` receipt; I/O/schema/programmer failures do not receive that status. The population manifest must omit `F2E_CSTATE` in that case. Near-duplicate P155 geometry must not be merged or truncated to fit CSTATE. The prior N1024/P155 **zero-edit/zero-local** synthetic entry check is narrower than these three calls.
