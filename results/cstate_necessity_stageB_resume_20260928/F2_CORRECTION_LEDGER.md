# F2 equation correction ledger

This is the **corrected project adaptation** of Luo et al., [arXiv:2607.18881v1](https://arxiv.org/abs/2607.18881), not a literal reproduction. The primary `main.tex` in the [source archive](../cstate_necessity_stageB_20260928/literature/2607.18881v1_source.tar) and the preexisting [method freeze](F2_METHOD_CONTRACT.md) govern this ledger. No outcome was used to choose an interpretation.

The paper's explicit `Σ=diag(mean V)` in Algorithm 3 is a declared approximation, **not** an unresolved correction. The original SIMO simulation and unavailable publisher/code material provide no authoritative numeric defaults for the project. Any future genuinely non-unique *equation* interpretation must stop that branch before a performance comparison; it must not be chosen by FER.
