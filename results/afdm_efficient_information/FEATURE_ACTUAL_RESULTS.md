# 实际先验教师的特征结果

实际 G0、共同 rounded delay=0 的 PDP-marginal 先验上，powers 的固定得分回归在本次独立测试集上优于 phase；phase 的较高输入特征线性信息 plug-in 没有转化为较好的四维输出。结果支持继续区分“特征含有信息”和“已训练模型能提取信息”，不支持宣称高维或低维得分压缩已保留大部分实际有效信息。

来源：`feature_actual_v1/`，源提交 `a3515da781acffe72e3fcee7a94f1973c08ff95e`。公开教师点为 `(delta,mu,logtau,logsigma²)=(.2,.35,0,0)`；1280 个连续潜变量独立采样观测，train/validation/test=512/256/512，全部特征共享数据。phase 主模型事先固定，未按测试结果改选 powers。

以上 SE 是保存的16批 MSE 变异估计，不是对不同方法差值的显著性检验。bootstrap 仅128次，信息 plug-in 还可能有高维有限样本偏差；不能除以教师 plug-in 后称认证保留率。圆对称族中 gauge 的理论充分性未使当前仿射回归得到好结果，也不能据此否定 gauge 本身的充分性。

数值教师采用 order24/phases48；与 order48/phases96 在全部1280行上比较，最大 log-density 误差 `5.1713e-10`、最大 score 分量误差 `2.7808e-9`，分别低于冻结门限 .001/.01。将导数步长从1e-4改为3e-5的最大 score 变化 `3.8463e-7`，低于门限 .001。1280/1280 行合格，测试集不合格0/512；未删失败行。order12/24/48积分质量误差分别 `6.6059e-7 / 4.8189e-10 / 1.9984e-15`。这些是已注册加密检查，仍不是解析精确性证书。

Gaussian 控制教师迁移固定使用 `feature_control_v1/model_1_phase.npz`（SHA-256 `8a6dca0e58fd62924387105da9c5ef688bc21c4d418390d65ee62af296e97fa0`）。来源基点 `(q,mu,tau,sigma²)=(0,.4,1.3,.7)`，在公开目标点仅乘固定坐标倍率 `(.4,1,1,1)`。四列对实际教师的测试 MSE 为 `(.800491,.917516,.745740,1.073889)`，均大于实际 phase 模型对应列。本比较同时改变先验、基点与 chirp，不能归因于单一失配，也不能称精确跨点 score transport。

完整 attempt wall 为 **34.177884 秒**，CPU 33.962199秒；进程累计峰值 RSS 1,609,433,088 bytes，不是独立 kernel 内存。教师 order12/24/48 分别1.123875/4.393459/21.051681秒，步长加密4.439504秒；特征计算.001524秒。已用组件压缩保存约113.66MB、2.512172秒，未新增积分节点或响应计算。这些类别均包含在 attempt wall 内，不能重复相加到总时长。
