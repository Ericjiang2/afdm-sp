# 已知 nuisance oracle 与候选歧义补充结果

补充对照揭示了两个不同问题：控制模型在已知 nuisance 和指定备择后获得较明显的检出增益；实际模型即使给予这些 oracle 信息，R=4 的经验检出率仍只有 **19/512=.037109**。因此，实际低功效不能仅归因于 nuisance 未知或复合检验取最不利阈值；近邻参数、有限R与有限校准下的辨别难度依然存在。本结果不足以否定局部正信息，也没有证明理想最优检验的功效上限很低。

另一方面，实际模型所有方法在全部保存评价组上均没有 exact 或64eps近argmin多解，但此前delta置信集合仍覆盖整个注册域。唯一数值最优点与可靠统计识别是不同要求；“没有tie”不是可辨识性或准确估计的证明。

## 理想NP上界与本次可计算参考

对固定真实null/alt密度，给定真实size alpha的Neyman–Pearson检验具有理论最优功效；在同一null满足该总体level的原部署检验也受这个理想上界约束。但本次使用原null样本的次序统计量校准，实际密度还是数值积分参考，故**经验oracle功效不是严格上界**，更不是对某个原方法经验计数的逐样本封顶。

冻结alpha=.05。控制m=64取第62个次序统计量，边际错误概率上界3/65；实际m=32取最大值，第32个次序统计量，上界1/33。这里的边际对独立校准数据与未来组一起取，不保证本次实现阈值的条件level。true nuisance和指定备择仅供明确标注的oracle；原模型、阈值、候选域、判决没有修改。
